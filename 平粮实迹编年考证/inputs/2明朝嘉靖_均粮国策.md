# 明朝嘉靖，均粮国策

公元1368年，朱元璋平定天下，改国号为“明”。

公元1370年，洪武三年，朱元璋下旨清查户口。

::: {.renwu}
说与户部官知道，如今天下太平了也，止是户口不明白哩。教中书省置下天下户口的勘合文簿户帖，你每户部家出榜，去教那有司官将他所管的应有百姓，都教入官附名字，写着他家人口多少，写得真，着与那百姓一个户帖，上用半印勘合，都取勘来了。我这大军如今不出征了，都教去各州县里下着绕地里去点户比勘合，比着的，便是好百姓，比不着的，便拏来做军。比到其间，有司官吏隐瞒了的，将那有司官吏处斩，百姓每自趓避了的，依律要了罪过，拏来做军。钦此。
:::

1381年，洪武十四年，下旨“攒造黄册”。

::: {.renwu}
洪武十四年诏，天下府州县编赋役黄册。以一百一十户为里。推丁多者、十人为长。余百户为十甲。甲凡十人。岁役里长一人、管摄一里之事。城中曰坊。近城曰厢。乡都曰里。凡十年一周。先后、则各以丁数多寡为次。每里编为一册。册首总为一图。鳏寡孤独不任役者、则带管于百一十户之外。而列于图后、名曰畸零。册成、一本进户部。布政司及府州县、各存一本。[^2_1]
:::

[^2_1]: 引自《大明会典卷之二十·户口二·黄册》

各州县按照要求的格式分派各乡都的里长丈量田地，清查户口，一一登记在册，各州县登记完成，汇总至府一级[^2_2]，各府再汇总到省一级（布政司），各省布政司再最终汇总到户部存档。户部存档一册封面为黄色，因此称为“黄册”。每年税粮收齐后还要造“实征册”，交给上级核对。

[^2_2]: 州县是否存留一册，待考。按《实迹》来看，“实征册”交到府衙才知道欠米，这样看来本县并不存黄册底稿。


1385年，洪武十七年，汤和奉命巡视海防，在浙江沿海先后设卫所城59处﹐使倭寇不得轻入。为了保证税粮供应，要求浙江当地清丈田亩，设立税则，大造黄册。无论建卫所还是造黄册，汤和在地方都是亲力亲为。也正是因为远离朝廷，使得汤和免于洪武后期朱元璋的猜忌而被诛杀。

::: {.renwu}
**汤和**（1326年－1395年），至正十二年（1352年）参加郭子兴起义军，授千户。在随朱元璋渡长江、占集庆、取镇江的诸战中屡破元军，累功升统军元帅。至正十七年（1357年），镇守常州，多次击败张士诚部。至正二十七年（1367年），为征南将军，在浙东击败方国珍部。尔后率部由海道入福州，俘获占据延平的陈友定。又随徐达率军征今山西、甘肃、宁夏等地。洪武十一年（1378年），封信国公。
:::

而对外防御（建卫所）和对内征粮（造黄册），可以说是历朝历代最为重要也是最直接的国家大事。前者保证不被打死，后者保证不被饿死。但中国历朝似乎都不是亡于此二者，而是亡于“病死”，即内部腐化。

明朝第二个皇帝不是朱元璋的儿子朱标，而是孙子朱允炆。年号“建文”。

1400年，建文二年，庚辰，在汤和定立税则15年后，浦江县想要重新修订税则。原本汤和订立的税则是依据田亩产量分别定税率（升/亩），产量低的税率第，产量高的税率高，但是亩产难以公平衡量，因此很多争议，也滋生了很多腐败问题，而建文年浦江县的改革是想统一税率，以田亩大小统一计税，避免争议。想法很好，计税很直观，但统一成多少合适呢？县衙一拍脑袋，那就平均值吧，于是政内乡就这么“被平均”了。对于国家而言，浦江县的税额保持稳定，看似平稳，但对政内乡而言，却是严重加税了。

于是当时有政内乡人毛伯玉因有族中之人在朝中做官，于是写信给“毛尚书”[^2_3]，陈述不合理之处。

[^2_3]: 未考证到建文年间有姓毛的尚书。


## 1400年，刘彦飞要改科均粮，毛伯玉写信毛尚书。

::: {.important}

邑民毛伯玉于建文庚辰年，因本县迪功郎刘彦[^2_4]飞受灵泉乡贿赂，要改七乡科则一例起米，伯玉以“赋役王册事”，致书毛尚书云。

[^2_4]: 《浦阳檀溪陈氏宗谱》乾隆丁未本中很多字跟现代简体字相同，如这里的“彦”，不写繁体的“彥”，还有“册”不写“冊”，“数”不写“數”，“盖”不写“蓋”，“粮”不写“糧”，“叠”不写“疊”，“卧”不写“臥”，“况”不写“況”，“野猪”不写“野豬”，“云”不写“雲”，“碍”不写“礙”，“郁”不写“鬱”，等。

毛尚书父母相公阁下：

“今以均管科则，吾等恨病切也，惊疾发也，敢摭所见干冒听闻。

昔大禹分九州，作贡九职之赋，须秩五爵，以明五服之义。夫人生有贤愚贵贱之分，而土产有高下肥硗之等。三代之时，计夫受亩，六国以后，编民易田，历代相因，至今尚尔。

且浦江山县为婺之支邑，其县有七乡，县之东南曰德政、通化、嘉兴、灵泉、感德，凡此五乡，田连阡陌，山岭低小，阳气多则五谷生成秀实孔蚤，所以时值惊蛰下秧，谷雨种田，苗稼丛生，勃然兴起，秋望之际，皆已收成，租税丰厚。县之西北曰政内、兴贤，凡此二乡，皆系崇山峻岭，僻坞深溪，其田之广，不过数十亩，穷源之处，难免野豕之耗，不可胜言。所以清明浸谷，谷雨下秧，芒种插苗，孟冬之稻，犹未收尽。因阴气多，山泉冷，株秧穗谷，岁以为常，即今可验，众所共闻。所以南乡倍收北乡之谷，以此七乡异科，尚古至今，有自来矣。

伏惟相公乃吾民之父母，均视其子，理固然矣。夫物不齐，田有肥硗，理亦宜然。相公未到平原旷野，与山谷绝异，今欲易科则，莫若遵上司明文，除零就勺为原则，吾民两无觖怨[^2_5]矣。伏惟相公少垂察焉。”

[^2_5]: 觖(jué)怨：不满与怨恨。

其书不报。

:::

查《浦江县志·卷七·官司志》乾隆己亥本，建文庚辰年，浦江县知县为程汝器，刘彦飞为当时的县丞。

关于毛伯玉，在不少文章中提到这个名字，应该不是一个平常人，但暂未找到详细生平资料。例如在《姑山毛氏宗谱》民国辛巳本中，有陈昌言写的序《重订姑山毛氏宗谱序》，其中说到“……而月山子思仁、笔峰子台，持其祖伯玉辑遗录《怡叟幽君集》来示余……”，清嘉庆年间陈志善所撰《毛氏重修宗谱序》中写到“……尚书公修于前，伯玉诸公修辑于后……”。陈舒平老师在文章《湃桥这个名称是怎么来的？》中对毛伯玉做了一些考证，包括《怡叟幽君集》里的诗《洪武己卯题崇因院壁》、《宣德戊申重建崇因院仍题旧额》、《南山十景》，其作者应该都是毛伯玉。

但这样一个既流传有文集又是家谱的主持修撰人，而且还是为民请命的勇士，却在家系中销声匿迹了。姑山毛氏在当时的浦江，不能说名门望族至少也是名甲一方的。据《姑山毛氏宗谱》记载，其第四世毛日严在南宋宝庆年间，捐资万金建造了浦江著名的席场桥，流传至今；其第七世毛洪是南宋时丞相，也是浦江历史上唯一一位丞相。如此一个大宗族的家谱对于有贡献的人物，其世系行传记录按理应该会有一定的传承性。

话说毛伯玉因为平粮写了这封信。但是，这封书信还未送出，朝中就发生了翻天覆地的变化。

1402年，建文四年，朱允炆叔叔、朱元璋第四子燕王朱棣攻下南京。建文帝随身边的翰林待诏郑洽等22人出逃。至浦江县郑洽府中，准备军械打算“起兵兴复”。但被族人举报至官府，官府搜查郑家，建文帝藏在一口井中躲过一劫，后来这口井就被称为“建文井”，一直流传至今。而郑氏族人为了与郑洽“划清界限”，而将其削出族谱。

::: {.renwu}

（20260810补）
传说，在下黄村，有个女人怀孕生子了，皇宫里的太师看星象算出是龙子诞生，于是派京兵来暗杀。同时朝里的“神仙”的也知道了这事，告诉女人一个逃难方法：“向前扔箸，向后扔碗”。拿一双筷子（浦江话“箸”）和一只碗，遇到河就往前扔筷子，就能架桥开路，遇到追兵就往后扔碗，会变成山阻碍追兵。同时“神仙”也派出将军来保护皇子，同时又派出大力士挑着石料来建金銮殿。但是女人把神仙告诉的方法记反了，变成“向后扔箸，向前扔碗”，而保护皇子的将军到了响山崖，马缰绳被崖壁上的藤蔓缠住，困在崖缝里出不来。最后皇子就被京兵追上杀了。将军知道这个消息后就自杀了，后人就在响山崖建了一个将军殿，而大力士知道皇子被杀后也撂下石头担子自杀了，石头矗立在苎陈山顶，长得像个柜子，村民称之为“石头小柜（浦江话念“巨”）。

而大畈人的传说是，被京兵追上杀害的不是皇子，而是陈氏祖先拿自己儿子替换下来了。真正的皇子后来繁衍了现在大畈陈氏一族。

:::

浦江待不下去，建文帝只好带领一干随从继续南逃，一直到福建福宁（今宁德），隐居“支提寺”中，而郑洽等一干随从也隐姓埋名，守护“龙主”。其中郑洽改名郑三合，其后代为郑岐村郑氏。2008年，在郑岐村附近的上金贝村后山发掘出一座古墓，经专家考证推测为建文帝陵寝[^2_6]。

[^2_6]: 资料来源：“宁德市明史研究会”微信公众号文章“‘龙隐宁川’建文帝朱允炆踪迹之谜”。

## 1512年，邹敏行清查田粮

::: {.important}

正德七年，本县知县邹敏行到任清查。每都选都长一人，保长十人，并书算弓手人等，沿坵履亩丈量，照依现今管业，填注业主姓名，造册。照旧科则，遵守永远。

::: 

田粮清查是个大工程，不是每年都会查的，查完田粮，就要“大造黄册”，按照规定黄册需要十年一造，从1512年到邹敏行清查到1552年韩叔阳清查，中间应该还有3次“大造黄册”，但《实迹》并未记录最近一次的清查，说明这三次仅仅是造黄册，而没有实际丈量清查。只要税粮总数足够上交，县里这些官吏也懒得下去逐一查对。


国家依据黄册来核对交税情况，而州县也是按照黄册来征缴税粮。黄册是以“户”为最小单位进行记录，记载每户所拥有的田地面积以及需要征收的税赋，但不说明税率情况，税率有州县自己决定，黄册只关心总额。而民众也只关心自己该缴的总额。关心税则的只有州县。

## 如何确定税率？

明朝时没有微积分，虽然有“书算手”，但“书算”能力仅仅是会计记账的加减乘除。对于田亩丈量，规则的长方形还好，遇到奇形怪状的田地，只能毛估。而不巧的是，“政内乡”所在的“山里”都是丘陵山地，“田无一亩平”，田地大都是奇形怪状的，这对于丈量清查工作带来了挑战。由此发明了“以米计亩”，就是用该田地的产量来计算“面积”，单位为“秤”，这一坵田能产1秤（15斤）谷，则管这坵田大小为1秤。这大大减轻了丈量者的计算工作，但同时也给“外乡”的灵泉乡及执行丈量清查的县吏提供了说词：产量不像面积那样固定不变，而是“年成”[^2_7]不同每年都不同，以哪年的产量为准？而“外乡”是以面积计算的，《实迹》中石文济状纸中就提到“……平原以土为田（亩），山乡以石为亩……”（第4.1节），说明两地田亩的计量方式并不相同。

[^2_7]: 浦江话称每年的收成情况为“年成”。

但税粮的征收不能依据田亩的面积，而是依据田亩的产能。有所产才能有所征，举个极端的例子，像沙漠那样的不毛之地，你去征个鬼税？因此“以米计亩”虽然不客观，但很符合征税的底层逻辑，因此千百年来一直沿用。

但是，这种“不客观”的计量方式，随着时间的推移，其误差会逐步累积。大家都想往自己有利的一方误差去靠。作为纳税户，尽量希望这坵田“秤”数越来越小，这样意味着可以少交税。碰到收成少的年份去理论：原来定10秤，你看实际收成只有8秤，这田只能定8秤。而州县的手段是税率，全县税粮总额不能变，大家都说田亩少了，那就税率普遍提高，反正都是均摊。比如某一年全县税粮总额少了一成（上浮10%），那就全县税率全部上浮10%左右。那具体每户摊多少？各乡粮长自己去计算。于是就出现“飞洒”了，跟粮长关系不好的，说“今年县里要加税率，你这里加二成”。不透明就造成了不公平。

大致逻辑就是这样，全国各地情况不一，出现“偷税漏税”的手段也各不相同，浦江县主要以“飞洒”为主。

因此，各地“有识之士”纷纷献计，要求统一税率，提高征税过程透明度，减少征税过程中产生的腐败与不公。这些“良策”只有口号没有实际细则，因此就又被另一拨人拿来作为新的腐败手段。


## 嘉靖年间

前面说的燕王朱棣后来成了“明成祖”，明成祖最大的两项工程，一是修《永乐大典》（1407年），二是迁都北京（1421年）。迁都北京后，防务重心也由南方转至北方，尤其是防御退居蒙古高原的蒙元残余势力。

1449年，正统十四年，明朝第6位皇帝明英宗在宦官王振的鼓动下亲征蒙古瓦剌部落，结果兵败被擒，即“土木堡之变”。

1550年，嘉靖二十九年。土木堡之变一百年之后的嘉靖朝，蒙古土默特部在首领俺答汗的带领下从蒙古一直打到北京城下，即“庚戌之变“。而南方沿海仍旧倭寇不断。

连年边境不安，军费开支剧增。嘉靖帝不得不考虑财政问题。

解决财政问题的手段无非“开源节流”，战争费用这个“流”不是想节就能节的，那就只有一条路：开源，增加国家税收。而普遍加税，容易引起民愤，从而导致内乱，这更不利于边防募兵，可能还要另外派兵镇压，更是增加军费。看起来是个死结。

于是严嵩出场了。

一般国家经济建设过程中都会伴随着贪官的出现。其实逻辑很简单，要搞建设要搞钱，就得先把办事的人喂饱了，否则谁会替你办事，尤其是办“钱”事。但是，作为贪官，你贪的钱只能自己花，不能传承，别想着荫子袭孙，因为这钱财本就不是属于你的。在家天下的皇权体系中，能传承万代的能且只能是皇权。

另一方面，有贪官的朝代必有清官。严嵩时期的榜样就是海瑞。巧合的是，嘉靖平粮事件发生时的浦江县令韩叔阳后来升任严州知府，严州下面有一个淳安县，当时的县令就是海瑞。但从另一个角度来看，清官也是“贪”官，只不过贪官贪的是钱财，而清官贪的是名声。

嘉靖帝研究的是道家思想，甚至后期表现出信奉道教。而道家讲“清心寡欲”，寡欲的后果是缺乏“上进心”，百姓能安心过日子，但在外敌入侵时无法抵御。一个国家想要立足，势必要发展，发展就要驱动力，而驱动人的最大动力就是贪欲。对内“寡欲”，对外“多欲”，这可能就是嘉靖帝的人格写照。

言归正传，贪官和清官并存，这就是嘉靖帝的“制衡手段”。干活贪污不要紧，但不要出格，不要引起民愤。一旦有民愤，就用清官弹劾，抄家没产。抄没的“非法所得”也是收归国家的。所以无论“养贪”还是“惩贪”，国家都不会吃亏，都是正收益。吃亏的只有百姓。

有人会问，谁会去做这个“冤大头”的贪官？可惜的是，任何时候都不缺“贪官”，在名和利的巨大诱惑面前，很少有人会去观察是否有陷阱。

再来看严嵩的经济措施。

普遍加税这种简单粗暴的方法显然是不可行，也是不符合“大贪官”的身份。

在核查过程中，发现了“财政赤字”发生的原因。国家预算时每年都有盈余，而到了年底结算，就发现实际收入比预算少，从而造成了入不敷出。而实际收入少的一大部分原因，就是税粮以各种借口产生“欠米”。比如这个省说今年我们这里发大水，粮食欠收，不仅没有税粮可能还需要国家拨款赈灾。另一个省说，我们这里因为税重，人口流失很大，很多户口逃亡了，他家的税也就没人交了。

这些都是客观问题。而其中反应最多的，就是“有田者无粮，有粮者无田”，很多大户有很多田地，但是按照各种减免条例不用或者低税率交税；而有交税指标的农户并没有可耕种的田地，自然也没有理由再交税。

就从这里下手：平粮！税粮按照田地实际产出来收税，谁种谁交税，不能转移到减免税户名下来逃税漏税。缴税依据什么标准：黄册。

这样就能保证预算收入能够如实完成，完不成的官员轻则不得升迁，重则追究责任。

总之告诉地方官员一句话，手段（政策）给你们了，税粮总数不能少。交不齐的有罚，把往年积欠都能交齐的有奖。

明实录中有不少关于这方面的上奏。

### 1531年，嘉靖十一年二月，刑科给事中徐俊民上疏
摘自《明实录·明世宗肃皇帝实录》，卷之一百三十五。

::: {.renwu}
〇刑科给事中徐俊民上疏请更定田赋，言：

"今圣明在上，锐意太平，而礼乐未兴，风俗未厚，则由田赋不均，而生养未遂故也。以今田赋言之：

有受地于官，岁供租税者，谓之官田；
有江水泛漫，沟塍湮没者，谓之坍江；
有流移亡绝，田弃粮存者，谓之事故。

官田贫民佃种，亩入租三斗，或五六斗，或石以上者有之；
坍江、事故二项虚粮，里甲包赔，或一二石，或数十石，或百余石者有之。

夫民田之价十倍官田，穷民既不能置，而官田粮重，每病取盈，益以坍江、事故虚粮，又苦摊纳。追呼敲扑，岁无宁时。而奸富猾胥，方且诡寄那移，并轻分重。此小民疾苦，闾阎凋瘁，所以日益而月增也。

臣请立为均粮限田之制：
将郡县田粮随各处原额通融均派，无论官民，合为一等；
坍江、事故，悉与蠲豁；
其旧熟新垦，一例起科。

就中分为三则：
膏腴为上，
沿山边海及居湖腹者为下，
肥硗半者为中。
上则全徵本色，
中则半折，
下则全折。

仍仿一夫百亩之意：
上富一夫无过千亩，
中富五百亩，
下富二百亩，
各听以百亩自给，
而其羡田每亩量加输边之税，亦以三则为差。
一夫适止百亩者，免其输边。
此外余夫，限以五十亩。
官宦加给圭田五十亩，
凡有羡田，一体加税。

如此，则多寡有节，轻重适宜，贫富相安，公私俱足，积贮充而边陲有备矣。"

### 1534年，嘉靖十三年九月，监察御史刘希龙陈言
摘自《明实录·明世宗肃皇帝实录》，卷之一百六十七。

::: {.renwu}
〇监察御史刘希龙以南京太庙灾陈言修省二事

禁纷更以安黎庶（禁止土地清丈扰民）

今田粮之制，诡寄、兼并、里书欺隐作毙，是诚有之。惟在官得其人，查革究正，使其奸弗得售可矣。何近来有司妄举丈地均粮之法，求媚上官以希保荐？然各官既不能履亩查丈，其势必委之里老、义民人等，那移增减，毙端百出，徒滋烦扰。此后务照旧额徵派，不许一概丈量生事扰民。

定分则以裕催徵（调整官员考核标准）

近例有司考满行取至京，钱粮不完者俱当送问驳回，致各官望风敲朴，以期免过幸迁。今行取考满官到部，查其任内所完钱粮不致大欠者，既免参驳，惟令及时催徵，而不临期苛责，庶傕科、抚字并行不悖。

### 1535年，嘉靖十四年十二月，河南巡抚简霄上言
摘自《明实录·明世宗肃皇帝实录》，卷之一百八十二。

::: {.renwu}
〇戊子，广东连州盗文兴隆等起，佥事吴玭、参将程鉴等剿平之。

先是，河南以田赋不均，请行丈量之法。既而民有来言不便者，而朝议亦以为纷更成法，无益于民。有诏："田赋悉从旧额，毋得轻变。"

至是，河南巡抚简霄言："日既丈量，则贫民有粮无地者得以免赔偿之苦，而富民有地无粮者无以遂欺隐之计。宜熟议其便：除未经丈量者照旧徵派外，其余丈量已定，悉从新制。中间若有富民增粮过多，屡行愬告者，委官查勘处豁；或将欺隐田地量为均派；或将减瞒等则量加增加；或将轻折钱粮量移抵补。务使贫富适均，不至偏累，庶于国法人情两便也。"

户部覆从其议，请通行天下抚按官："自但有诡寄兼并告发者，从公勘处，随事改正，不许一概丈量，致生劳扰。"诏从之。

### 1548年，嘉靖二十七年六月，南京给事中郑维诚、御史龚秉德等陈言
摘自《明实录·明世宗肃皇帝实录》，卷之三百三十七。

::: {.renwu}
〇户部议覆南京给事中郑维诚、御史龚秉德等奉诏陈言财用六事  

1. 复飞挽（恢复漕运实物纳税）

    国初开中盐粮，取助军饷。永乐初，每盐一引输粟五斗二升，后渐加为米三斗或五斗，又定为常股、存积之名。即荒城孤戍，一悬开中之令，而刍粟山积矣。自成化时改为折色，其弊始滋。夫折色之不如本色，利盖有四：可以省和籴之扰，可以杜侵冒之弊，可以慰待哺之望，可以开垦辟之工。而今之不能复本色者，弊亦有三：往者商自募民以佃塞下之田，得谷为易，今边田多污莱矣；往者塞下实而米价廉，今且倍之矣；往者无戎虏蹂躏之患，今岁苦虏矣，亦安所从得刍饷而应召乎？今宜平价减量，非本色勿收，使得倍蓰之利而怀乐趋之心，不责一时之效而图数世之利。其权势占中、经商掊克、官吏需求、额外劝借，悉与蠲汰。  

2. 广垦田

    沿边隙地数千余里，而以防虏不暇佃作。宜敕所司不论军民，广为召集，仍量给以牛具，使之尽缘南亩。度虏所入地，则深沟峻垒以防侵轶，设堡聚居以便守望。三年中能垦田十之三者，给以重赏。其内地如山东之沂、费、剡、滕，南都之和、頴、滁、寿，仿此。  

3. 清芦课（整顿芦洲赋税）

    江南沿江芦洲，上下千里，历十余郡，地不附于版图，力不假于垦治，豪家輙以十取利而一报课，官吏莫敢谁何。宜敕巡江御史按查，漏籍者官为计地给民，岁入其赋十之三，庶国课不亏，贫民亦得沾惠。  

4. 申钞议（重申宝钞政策）

    国初开局制钞，总利权于上而通实用于下，法严利溥。自钞法不行，而国家匪颁之用皆布诸京师，积钞之家展转收纳，烦不赀。宜改用折色，岁可增储积数十万。  

5. 时催徵（优化赋税催征）

    催徵之法，缓则纵奸，急则扰民。不如重府县之责而考其成，乃为无弊。迩者吏不久任，法不画一，故国课或侵牟于积猾，或龃龉于权门，日亏月削，玩视成风。宜申明祖制，久任府县官，任内粮不足者，不得给由选用。  

6. 稽实费（核查实际开支）

    往者修理琉璃河桥，初估谓须百万金，后仅用九万金耳。举此一端，余可例推。是故京营则费于老弱之影射，摆边则费于客兵之调集，在北则有河工之汗漫，在南则有广寇之绎骚。凡此诸费，皆茫无稽考，所当严核。  

上纳其言，命以次举行。钱钞收本色，原备朝廷不时之需，今既称不便，其量兼折色收之。
