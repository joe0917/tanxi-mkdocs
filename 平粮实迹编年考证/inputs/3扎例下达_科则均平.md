# 扎例下达，科则均平

## 1551年2月，韩叔阳丈量田亩

::: {.important}
至嘉靖三十年二月，本县知县韩叔阳仍行丈量，于本年七月内，要将新升补之多余官米，欲行均减，着众都长赴司具呈。
:::

韩叔阳（1512-1565），字进甫，别号凤桥。生于正德七年十二月二十六日，卒于嘉靖四十四年七月二十七日，享年五十三岁。

嘉靖九年（1530），师从吕泾野。

嘉靖二十六年（1547）中进士[^3_1]，位列三甲第243名。派至户部实习。

[^3_1]: 嘉靖二十六年（丁未科）进士榜号称“明清科举第一榜”，状元为后来的内阁首辅李春芳。榜上人物包括本文相关的韩叔阳（浦江知县）、汪道昆（义乌知县）、李一元（金华知府），其他名人还有隆万年间内阁首辅张居正，以文学家和史学家著称的时任刑部尚书王世贞，而该榜中还有一位浦江县人：张元谕。而张居正后来在万历年间推行“一条鞭法”的税赋改革，其实践基础可能正是基于嘉靖朝中后期众多“平粮”或成功或失败的案例。

嘉靖二十七年（1548）“以奉檄运饷有功”，被授金华府浦江知县。修《宋文宪公文集》。

嘉靖三十二年（1553）升户部主事，掌管田地、户籍、赋税等钱粮事宜。

嘉靖三十七年（1558）任严州知府。修《范文正公政府奏议》[^3_2]

[^3_2]: 修于嘉靖40年（1561），现美国加利福尼亚大学伯克利分校有藏本。

嘉靖四十年（1561）擢升为湖广按察使司副使。

以上主要整理自葛鹏云著《高淳出土明湖广按察司副使韩叔阳墓志考》和《明代高淳韩叔阳夫妇墓志考释》。

而按《浦江县志·卷七·官司志》乾隆己亥记载：

::: {.renwu}

韩叔阳，字泰升，号进甫，高淳人。进士，二十八年任。兴学造士。三十二年建宋潜溪祠，刻其全集，功在斯文。有去思碑，祀名宦。按薛应旗《建宋祠记》，“韩侯知邑之二年庚戌”，则是二十八年己酉任矣，又吴良悌《修宋集叙》，“二十九年邑令韩君”云云。旧志作“二十九年”误。

:::

按照前文邹敏行清查丈量的时间计算，韩叔阳提出丈量田亩正常时间应该是1552年。之所以要提前到1551年开始准备，是因为这不仅是难得一遇的体现政绩的大事，而且刚好1552年又是自己的“考满”[^3_3]年，提前丈量，尽量做到完美，给自己的三年考核提供足够的政绩素材，给自己前程搏得一个好的基础。

[^3_3]: 考满：是明代对官员任职期满的考核制度之一。通常任职满三年进行一次“考满”，也称为“任满”。

交税粮时间一般在八、九月份，七月份由县官吏率粮长进京领回“勘合”文册，粮长依据“勘合”进行征粮。二月发通知，要求七月底前完成摸底，这样后面就可以根据本年实际缴纳税粮情况而制定新的税则。

## 1551年11月10日，金朝兴等发起要清查田粮

::: {.important}
金华府浦江县一等都隅里老金朝兴等，告为清查田粮以革奸弊以苏民困事。

嘉靖三十年十一月初十日。

布政司批：仰金华府行该县勘处报缴。

分守金衢严道右参政钱批：仰府查行事理，从公勘议报缴。

分巡浙东道佥事寇批：仰府逐将其情公议报缴。
:::

金朝兴的告纸内容《实迹》没有记载。关注两个细节。一是金朝兴的抬头“一等都隅里老”，后面还有一个类似的名衔“一等都隅粮里老吴孟用”，关于里老粮老的等级，史料很少有记载。“一等都隅里老”是里老中的最高等级，属于德高望重者。另一个细节是提出“清查田粮”的不是县官，而是有威望的民众，这里的含义是：清查田粮是民意，不是县里要做。

另外，《实迹》中有很多“告为……事”，有些是现代意义上的“告状”，有些仅仅是“告诉”上级。区别就在于有没有“被告”，有具体“被告”并申明要惩罚“被告”的，就是“告状”，或者说是“诉状”。为便于描述，本文统一称“告为……事”为“告纸”，明确是告状的，则称为“诉状”。

金朝兴的这则告纸获得了各级批示同意。

## 造实征册发现欠米

::: {.important}
本县造册解赴司府会总造实征册，仍算又欠下官米一百余石，回县后堂查对，推选都长二十三人，乡书七人，调乡查对，在后堂查理二个月余。又遇上司札例行县“均粮均地”，及繁昌等县奏行“均则”等言，县主韩受贿，听信都长潘思容、周克昌弄权，要将政内乡与灵泉乡均为一则。
:::

清查完毕，发现官米欠100多石（总额欠300多石），虽然不多（欠米总额为税粮总额的3%左右），但欠米是影响政绩的大事，尤其还是在考满的关键期，马虎不得。正头痛如何应对，刚好上面有政策（札例）下来号召各地“均粮均地”，这样一来可以名正言顺重新洗牌重算税粮。

从逻辑上看，这段文字应该在上一段之前。汇总造“实征册”一般在缴纳“秋粮”（八九月份）的同时进行，被上司金华府查出总额欠缺，因此十一月份提出申请要清查田粮，一来争取回复上司的时间，二来也是找到“补交”的来源。

## 1552年4月17日，金华府转达上级的扎例政策

::: {.important}

札例

金华府，为建言民情等事。

嘉靖三十一年四月初三日。

奉浙江等处承宣布政使司分守金衢严道兼理黄册右参政钱札付。

承准户部照会。

浙江清吏司案呈，奉本部案，仰该本部题。

陕西清吏司案呈，奉本部送准礼部咨，该本部题。

嘉靖三十年月日不等，于礼科抄出广东等处广州等府顺德等县吏部等衙门办事官吏监生军民人等奏本七本，计事一十三件。

该本部会同各部、都察院、通政司、大理寺、六科议得：琐细及窒碍难行外，宜从户部等衙门勘处，禁革施行。

题奉圣旨“是，钦此钦遵”。

开单：

内一款，该陕西西安府同州郃阳县军籍冯臣，奏为乞恩均地均粮存恤贫难事。

又该县民杨林奏为陈情分额均地均粮存恤生民事。

嘉靖二十四年十一月。

又该河南怀庆府武陟县民阮佐，奏为乞恩均平利害以安生民事。

又直隶宁国府南林县军籍刘瓒等，奏为乞恩比例均粮革弊苏民事。

命下本部，移咨各省及南北直隶各该巡抚、都御史、节要，责委布政司并南北直隶该分守管粮廉政任事之官：

责委各州县素有才望能干正官，将县田粮逐一查勘，内除“各府田粮原清、民无异词，不便于均地者，不必一概丈量，致生骚扰”外，但有如前不均之处，富家有田无粮，贫民无田有粮，致累百姓抱赔逼勒逃窜，即吊取历年黄册、应查地粮文卷到官，督同各该有司掌印官较定官尺，提集各里排年、里老并年老知识人等。

先着令报出“某里原某地，地该若干，内有粮地若干，又有无粮地若干，自某处起至某处止”明白，各送鱼鳞格眼文册明白，即于地界上立定牌撅，明书“地主姓名某人数目”在上，然后委府佐贰并州县正官，如本处正官才不堪用者，另委别县别州干理，务要公同，各该里甲跟同，逐一沿坵履亩从公丈量。要见实有田地若干，比之原额有无增损，税粮有无添减。中间如有无粮田地，许即首出，并不征催先年收过子粒。量过地田之处，即立小石碣以防奸民那移之弊。

各里通完，然后总计该州县原额田地若干，税粮若干，肥田若干，瘠田若干，照依彼中田粮则例，令各原委及同该州县官，亲定田粮上中下等级，照亩均摊，不许转委州县佐贰官，以滋多弊。

如有隐匿、那移等项情弊，许诸人讦告，就将讦出地土给赏，仍追先年花粒，并将本地四邻及该里该甲户头人等通行连坐，从重问罪，改正施行。

大抵均地之法，是以有余补不足，惟在不失原额，不许分外加增，随时处宜，惟在得人而已。事完，通将丈量摊过地粮各数目分析明白，造册奏缴，青册送部查考，已后如遇大造黄册之年，将均过地粮造入各里各甲格眼图册内，以备查照。

其嘉靖十三年并二十四年，陕西郃阳县民杨林、河南武陟县民阮佐，各所奏情词报奉钦依“是”，并户部“知道事理，未敢擅便”等因，嘉靖三十年十二月十八日，该部尚书等具题。

本月二十日奉圣旨“是，钦此钦遵”等因，抄出到司，案呈到部，拟合奉行。为此除外，合行照会本司，着落当该官吏，照依本部题，奉都察院报浙江九十九号勘合札前事理，行本司备奉钦依内事理，并转行分守管粮等道，责委各府州县。

须至帖者。

嘉靖二十一年四月十七日。
:::

时任金华府知府的陈元珂是嘉靖二十六年（1547年）开始任职，到1553年是第二个考满年，因此在“大造黄册”上跟韩叔阳一样，也是尽力表现。他上呈的“建言民情等事”，《实迹》中没有记载详细内容，但可以推断应该也是关于“清查田粮”的，甚至可能直接抄了浦江县的告纸。

金衢严道兼理黄册右参政以札例作为“帖”批复。实际是一种司法建议，并非强制执行的行政命令。

最大问题就出在这份“札例”上，说是要均粮，但又不明说怎么“均”。是否是所有地方科则“均为一则”，大家使用统一的税率？那这个文件是户部发的，到底是全国统一？还是每个省统一？还是各府统一？还是说只要各县统一就行？按照札例“实施细则”来看，显然不是。

首先该札例的对象是“均地”而不是“均粮”。其总原则是：“以有余补不足，惟在不失原额，不许分外加增，随时处宜，惟在得人而已”。也就是说在保证税粮总额不变的前提下，找出那些“富家有田无粮，贫民无田有粮”者，有田的富户多交粮，无田的贫户少交或不交粮。

其次札例的目的是“清粮”而不是“平粮”。浦江县将其理解为平粮，姑且不论是否有各自私心。单单就解决问题的方法上就出现了偏离。“平粮”的起因是全县税粮少了300多石（其中官米100多石），韩叔阳也进行了“履亩丈量”，至少在数据上已经查出欠税粮的问题所在，虽然《实迹》中没有写明，但是既然去查找问题了，可能也找到问题了，那就针对问题解决问题。而按照灵泉乡的说法，这次欠米我们补足了，下次为了防止需要再“清查”，我们统一税率吧，刚好国家也是这么号召的。从应诉手段来说，这是完美的转移话题。由防止再欠，转为防止再查。而按照一些史料来看，欠米的根本原因实际跟清切田粮的目的是一样的，都是因为“飞洒”。

再者来说，灵泉乡为什么要推动“平粮”？当然一方面是迎合前面说的县里的欠米解决，为什么会欠米得有个说法。而另一方面，也是希望通过这次平粮的机会，减少本乡的税粮。但是这种方法是极不光彩的，也注定会招致纷争。因为整个县的税粮不变，自己乡的税粮少了，势必需要其他乡来负担。历史上也有很多“为民请命”的人，为本地百姓争取较低税率，最有名的估计就是在整个金华地区被人尊称为“胡爷爷”的胡则，他们的做法不是将本地百姓的税粮转移到其他地方，而是向上反馈，要求直接减税。

## 1552年4月29，浦江韩知县发告示通知全县要平粮

::: {.important}
浦江县知县韩为奉例均平科则事。

合给示仰该县人民知悉，即将本县七乡轻重科则并租寺米通融均为一则。

本年四月廿九日给。
:::

由后面双方告纸可知，平粮规则为税粮税率全县统一：每亩3.2升/亩。而之前的税率是灵泉乡4.4升/亩（水田），政内乡是1.9升/亩（水田）。

这里依据《嘉靖浦江县志》和《乾隆浦江县志》记录，整理并计算了当年各乡田亩及纳税情况，因为县志记载数据并不全面，因此部分数据只能进行推演计算，然后用推算结果核对实际情况。

前面提到嘉靖元年秋粮米13666石，而按照《实迹》1552年7月13日石文济的告纸中记录，当年“七乡额米”为13600多石[^3_5]，从嘉靖元年到嘉靖嘉靖三十一年，三十多年税粮保持不变，而且数额人人皆知。

[^3_5]: 傅本序文记载，康熙六年的税粮为16031.05985两。

按照这个数量（13666石），结合平粮后税率统一为3.2升/亩的标准，很容易推算出平粮后各乡的税额。平粮前的税额，因为水、平、高田各自亩数缺乏数据，因此各乡统一按照“水田”的税率标准进行计算。由此可以推算出各乡平粮前后的税额变化情况，如下表：

| 乡   | 平粮前   | 平粮后   | 增加量    | 增加比例 |
| :--- | --------: | --------: | ---------: | -------: |
| 德政 | 3162.24  | 2906.27  | -256.0    | -8.09%   |
| 通化 | 2405.96  | 2317.58  | -88.4     | -3.67%   |
| 嘉兴 | 2727.81  | 2811.44  | 83.6      | 3.07%    |
| 灵泉 | 1889.09  | 1533.62  | -355.5    | -18.82%  |
| 感德 | 1751.95  | 1567.05  | -184.9    | -10.55%  |
| 政内 | 980.68   | 1717.55  | 736.9     | 75.14%   |
| 兴贤 | 748.27   | 812.48   | 64.2      | 8.58%    |
| 总额 | 13666    | 13666    | 0         |          |

可以看出，政内乡增加额为736.9石，与《实迹》描述增加800多石基本吻合，而从增加比例来看，政内乡的加税程度比推算的还要严重，增加率已经超过100%。另外，政内乡增加的800多石增米，并非《实迹》中说的全部从灵泉乡减入的，灵泉乡减入了其中的一半左右。

至于清查出的欠米（总额300多石，官米100多石）到底欠在哪里，《实迹》没有记录，无从考证，也无法推算。单就平粮后的税粮增加额数据，就可以清楚地理解各乡对于平粮政策的态度了：灵泉乡最支持，政内乡最反对，其他乡观望。
