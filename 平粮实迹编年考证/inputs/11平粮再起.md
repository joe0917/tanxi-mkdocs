# 平粮再起

## 万历丙戌年（1586），黄克辉等平粮。

万历丙戌为万历十四年，本案结于万历十五年，有一本著名的书就叫《万历十五年》，书中称该年为明朝国运转折之年。《实迹》没有详述此案例，仅将判决结果列出。

其中两个词值得关注，“照米派征”和“照亩派征”。政内乡一贯是“照米派征”[^11_1]，而黄克辉主张“照亩派征”。前者征收基数为重量单位，而后者为面积单位。浦江县至今仍用重量单位“秤”计算田亩面积。一“秤”田表示这一坵（田亩的量词方言）田平均大概能产一秤谷（15斤）。

[^11_1]: 第4章石文济状纸中提到“平原以土为田，山乡以石为亩”。

:::{.important}

万历丙戌，灵泉乡总书舞弊，计将通县田粮一概照亩改派，以致我太祖陈九经控告各宪。今将节推老爷并分守道老爷朱、巡按老爷傅、恤刑老爷游金参附后。

该县灵泉、政内乡七乡，田土各自有肥硗不同，因土定则亦各自有轻重不等，节经多官勘审，据拟照米派征，历年成案具存，通邑民情永协，向遵行之无异议矣。

乃总书黄克辉倚恃衙门积恋，辄敢舞文为奸，计将通县田粮概为照亩改派，因而构通棍徒戴邦明等架空捏告，罔上行私，鼓动乡民哄然告扰，且阳假仗义执言之举，阴图科敛索诈之谋，此真治世之乱民也。若不重加究治，何以肃法纪而儆将来？

黄克辉引例拟遣，允快舆情。戴邦明姑坐诬徒，陈石虞词有添捏情非得已，姑杖未到。方叔敬捏词捏帮应另提结。

其概县七乡田粮俱从旧制照米派征。

取问，拟：黄克辉违制杖罪，引例充军；戴邦明诬告徒罪；陈石虞不应照出；方叔敬另为具招。

于万历十五年二月二十日解。

蒙带管分守道朱批：审得积书黄克辉变乱成规，主唆戴邦明捏词罔上，拟遣允当其辜。第本犯尚执以刻单为词，仰府再一鞠以服其心。缴。

行间本年三月内，蒙巡按老爷傅按临会审得：黄克辉以积书为奸，希图诓骗，串通戴邦明等告，欲更易成规，此等积恋若不速加重治，法纪安在耶？仰府三日内招解。

行间本年四月内，蒙恤刑老爷游按临会审得：丈量之祸流毒海内，正以狐鼠之辈因缘为奸，故其创愈深而其殃愈烈也。黄克辉乘机网利，紊乱成法，不痛惩之无以谢黔首。与戴邦明俱听该府画法究拟详行。

蒙府严：“提方叔敬，拘取黄克辉、戴邦明等一干人卷到官，细加严审，将虞士幸、倪戴周，楼志端等众，执万历十四年分本县一应钱粮由票，委系克辉赴道算派，弊改照亩发式本县”等情。

看得：该县七乡田土之肥硗、粮则之轻重原有差等。然于七乡之中，灵泉平阳称上壤，故亩阔而米则稍重；政内山乡称下壤，故亩狭而米则稍轻。此自国初以来至今，节经府县勘拟俱为照米派征，遵行日久，民且相安，世世不易之良规也。

而总书黄克辉敢倚积恋，舞文为奸，乃乘算派钱粮，辄以照米私改照亩，簧鼓人心，变乱成法，真为恶之首而罪之魁矣。夫由票虽奉粮署道颁发，算派钱粮数目皆出克辉之手，又安得以刻单而藉口也？拟例问遣，且有余辜。戴邦明、方叔敬乘机捏告纷然，拟例问徒，夫复何辞？

府主曾如春、节推徐万仞、县主俞祖善通融酌议：七乡田土各自以为轻重，科定十六则，乡额无亏，府县勒碑。
:::

## 康熙己巳年（1689），陈应祚等平粮。
此次事件中出现了一个人物引人注目：傅旭元。《实迹》描述为“县霸梼杌傅旭元”。梼杌是上古凶兽，用来形容顽固不化之人。

:::{.important}

大清康熙己巳年四月初十日，灵泉乡奸恶泼衿陈应祚等复图更乱成规，捏以吁宪广布覃恩等词耸控署任府主常，批县查覆。蒙县主赵青天着七乡酌议申详，计抄原词，并本乡呈词，又并县主详文于后。
:::

### 4月10日，陈应祚等请求平粮。

陈光发等请求金华府指示浦江县平粮。

:::{.important}

浦江县合邑士民陈光发、黄宗鲁、陈应祚、张芹等，呈为吁宪广布覃恩剔弊苏民以垂不朽事。

政简则民易从，绪繁则弊日积。念浦弹丸僻壤，田地山塘虽少，派征科则较多。官田有五，民田有八。民田每亩自三分五分以迄九分零，官田每亩自一钱二分三分以至二钱五分止。官田民田数几倍蓰，一应里甲差徭人丁杂派俱照正粮供应。凡管官田粮重者一至现年里长，苦累粉碎难堪，变卖无由，白送莫受，祸系钉骨，害深黑海。及推收大造之年，为弊尤甚。承管里保册科等役贿行欲肆，以官易民，以民作官。蚩蚩之民听其飞洒，无从查考。堂堂县令习于积弊，不暇觉察。狡兔获免，耿雉罹殃。总因事关国课，谁敢妄陈更议？

今幸遇圣主覃恩，谕著经管钱粮各司道详察有无，细阅有无应行更改增删，务期永久可行。而各宪随体通行下颁，诚为天地立心，为民物立命也。

现有永康县与浦同患，已经详请田地山塘官民扒平一则起科之文，蒙批在案。如浦亦得与永康并金兰等一视同仁，则士民易以输将，司令不难考成。且编审之期，督征册籍条贯不紊，送核览简易无扰。

伏乞宪天大老爷严行该县，务将田地山塘无分官民，只就四项悉归一则，究追通邑钱粮复还旧额，一体遵依，毋致捏覆转详各宪，上以布圣天子之宏恩，下以苏穷民之困苦。迫切连名上呈。

署府主常批：仰浦江县确查速报。

四月初十日准。
:::

### 政内乡连名抗议

浦江县收到金华府指示后，召集各乡征求意见。政内乡96人连名抗议。

:::{.important}

浦江县县主赵青天出示：着七乡酌议详覆。

计拟我乡呈覆词状于后。

政内乡合乡士民陈文耀、陈汝衡、虞彭年、朱德勉、石光庆、陈可有、周守龙、张士志、蒋光英、吴守儒、胡允文、陈心广、陈仲礼、周君宇、陈文魁、陈光行、陈之贵、虞国恩、朱德卿、胡汝亨、石端志、胡汝亮、陈楚瑜、石逢吉。

生员陈之炳、潘惟旦、石邦河、虞调元、陈元壁、陈元兆、虞邦汉、张用鼎、石邦淳、陈元联、陈作梅、陈之扬、何尔渊、张国翰、潘企臣、周复生、陈君辉、陈元会、石兴方、蒋升等共三十二人。

里递张惟祥、张惟清、张鼎卿、丁汝卿、赵文进、吕尚琼、黄一广、王一志、何惟良、罗元章等

共九十六人。

合同具词本县恳覆，呈为恳仍古制恩赐详覆惩究刁讼以安民生事。

切浦自唐建邑以来，随分七乡，不以一则科征，因田土之肥硗定粮额之轻重，其所由来久矣。宋、元、明历遵旧制。

洪武七年命信国公延坵履亩相土定额，随在宜民。

至嘉靖壬子，有灵泉乡土豪朱文经更改七乡科则，乡有廪生陈九经具疏奏闻，朝廷命下抚按转行司道，府主勘问，奸豪拟徒，旧制不易。

万历丙戌，复有灵泉乡总书黄克辉假京制全书为圣旨，夤谋照亩科征，经复奔控各宪，准敕府县酌议七乡田土各自以为重轻，科定一十六则，乡额无亏。户部铸铜版以定科例，府县勒碑石以垂不朽，诚万世不易之常法，百姓乐输之善政也。

即今圣天子御极以来，俯察民情，剔弊防奸，于康熙三年间颁行清丈田土，有则升科，无则汰除，并无更科改则之举。

其率由旧章，流风善政，自可媲美于唐虞矣。

忽今复出灵泉乡行险泼衿陈应祚、张芹等，势倚田连阡陌，贿通县霸梼杌傅旭元，仗饷衿为护符，希改成规，阳假仗义执言之举，阴图科敛索诈之谋，霹造合邑士民公呈，假借多则多弊名色，捏陈光发、黄宗鲁等鬼名，以吁宪广布覃恩等事耸诳府宪，送台查弊。

切灵泉乡平阳沃野，土厚租多；政内乡山高水冷，土薄租微，何堪概以一例取盈？设以一则科征，不分田土厚薄，奸豪得计，良善荼毒，山乡之民亦何乐耕于其野哉？今豪以官额病民为词，切官额七乡俱有管业授受之际，预先稽察里书册保，何得舞弊于其间哉？

总之，土有厚薄，粮分轻重，譬之温处之产不能比例于苏松，苏松之粮何能均加于温处？且古制彰彰于勘合，煌煌于县志，民情协而遵行久，一旦纷更多事，其如铜版碑石何？

奸书舞文已经重拟，豪衿鼓政岂容宽宥？隆遇青天仁政宜民，清廉首出浙省，神明佩服遐迩。恳恩赐详覆宪，仍遵古制，救民乐业，斩奸除害，甘棠不朽。

急切连名抄粘原疏上呈。

县主赵青天批语：经制科则原分地土厚薄，历代相沿，何敢纷更移易，变乱旧章？准着该房叙详申覆。
:::

### 5月6日，浦江县知县上呈金华府

浦江县知县收到政内乡连名抗议书后，上呈金华府。5月14日金华府回复：不同意平粮。

:::{.important}

赵县主老爷详文于五月初六日，前赴署金华府事，本府清军总捕厅加一级常案下呈，计抄详文于后。

合邑士民陈光发呈词等情，前赴署金华府事。本府清军总捕厅加一级常案下呈，准。

蒙批：仰浦江县确查速报等因到县。

蒙此遵，出示传集原呈士民查议叙详问，据：

政内乡士民陈文耀、陈汝衡、虞彭年、朱德勉、周君宇、吴守儒、周守龙、张士志、蒋光英、胡允文等六十四人。

生员陈之炳、潘惟旦、虞调元、石邦河、陈元璧、陈元兆等三十二人，里递张惟祥、张惟清、黄一广等九十六人。

呈为恳仍古制恩赐详覆惩究刁讼以安民生事。

查勘得：浦邑田土厚薄不同，附郭平阳其土膏厚，僻壤山谷其土瘠薄，照依田土之厚薄以定粮米之轻重，经制分晰各则，历代相沿。若遽为纷更移易，不分官民一例均输，不惟变乱成规，奸顽得计，而粮重者既以减轻为得计，则粮轻者必加重为苦难。如此则使之争讼纷纭，将必致逃亡见告矣。

今据士民陈文耀等具呈前来，卑职核详情由，理明词正，而先朝奸民更改告讦之案有陈氏谱牒可稽，应遵旧例不便纷更。今奉批查理，合详覆为此具文，申伏候宪裁定夺。

康熙廿八年（1689年）五月十四日，蒙署金华府事，本府清军总捕厅加一级常青天老爷金批：永邑有扒平之详，致浦民亦欲效行。据详，粮之轻重随田之厚薄，诚不易之公论，亦当时编审之无私也。如详。仍遵旧行。此缴。
:::

万历年和康熙年的平粮事件，仅列原文，未对详细过程及相关人物进行考证。

从明朝的嘉靖、万历到清朝的康熙，始终都无法完全平息平粮的念头。“有人的地方就有江湖”，有（钱）粮就有纷争。最终税粮问题的解决，不是靠制度的完善，而是靠工业经济的发展。2006年，中国全面取消了农业税，从此再也没有税粮纷争。
