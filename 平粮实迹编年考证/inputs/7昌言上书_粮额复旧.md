# 昌言上书，粮额复旧

## 1553年2月7日，义乌县丞踏勘造册完成

义乌县县丞周友[^7_1]刚过完年就马不停蹄地赶往浦江。从正月18日接手浦江“踏勘造册”，到2月7日“申关”，满打满算也就20天。走访了浦江地界不少犄角旮旯的地方。

[^7_1]: 按《义乌县志·卷九官师志》（康熙壬申）p122记载：周友，四川汉州人，监生，（嘉靖）三十四年任。当时的义乌县令正是前面提到的汪道昆。


:::{.important}

金华府义乌县县丞周，申关：

奉本府帖文，备蒙巡按浙江监察御史林批，承前事委官，卑职协同浦江县县丞主簿从公蹈勘查议，要见政内、灵泉二乡与各乡田土有无平阳山谷肥瘠异同，原额规则是否与民利便，韩知县所议均科应否允当，明白取具，归一由结，并原提未到卷犯拘齐解府，以凭“覆审施行”、“承委官员务要秉公持正，勿拘成案，区处宜民，克终厥事，毋得偏徇不便”等因到职。

切照知县韩叔阳初审之时，“已将有丁粮之甲首顶替无人田之里长，均年均图造为草册，差吏魏拱辰解赴钦差粮储参政老爷史处查验明白发回本县誊写正册外，将所均年均图分为十段，又造十段册以便所编均徭造完解赴分守道参政钱处查验明白发回本县贮库。前项十段等册似与勘合相符，伊县并无“有粮无田、有田无粮”之民，民甚称便。

后因本官欲以山溪平阳田地不论肥瘠高下通欲均为一则，每亩科米三升二合，如政内乡山溪之田原额七百石，今欲加至一千五百石，准免半里差徭，未为不善。但民多喜轻畏重习故安常，以致告争势所不免。”

今蒙行委，卑职于本年正月十八日离任前往浦江县，协同县丞张寅、主簿杨楫亲诣二乡踏勘。

勘得政内乡自二十四都至二十七都俱高山峻岭，草木繁茂，其间虽有夹溪平阳田地不过十分之一。

及勘灵泉乡自十七都至十九都田地虽颇肥瘠亦有五分之一居山溪之内。

再照政内乡如前何岭、毛桃石、东湾口、和尚坪、唐公岭、大姑寺等处，多叠石夹溪之田，果山高水冷，肥瘠相半，故定税之初稍轻于六乡，免其差徭半里，尚且每年输纳各项钱粮，直待货卖柴木禽兽方行完纳，迟违多致贻累官吏。灵泉乡共三都俱平阳一都居山曲高下田地颇有肥饶，故征粮独加于六乡。据二乡山谷平阳田地因有肥瘠不同，故粮有轻重之异。概以七乡论之，田粮轻重大率不甚相远，惟灵泉乡原额颇重，政内乡原额果轻。

今委卑职等议欲挈规均平，合以政内乡原免半里全里不免，以益其轻，灵泉乡原额粮重减其差徭二分之一，以裒其重。前项粮额照依旧制以绝争端，永为定规，庶几二乡之民允服，免致告扰之繁。

原系院道批拟均粮重务，职等位卑职小未敢擅便，理合具由关申前事，烦为申缴施行。

须至关者。

嘉靖三十二年二月初七日。

县丞周申府详夺。
:::

最终周友上报金华府的建议是：税则还是保持原来，之前平粮时说要减免一半政内乡徭役，该减免也取消。政内乡保持与之前一样。而灵泉乡也保持原来税则，但是考虑原来税则较重，因此减免三分之一的徭役。看起来这样的建议照顾到了诉讼双方的诉求，但新的问题来了，其他都没变就减免了灵泉乡的三分之一徭役，那减免部分由谁来承担？

之前政策：

| 乡       | 税粮变化    | 徭役变化    | 备注       |
| ------- | --------- | --------- | --------- |
| 政内乡     | 增加  | 减半        | 与旧则相比 |
| 灵泉乡     | 减少  | 不变        | 与旧则相比 |

现在政策：

| 乡       | 税粮变化    | 徭役变化    | 备注       |
| ------- | --------- | ------------- | --------- |
| 政内乡     | 不变  | 不变        | 与旧则相比 |
| 灵泉乡     | 不变  | 减少三分之一 | 与旧则相比 |

收到义乌县丞周友的申关，负责黄册的右参议要求浦江县“县丞吏书”（县令暂缺）赶紧补造黄册。

## 1553年2月15日，浦江主簿杨楫申请重新造黄册

:::{.important}

本县主簿杨，申为督造黄册事。

蒙本府牌差催前事，该蒙右参议顾钧牌“仰县官吏速将京司黄册差县丞吏书解府”等因。

今蒙催解紧急，或照依原发草册清写，伏惟听候呈详科则克日造报，本县未敢擅便，诚恐久违，理合备由申详。为此县司合行具申照详示下施行。

右申金华府。

嘉靖三十二年二月十五日，

主簿杨楫申。

署金华府事，推官郭批：黄册且照草册造完，总有可改候下次再造亦未为害也。况钦限已违又岂可违误如此也。限五日内作速完报。
:::

主簿杨楫请示是否按照“原发草册清写”。金华府推官回复：就按草册赶紧造完，要改等下次再改。

税则已定（保持原样），那就开始继续造黄册。从后文可以看出这时按照原来规则造完的黄册，后来顺利交付南京户部。

## 1553年4月29日，陈贵等申请放人

:::{.important}

告状人陈贵等四十五人，告为乞赐亲勘超冤事。

情为陈贤四十七、石光明等久狱未疏，黄册粮米恩蒙照旧造解，民冤未经超拔，为此连名上告府主洪公谐。

嘉靖三十二年四月廿九日，准行。

批发东阳县知县吴输词、永康县知县杜廉会勘明白，具由申府，以凭覆审详施行。

嘉靖三十二年五月初四日帖。

:::

政内乡人觉得既然黄册都“照旧造解”，说明政内乡是胜诉了，理应放回被羁押人员。于是陈贵等四十五人连名上告金华府，此时知府陈元珂已经升任宁绍兵备道。新任知府为洪公谐。洪知府安排邻县东阳和永康两个知县“会勘”。

从1552年底韩叔阳被判“还乡”到现在（1554年4月），浦江县属于没有知县的管理真空期。从后面朱八四的奏折来看，黄册虽然按照原来税则，但是本年的实际税粮还是被本地吏员做了“飞洒”，政内乡的税粮比往年多了400多石。而作为临时调任的两个邻县知县，想查明情况，也被“拦嘱”。当然这时候还没有到交粮的时候，政内乡人还未发觉。

## 1553年5月8日，陈昌言上书知府洪公谐

陈昌言写了一封长信随陈贵等的诉状一同呈给知金华知府洪公谐。

**陈昌言**（1521-1578），字希禹，号龙桥。政内乡26都会龙桥人，时年32岁。

按《浦阳檀溪陈氏宗谱》行传记载：

:::{.renwu}

贤百五十一，讳昌言，字希禹，号龙桥。会龙，魁廿八幼子。邑増广生。按行状云，公胸储珠玑，笔驱风雨，奈罗（罹）改科之害遂阻上进之心。恬澹寡约，安贫乐道。著《贫愚集》以自娱，至以女聘脱亲兄之缧绁，尤足以征天性之厚，非夫人所易能者矣。

正德辛巳六月初六日生，万历戊寅六月廿八日卒。

娶毛氏，嘉靖甲申八月廿八日生，万历戊申正月十一日卒。享寿八十五岁。合葬前山坪。

生二子九街（举社学生），九衡，三女，长适后张庠生张元种（中），次适市西庠生项元守，三适前于。

:::

而按“会龙贤百五十一公行状”记载：

:::{.renwu}

府君讳昌言，字希禹，号龙桥，邑庠增广生也。胸贮珠玑，笔驱风雨，顷刻成文，追倚马之高才；须臾诗就，蹑七步之后尘。奈罹改科之害，遂阻上进之心。恬澹寡约，安贫乐道，著《贫愚集》以自娱。乃以女聘释亲兄缧绁之累，而手足之义敦矣；奉岳父尽膳养葬祭之礼，而夫妇之伦笃矣。名高望重，车马敦迎，如市良有以也。

享年五十有九，曷胜孔明五丈原之悲。淑配毛氏，静德幽闲，享寿八十五岁。其殆不足于府君者，取偿于安人也乎？生二子：九街、九衡。长字子正，博学善文，工于楷书，中弃书业而归事双亲，开义塾以训弟姪，例授本邑社学生，奉养寡母，友爱昆弟，纂修家乘而光先德；次字子平，亦善诗文，雅有父风。兄弟隆孝养而敦友于，通族之所景仰也。以次子一信字德重继兄为后，亦长厚能文，割股疗伯，可谓一门孝友，翰墨余香，引之弗替者矣。

后学敏因状龙桥府君而波及之，然三世隐德，固非拙笔所能绘也。

天启七年丁卯冬月

增广生 姪孙克敏谨志
:::

:::{.important}

金华府浦江县儒学治下增广生员陈昌言，系政内乡二十六都一图民籍，谨薰沐顿首百拜肃书进呈。

即师相大柱国太祖父母老大人先生台下：

书为恳乞恩庇广开言路以恤民瘼以救生灵事。

念言不幸生居山谷，忝蒙作养自守颇坚，日诵圣贤之书，时凛卧碑之训，每期致知允踏，以求无负圣谕古人教戒也。并不敢轻于干谒[^7_2]以自丧所守，但有关于一乡之利病，在山民既限于不能言，在案词又病于不能详，在言又谨守夫惟生员不讦之戒，是以下情终无由以上达，而民力之殚、民膏之竭、乱心之起，职此故矣。言今事干切身，甘冒罪实敢昧死为大人言之，伏乞广开包荒虚心体物宥罪采纳，则大人再与山民造命，而言之所学为无负矣。

[^7_2]: 干谒：指自荐，跑关系。

切念浦江地有山谷平阳，肥瘠高下向背寒暖之别也。故《禹贡》曰“田有三等，赋有九则”，《诗》曰“相其阴阳，观其流泉”。是以我太祖高皇帝龙飞淮甸，迅扫腥膻，肇造寰宇，委改定则，靡不竭尽心思劳费谋画。

因浦江土有七乡之异而定为七则，良有以也。去年韩父母欲将通县均为一则以革欺隐之弊，甚盛心也。但五乡之米俱得如故，均得固可，不均亦可，是以缄默不言。独政内乡之山田，旧额米不过七百余石，而新加之米反倍加一千五百余石，至于灵泉乡之米减去六百余石，是山民代灵泉人纳税当差，而彼享安逸之利也。此政内乡独于灵泉抵牾，而迄今事之未成也。

近承上司明文“已照旧造册解京司矣，府县册已造完矣。夫何今日又有平米之事乎？”其费过纸张劳尽民力不暇殚述。言且备以政内之不如灵泉者先敬陈之，而后及于平米之利害，试垂听焉。

彼七乡之米政内惟轻而灵泉稍重者，岂圣祖委官定则之初厚薄于其间哉？由政内之害有十而灵泉之损无一故也。

是故夹山兜水叠石为田而广平坦夷者，不灵泉也；山高水冷五谷不结而暖气长苗者，不灵泉也；鸟鼠交侵野猪猿食而日夜不守者，不灵泉也；流沙淤塞草木荫蔽而避水开阳者，不灵泉也。

狼虎伤噬则鸣金持械以驱逐，其能若灵泉之清静安逸乎？水田一亩则收获止有二石，其能若灵泉之高田而反倍得者乎？山谷壳厚则舂米以折其半，其能若灵泉之斗谷而米有八升者乎？

吾见灵泉塘池广阔而山间之坑水易涸车戽[^7_3]无望者信不如矣，灵泉土厚水深而山间之沙田疏漏即注即干者信不如矣，灵泉平易便利而山间之竣岭重越商人少至者信不如矣。

[^7_3]: 戽：音hu，汲水灌田。

且山间之民生于山而不能食于山也，以岁岁仰给于灵泉者十分有九，搬运之劳则险越重岭，洗锅待粮家有饥色，即遇小旱则山间男女为灵泉之奴仆者不知其几也，衣服器皿之当没于灵泉者不知其几也。

小民无资当典则惟采草根剥树皮以救残喘，张目待哺终日不得一食者有之，二日始得一食者亦有之，民皆菜色而饿殍相继，此言之目击心痛者也。使有家国之责者闻之不能不怆然而悯矣。

言生长于此，习知民痛，并未见山间挑谷出灵泉济贫者也。况灵泉之乡泉甜土肥民殷家富，栚木之植一望无际，田豆荞麦之得广种兼收，夏豆木棉之利多栽并蓄，在山间之民非安于逸而不种也，但山气凝寒霜露先坠，虽种而无收也。昔人有悯农之诗云：“二月卖新丝，五月糶新谷；医得眼前疮，剜却心头肉[^7_4]，则此言之亲切有味无甚于山间之民矣。

[^7_4]: 出自唐代诗人聂夷中的《咏田家》。

盖山间取灵泉之当并偿灵泉之债，不能尽皆银谷，是故或以苦楮[^7_5]、或以山栗、或以靛青之类悉输积谷之家，如一次失信则荒年生路无望矣。是山间之所产，于灵泉而尽有也，彼以一谷之多而易我所尽有，其情亦可痛也。

[^7_5]: 苦楮：即苦槠，也叫苦栗。

及至秋风乍起，山内先寒，腊月之夜则烧柴火以待天明者，吾见亦多，盖草荐以代被者，吾见亦多也。

夫以灵泉之利既如彼，而政内之害又如此，而犹又为均米之说者，夫岂无所据见也哉？盖其计有三，而言之易入者有五。

曰遵奉勘合也，曰均米者爱民一体之心也，曰均得成韩父母永血食于浦邑也，此其计之善者也。

言也虽处山谷亦尝与闻勘合之行，为“有地者无粮，有粮者无地”，为“均地均粮”，非以概均天下之科则也，其中有云：“如有不便于民者，不必一橛骚扰”，是盖圣天子惠养元元之盛心，固欲为之，司牧者以善法其意也。

况七乡之额行之已久，吏习民安，在今日顺而治之可也，行其所无事可也。设使可均则，定额之初固非无人而奚待于今日耶？必欲均之，则山民愚蠢难化，教之则难兴礼义，激之则易与为乱，亦风声气习然也。倘或变生肘腋，则政内必与灵泉相攻，他日养成乱陷阶，则于韩父母之盛名有玷，而于大人之心力亦劳矣。如之何使爱民之心反为变民之举，而血食之念变成召乱之媒乎？

何以谓其言之易入者有五？曰：山民之稠过往昔也，土地之辟过往昔也，山内有杉木生漆之财也，苎麻桐油之利也，山禽麂皮之得也。

要之杉木之植固可得利，然而万亩荒山之中种得一亩已是有力人家矣。虽不种亦输税者不知几万顷也。自其成材得利而言之，则杉木求用于三十年之后，苎麻油漆之类求用于六七年之后，自此以前固不能年年而得利也。便是麂皮之得，出于游手好闲之徒，然十人共逐一麂，大者不过值银三钱足矣，使十人均分，不知可以偿十人之工食否乎？况终日得一兔者有之，终日上下山林而不一得者亦有之。盖民之气力只有此数，不在此则在彼。无田可种，故种山以度日，逐麂以求食，亦大不得已之计也。虽是山民之众不比往昔，然生一人则册增一口而宣力于国家矣。

言以为人固可增第，恐封域有限，而世界不可扩也。以有限之田，而供此生生不不已之人，尚虑其田亩之少，而无土营生也。

大人不察而信易入之言，窃谓大人民情土俗未能易知也。今蒙选委贤能均为上中下三则，言恐虽不比初时倍加之重，然于政内未必不加，于灵泉未必不减也。相沿陋习，时难顿革，民心思乱，又乘时起矣。是于国家无益，于灵泉有利，于山民有害也。

况政内之米照旧当差尚且十室九空，至于粮长一当则又室如悬磬矣。故人之报私恨者惟愿其当粮长以破家，若是者夫岂民之顽梗而粮之难收哉？亦以一年之所收不足以供一年之所费，而钱粮之难办如此也，以故情愿卖田以避此役。在灵泉之人则又百计以谋粮长之当矣。果如额外加米，则灵泉之富者益富，而山民之贫者愈贫也。斯民乌得而不至于弄兵耶？是非好讼而好兵也，忧其里长徭役之难当，粮税之难办也。数年之后，官有督责之威，吏有催迫之苦，虽有好田贱卖于人而亦无人来买矣，终至于卖妻子以完官以及逃亡之祸者，此必然之势也。

大人绎而思之，无怪山民之忧惶无措而至于乱也。设将政内之米减入灵泉，则灵泉人又与政内相争矣。恶民之名不在政内而在灵泉也。

言虽不通时务，常读宋史，恒以为靖康之祸不在徽钦北狩之时，而在王安石见用之日。自今言之，安石新法之行本欲强国而非欲误国也，但其所学之偏执议之坚，恐人阻格，则以异同为用舍，故引结凶邪牢不可破，而国随以亡，千载之下尤为之太息也。大人廊庙宠才，赞襄效职，肯使安石覆辙复蹈于今日乎？

古人谓“处江湖之远则忧其君，居庙堂之上则忧其民”。伏乞大人以忧君之心先于忧民，绝口不言均米之事，赐山民以更生之路，则洪恩之旁及，祝颂之浃洽[^7_6]，合远近而无间矣。

[^7_6]: 浃洽：音jiā qià，融洽，亲近。

必不得已，请于通县额外更加政内之米，或百石或百五十石，以输于国家，则于灵泉固不减，而山民之乱心亦息矣。此最今日之急务也。

《书》曰：“消患于未萌，保邦于未危”。又曰：“怨岂在明，不见是图”。《易》曰：“履霜坚冰至，君子以防微杜渐”。敬以是为大人献言也。目见山民蜂屯蚁聚，人人思乱，万或适遭其变，则言之妻子亦不保矣。天日之诚誓不为习俗所移，以累圣明之治，及大人作养之恩也。行将自经林木举家焚燎也。狂言发于忠悃，不识忌讳，实甘分罪。倘蒙俯鉴下情，虚心听纳，则山民幸甚，生灵幸甚。临书不胜战栗恐惧之至。

嘉靖三十二年五月初八日具。
:::

陈昌言信中主要对比政内、灵泉两乡的百姓生活，前者贫苦后者富裕，用情至深。

然后针对县里三“计”，即三个平粮的理由，逐一进行解释其不合理性，另外针对灵泉乡提出政内乡有五个“易入”，即其他经济收入，也一一做了反驳。

最后表示，即使退一万步讲，国家真的有难要加税粮给政内乡，那我们即使再穷也是责无旁贷，但这粮是交给国家，而不是去“救济”富有的灵泉乡的。

陈贵等的诉状主要是请求放人，陈昌言的上书有些“不合时宜”，这时候其实上面已经决定不平粮了，战略重心应与陈贵等的诉状同步，陈述理由请求释放无辜人员。但信中只有大篇幅的感人的关于平粮对山里人带来的灾难，而只字未提被拘役的人员。

## 1553年6月27日，知府洪公谐回复

:::{.important}

本府洪公谐纳。行牌：仰县除原清切民无异词不必丈量者，即便具由申府施行，毋比常违。

须至牌者。

嘉靖三十二年六月廿七日，

吏陈有仁承行。
:::

知府洪公谐指示“原清切民无异词不必丈量”，实迹就是政策“札付”的原话，自己啥也没说。压根没有理会陈贵等请求放人的诉状，对陈昌言的书信也算是给了一个左右逢源的回复：上面没有明说平粮（也没有说不平粮）。
