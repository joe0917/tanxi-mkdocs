# 均中不均，文济上告

## 1552年5月3日，政内乡上告至金华府

政内乡（石文济等）对平粮政策表示抗议，上告至金华府。金华府批复无需变更税则。

石文济，名石津，字文济，和溪（今杭坪石宅）人，时年约六十岁[^4_1]。

[^4_1]: 摘自陈舒平《最后的岱岳》。

按《浦阳和溪石氏宗谱》记载：

:::{.renwu}

俨廿九，讳津，字文济。譲十二公幼子。娶北隅黄氏，继娶于氏，生一子香，女适本里毛。嘉靖三十一年首倡平粮义举。

:::

:::{.important}
嘉靖三十一年五月初三日。

告状人石文济等系浦江县政内乡二十四都军民等籍，告为乞宣天恩因地制宜保国储以苏民患事。

开国以来，本县七乡照地肥瘠定粮科则，恩垂万世，民无异议。独政内一乡，僻在穷谷，开山为田，林木深阻，鸟豕交道，五谷不实，各乡原湿膏腴，薄种广收，山田竭力耕种，收不及半，致蒙减科定粮，比于各乡不同。

今年大造，伏蒙颁札清切田粮，固为革弊安民，切奉札开：“惟在不失原额，不许分外加增，随时处宜，惟在得人而已”、“内除各府田粮原清民无异词及不便于均地者，不必一概丈量，致生骚扰”等因。蒙此体恤民情，不失开国定粮之旧典。

怎奈外乡田沃民富，多途奔竞，将膏田之重米减入山田之轻则，穷民或米一斗倍至二斗有零。切思平原以土为田，山乡以石为亩，旧则尚轻，纷纭消乏，若使坐陷一则，不免阻陷国意，且致富民得所，山民逃移，均中之不均，阱中之加陷。况蒙韩知县田已丈量明白，原额不失，草册且经完解，复何更变，民焉遵守，不上投鸣，正谓法立弊生，遗患非小。

伏乞怜准查照国典旧制，轻重归原，民心安服，国储可保。为此情切，连名上告府主老爷施行。

批：本县田土已经清切田粮，近来取行乃部中勘合，只宜照常回报足矣，何须再更。仰韩知县查明报缴。
:::

政内乡抗议平粮的理由是：

之前确定的税则是依据各地产能不同确定不同的税率，施行几百年没有争议，合情合理。而今年上面下达的政策是要保证交齐“原额”，是针对“欠米”，对由此产生争议的田亩进行“清查丈量”并统一税则。对于没有争议又“不便均地”的就保持原样。

外乡田肥产能高，税率自然高；山里天地贫瘠，税率理应低一些。

再说之前县里欠米也已经查清交齐，以此理由进行平粮，并不符合政策要求。

## 1552年5月4日，灵泉乡也一起上告金华府

在政内乡上告金华府并获批的同时，灵泉乡（朱子高）也一起上告金华府，说明平粮的好处。

:::{.important}
告状人朱子高年甲不齐系金华府浦江县十八都军籍，告为恳天遵照圣例兴革利弊益册苏民事。

续奉勘合内开，繁昌、桐陵、高谅等县，为因科不均，欺隐田粮，俱各具情奏准差官丈量清彻欺隐，但现存田地不分高下，均为一则，是以奸民无所庸其弊，愚民不致受其辜，征纳两便，弊根可除，天下通行，万民称快。

切念本县原立七乡官民科则，共计八十余等，名色多端，茫昧以至攒书弄弊，富室欺隐，亏欠额米三百余石，遗陷通县赔纳，较弊甚于繁昌等县。正德七年已蒙邹老爷设法清理，仅十余年，旧弊复作，渐复亏欠如故。

见蒙督令新旧监都保长沿坵挨蹈履亩丈量，原额虽蒙查复，亦仅用功于枝叶，而未蒙拔本塞源也。揆其所由，定其科则，繁昌止蒙并为一则，以杜病根，适幸前本颁行海内，几出旷感，欲将官民田土通融定为二则，揭榜谕众，六都莫不忻感。

独有政内一乡，原则果轻，获利已久，结党阻滞，深图自便。切彼乡当开国之初，乱离之后，地僻人稀，意在抚集，所以定税独轻。即今民聚地辟，风气大开，实为财薮，与各乡利甚悬绝，实迹昭彰，自不容掩。设使依奸拘于旧例，则彼世受其利，而各乡咸受其害。况俗有推迁，法有变通，安得以一乡之私情而梗朝廷之良法。若不急上告鸣，失此机会，更无伸洩。切如嘉靖二十年间，蒙监察御史奏为清乞田赋以成盛世事例，准行府县，又被伊乡夤缘不行。似此得计，仍图侥幸。

伏恳天心，遵照事例，即将官民田地均为一则，虽使妇女稚子亦知所以算计办纳，而老奸巨猾无所措手，用计一劳永逸，造福无穷。有此利害，具状上告。

嘉靖三十一年五月初四日，县准。
:::

灵泉乡提出平粮的理由是：

为了防止“偷税漏税”，上面有政策要求各地尽量统一税则，以防“奸民”作弊，做到“愚民”无欺。而本县税则多达80多种。办事人员与富户勾结欺隐，上下其手，导致全县税粮欠米300多石。

从上次邹知县清查到现在才十多年（40多年），就旧弊复发。这次韩知县虽然已经重新清查并收回欠米，但治标不治本，要从根本上解决“偷税漏税”问题，就得响应号召统一税则，做到公开透明，“妇女稚子”都知道该交多少税粮。

政内乡因为之前定税过轻，现予以纠正。嘉靖20年时，上面已经让府县进行平粮，结果被政内乡耍赖阻止，这次他们又出来阻止耍赖。这样下去，大家都靠“闹”分配，县里还怎么管理？

对于上述两则针锋相对的告纸，金华府批复了政内乡的，而没有批复灵泉乡的。知府陈元珂政治嗅觉还是比较敏锐的，在征粮事情上，他的政绩首先是不能有“欠米”，锦上添花的才是“平粮”，平粮是一门技术活，浦江县提供的这个策略是一刀切，显然过于粗糙，隐患很大，自己不能擅自做主。

## 1552年5月19日，继续上告监察御史

朱子高见上告金华府不成，继续向更高一级的监察御史上告。并获得批复，要求金华府查议。监察御史虽然不是知府的直接上司，但属于省级官员，与自己的直接上司平级。

:::{.important}
朱子高等复捏以乞恩遵旨均平田粮革弊苏民事。

〔耸诳〕

藩司批：仰金华府查议详报。

嘉靖三十一年五月十九日状。
:::

## 1552年5月22日，张元等县吏上呈“平粮”并“留官”

张元等县吏再上呈，这次除了“平粮”还要“留官”。后面有金华府关于“留官”的批复，要求再待两个月。这则上呈的内容不详，但可以推测主要是“留官”，平粮是大事，韩叔阳是支持平粮的，而支持平粮的吏员知道，想要成事需要“县主”支持。有意思的是，傅本实迹加了“捏控”两字，前面朱子高的告纸则加了“耸诳”两字，可以看出里面有对政内乡人“控告”的语句，从后文可以看出，在这个阶段，县里抓了政内乡10名抗议者。

:::{.important}
粮里老张元、黄宗鲁、郑师仁、朱子高等，呈为乞恩宣旨留官均科清册革弊苏民事。

〔捏控〕

巡按浙江监察御史林，批：仰金华府查究明确议处呈夺。此缴。

嘉靖三十一年五月廿二日，张元等状。
:::

## 1552年5月28日，金华府要求浦江县展开调查

金华府依据上司（浙江布政司、监察御史）的指示调查上述状告，上司没有明确表态，自己也不好有所表态，仅仅做了一个帖文，说你们自己处理，这事是我的政绩，不要给我惹麻烦。看起来没表态实际态度很明确：怎么做是你们的事，做好了大家都有功劳，做不好你们自己负责。

:::{.important}
嘉靖三十一年五月廿八日。

蒙浙江布政使司批发浦江县二十四等都灵泉等乡军民等籍石文济、朱子高等各告粘连状词，
蒙批：“金华府查议详报”。

蒙巡按浙江监察御史林批发该县十七、十八等都灵泉、感德等乡粮里张元、朱子高等呈词，
蒙批：“仰金华府查究明确议处呈夺。此缴”。

蒙此：看得各人词内，石文济等乞要查照国典旧制，轻重归原等情，朱子高等乞要准留本官在任，将量过田地遵依奏准事例均为一则等情。

据查一宗“清查田粮以革奸弊以苏民困事”，蒙布政司分守右参政钱及分巡佥事寇批发浦江县隅都里老金朝兴等呈词，行据该县申：“该知县韩叔阳查得本县山高水冷，土瘠利微，所收租谷不能抵办钱粮，今将三项量行裁减，平为一则，每亩科米七斗三升三合，共减去官米七十石有零，以前新升余米补数，人皆称便。”等因到府，就经转详司道允示行县遵照讫。

又查一宗：“建言民情等事”，于嘉靖三十一年四月初四日奉布政司并分守右参政钱札付，承准户部照会及蒙巡按浙江监察御史林案验，奉都察院勘札行府传帖“仰县掌印官速查该县田粮，若原清彻民无异词不必丈量者，即取粮里老总结具田申府转报，如有田地增损、税粮添减、奸民那移稳匿等弊，应该委官挨蹈丈量者，作急驰报”以凭委官清踏，去后未报。

今蒙前因，照得该县田粮已经清蹈处分，虽有虚涉坍江，亦以裒[^4_2]多益寡，尽足原额，申详司道允示遵守。

[^4_2]: 裒：音póu，減少。

今朱子高等复要一则科粮，民情未妥，向背合行勘处。

为此帖：仰本县即行韩知县照依帖文内，并原奉勘合内事理，即将发来词卷各人呈告前项事情，逐一查究明确，议处停当，务使官民称便，两情允惬，以服众志。此事原系本官重大功迹，作速具由覆审施行，毋得偏徇迟误不便。

须至帖者。

嘉靖三十二年六月初二日帖。
:::

## 1552年6月12日，西市老农楼永富

:::{.important}
本年六月十二日，有西市老农楼永富见本官要平通县科则，衣巾进县具禀县主，县主不允，答曰：“你来说迟已”，以言慢之而出。
:::

西市老农楼永富见县令。这段描述说明县里还是决定按既有政策进行平粮。

此时是六月，接下来就是新政出台后的第一年纳税。韩叔阳经过“踏勘”各乡田亩实际情况，也确实感觉到直接平粮对政内乡是严重的加税，负担过重。因此在执行平粮政策的同时，又减免了政内乡一半的徭役。
