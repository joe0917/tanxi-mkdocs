# 前言{.unnumbered}
平粮实迹研究起始于2020年5月。

## ※ 关于本文{-}

首先说明，本文不是论文，没有严谨的研究框架，没有综述，不是建立在什么理论基础上，没有解决什么问题，更没有创新点。另外，这也不是小说，不是随性创造的，甚至没有任何虚构的人物。再者，它也算不上是历史，因为它实在太渺小了，它的人物几乎很少出现在史学著作中。

姑且称之为“记录”吧，或者说叫历史记录，不是关于大人物的历史，是普通人的历史。

家谱中常说，“国有史，家有谱”，“谱即普也”，而这个记录本身就来源于家谱，是多本不同姓氏家谱的共同记录，是最普通人的记录，原文名字叫做《平粮实迹（平糧實蹟）》，以下简称“记录”或者《实迹》。

## ※ 关于《平粮实迹》{-}
由于谱师水平不一，《平粮实迹》流传、刊印过程中出现了很多错漏、舛误之处，本次整理修订《实迹》原文时参考了多部家谱，在尽力修复原貌的前提下，进行了标注与校正。

主要参考了以下家谱：

1. 《浦阳任氏宗谱》，刊印年份：光绪乙巳（1905），以下简称“任氏宗谱”。
2. 《浦阳湖溪虞氏宗谱》，刊印年份：民国壬申（1932），以下简称“虞氏宗谱”。
3. 浦阳杭溪蒋氏宗谱，刊印年份：民国丙子（1936），以下简称“蒋氏宗谱”。
4. 浦阳薛氏宗谱，刊印年份：民国丙寅（1926），以下简称“薛氏宗谱”。
 - 以上四本宗谱中《平粮实际》序文标题为：“粮额徇古序”。撰序者落款为：“康熙四十年（1701）菊月，浦邑后学筑岩傅旭元书赠”。
5. 浦阳檀溪陈氏宗谱，刊印年份：乾隆丁未（1787），以下简称“陈氏宗谱”。
 - 陈氏宗谱中《平粮实际》序文标题为：“平粮实迹序”。撰序者落款为：“雍正己酉年（1729）孟夏月，邑庠生启经撰”。
6. 和溪石氏宗谱，刊印年份：民国丁卯（1927），以下简称“石氏宗谱”。
 - 石氏宗谱中《平粮实际》序文标题为：“平粮实迹序”。撰序者落款为：“乾隆五十八年岁次癸丑（1793）冬十月，裔孙谨序”。
7. 浦阳盘溪周氏宗谱，刊印年份：民国己丑（不明），以下简称“周氏宗谱”
 - 周氏宗谱中《平粮实际》序文标题为：“与平政内乡粮事记名”，撰序者落款为：“乾隆丙申（1776）初冬，如金谨志”。

同时对以上收集到的宗谱进行整理，可以看出《实迹》内容基本一致，而序文主要有两个版本，一个为傅旭元所撰，一个为陈启经所撰（和溪石氏版本是依据檀溪陈氏宗谱本改编而成）。而盘溪周氏没有《实迹》全文，仅有一篇“记名”文，主要依据檀溪陈氏宗谱中关于平粮实迹的记载，抄录了周姓人物的参与情况。为了便于区分，傅旭元作序的称为“傅本实迹”，而陈启经作序的称之为“陈本实迹”，具体哪一本家谱记录，则以家谱名称呼，例如“任氏本实迹”。

## ※ 关于明朝时期的税粮{-}
《平粮实迹》中的“粮”指的是税粮，现代称之为“税收”。

从古至今，税收一直是一个国家的根本，虽然形式发生过变化，比如由实物缴纳改为了钱币缴纳，但有一点始终没有变化：交税是每个民众的义务。但中国人似乎从来都没有认识到过这一点，始终有人在绞尽脑汁“偷税漏税”。究其原因，应该是我们的纳税，从来只是“义务”，没有对应的“权利”来平衡。这一点我们通过对税赋予的两个属性就可以看出，这两个属性为：强制性和无偿性。这是有悖于现代税收的底层逻辑的：民众购买公共服务机构（通常为政府或军队）的服务。

《实迹》是一宗跟税收相关事件的记录，或者说仅仅是对公文的抄录。事件发生在明朝嘉靖年间[^0_1]，具体而言是始于嘉靖三十一年（壬子），公元1552年。嘉靖是一个喜欢修道的皇帝，肯定也了解道家的“无为而治”。但道家思想理解历来五花八门、路数不同、深浅不一，研究嘉靖执政理念的学者很多，我们的记录虽然也偶尔提及“圣旨”，但跟嘉靖帝和他的思想关系不大。总体而言，那时候明朝已经开始出现腐败，就税粮而言，出现了名目繁多的“偷税漏税”手段。

[^0_1]: 《实迹》后面还记录了万历年间及清朝康熙年间两次平粮事件。本文中所说的平粮实迹事件仅表示嘉靖年间浦江县的平粮事件。

跟现在直接交给国家税务机关的缴税方式不同，当时的税粮是交给州县，再汇总到省，最后再给朝廷。朝廷不管州县交多交少，只要每个省每年足额交齐就行，同样省也不管个人交多少，只要州县交齐就行。针对普通民众而言，交多少税不是法律规定的，也不是国家收取的，完全是由州县来定。因此那时候的“偷税漏税”性质跟现在也不一样，现在偷漏的是国家的税钱，而明朝时仅仅是州县的税钱。

由此出现的偷税漏税手段和现在也完全不同，总体而言，区别在于现在只需算自己的，直接面对国家，而之前不仅算自己的还要算计别人的，尤其是相邻的，相邻田地，相邻村，相邻乡，而面对的是州县。所以出现五花八门的漏税漏税手段，主要有[^0_2]：

[^0_2]: 引自《明代黄册制度》，韦庆远，中华书局，1961。

- 飞洒，又名飞走、洒派、飞派，就是占有大量土地的豪强地主，把自己应负担的田赋或徭役通过细分的办法转嫁给农民。
- 埋没，即豪强地主把自己所占有的田产通过各种办法隐瞒下来，不负担或少负担税役。
- 虚悬，即豪强地主把自己所占有的田产虚为买卖，或假称卖与农民，或买田时收田而不收粮，或买田时故意改重则为轻则，多买少报等等，以规避税役。
- 脆寄，就是豪强地主把自己的田产寄在别人的户下，以逃避税役或减轻税役。
- 挪移，把民田担作官田，以好田报作坏田，或以多报少，以少报多来谋私利。或将自己所在的里分甲分挪移，在应役之年，把应役之甲往后移，过了以后又移作已役之甲。
- 影射，用飞洒、假名、乳名等等手段把田产欺隐下来。

## ※ 关于浦江{-}
再来说说《实迹》中事件的发生地：浦江县。

按照明朝嘉靖时期的行政区划来说，浦江县跟现在一样，属于当时“两京十三省”中的浙江省，全称为“浙江等处承宣布政使司”，简称“浙江布政司”。布政司负责民政，设左、右布政使（从二品），左、右参政，左、右参议。而浙江省下面还有另外两个省级机构：一个是“都指挥使司”负责军事，一个是“提刑按察使司”负责刑狱。其中“提刑按察使司”简称“按察司”俗称“宪司”，按察司长官为按察使（正三品）。然后还有一个叫“巡按浙江监察御史”俗称“藩司”，是中央“都察院”直属下派的。

我们整理一下，《实迹》中提及[^0_3]的省级机构主要有：

[^0_3]: 仅嘉靖平粮事件。下同。

1. 浙江布政司（民政）

浙江布政司分为四个道：杭嘉湖道，宁绍台道，金衢严道，温处道。浦江县所属的金华府归属于金衢严道，金衢严道下辖金华、衢州、严州（下辖淳安、建德、桐庐等）。《实迹》文中提及的布政司职务主要有（含官员姓氏，下同）：

- 浙江等处承宣布政司使分守金衢严道兼理黄册右参政钱；
- 钦差督理粮储兼管黄册右参政史；
- 带管右参政潘；
- 浙江等处承宣布政使司分守金衢严道参政谢；
- 分守金衢严道右参政；
- 布政司兵备副使谷。

总的来说，跟平粮事件相关的省级官员主要是右参政（相当于现在的副省长），而该右参政还“分守”金衢严道，也就是分管金华、衢州、严州三个府。而且右参政还经常“带管”或者“监理”黄册道。这里需要补充说明的是，布政司下面除了各地“分守道”，还有“督粮道”和“督册道”。这三者具体分工如下[^0_4]：

- 督粮道（1人）：负责征收、押运漕粮。
- 督册道（不定）：负责督造鱼鳞图册、黄册。
- 分守道（不定）：向各府传达催办布政司的公事。

[^0_4]: 引自《显微镜下的大明》，马伯庸，湖南文艺出版社，2019.1。参考自《明史·职官志》

2. 都指挥使司（军事）

《实迹》中没有提及都指挥使司相关官员。

3. 提刑按察司（刑狱，宪司）

《实迹》文中提及的按察司职务主要有：

- 按察司分巡佥事姜；
- 浙江等处提刑按察司廉使司谢；
- 按察司带管分巡副使陈；
- 浙江等处提刑按察司带管分巡浙东道郑；
- 分巡浙东道佥事李。

4. 巡按监察御史（检察，藩司）

《实迹》文中提及的巡按职务主要有：

- 巡按浙江监察御史
- 钦差巡视都察院御史王
- 钦差提督军务巡抚浙江并福兴泉漳地方都察院右佥都御史李。

巡按御史往往是皇帝亲自任命的，因此称之为“钦差”。巡按品级不高，但是代表的是皇权，因此地位很高。

接下来看“府”一级（现在的地级市级别）的机构，浦江县的直属上级是金华府。金华府属于浙江省四道中的金衢严道，位于浙江中部。府的最高长官为知府（正四品），下面有同知和通判，称之为“（府）佐贰官”。

《实迹》文中提及的金华府职务主要有：

1. 知府；
2. 同知；
3. 通判；
4. 金华府郭推官。

推官是巡按在“府”中设置的派驻官员。

最后再来看“州县”一级的机构：浦江县。府下面大的发达的地方叫州，浦江是小地方，所以是县，到现在为止还是县。浦江县位于金华府最北面，往北与杭州府、绍兴府交界，南面是义乌县和兰溪县。浦江县是浦阳江的发源地，并以此得名。

县的最高长官是知县，知县在明朝皇权行政体系序列中算最末一级了，县衙有县丞和主簿，称之为“（县）佐贰官”，虽然称官，实际只能算吏，并不在皇权体制内，也不受皇权信任，《实迹》中有户部勘合记载“令各原委及同该州县官，……，不许转委州县佐贰官，以滋多弊”，明言只能委任知县（执行）不准佐贰官插手，以防止滋生腐败。明朝体制内官员是要通过科举考试，考中进士，然后由朝廷委派，委派的最初级地方官就是知县。“官”一般不在自己户籍所在地任职，而“吏”基本都是由当地人担任。其他“吏”还有包括典吏、巡检、驿丞等。

《实迹》文中提及的浦江县职务主要有：

1. 知县；
2. 县丞；
3. 主簿；
4. 典吏。

县再往下就是乡，乡下面是都（县城里的叫隅），嘉靖年间浦江有7个乡30都，分别是德政乡（辖1-5都）、通化乡（辖6-12都）、嘉兴乡（辖13-16都）、灵泉乡（辖17-19都）、感德乡（辖20-23都）、政内乡（辖24-27都）、兴贤乡（辖28-30都）[^0_5]。相对而言前面五乡算平原而后面两乡算山地。因此到现在浦江人还是称前者为“外乡”，后者为“山里”。

[^0_5]: 引自《浦江县志·卷二》，乾隆己亥本。

《实迹》文中提及的乡、都一级的职务主要有：

1. 里长（里老）
2. 粮长（粮老）
3. 递年（里递）
4. 排年
5. 攒造
6. 书、算手

洪武十四年，朱元璋下诏编制赋役黄册。《明史·食货志》记载：“诏天下编赋役黄册，以一百十户为一里，推丁粮多者十户为长，余百户为十甲，甲凡十人。岁役里长一人，甲首一人，董一里一甲之事。先后以丁粮多寡为序，凡十年一周，曰排年。”也就是说，黄册以一百一十户为一里，推举其中丁口、田粮最多的十户户长，在十年中轮流担任里长；其余的一百户分成十甲，每甲十户，这十户户长在十年中轮流任甲首。里长与甲首分别执行这一年中该里、该甲的差役，他们轮流的次序，根据丁粮多寡排定先后。

黄册格式由户部攒造，并由地方政府依式翻刻，并发至里甲，由甲首发给各户依项如实填写；民户如实填好《清册供单》，将册本交给甲首，甲首再报给里长。史载“里编为册，册首总为一图”，即把每里（一百一十户）编制为一册，然后，再逐级上报至户部。“上户部者册面黄纸，故谓之黄册”，也就是说，送呈户部的人口赋役册表面用的是黄纸，所以叫“黄册”。

黄册中，首列户主姓名、贯址、户籍、应役年份与职役，其次以旧管（原有人口及田宅等）、开除（已故人口与减损田宅等）、新收（新增人口及田宅等）、实在（现在实有人口及田宅等）之“四柱式”，登载丁口及其生老病死、事产及其增减推收、赋税记录、赋役年份等各项内容，以此动态反映人口增减和财产变化[^0_6]。

[^0_6]: 引自中央纪检委、国家监察委官网文章：[玄武湖上藏宝册 明朝人口普查往事](https://www.ccdi.gov.cn/lswh/shijian/202012/t20201211_231680.html)。


具体到各地各个时期，管理及称呼会有所不同。总体而言，里长（里老）负责一般性事务；粮长（粮老）、递年（里递）、排年主要负责税粮的征收；攒造是负责造黄册的事务员；书手和算手，一个负责记账登记，一个负责计算。
