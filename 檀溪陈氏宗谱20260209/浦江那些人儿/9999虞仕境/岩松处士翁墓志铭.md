# 巖松處士翁墓誌銘
```
题：[]賜進士第福建提刑按察司僉事 紹興府會稽縣司馬相拜撰
峕：[]嘉靖廿三年歲次甲辰夏六月朔日吉旦
初始点校：[20260719]《浦阳湖溪虞氏宗谱》民国壬申[1/11]p170
修订参考：[20250825]《浦阳湖溪虞氏宗谱》民国庚申[1/1]p348
```

虞氏固為成都宦族，至三世祖諱士寧，字明安，始自杭遷至浦陽縣北二十五里湖溪。其地山川秀麗，人文玉立，為浦北之巨族。處士諱仕境，字存邦，號巖松，厥考早逝，母張氏矢志守節。處士自失怙時，方在童年，祖廷光府君每以家業廢墜為慮。及長，卓自立，慷慨有為。痛父之沒，極誠孝母，承順祖意。祖晚庶育二叔一姑，未及長而祖謝世，處士不廢姑叔之禮，俟長為婚嫁。兩叔既冠，欲求分居，處士正色曰：「叔姪務宜黽勉同心，以光先烈。且若分居，何以慰祖心於泉下？」合食迄卒，時相好無尤。治產積居，贏餘即周鄉鄰之貧乏者，鄉人感之，稱為長者。每恨生不逢辰，弗暇工文詞為舉業，以効勞於皇朝。隆師尊友，訓其子學舉子業，以償夙志。娶同鄉陳氏，育二男，長諱銓，即遊邑庠；次諱鑣，亦極英偉。孫男六人：大經、大綸、大緯、大縉、大紳、大純，器宇均屬不凡。處士葬西山，立石墓上，冢君走書乞文於余，因潑墨而為之銘。

銘曰：  
世有幽人，金玉其音。天胡豐於其才，而杳於其齡？吾欲問天而天冥冥，吾往問人而人咸欽。姑取其孝義之行，卓越之操，書而刻之堅珉。

峕嘉靖廿三年歲次甲辰夏六月朔日吉旦
