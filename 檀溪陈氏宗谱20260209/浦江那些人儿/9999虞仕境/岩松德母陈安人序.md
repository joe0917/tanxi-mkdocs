# 巖松德母陳安人序
```

初始点校：[20260719]《浦阳湖溪虞氏宗谱》民国壬申[1/11]p168
修订参考：[20250825]《浦阳湖溪虞氏宗谱》民国庚申[1/1]p346
```

安人陳氏，本里白巖山前厚七十三公[^1]長女也。笄年歸虞門，仕境字存邦，別號巖松者。巖松早孤，而安人相之，事寡姑張氏二十年，略無忤色，宗族咸以孝稱。而巖松公喪，安人事之愈力，克新先業。課二子習儒，長男銓遊太學，官授武岡州州判，州人以循良頌；次男鑣善孝友，薦紳輩義而舉之。邑侯張諱絅者，三肅登請，始乃膺寶薦。厥孫若經、若綸、若縉、若建中者，進修於鄉國學，彬彬然，孰非安人孝行之所感，家敎之所遺？而巖松公刑于之化可知矣。安人孀居二十六年，享壽七十而終，親族遠近，至今戚慕不衰。茲忝譜任，敢不書之，以爲表揚一助云。

眷姪陳嘉言識
