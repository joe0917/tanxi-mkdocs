# 金氏重修宗譜序
```
题：[]邑庠生傅旭元拜撰
峕：[]大清康熙歲次癸巳一陽月下浣吉旦
初始点校：[20260702]《浦阳龙溪金氏宗谱》民国戊午本[1/1]p7369
修订参考：[]
```

譜何為而作乎？所以親也。夫人上自君公，下及士庶，莫不有一本九族之親。惟載之於譜，斯知宗源有本，支派有緒，昭穆有次，尊卑有等。倫紀攸分，則綱常不墮，而親之道不替。譜之所繫，不甚重乎？是以巨姓大族，或十年而一修，或二十年而一修，踰此失修者，謂之不孝，是忘親也。

乃若金氏之族，自郡馬公以忠孝開基，而次子元六府君，由茶場卜遷於義烏前金，以後閱九世，再分於浦陽新橋及前嚴之所，三分於橫塢，四分於右溪塘。丁戶日繁，族居星散，固非若他族聚處一方，比閭相望也。向非譜牒所誌，幾何不視親族為路人耶？矧遭甲寅兵燹之餘，而居於舊宅者不越二十餘戶，餘多遙徙他鄉，則其勢益渙，而譜尤不可不亟修也明矣。

余今參稽譜錄，自康熙庚戌年間續修以來，暨今癸巳，已越四十餘年，何其曠遠疎失若是乎？然而自方其意也，蓋經亂離之後，俗凋風敝，勢難復曩日之盛跡，且覩斯譜也，祇令人增叔季之悲，故欲修而不忍也。而不知盛而衰，衰而盛，自古皆然。使金氏之子弟，樸者習於勤儉，秀者志於詩書，則裕後光前，未始非旦暮間事也。

宗老因族居星散，以親之道，先足使後人於百世以上、百世以下，展帙而瞭若指掌焉。爰是屬余作此以為之序云。
