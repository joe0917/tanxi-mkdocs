# 月泉傅氏明譜錄略
```
题：[]第三十二世孫旭元謹識
峕：[]康熙五十年歲次辛卯重九之吉
初始点校：[20260629]《月泉傅氏宗谱》民国戊子本[1/8]p022
修订参考：[]
```

月泉傅氏，裔出商朝傳說，世居長安。當齊建元時，有諱建者，官中山內史，生子昌。昌生二子曰剛、曰柔。剛仍居長安。柔字仲席，歷官鄂州刺史，無為而治，謳歌載道。值隋大業之亂，避蹟鶴塘。唐天寶間，析烏傷而置浦陽，則鶴塘屬籍焉。縣誌人物記詳載柔於政事，為祀鄉賢祠，又載墓在鶴塘。譜牒以建為始祖，柔為三世祖，其居長安者不復引贅。柔生二子曰興仁、曰興我。仁行茂五，官丹陽縣尹，生凝。凝行定四，生二子曰縉、曰船。縉行宴一，生金。金行子一，生守謙。謙行文一，生四子曰聖、曰正、曰傑、曰白，以天為行，聖其一焉。生器。器行用一，生二子曰孔揚、曰孔忠。揚行廷一，生一子祐。祐行京一，生二子曰倫、曰仲，為第十三世。倫行明一，生珙。珙行賓一，生兀。兀字立挺，號養齋，仕仙居縣學教諭，行存二，生獻。獻行師一，號白雲，著有《漁樵集》，生璧。璧行珍二，生菁。菁行堅二，字世盛，號梅軒，生子禮。禮為第十九世，行守二，字宗節，任月泉書院山長。元至大啟元戊申修輯譜牒，方韶卿鳳、吳淵穎恭、黃晉卿潛俱撰有譜序。今傅氏譜稱月泉者，以山長修輯也。

禮生三子：長曰政，字子仁，任鄂州提舉；次曰循，行儒二；幼曰恆，字子常，行儒三，邑校貢士，任谷陽主簿，同里宋濂有贈序，後調建陽，蘭谿吳沉有贈序。政行惱一，生二子期祖、開祖。關祖字仲德，行宗二，為二十一世，世居縣前東首馬豹橋，是名東湖塘。生二子曰定，行安三；曰琪，行安四。琪生四子曰奴、曰丑、曰常、曰榮。其次諱丑者，行然三，生三子：長貞，行浩七；幼子容，行進二十，徙杭州新城；次芽，行浩九，幼子足，行進十六，遷居嚴州蘆茨；幼開，行浩十，長子程，行進十七，移居於七里橋北。其四諱榮，行然五，生三子：長勝，行浩八，生三子穰，行進七，為十五都麗水源口祖；秩，行進八，為一都曹村祖；積，行進十三，為二十四都西灣塢口祖。次明，行浩十一，生二子京、郡，郡行進十八，為四都杭平壇月泉畈祖；幼春，行浩十二，生四子，幼填，行進廿九，仍居縣東，後為桐木殿後祖。自建祖始至進字行，凡二十五世。杭平壇進十八公生五子曰崇，行立十一；曰崙，行立十五；曰森，行立十九；曰泗，行立廿四；曰儀，立三十七。惟長房立十一、幼房立三十七，分為東西兩房。其東行立十一公生三子：恩，行成四；祐，行成九，冠帶壽官；祥，行成十四，生四子榮十三、榮二十、榮二十八、榮三十九。其次榮二十諱桿，冠帶壽官，生二子文英，行傑五十七；文盛，行傑六十八。英生二子曰愷、曰悌。愷字惟元，號際明，行忠七十八，明天啟六年丙寅，相邀四明毛九翔重修譜牒，詳載生卒葬娶，以吏員選授雲南石匣典史，後陞縣丞，同子大順終居北京。其三榮二十八諱伯洪，生二子文寶，行傑三十二；文會，行傑五十八。會生二子曰俊、曰冬。俊行忠七十三，生五子曰明、忠、啓、元、瑞，共四大元。字希遴，行和百五，篤信薩守，鄉里稱為長者，生一子理，行仁九十二，克昌厥宗。其西立三十七公，冠帶耆賓，生三子：長曰襟，次曰被，幼曰衽。長幼兩房又有西邊上下之稱。

幼房衽，行成四十二，恩給冠帶耆壽，稱為西邊上頭。長房襟，行成三十一，生子伯元，行榮四十七，生文福。福字良德，行傑六十六，為生五子：鳳、鸞、鵬、鶴、鵠。長諱鳳者，字惟鳴，號岐山，行忠八十二，醫學訓科，優獎孝子，傳載省府縣誌。生四子：奇、章、意、彥。諸以醫名，且諸以醫傳其子若孫。長曰大奇，字希賢，行和四十五，配李氏以苦節稱，生二子必魅、必元。元字時選，行仁廿一，勤儉克家，生二子德、行德至。次日大章，與奇雙生也，行和四十六，字希成，號斐公，邑庠生。生平仗義，不負託妻寄子，學院張公希良以「義高嬰杵」四字獎之，通邑稱頌義士，素入邑誌，集有詩歌行述，詳見愚谷張先生撰傳，享年八十有四。師朱氏以賢淑稱，義門立羽節先生撰有賢媛傳。三子：長旭元，行仁廿四，字晉初，號築巖，邑廩膳生，優獎文學，載入邑誌（八字續），以浦江文獻自任，重輯募刻諸先哲文集，生子萬九、萬一。次旭亨，行仁三十八，字嘉仲，入金華府學，生三子萬年、萬里、萬榮。年字介眉，行恕十四，生三子洵達、洵遠、治選。幼旭貞，字叔韓，行仁六十七，以次兄建萬里為貴。其三日大意，字希正，號九如，行和六十三，先自章買吉兆葬祖傑六十六於金華知道山釋樹塘頂。康熙甲寅閩變，地遭蹂躪，大意慨然念之，又以路遠失達祭掃，遂自買地周西塢，擇於丁巳臘月六日，從金華遷移厝焉，亦可謂順孫矣。其四曰大彥，字希美，號哲齋，行和九十六，年八十二，明受朝廷耆老綿米肉養老之典，恩榮八品壽官。歲當戊午，命其子一說合族修譜。今年辛卯，又命姪必元、旭元、一元、一貴、一瓊、一耀，三十三世孫心賢、心璋、萬榮輩重修譜牒，是誠有心敦本睦族、尊祖敬宗者矣。配張氏，八十齊眉，康健而壽，生四子：長一說，行仁三十四，字商霖，戊午重修宗譜，為鄉賢祠奉祀生，無子，以親姪麟瑞為嗣；次一讓，行仁五十三；三一讚，行仁六十五，字贊侯，生二子麟現、麟瑞，瑞為長兄後，現生子士英；幼一詔，行仁八十六，字玉書，能世傳其醫業，生三子麟琦、麟璋、麟玫。蓋斐公、哲齋兩房，又自杭平壇移入城中四牌樓、橫街、大街居焉。

溯建祖至仁字行，凡三十二世；恕三十三世，如洵、逵輩，承字行為三十四世。逆數齊建元時，約一千三百有餘歲矣。自仲德祖二十一世以來，世皆隱約田間，其以醫著者甚多。若二十四世以前遷居别處，不既悉載；其二十五世不特本縣移居，志其地里，即遷他都他邑者，亦為詳其支派，記其行蹤，總以俾知傅氏源流耳。至柳溪傅氏，為宋傅堯俞之後，與月泉傅氏為隋傅柔之後，迥乎各別，不敢强附。嘗稽義門鄭氏，著有《明譜錄》，俾子孫觀之，一覽即知支派。今倣其意而識源流支派，錄略一篇，以復叔父重修譜牒之命。一錄之書於譜首，俾令後之人見而識焉，庶不忘敦本睦族、尊祖敬宗之意云爾。
