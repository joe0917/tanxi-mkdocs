# 江西淮安府典寶東溪虞公行狀（富三十六公）
```
题：[]鄉貢進士嘉興府平湖縣教諭眷晚生張元慥謹撰
峕：[]峕天啓元年歲次辛酉冬月之吉
初始点校：[20260719]《浦阳湖溪虞氏宗谱》民国壬申[1/11]p176
修订参考：[20250825]《浦阳湖溪虞氏宗谱》11卷[1/1]p354
```
辛酉之夏，虞姓將治譜事，吾季兒丈父華陽翁諱大勲者，攜祖東溪翁序文來商於余曰：「譜氏欲華我祖一言」。時多傳述其美，纍纍若若，至於閣筆難從。
有誦德者曰：「孝友飭躬，齊夏範俗，允矣君子，温文如玉。」
有稽行者曰：「胸藹藹，貌于于，口娓娓，步徐徐，隳岸斬崖，丰宇坦夷。」
有闡敎者曰：「開講席乎？課緗幃乎？仲子補諸生，遊邑庠，其公之敎乎？」
有寫樂者曰：「風之軒也，水之榭也，方客之與遊也，竽無濫，鋏無彈也。」
有稱後者曰：「王三槐與燕五桂與？子無鷟發與？孫如蘭茁與？」勲猶為未盡也。

嘉隆間，婺郡四大富民，各捐資數百，搆府主陳祠，實我祖首倡其義。至入粟輸邊，擢居江西淮安府典寶。宦成身退，菟裘營老。朱之散堵，潛之解組，鹿門浮邱，皆祖之儔。備陳眾論，願就定評。予曰：「翁配樓氏，舉丈夫子六，迄今曾元盈庭，豐腴冠邑，殘躅多芳，隻語奚罄，合眾口兒欲勒之碑，方是我兒丈全體祖也。」今並載以爲序。

峕天啓元年歲次辛酉冬月之吉
