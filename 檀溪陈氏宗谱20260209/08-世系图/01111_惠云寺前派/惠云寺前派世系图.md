# 惠雲寺前派
```

峕：[]
初始点校：[20260916]民国庚辰本[1/33]P111
修订参考：[20260916]乾隆丁未B本[1/6]P3145
```

癸未[^1]世系載：九一公有二子，曰仲六、仲七；詵一公有二子，曰欣一、欣二；能二公一子，行十，諱原，稱添六七，原之子曰宗七十二，皆誤也。

按寫傳云：九一析居富春，今譜不序[^2]。仲六、仲七皆九二之子，寫系同。詵一公有三子，曰興一、興二、興三；能二公有二子，曰天六、天七；天六有子曰宗七，天七有子曰宗十二，寫系亦同。至千十一公有一子，諱曰雷，寫傳與丁酉[^3]同，寫系與癸未皆缺。興二公之幼子，行居七，寫系與寫傳異，與癸未同。他若寫系所載十四世諸府君暨歷代之婚諱塋里，則寫傳已失之矣，又曷怪丁酉重修僅詳列七世乎？今特參互考核而釐正之，以補闕存舊云。

[^1]: 癸未，21修，“淸乾隆廿八年癸未第二十一修（1763）”。
[^2]: 乾隆丁未本为“叙”。
[^3]: 丁酉，15修，“淸順治丁酉一修（1657）”。
