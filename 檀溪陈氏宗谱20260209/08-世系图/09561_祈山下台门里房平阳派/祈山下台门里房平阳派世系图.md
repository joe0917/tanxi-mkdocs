# 祈山下臺門裏房平陽派序
```
题：[26/廉258]第廿六世孫耀偀謹序
峕：[22修]乾隆五十有二年歲次丁未冬月朔
初始点校：[20260923]民国庚辰本[9/33]P561

```

克湛公，恩七百十七，字思魁，號奇山，祈山派斌三公十一世裔孫。避荒亂，攜家至平陽，娶方氏，子四曰：元鳳、元鶴、元龍、元麟。戊申所修，已詳其諱字，并各生年月日時。嗣後纂輯，苐仍其舊，蓋山川間隔，音問不通，無如何耳。

癸巳夏，其孫之璧來謁家廟，誦述其高曾顛末，信而有徵，且告其祖父續譜之命，殷勤懇切，情見乎辭。迄今十餘載，而孝思不能沒也。因遣人致信，璧乃賷其繕稿一卷，自奇山以下，生卒嫁娶里墓，無勿詳晰。爰從定例，另列系表，以附祈山下臺門之末，予其請，成其志焉。

嗚呼！平陽，温府屬邑也，與青田接壤，西北過之，乃抵縉雲，踰東陽，又折而西北，歷義烏，始達縣之東南，以至於城。城去吾鄉更五十里，可謂遠矣。且其間崖谷峻隘，波浪險惡，璧以遺命之故，獨不敢辭，謂非君子仁人所亟為嘉許者耶？矧其祖先固有功於宗族耶？

公高祖諱廷璉，樂善好施。曾伯祖早世，其安人張氏守節入祠享祭。曾祖諱暹，號石橋，秉性端嚴，治家整肅，捐助建祠基址，又撫孤成立，號曰東谷，贊成家廟，以孝行聞，是為公之伯祖。祖諱應祿，號仰橋，其墓有誌，則人可知也。父諱尙貴，字德良，號思我，生公昆季凡四人，而綿延弗替者惟公嗣。吾於公嗣有厚望矣。

今夫為善無不報，理之常也。維公祖考代有德行，而其後弗克皆昌，將毋天之厚於公嗣更有在耶？為公嗣者，考於田，勤於學，敦行孝友，不辱其先，則顯榮褒大，雖不克有於其身，必將錫於其子孫；雖不獲見之于今日，必將遇之於後人。瓜瓞蕃衍，又何足為公嗣慶幸哉！

乾隆五十有二年歲次丁未冬月朔，系表既成，沿流遡源，偀與同派乃為之識其大略，述其舊聞，俾知夫公以一人之身，距千里之遠，而成家聚族，為前人光者，其來有自也夫。
