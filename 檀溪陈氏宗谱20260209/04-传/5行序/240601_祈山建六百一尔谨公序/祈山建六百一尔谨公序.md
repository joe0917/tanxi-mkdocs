# 祈山建六百一爾謹公序
```
题：[]眷小弟邑庠生王德懌頓首拜撰
峕：[20修]乾隆十一年丙寅正月
初始点校：[20250805]民国庚辰本[3/33]P384
修订参考：[]
```

國有賢臣，社稷之福；鄉有名士，閭里之光。然後爲賢臣，未有不自今之名士昉也。

吾友爾謹者，奉椿萱以孝，處棠棣以恭，敬老慈幼，素方有訓，其素行固有足多者。要不特此也：平生重然諾以勿二，篤躬行以無偽，則白圭素絲可爲公頌；結金蘭如昆玉，睦宗族似春風，則《杕杜》《行葦》可爲公詠。學飽青箱，文吐白鳳，有雍容爾雅之譽；圭璧其躬，金玉其度，有緩帶輕裘之致。其可矜可式爲奚似乎？

無如天不可知，琴弦累續而累絕；猶幸德不孤立，雀屏屢開而屢中。設非德修於身，奚以洩洩融融？不愧家人占乎，且其幼時好學不厭，好禮不怠。經術湛深，丙辰歲擢入成均；甲子科舉鄉進士。奕奕熊熊之兆登朝，已爲有自；然猶閉戶齋居，批閱不輟。遇知己則以所錄告，遇子姪則以所課責。平素樂取人善，心誠好之，有非稍涉矯託者。寧非名士風流，爲閭里增光也耶？

苟其司馬再升，則深山之採依然；一四門之闢焉，則名士賢臣，一而二、二而一哉！爰爲俚句以祝曰：

高山仰止景行開，
神交數里日往來。
裘馬翩翩羊叔度，
綈袍戀戀故人懷。

鄉貢進士攀雲客，
夢筆生花天所培。
眼前零落難圖報，
惟願於公位列台。

乾隆十一年丙寅正月
眷小弟邑庠生王德懌頓首拜撰
