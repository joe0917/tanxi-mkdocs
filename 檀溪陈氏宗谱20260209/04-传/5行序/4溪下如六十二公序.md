# 溪下如六十二公序
```
题：[]叔尚震字德龍誌
峕：[15修]順治十五年戌戌孟夏之月吉日
初始点校：[20250804]民国庚辰本[3/33]P380
修订参考：[]
```

姪諱國源，字良進，別號宗源者，孝友慈祥，恭勤儉約，務樸茂以修身，惟謙和以應世。其素行之端莊，不能枚舉。惟壯年時，重新堂構，恢擴祖基，不吝己貲，以莊一門之觀。中年因親叔景時公無嗣，將馬公塔田五十稱立約以存親叔之祭。奈諸弟姪遭賦役繁苛、綠林擾亂，乍將前田移易以周急。姪復感激，易己產以贖前田，先人之血食永有賴焉。

惜上蒼不祐善人，娶而再續者三，未得一裔。茲値耆耋，理當立繼，乃繼仲弟國淸之次子元禁爲嗣，另拔祭田二斗（土名寺口）以爲三妻無出之祀，餘則與長姪均分。此皆姪平生之懿行，劣叔所素欽哉！謹識之於譜，以爲合族之仰止云。

順治十五年戌戌孟夏之月吉日
叔尚震字德龍誌
