# 會龍恩五十一公序
```
题：[]眷晚生虞邦璵頓首拜撰
峕：[15修]順治十四年丁酉仲冬旣望
初始点校：[20250804]民国庚辰本[3/33]P379
修订参考：[]
```

自往聖昔賢著訓陳謨，罔非以綱常倫教之重，敦風俗、厚民彝，垂型百世者也。余思則古稱先，雖足曠百世而相感，然與其稽古行誼，又不如與今之長者聚處，足以敦風俗、厚民彝，垂型百世爲較易也。長者謂誰？吾得之陳翁諱維藩，字思鎮，號定宇者近是。

翁父德徵公，秉性醇良，節儉正直，時稱前輩典型；母邊氏，賢淑有志節。生翁五昆季，皆錚錚人傑，有馬氏五常風，而翁即最良之白眉乎？翁生而頴悟，雖不能含今茹古、咀英嚼華，但氣融沆瀣，心絕塵埃。咳吐儻來軒冕，杖藜歸去田園，脂膏莫潤，圭玉無瑕。雖職非羊刺史，而廉潔不阿，殆其似之。

且天性孝友，奉兩尊人，深愛誠篤，晨昏不少怠；其敬伯仲，情誼愷摯，不啻玉昆金友。義合親朋，志言翔洽，無愧耐久忘年。平居無疾言遽色，人或以橫逆加之，漫不與校，唾面自乾，婁師德不得耑其有美。所謂「晚食當肉，無事爲貴」，不求於世，不忤於物，浩蕩天地之間，心不怵惕之驚者也。

明季邑令譚公，奇翁之品，欽翁之德，尊翁之齒，舉鄉飲賓耆之典，揖讓黌宮，士民咸爲欣慕。暨本朝定鼎，邑父母韓侯復舉爵豆而重賁焉。夫孰非德之所致者？今翁花甲重新二十六矣，壺中日月猶長，會須學榮啓期鼓琴而歌三樂也。

方其慶集一堂，不惟三丈夫子元謨、元築、元輔皆品行端方，斑斕膝下；而且孫枝茂植，盡爲似續之允，列鳳毛、序麟趾，蔚蔚然三代人文，真天倫樂事哉！孟夫子謂「聖人不過盡人倫之至」，而公其盡之。雖曰今之長者，其即古之行誼歟？

余愧弗文，然君子立言，順天揚善，欲爲叔季敦風俗、厚民彝，垂型百世，微公其誰與歸？因樂爲之序。

順治十四年丁酉仲冬旣望
眷晚生虞邦璵頓首拜撰
