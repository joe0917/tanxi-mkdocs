# 祈山承六百七十五茂川公序
```
题：[]眷小姪邑庠生虞邦暹頓首拜撰
峕：[]康熙三十四年乙丑暮春月
初始点校：[20250804]民国庚辰本[3/33]P378
修订参考：[]
```

余乙丑春，别業祈山之下。花木敷榮，禽聲睍睆，絃誦之餘，或登高而長眺，或覽勝以舒懷。見夫山水之環繞而流峙者，檀溪陳氏爲足壯觀焉。顧川岳鍾靈，代有賢者，徘徊久之。偶値林叟，顧余而言曰：「昔有陳公諱尚經，字德大，别號茂川者，以忠厚醇謹稱於鄉邑，有高人達士遺風。」余詢之，乃備語以巔末：

公配邵氏，生二子：長克琳，次克瑤；繼配賈氏，生一子克珪，咸恂恂乎美士也。奈昊天不弔，長君不以壽終。次君克嫻庭訓，而孝謹著聞；幼君品行端方，聲稱藉藉，爲士林所矜式。然此諒所共曉，吾更知公之事親也，能愉色而婉容；其接鄉黨也，能溫潤而柔栗；其若居家、好客、戚與姻戚也，能以禮以仁，又殷勤而肫切。

且公之繼配，係北直遵化縣賈都堂之次女，與范相國爲連襟，頻遣使請公。公偕幼君至京都者二，相與盤桓數載，人皆嘖嘖以爲奇遇。而公視富貴漠然，不足以動其心。後抵家，邑侯范公往謁其門不啻再四，公亦坦然不以爲意。以視夫世之役役榮名，而誇耀成風者，相去徑庭矣。

及晚年好靜，足跡不入城市，惟課子讀、督奴耕。每際佳會良辰，或與二三知己把酒臨風，笑傲煙霞以自適其天真，不復顧人間事矣。其與古之高人達士寄跡林泉者，何多讓焉？於是鄉邑益推重之。戊申冬，陞任毛公遂舉鄉飲，額匾旌獎。享年七十而終。

語罷，攜杖竟去。是夜晴空雲歛，月出東山，幼君楚瑜邀予過飲，言論之閒，無不與林叟相符。予於是嘆公之爲人未易多覯，向非林叟之見聞日習，無以熟悉；夫公非公之德行夙嫻，亦無以見諒於林叟也。林叟未詳其姓名，殆亦有德而隱之流亞歟？

余雖未及見公，聞公之行，如見公焉。是誠川嶽之所鍾靈，而挺生抑亦忠厚醇謹之報有不爽者也。將見公之子若孫，擴前業而丕振家聲，□□乎未有艾者，未始不於是以垂裕於無窮也。今年公之諸孫問字於余，因述林叟之言，乃援筆而爲之序。

康熙三十四年乙丑暮春月
眷小姪邑庠生虞邦暹頓首拜撰
