# 會龍承三百十五可遠公序
```
题：[]孫壻鍾元薦頓首拜撰
峕：[15修]順治十五年嵗次戊戌三陽月
初始点校：[20250804]民国庚辰本[3/33]P377
修订参考：[]
```

太翁陳公諱可遠，字德毅，號仰懷。公自九嵗而曾太翁懷石公已逝，仲太翁德忠公尚止三月。曾太母周氏安人以冷玉之操、淑愼之徽，撫太翁伯仲，嫓隆孟母之多劬，紹休序姜之無逸。而太翁之事高堂也，承懽而寢興勿怠；其友同氣也，敬愛而塤篪愈篤。

太母周氏安人毓二麟：長諱用奇，雖不入泮水，寶巳駕美商山；次諱用韶，聰穎天亶，潛心書史，曳裾彤階原無足難者，第意在鴻儀，姑爾塵封緗軸，遂身任太翁都長之勞，心體太翁拮据之瘁，躬居梓里，孝友親睦，罔勿誠篤。即經營木植，而仁稱義頌，遍揚杭越，此繼美於太翁，而太翁之美益彰也。

繼太母周氏安人育四麟：諱用彥、用靖、用章、用端，皆以傑出超羣，蔚然人望。况蘭枝之茂，抑且更繁。點額景福之介，固巳然矣。至如太翁之懿行美績，不能殫述其宏偉，而遠邇欽仰者，惟積陰德之事爲最。再者砌路修橋、捨棺施履、夷險阻而濟窮民，此皆發於心性之自然，初非覬福於天而爲之。

抑知天眷惟殷，隆報之見於當身者不一而足，疆畞增廓，堂構聿新，家徵豫順之休，躬享康樂之祉。由是鄉耆推以都長，邑侯舉以公正。使其遐齡永享，而惠愛之及人，不更有盛焉者乎？然壽止六甲而終，而懿範流芳，燕翼是貽，儼然有關睢麟趾之風。即綘老之年，自有不能與之矜勝者，彼世俗之子，亦安能幾其萬一耶？

薦以蔚菲寒微，得叨次，嗣君外父諱用韶，字思舜，號章漢公者之恩。實惟太翁洪鈞大造之德，尤寤弗諼者也，敢不追維生平實蹟，詳列悉著，銘鏤簡冊，昭垂奕禩哉？謹序。

順治十五年嵗次戊戌三陽月
孫壻鍾元薦頓首拜撰
