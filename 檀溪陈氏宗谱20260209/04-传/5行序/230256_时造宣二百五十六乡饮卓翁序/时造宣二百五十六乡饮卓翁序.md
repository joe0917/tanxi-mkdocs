# 時造宣二百五十六鄉飲卓翁序
```
题：[]眷小弟府庠虞調公頓首拜撰
峕：[19修]雍正七年己酉荷月榖旦
初始点校：[20250804]民国庚辰本[3/33]P382
修订参考：[]
```

陳子瞻淇，英年俊偉，學業超羣，與余季子瑞驥文字相知。驥不自揣，儼赴西席，時歸省因相告曰：「其地秀竹茂林，環山帶水，有古道君子焉，即瞻淇尊翁諱之端，字永充，號卓翁者是已。」余欣然曰：「陳君昔年曾幸識生荆平膾炙人口，固知之素矣。」

翁古心質貌，行事端方。居家孝友，處世謙恭，舉動必循規矩，言論不敢虛誕。

康熙辛丑年間，奇旱，恻焉心傷，發粟蠲賑，鄉人賴之。宅有婚娶不逮者，力爲贊成，俾有室有家，翁之賜也。鄉鄰紛難，均爲排解，綽有魯仲連風。

晚年怡情山水，課讀督耕，無有虛日，而家業愈豐。今七十有一矣，壽彌高，德彌邵，邦之典型，鄉之儀表，於翁是望。

去歲十月朔，邑侯秦仰翁德望，延翁鄉飲，以光賓席，父老子弟共欽其德輝。所稱古道君子，豈虛語哉？

大凡積厚者流遠。吾知瞻淇大器晚成，蜚聲藝苑，直指顧間耳。翁家君早世，遺一孫忠厚樸實；將孫又生孫，瞻洪三子聰穎異常，鵲起而玉立，翁之娛老正無窮矣。

時方夏季，翁族譜事將竣，余慕其爲人，因季之子告，以不文爲翁序。至將來德業，又俟後之君子補筆云。

雍正七年己酉荷月榖旦
眷小弟府庠虞調公頓首拜撰
