# 祈山恩三百三十七澹如公序
```
题：[]眷小姪邑庠歲貢虞邦暹頓首拜撰
峕：[16修]康熙廿四年乙丑春月
初始点校：[20250804]民国庚辰本[3/33]P380
修订参考：[]
```
（原文题目勘误“恩三百三十七”，实为“恩三百六十七”）

余方幼讀書時，先君嘗示余曰：「讀書則人敬之，積善則鬼神敬之。此二語汝當終身佩服而勿失。何則？夫讀書可以光身，而積善可以裕後也。」余以爲斯言其㫖，而求其行此者之難其人也。

先君曰：
「與汝言古人則遠而難稽，言今人則近而可法者，未有如同庠檀溪陳友諱克諤，字思輝，號澹如其人也。乃與吾交善，資敏而好學不怠，性醇而樹德務滋。

髫年失怙，克自振援，奮志舉業，不以素封累其心。而華飾之風、持籌鑽核之事，掉頭不屑。好文史，愛恬靜，一切俗人罕得見其面。乙未遊庠，足跡不履公庭。生平惟道義自矢，富貴不淫，取與不苟。其與古之耕莘樂道而囂囂自得者，不是過矣。故文章品行，蔚有聲望，而士林咸矜式焉。

不寧惟是，
其事母氏，承歡膝下，而定省之節克敦；
其處兄弟，和樂一堂，而友恭之誼彌第；
其交友與居家以及待姻戚，然諾不欺，恩義交摯，而謙和肫切之情未嘗少懈。至若周急澤枯，恩每施於不報；爲善之心，不利而勉，無畏而强。真卓爾不羣，一時標的也已，謂非讀書積善之模範而可法者乎？」

先君與余言如是，予嘗記憶之，景慕其高風，恨晚不及親炙焉。

乙丑春，別業檀溪，雖先生往矣，而有不與之俱往者。嘗訪其俗時，有橫經者或頌於口，負耒者或歌於野；更有廬其舍、農其田而沐其德澤者，至今嘖嘖稱道不衰。

噫！先生之流風且若是，在當日宜錫以遐齡而綏夫福履。無何昊天不弔，享年五十有五而終。蓋天之所以靳於先生者，必大昌厥後也。

先生元配趙氏，生一子曰元燦，而孝友益敦；繼娶柳氏，生二子曰元炳、元煜。意氣千古，倜儻不覇爲閭里所推重。要非先生之積善，不克臻此。將見蘭蕋森森，鳳毛秩秩，而未有艾也。時修陳氏宗譜，傳文無有一言及先生者，予於是序之，以見先君之言與先生之行並垂不朽云耳。

康熙廿四年乙丑春月
眷小姪邑庠歲貢虞邦暹頓首拜撰
