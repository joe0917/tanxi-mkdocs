# 祈山延一百九十九平階公暨西園公合傳[[陈宗泰]]
```
题：[]受業從姪邑廩生其善頓首拜撰
峕：[31修]光緒庚辰孟夏之月
初始点校：[20250806]民国庚辰本[3/33]P389
修订参考：[]
```

公諱宗泰，字魯瞻，平階其號也，行延一百九十九，廉三百四十三榮登公之長子。

公自幼讀書，穎悟過人，年十七遂遊郡庠，逾弱冠食廪餼。歲科二試，慣列高等，名重一時。精舉子業，鏖戰棘闈，房薦堂備者數次，甚至有明日放榜、今日額滿見遺之事，良可惜也。

平生捐棄世事，惟以陶成後學爲己任，東及暨陽，北達桐邑，咸負笈相從。成大成小，沾化雨者，指不勝屈。故雖不遂科名，而遐邇蒙其教澤，其有功於世非淺鮮也。

年週花甲，錄取恩貢生。晚來愛遊山水，徜徉林下以樂餘年，壽符古稀。子一，諱英梅，考諱靈翰，諱文苑，别號西園，即善受業先生也，耳提面命十有餘年。迄今稍識之無者，皆先生之惠，善故知之最悉。

先生恪遵庭訓，克紹箕裘，入縣庠，補廩膳員，亦不識人間塵俗事，手不釋卷，沉潛入理，披閱經史，不知東方之既白。以故學貫今古，淹博過人。所恨者，鄉試三膺鶚薦而不售，抑何其文行之深純似先人，而功名之阻抑亦似先人也。

事親孝，肅然起敬，歷久不渝；至待人則亦有甚厚者。嘗見蒲陽張某，因妻爲先生家育子，託借百有餘金以求生理，約至年終奉趙。逾期不償，轉約來春貨物出售償納。其所業生意必過先生門，爲先生謀者咸謂：「將伊貨物傭人一阻，便可蚨歸故主。」先生曰：「伊之貨物，命在其中。吾爲其獲，伊之存亡未可卜也。且彼縱無恙，而傭人多費銀錢，彼之債愈不得償矣。吾不忍爲，姑待來春可也。」厥後此錢竟以負終，而先生於各處債主，悉將己田出售以償，家計遂因之而蹙。人謂先生愚，吾謂先生厚矣。蓋世人多以機械勝，而先生獨以仁慈勝。其爲張某欺者，亦因伊妻育子之情，夫豈其愚者哉？然則舉此一事，而先生存心之厚可知也。

先生教育後學，成材者甚夥。晚著《周易象義通鑑》一冊，已行於世；又有《孫子註解》《金剛經辨》等書。惜乎先生命途多舛，不特富貴兩窮，即生一子柏梁，秉質愚魯，不能紹業，而又天折無子。噫！冥漠正未可知，以先生者而無後，安能不以伯道之無兒搔首而問青天哉？

善留意久之，欲爲柏梁承繼一子，以續先生後。而當時親房明揚、遐昌二叔諸名下，尚未有昭穆相當者，是又所望諸後日之有心於先生者矣。
