# 祈山允文公暨安人王氏合傳
```
题：[]歲貢士海鹽學訓導盤洲周璠頓首拜撰
峕：[22修]乾隆五十二年歲次丁未孟冬
初始点校：[20250806]民国庚辰本[3/33]P386
修订参考：[]
```

府君諱元毓，字君靈，號允文，譜行惠一千一百三十有八，係恩九百九十一[[陈克珪|逸樵公]]之幼子也。

府君生而謹慤，不表暴以炫俗，湻實孝友，忳如也。既逸庠，亦不興時輩競進取。

安人中余王氏，謹婦道，語不踰閫，生一子啟端，甫四嵗而允文君卒。又二年，孤兒患痘瘡甚，陽藥不得下嚥，氣息奄奄，醫者束手無策。安人乃仰天跪告曰：「倘氏矢心有二，與伊父或有遺行，神則竟絕其嗣。」語畢，悶絕於地，良久乃甦，而病者已能言矣。旁觀咸驚異，有嘆息泣下者。

先是康熙三十四年，嵗歉收，里門或不得舉火，而公家素節儉，餘粟陳因，則盡出所有，與兄元惠先期告無食者，設廠宗祠，始辰終酉，戶絡繹不絕，人給粟如干傾囷凛乃己，蓋遵母胡氏太安人之命也。

且丙寅之秋，子適外出，以鄰竈之失火，將燬其堂室矣。安人知勢難撲滅，不顧身家，與媳張氏、孫光大，冐燄突入，盡抱先祖之神主以歸。所居去火不數武，能安然無恙者，又何非安人之孝感哉？

安人學於舅姑，既經紀其家，一於仁厚，每以澆薄爲後人誡。性柔順，慈以畜下，惟勵學則嚴，學□者周獎以荻教，遺風不誣也。孫光大、曾孫祖鴻、三閏，識者謂遲速不可知，而善無不報，有明証矣。

論曰：

余與光大相友善，而祖鴻余從姪壻也，三閏尚幼，頭角見矣。今去安人告天之日且數十年，而其家聲未大顯於世，將神都不省記耶？天道遠，人道邇，當危急之際在片刻之間，遠者且捷於影響。非然而爲善者其懼，故稍示稍之神奇，其亦常也。繼而善日積，慶日餘，紓緩從容，兩不相謀，知其必有合也。然則善人之子若孫，勉乎哉！積以俟其餘耳。

書於陳氏於譜，以爲將來勸。

乾隆五十二年歲次丁未孟冬
