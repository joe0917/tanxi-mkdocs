# 祈山聰二千九十八登仕公暨孺人戴氏合傳
```
题：[]姻弟郡庠生戴供頓首拜撰
峕：[29修]咸豐八年嵗次戊午孟夏之月
初始点校：[20250806]民国庚辰本[3/33]P387
修订参考：[]
```

府君諱祖瀛，又諱錫疇，登仕其字也。

先世代有聞人，曾祖允文公持躬孝友，早年遊庠；大父鄕飲介賓啟端公，樂善好施，稱爲一鄉善士；父靜齋公，遂學中余，王東墳先生甚器重之，因屢試不售，循例入太學。子四，府君居其次，生而韶秀，稍長儀容都雅，誠如史公之狀畱侯者。

周盤洲先生早以頭角見稱，後從其家平階先生遊，秉姿捷給，讀書不數過輒成誦。至於與談經義，倘有未達，不憚再三煩瀆，及其旣悟，則旁通曲暢，如冰斯渙而無不流也，如雪斯融而無不化也。嘉慶癸酉科試，周宗師臨郡援取入泮，惜未歲試，竟以瘵疾亡，時府君二子俱未成立。

孺人戴氏，予堂伯邑庠生在廷公女，年未四旬，抱尸而哭曰：「天乎天乎！汝竟棄予而去乎？汝卽忍予棄，其忽棄汝二子乎？」一號悶絕於地，因救得甦。旣終喪，嘗稱未亡人，時時指戒二子曰：「吾六歲喪母，賴父教養；二十四歲來歸陳氏，全賴爾父樹立家聲。而今已矣，爾等須勤耕讀，無廢先人之業，庶幾死者亦稍慰焉。」

按孺人温柔誠篤，不苟笑言，不妄舉止，奉舅姑以孝，處妯娌以和，見叔伯以敬，臨奴僕以嚴。至攝理家政，一切喪祭、婚嫁，罔不恪守舊規，井井有條。奈時運坎坷，迭被鄰火殃及，幸賴先人緒業，加以孺人勤儉，復舊仍址，拓其門閭，雖無多藏，亦不甚缺需。若孺人者，眞足爲府君之內助矣。

府君生於乾隆甲辰閏三月初五日子時，卒於嘉慶乙亥六月廿五日巳時，年三十二歲。孺人生於乾隆丙申八月廿七日巳時，卒於道光丙午五月廿二日申時，享壽七十一歲。子二：長榮績，次榮維早世。孫一，兆基。孫女六，長適予胞姪郡庠生名贊襄，餘皆擇配遣嫁。

府君以勤學好問，博取弟子員；孺人以節孝得享遐齡，亦盛事也。今其子績欲表揚先人潛德，適逢修譜，以予屬在姻親，稔其父母行事性迹，向予乞傳以貽諸後人。予不揣固陋，略舉所知，以傳其大概焉。

咸豐八年嵗次戊午孟夏之月

姻弟郡庠生戴供頓首拜撰
