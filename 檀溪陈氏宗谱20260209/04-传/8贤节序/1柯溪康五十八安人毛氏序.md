# 柯溪康五十八安人毛氏序
```
题：[]府庠生虞調公頓首拜撰
峕：[19修]雍正七年己酉孟秋月穀旦
初始点校：[20260824]民国庚辰本[3/33]P417
修订参考：[]
```

嘗讀詩至《斯干》之什，有曰「無非無儀，惟酒食是議」，蓋婦人以無才為有德。然不知有德者必有才，求其德與才兼備，而矢志靡他，壽考令終者，求之晚近，千百中不一覯也。陳君諱惟康，字用寧，安人毛氏，殆其倫歟？

陳君忠厚樸訥，兼有才能，生四子：長有興，次有發（出繼惟明為嗣），三有雲，幼有隆，字汝靜，方在懷抱，而陳君謝世。是時安人三十有二，煢煢孑立，三子俱未成立。雖家食有餘，非劬勞苦守，安能有成？陳君與先大父相契莫逆，先大人暨叔父諸昆時往來其家。陳君捐館之日，安人哀甚。先大人指汝靜曰：「此子眉目清秀，體貌魁梧，長必光大先緒，安人其毋哀。」汝靜年二十外，果卓卓自異，與兩兄黽勉同心。

安人董理家政，慶盈寧謐，歌樂業，棟宇聿新，美輪美奐，正屋抱三十餘間。而後兄弟分爨，安人輪膳諸子，諸婦朝夕承歡，尤喜孫枝繞膝。安人自撥膳田二石零，以作茶菓之資；又新塘一日，取魚以供燕飲。沒則三房輪管，以作祭祀。誠巾幗中丈夫也。其德、其才、其節、其壽，洵晚近所罕覯者。是為序。

雍正七年己酉孟秋月穀旦
府庠生虞調公頓首拜撰
