# 會龍惠三百四十三邊氏太孺人序
```
题：[]暨陽邑庠生王鑑拜撰
峕：[17修]康熙四十年辛巳季秋月
初始点校：[]
修订参考：[]
```

聞之《易》曰：夫夫婦婦，而家道正。如天主於施，而無資生者，何藉於資始？地主於受，而無大生者，何藉於廣生？此天地有各不相離者若是乎？成德而立業者，皆賴賢內助以成之也。故女德之可風者，不可不傳，而傳之不可不詳也。吾於陳宅太孺人之知實矣。

生於邊之名門，言笑不苟，不出戶限，孝事父母，敬事叔伯。其歸於陳之望族也，三從有道，四德無虧。移其孝事父母者，以孝舅姑；移其敬事叔伯者，以敬夫子。與公琴瑟數十年，並無怨言疾色，信乎克相家政，初無勤始怠終。由是箕裘之業裕如矣。凡此者，何莫非汝能太翁之德厚，而得此賢內助也？

誰知天命失祐，公未至知命之年，已仙逝矣。噫！公雖沒，而公之德業不與之俱泯，其誰信之？凡公未了之事、未竟之志，皆賴太孺人以成全之也。篤生賢豪有七，皆成德之人，而四嗣之芬，尤超於兄弟之外。弱冠採芹，文章名世，孰非太母之規範，令德而養成此賢嗣也？

予屬至戚，備悉巔末，敢俚言以序。

康熙四十年辛巳季秋月  
暨陽邑庠生王鑑拜撰
