# 會龍宣三百十一節婦周氏安人序
```
题：[]年家眷侍教生朱鶴鳴頓首拜撰
峕：[19修]雍正七年歲次己酉季秋吉旦
初始点校：[20260824]民国庚辰本[3/33]P418
修订参考：[]
```

事之有關於風化者，莫大於節孝，故君子樂表章之，以為世道人心勸。節婦陳周氏，係盤溪周氏之女，幼適陳之薇為室。入門即修婦道，事姑以孝聞。一切中饋烹餁、澣灌緘紉之勞，皆身任之，不以累姑。不幸夫遘疾，奉侍湯藥，衣不解帶者數月。是時節婦年纔二十三歲，生子以光，甫六十四日，呱呱在抱，而夫已逝世矣。節婦撫棺號慟，水漿不入口者數日，濱於死者屢矣。繼乃嘆曰：「氏死則老姑何所倚？孤子何所恃？是未可以死也。」遂忍淚力持家政。其事姑也，以婦道而兼子道；其育子也，以母道而兼父道。持家一秉禮法，內外肅然。歷今四十餘年，苦節之貞，始終如一。今其子且生三孫矣，家日充裕，安享子孫之養，豈非女子中偉丈夫哉？方今國家崇獎節孝，年例符合者，許有司不時上聞，建坊旌表。如節婦者，真不愧此盛典者也。予故因伊子之請，而為文以表之，俾觀風化者有所採焉。

雍正七年歲次己酉季秋吉旦
丙午科浙江鄉試中式禮記經元，年家眷侍教生朱鶴鳴頓首拜撰
