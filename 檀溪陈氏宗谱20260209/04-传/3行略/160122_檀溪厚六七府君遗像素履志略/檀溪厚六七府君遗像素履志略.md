# [祈山]檀溪厚六七府君遺像素屨誌略[[陈宗贞]]
```
题：[]宗礽孫元庠盥手拜述
峕：[16修]康熙二十三年嵗次甲子仲夏之吉
初始点校：[20250423]民国庚辰本[3/33]P366
修订参考：[]
```

按，府君乃湻廿六公之幼子，而[[陈宗元|厚四八府君]]之親弟也。公生而岐嶷，長而頴悟。凡家庭瑣務，一聽長兄主維，而公惟日與詩書翰墨相周旋。登高能賦，遇物知素，卽古所謂博極羣書者，無以過也。

生平著作有詩文数卷，目之曰《依本葫蘆》，恆爲文士之所傳誦。其命名意云，尼父尚不敢自任作者，今此之名庶幾傳述先賢之緒餘耳，是以集句詩多屬和韻，而機杼自成一家，類多高出前人。奈遭甲寅兵燹，頗多散失。

猶憶故老傳公之逸事：公一日醉遊杭之天龍寺，乘興題詩於壁，云：

愛向天龍深處遊，眼前景致果清幽，
清泉流出石根底，倦鶴飛還松樹頭。
坐久不知紅日墜，話長空被白雲畱，
（再）登實殿重叅禮，惹得香煙兩袖浮。

適有浙江廵按御史錢公亦至此寺拈香，見新題墨跡未乾，諷詠良久，急令人訪公求敎，而公篤意婉辭，終不往見。人問其故，則曰：“吾非應詩賦取士科，安能向貴介前鞠躬屈折耶”。其養高自重有如此者，故雖無書不覽，而絕意仕進，止課長子魁百廿五諱廷讜[[陈廷直]]者，青年入泮，蜚聲黌序[^1]。祈山遊庠者自此始。

噫！若六七公者，開檀溪文學之祖，擅浦北辭賦之宗。非所謂高尚其志、不事王侯者乎？

重興惠雲禪寺，著有碑記，出經入史，屢屢膾炙人口，至今不絕也。至若堂搆聿新，腴疇式廓，特其生平之未事耳，烏足以揄揚其萬一哉？

公諱祐，字宗貞，號拙翁，行厚六十七，生子六人，孫枝數十，至曾元不下數百。每嵗展墓拜壽之時，男女紛紛，咸謂公之陰德所致也。

生成化戊子（1468）三月初三日，卒嘉靖己亥（1539）十一月初三日，享壽七十有二，葬仙人獻掌形。廕生賢達，多不古所稱“地靈人傑”，洵不誣矣。

後生晚學不敢贅一語、贊一辭，惟以其聞於先人之日、授最眞者，係公之素履實行，誌之於遺容之上，以深如在之誠云。

康熙二十三年嵗次甲子仲夏之吉

宗仍（礽）孫元庠盥手拜述

[^1]: 清·沈欽文《雪谿詩鈔》序中有“子維崧能讀父書，蜚聲黌序”。
