# 祈山惠二百廿七汝列翁行畧
```
题：[]姪壻張位別號岱峯拜撰
峕：[16修]康熙二十三年嵗次甲子仲冬月吉旦
初始点校：[20250801]民国庚辰本[3/33]P367
修订参考：[]
```

公字汝列者，賦性純樸，處世仁柔。一生止知勤耕節用，式廓祖基，更有光前裕後之業焉。又見厚待親朋，禮重賢士，村中尤其特著者也。余因蔦蘿[^1]之屬，妄作俚句為之序曰：

予觀為人，其仁慈寬厚，悠悠然有無懷葛天之風也。與世無爭，與物無忤，處心罔殘刻而見純良之雅。為人排難，為人解紛，處眾尚調和而見謙沖之度。遇親朋，禮賢士，慇慇致敬，未嘗不始終隆盛。

嗟嗟公念祖父創業之艱，登仙杏邈莫云覯矣。每飲必祭，而加敬然。家業之久而彌昌，遠而彌光者，皆由主伯亞旋，好樂無荒。應歌良士蹶蹶勿遑，二老齊眉，士女交警兮。當呌雞鳴昧旦之賢良，頷領分廿，斑斕繞膝兮。宜頌螽斯振振之篇章。

噫！斯何業也，胡為乎盛哉？良由中懷仁善，勤儉治家之所致也。是為序。

康熙二十三年嵗次甲子仲冬月吉旦

姪壻張位別號岱峯拜撰

[^1]: 蔦蘿：出自“《詩》「蔦與女蘿。」”
