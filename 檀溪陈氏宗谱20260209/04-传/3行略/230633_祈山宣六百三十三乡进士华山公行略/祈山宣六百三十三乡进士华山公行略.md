# 祈山宣六百三十三鄉進士華山公行畧
```
题：[]年家姻姪王宇淸頓首拜稿。
峕：[21修]乾隆廿八年昭陽協洽之嵗，元英揉滁月朔旦之吉。
初始点校：[20250803]民国庚辰本[3/33]P369
修订参考：[]
```

公諱啓承，字心烈，華山號也，行宣六百三十三。父君餘公，母朱氏安人。公生時，父己四十二春秋矣，鍾愛異常。見公童而頴異，長而孝謹，尤愛之。而公之事二人也，無事不以父母爲心。故雖席素豐，恪勤舉業，弱冠遊庠，志切顯揚。無何，二老先後後世，終鲜兄弟，乏將伯之助，惴惴焉懼不克守祖父業。廼援例鄉貢，而督理家政持身素勤儉，凡內外錢榖以及奉先貽後【跳转至p371】諸鉅細務，莫不遵前人遺規，未嘗改父之政。乃不十餘年間，而手創之業數倍於前。浦俗以稅至千石稱富翁，公殆當之而無愧焉。

公郎五，孫枝振振，長幼同爨者近百指。乃建廳房一座於祖廳之右以居家衆，志在紹先，而堂額懸曰"佑啟"，更曉然於所燕翼者咸正無缺矣。且建書室，置賢產，延請名師益友，俾成人莫不有德，而小子咸樂有造。迄今登其堂，遊其齋，接其人，才濟楚，斯文彬郁羣體，其子若孫有以光於前，何莫非公之遺澤有以裕於後也。

我共奉先也，不唯乃父多立祭產以裕百世蒸嘗，更念吾父出繼次祖，生祖不得與祭，復另置腴田俾子孫世世奉祀。仁率親，義率祖，爲人後而祭及本生，公不忍忘其所自出，錫類以行其義也。

其於宗族也，貧儒資其膏火，困窮周其衣食，且捐田於宗祠以給老人之胙，引年也且廣神惠焉。在昔康熙六十年間，歲大祲，鄉地嗷嗷，公出米穀多方哺之，不計所費。至郡邑間有大興作、大工役，必待眾擎而後舉者，每樂輸以囊之。若里左之修圯濟涉以利行人，本家之義塚祊田波及亡僕，則又餘潤之流於近河者與。

公一生好行其惠，而自奉質素，豈不取之裕如哉？蓋其性然也。德配張氏安人，在城邑庠張德甲公女，原任寧都縣知縣紹開公孫女，生有賢德。其來嬪也，孝於公姑，慈於卑幼，訓子有方，持躬躬斁。公之昌大門閭，蕃蔭子孫，安人內助實多勞勩焉。

公生康熙戊午年七月初四日[^1]丑時，卒乾隆癸亥年閏四月初二日酉時，壽六十六歲。安人生康熙壬子年四月十六日酉時，卒乾隆庚午年十一月十七日辰時，壽七十九歲。公曾卜吉兆於勝峯以厝二老，及考終易簀，囑附葬墓側，以終始吾膝下之志，因及安人合祔焉。

舉丈夫子五：鄕貢三，太學二。女二：長適盤溪邑庠潘啓兆，幼適在城邑庠張守濤。孫吏部候選者一，太學入泮者連鑣而進，其餘勤習舉業，皆欲攀鱗傅翼焉。孫女多人，曾孫數十餘，長在庠，稍長者能業儒，餘俱幼。欲知後勁，正方興而未艾也。至若元孫，此更衆響之先聲，而茂林之始秀者與。公始一人之身，而孙枝百人，冠裳四世，莫不席豐履厚，爭自樹立以顯其先。家聲之盛，冠於鄉邑。

公之父母中年得公，固冀其昌後也；公事事心乎父母，亦冀其昌後也。而於斯爲盛，其昔念曾到此歟？嗚呼！公及公之父母，亦可念笑於九天也哉！

癸未冬，公孫等來請公傳並像贊時修家乘也，清以固陋且老昏謝不敏，羣賢固請不獲辭。念公在時，曾請謁焉，知公之行美不勝書。柰（奈）馬齒加長病健忘紀，所能憶如右，餘俟知公而能文者，是爲行略綴以像贊。

贊曰：繄，公之貌温而易，繄，公之行湻而懿，繄，公之業創而繼。陌廣棟隆，善述其事；燕子詒孫，善繼其志。心父母心，施勤衆濟。夫是以嗣公之後者某不鵬飛而鵲起，將拜公之祀者世世雲祊，莫不雍雍而棣棣。

乾隆廿八年昭陽協洽之嵗，元英揉滁月朔旦之吉。

己酉科拔貢生，奉特簡山西州縣試用，歷署河津縣、芮城縣、趙城縣、靈石縣知縣，年家姻姪王宇淸頓首拜稿。

[^1]: 行传（民国庚辰本[17/33]p252记录为七月十四。
