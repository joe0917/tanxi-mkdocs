# 祈山惠三百二十三君餘先生記略
```
题：[]桐江歲貢眷晚生何思麟頓首拜撰
峕：[18修]康熙五十四年旃蒙協洛暮春之朔
初始点校：[20250801]民国庚辰本[3/33]P368
修订参考：[]
```

甲午之春，陳氏纂輯家乘，于既僣筆而為之敘矣。因詢及心緯兄曾祖父叔伯三世以來皆盛德所鍾，何獨無傳？豈後人不欲頌述前人耶？抑前人不欲後人揄揚耶？

心緯兄曰：「然。余自束髮受書，先大人輒以過情聲聞為戒，諸伯父平居訓子姪輩亦然。蓋務實不務名，由來已久，非不欲傳，實不敢傳也。」

予聞之喟然曰：「異哉！諸先達卓犖之見，非流俗所可並也。雖然，予不乃見諸先達之令範矣。若令伯父君餘先生，不嘗親炙其德乎？倘不能修一言以志屋烏之愛，則歉實甚。」

先生自少失恃怙，與四兄以猶子繼同伯母。愛護調恤，喜得所依。迨不踰年而繼母奄逝，四兄又不善經理，家產亦由是日消。兼值戊子兵燹，舉家逃竄，年未及冠，備嘗艱苦，而剛方自立，初不欲受人憐也。

適術士有金蘭谷者，決滎枯休咎，頗稱神鑑，嘗以石季重器之。

厥後營立家計，更建爽塏以為創業基址，宅旁建學舍十餘楹，池魚花木，意趣自佳。賴室人義泉朱氏實左右之，慇懃家計，甘苦共嘗，誠閨閣中賢友也。誕子女各一，女適盤溪庠生周子，甫弱冠補弟子員，娶龍溪尚開公孫女為媳，恭儉克孝，足嗣徽音。

前以千鈞一縷，未免以煢煢孑立為念，迄今而孫枝玉立者已五人矣。乃為亡室朱氏卜吉兆於勝峯之南，生塋附焉，洵陶氏塚異日發祥之券也。

比年以來，資產大倍於昔，子孫衣食自有餘饒。爰定賢產貳百稱，以獎勵後進，祭產數亦如之。又捐大宗祠田三十三秤於祠側，稍充春秋二祀，使合族紳衿暨執事永遠給胙，以鼓舞後來。今年將耄耋，惟日扶笻杖與親朋故舊共樂餘年，尚何他求哉？

辛卯秋，與心緯兄同赴試浙闈，臨行餞贈，禮意剴切，將有厚望焉。無何，兩人俱已挫敗，而先生亦於八月之望升遐矣，享壽七十有五。聞訃不勝悲慟。

且曾記先生言，少時讀書未能卒業，而談及道義節俠之事，辨論具有理解，霏霏之玉屑猶縈繞耳畔也。心緯兄亦應之曰：「誠哉是言！即以伯父之言傳伯父可也。」爰命予握管以記之。
