# 祈山建二百三十六介賓景須公修名紀畧
```
题：[]叔成璧拜撰
峕：[20修]乾隆十二年丁卯仲春之吉
初始点校：[20250803]民国庚辰本[3/33]P372
修订参考：[]
```

從來敦實行者無沽名心，居常匿跡，韜光以聲聞過情爲戒。究之行成名立，有欲掩之而終不能自掩者。

族姪諱光灝，字景須，係宣二百三十二府君耆碩心周公之冢嗣也。自幼與余同受業於令叔心遠先庄之門，共筆硯遊庠。後余數年，生平飭紀敦倫，孝行純篤。

猶憶其尊公年七旬有餘，染痰氣症，君與乃弟諱光頴、光顓左右就養，侍奉湯藥，衣不解帶者三年。其後居喪廬墓，盡禮盡哀，此宗族鄉黨所人人稱孝而無有間言者也。至其尚義輕財，種種樂予好施，他不具論。

乾隆二年，浙省奉閣部憲稽署巡撫都察院事查覆，各州縣人文衆盛者詳請題陞學額，通庠議費正在躊躇間，君之昆季三人踴躍而爭任其事。後雖事不竟成，其慷慨之風有見推於闔邑者矣。

今正舉行鄉飲酒禮，君膺介賓之選，爲閭里榮。一時薦紳先生高其誼，多有贈以詩文者。令嗣祖禮向余問字有年，曾於去歲入泮，因現在修輯家乘，乞言於余以彰乃父姱修。余自揣不文，令取薦紳所贈詩文載之，而乃父訾其聲聞過情，秘不復出。旣已無可奈何，持介賓看語二通以示余。余受而讀之：

縣主揚看得：
介賓陳光灝居家友愛，行己無虧。
言有物而行有恆，端方共凜，
柔不茹而剛不吐，正直羣推，
而且
義濟鄉鄰，惠澤普周於里黨；
急公奉上，輸將不待於追呼。
善俗型方，洵屬人倫之模楷；
維風勵俗，允宜大典之光榮。

府主鄭看得：
介賓陳光灝醇謹可風，端方足式。
旣承先而肯搆，身列黌宮；
亦課子以成名，聲馳泮水。
宜膺介賓之典，用彰懿行之休。

讀竟，笑謂祖禮曰：「二看一字不虛，尊公卽欲逃名，此豈其能自掩乎？」遂援筆書之而授之，因并所撰而紀之。

乾隆十二年丁卯仲春之吉

叔成璧拜撰
