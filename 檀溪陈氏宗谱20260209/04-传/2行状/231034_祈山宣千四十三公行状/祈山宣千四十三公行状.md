# 祈山宣千四十三公行狀[[陈成璧]]
```
题：[]門人從姪歲貢士以肅謹誌
峕：[31修]乾隆二十九年甲申春三月
初始点校：[20250731]民国庚辰本[3/33]-p355
修订参考：[]
```

公諱成璧，字介圭，號商山。弱冠充邑弟子員，不數載補廩膳生。至康熙壬申年出貢，恭逢皇太后萬壽恩詔，各府州縣學歲貢拔作恩貢，故以通省計之，公列第十八名。享壽六十七歲，與安人周氏合葬本都土名馬鞍峧，艮山坤向，墳塋睪[^1]然宏敞者，即公之夜臺也。

公自幼穎異，讀書過目不忘，工文章，的為舉業正宗。自應試以來，司衡輒取高等，領袖羣英者不可數舉。故合郡文人，皆以得交於公為幸。事親至孝，請安視膳，已有古人養志之風。而乾隆丙辰年，我皇上御極，恩賜天下老人八十以上者壽官，給以正八品冠帶。公父惠五百九十六諱元士公實符其例，然無力者多不能沾惠，而公則喜不自勝，慨然曰：「吾日望所以尊親者而不得，今其時矣！」急請於郡守。郡守姓袁諱學謨者，係科第出身，雅愛公之文藝，兼鑑公之孝心，即行申詳，并手書「壽耉（耇gou3）傳經」四字匾額以贈，其為閭里榮何如也！

且公之幼弟光，雙親所鍾愛，而公之所以待之者，一如乎親之所期，其善體親心，則且以友成厥孝焉。處鄉鄰中，亦甚平易近人，而不務本業之徒，望而不敢來前，其使人有所忌憚予如此。

晚年寢處於惠雲山房，四方從遊者益衆。不論敏鈍，一經品題，便成佳士。故南至暨邑，北極桐江，凡學成而名立者，大半公之生徒。所著有《四書講義》數十卷，雖未付梓，而宿儒初學競相抄錄，一時紙貴焉。工草書，巨細俱有龍蛇飛舞之致；尤善審音律，藉以陶寫性情，非如折柳黃荂，徒供俚耳已也。

夫以公之文學德行如是，即僅僅以貢士終，識者當不以科名之成敗論矣。又況明德之後必有達人，長孫紹祖學有成就，倘得雲雨應，當破浪飛騰，豈患不克昌厥後歟？

今當家乘重修之際，肅敢本於親炙者，略書其大槪於譜首，以為砥行立名者勸，而詞之工拙則不之計也。

乾隆二十九年甲申春三月

門人從姪歲貢士以肅謹誌

[^1]: 睪：yi4伺视；侦察
