# 平湖派延二千五十四宗禮公行狀
```
题：[29世/毓1071]前海寗縣知事，從孫景鑾頓首百拜謹撰
峕：[35修]民國十四年元月 日
初始点校：[20260724]民国庚辰本[4/33]P443
修订参考：[]
```

公諱宗禮，字秉周，清太學生也。予曾祖王父丈夫子三，王父居長，公居次。少頴悟，入墊讀書，為羣兒冠。

咸豐辛酉，洪楊起兵討滿，然嗜殺無人道，所過尸橫原野，閭里為墟。予家避亂於桑陰塢，王父乃召集鄉里健兒數千人，斬木揭竿，以平賊為己任。其時公未冠，起謂王父曰：「天下洶洶，未易定也。兄先出，遲我三年，即當從兄於軍旅矣。」詎意疫作，予家死亡相繼，會祖王父及王父同時逝世，公亦罹重疾。乃抱病居喪，竭哀盡禮，如成人。嗣寇退，公乃奉曾祖王母歸居平湖村中。曾祖王母見廬舍蕩然，乃建屋數十楹，鳩工庀材之事，悉公任之。又當兵後，歲荒餓莩遍道，公善承曾祖王母之命，凡里中無告者，解衣衣之，推食食之，活人無筭。

公事母孝，迨曾祖王母病篤，焚香禱天，誓以身代。舉家均為所感，各禱神祇，願分己筭以益之。公天性醇厚，而淡於進取。自納粟入成均，即不復應試。晚年以課徒自娛，間或經商吳越。然重義而輕利，不屑競競錙銖，計較得失，輒為友所負，以喪其鉅資，公之意終豁如也。

光緒壬辰，予年十七，受業於[[虞善扬|虞柳堤]]夫子之門。公導予往，途次具示：「長髮亂後，村中以吾家為最忠厚，亦最吃虧。然喫虧者長存，忠厚畱有餘地步，汝曹其知之。」又見道旁古松丸丸，指之曰：「彼拔地而參天者，非松耶？匠石操斧斤以求棟樑者，舍是莫屬也。蓋有非常之才，必有非常之用，男兒當知所立志。」予皆記之。不意公乃於是歲卒，痛哉！

夫人虞氏讀書明大義，待人慈祥，治家嚴肅。公逝之後，勵志六七年如一日，鄉黨稱之。子三：長時鍾，次時錦，季時誌。女一，適前嘉興縣事張夢奎。至曾孫輩繁名均嶄然露頭角，咸以為盛德之報云。

贊曰：
畸行易見，庸德難能。
俗尚刁詐，而不競不爭；
風成澆薄，而親親仁民。
自非宅心之厚，烏克造詣之純？迄今雲礽雀起，蟄蟄繩繩，或馳譽於梓里，或觀光於燕京。看家聲之一日千里，見天道之報施善人。
