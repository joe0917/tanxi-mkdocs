# 會龍俊五府君行狀
```
题：[]順天府治中張天錫誌
峕：[]洪武甲子四月
初始点校：[20250512]民国庚辰本[3/33]-p337
修订参考：[]
```
公號珪，字禹玉，郡馬雄公之曾孫也。與余交談甚善，誼結忘年。一日先我而歸，余聞訃則匍匐徃（往）弔焉。見其二子友桂、友蘭淚交顏悴，泣告予曰：「我父與叔往還二十餘年，以義氣相孚，繩教二子以詩禮相導。將謂愛日之歡尚未有艾，今罹不幸，徒切終天之恨。吾先君之素行實歷，叔所盡知。茲蓋棺論定，乞書行狀以示後，則不肖含恩無既，而先君亦瞑目於地下矣。」

余聞豈容寢默於言哉？惟公幼經亂離，長逢盛治，不喜華麗，惟事樸素。生平以孝友自持，以和平自率，未嘗與人爭競，人亦無敢犯者。所交皆賢士鴻儒，咸有詩文相接。

其先有太祖諱雄，字茂才者，乃宋趙王崇袍壻也。先以鄉試中式，後選爲郡馬，授襄陽府錄事。每立功德，著聲朝野。兼高星地之術，自造佳城於本里圭坑盤山嶺下，眞鳳起龍盤也，而爲終身之所焉。且慮及世遠年湮，撥田於彼，永作祭產，俾子孫知有祖墓而興思焉。其遺語有曰：「拍田五畞，土名墳口，時當祭掃，子孫世守。」

府君深思及此，又將己置田二十畝以爲助祭之資，此其不忘先德也。臨終戒子曰：「我死後不可作佛事。」教子義方，此其貽慶後裔也。府君生子二人，孫三人，曾孫三人，卒葬拓樹黄大畈金星月角形，此其始終之詳也。書之以應二子之請。

洪武甲子四月
