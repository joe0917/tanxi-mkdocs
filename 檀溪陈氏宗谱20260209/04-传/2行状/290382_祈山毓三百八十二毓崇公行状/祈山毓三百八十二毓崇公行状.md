# 祈山毓三百八十二毓崇公行狀
```
题：[29世/毓1071]族弟前奉化縣知事景鑾謹撰
峕：[34修]中華民國六年六月
初始点校：[20250801]民国庚辰本[3/33]P364
修订参考：[]
```

先生諱毓崇，字桂山，前清名諸生也。嘗從堂兄[[陈其善|敬齋]]先生遊。敬齋先生爲吾里宿儒，每歲授徒數十人，先生爲文有奇氣，輒冠其儕輩。敬齋先生亟稱曰："此必非池中物也。"

先生遊庠後，益勵志劬學，雖當祈寒盛暑時，未嘗離書卷。所居在祈山之麓，山麓有泉環抱如帶，萬木森植，蒼翠依然。先生來往其中，挾策吟哦，谷響相應，如出金石。山中人見之，羣相驚歎，擬爲神【跳轉至p366】俊。詎文章無命，屢應闈試不第。先生慨然曰："吾見祈山上之大木，或選於工師任棟樑之重，或長遺棄於山中爲居民之蔭庇，要之其有功於世則一也，又何必被選之足羨而遺棄之是悲也哉！"先生遂屏絕仕進，潛心於岐伯黃帝之書。不數年學成，出其術以濟世，踵門而丐藥者日必數十人，先生皆如所求以應之，活人無算。

憶鑾甫十五歲時，會黃桂山師設帳祈山，先君子命鑾從學焉。先生與先君子相友善，每當令節晏客，嘗招鑾赴焉。鑾見先生貌癯而清，丰神奕奕，及酒酣耳熱，則議論風生，在席之人皆拍掌稱歎不置。鑾爾時年幼無知，亦不識先生春秋幾何，品詣奚若，惟默歎此老才智洵爲天授而已矣。

先生享壽五十五歲，德配鍾氏。子一文林，字翰卿，鑾總角交也，金衢嚴四府公學畢業生，辛亥光復爲縣議會議員，今任壺江高等小學校校長。孫一，景棠。

中華民國六年六月
族弟前奉化縣知事景鑾謹撰
