# 會龍賢廿八公行狀
```
题：[19世/欽279]從姪九街謹誌
峕：[13修]萬歷三十三年乙巳春月
初始点校：[20250513]民国庚辰本[3/33]P345
修订参考：[]
```

府君諱仕謹，魁三十一公幼子也。天性孝友，器宇宏廓。壯年代父釋罪，備嘗艱苦；晚景鼎新樓宇，貽厥孫謀。鄉里有爭，悉以善言解息；平居無事，喜怒不形於色。

娶一都安人黃氏，賢而內助，勤儉持家，充拓由（田）業。生子三人：長曰九有，邑命保正二十餘年，盜息民安；次曰九德，孳孳向善，樂志邱林；幼曰九珠，聰明天啟，善達堪輿，又能孝思不匱。

衆以同堂高祖湻四公墓側朽木欲伐而分之，公獨語於衆曰：「此即祖宗血食之源也。衆分則散而無再合，併衆而放利，或可久。」於是計値貿金，總權收放，秉公持正。越二年，果有羨餘，遂易祭田三畞，土名瓦窰坵是也。

嗚呼！此公仁孝之蹟，余敢不誌之，以伸公於家庭間哉？

萬歷三十三年乙巳春月
從姪九街謹誌
