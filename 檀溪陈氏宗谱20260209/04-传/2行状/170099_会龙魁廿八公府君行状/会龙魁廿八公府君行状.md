# 會龍魁廿八公府君行狀
```
题：[]賜進士第兵科給事中乙卯解元慈水鄭卿拜撰
峕：[]嘉靖己未夏六月中浣之吉
初始点校：[20250512]民国庚辰本[3/33]-p342
修订参考：[]
```

府君諱淮，字廷淮，厚二公之三子，三節氏之嫡孫也。生平以節氣自持，故號植松處士。生而孝友，志節過人。其治生之勤，無分早晚；囊有餘資，同兄拓基建造廳廡。舉凡家事，以身先勞，不避險阻。代兄當糧長一十八載，盡心體國，公私交贊，屢請鄉飲，堅辭不赴。

生四子：長曰玹，素有大志，撫弟讀書；次曰璠，終日怡然，一塵不染；三曰昌言，聰敏夙成，早遊邑庠；幼曰端，蚤世。女一，適合溪黃。府君享壽六十有二，安人以悼府君過慟而殁，壽亦六十有二。嘉靖戊戌，同日舉殯廿八都寶巖上鳳凰形。噫！府君實歷如此。

余與翁子義切連牀，情不容辭，敬述其狀於譜云。

嘉靖己未夏六月中浣之吉
賜進士第兵科給事中乙卯解元慈水鄭鄕（卿）[^1]拜撰

[^1]: 郑卿：明代浙江慈溪（今宁波江北区半浦村）人。半浦郑氏始祖郑毓后裔，嘉靖三十四年（1555年）‌考中‌乡试解元‌（第一名），次年（‌嘉靖三十五年，1556年‌）登‌进士‌第。
