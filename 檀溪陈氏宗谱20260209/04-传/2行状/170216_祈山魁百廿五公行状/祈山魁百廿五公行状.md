# 祈山魁百廿五公行狀[[陈廷直]]

```
题：[]邑庠外孫趙宦頓首拜撰
峕：[13修]萬歷三十一年癸卯仲夏
初始点校：[20250513]民国庚辰本[3/33]P343
修订参考：[]
```

外祖魁百廿五，諱讜，字廷直，別號友梅，邑庠生也。爲人樸茂醕（醇）篤，處己端方，居家孝友，潛德幽光，數十年於茲矣。至今里中耆德之士，親見其爲人者，猶嘖嘖稱誦不已。豈非公道在人心歟？豈非真實之行，良心所景慕歟？

宦生也晚，不識外祖狀貌，及識人言，稔聞外祖嘉行懿德。蓋吾母氏常稱以爲訓，而母氏之端嚴孝敬，口不能殫述者，又儼然外祖家法也。以此思外祖爲人，及陳氏宗黨中所稱述者，洵一族之懿範哉！奈何令湮沒無傳若此乎？

癸卯夏，陳族輯譜牒，往外祖有行狀及行實，傳久而遺失。仲舅氏小溪公命宦誌其大槪，因爲之述云。所著有《友梅詩集》、《愛傳》二書，載別錄。

萬歷三十一年癸卯仲夏
邑庠外孫趙宦頓首拜撰
