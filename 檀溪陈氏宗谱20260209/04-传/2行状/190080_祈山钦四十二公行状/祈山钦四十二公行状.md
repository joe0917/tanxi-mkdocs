# 祈山欽四十二公行狀[[陈大纶]]
```
题：[]腸進士第任江西吉安府永豐縣知縣，耘野瞿式耜拜撰
峕：[]天啟四年歲次甲子之夏
初始点校：[20250514]民国庚辰本[3/33]P349
修订参考：[]
```

浦邑陳君諱大綸，字伯信，號林泉，固檀溪耆彥高隱也。秉心易直，素行和平，雅敦禮讓，初無矯飾之情；九好施予，曾何告嗇之念。鄉閭質成，則論以理，恕以情；居家百忍，責己容人。有如國課告虛，公則慨然樂助。至若鄉賓屢舉，公則退然固辭。

且人情雕巧如盤蛻[^1]，而公任質自然；世態儇薄若春冰，而公真懇自持。故天與善人，家道日益豐裕；壽以德符，享年九十有三。晚景康健，强履卻鳩[^2]。先室樓氏相夫起家，繼室戴氏宜男多福。一女擇配名門，九男階前遶膝。每歲時宴集，衆雜進稱觴，公慇慇以孝友示，懇懇以儉樸訓。

予竊羨公爲人愷悌醇厚，坊表鄉鄰，於古人中求之，殆王烈、張公藝其流亞耶？至若堂構燕如，阡陌恢如，凡一切紛華富盛，固不足爲公多，亦不足爲公道也。

公幼郎君諱尙祉，號泰元，任敝邑滸浦巡司，與余頗相知契，因知公爲人甚悉，敢以俚言述公之行狀云。

天啟四年歲次甲子之夏
賜進士第，任江西吉安府永豐縣知縣，耘野瞿式耜拜撰

[^1]: 「盤蛻」喻人情反覆
[^2]: 「卻鳩」用「鳩杖」典，指年老強健
