# 祈山賢百五十六公行狀[[陈仕聘]]
```
题：[]眷侍生樓一堂頓首拜撰
峕：[13修]萬歷三十一年癸卯孟夏月
初始点校：[20250513]民国庚辰本[3/33]P348
修订参考：[]
```

府君諱逑，字仕聘，號嚮巖。

稟山川之秀，鍾造化之全。其素性也温厚，其制行也渾然。剛方耿介，高致清廉，公庭勿涉，勢利無干。聰明穎悟，經史淹貫，不求仕進，惟遯林泉。匪人勿交，非義不言。

嘉慶（靖）三十六年間，兩次糧銀解京，皆係己資代納，不責細戶償之還。

迎風月以爲儔，樂山水以爲緣。高人逸士，契結忘年，或載酒而長歌，或秤局而盤桓，或怡情於短棹，或適興於長竿。志不在魚而自樂，心能契月以幽閑。凜凜乎山林之經濟，巍巍乎塵世之行仙。

內君周氏，淑德天全，鼎新華厦，廣置腴田。公生二子：思聖、思賢，克遵父訓，有光於先。維公壽域，洩頂之源，天造地設，預指牛眠[^1]。善加厥後，瓜瓞綿綿。

萬歷三十一年癸卯孟夏月

眷侍生樓一堂頓首拜撰

[^1]: 「牛眠」用陶侃葬母典，指吉穴
