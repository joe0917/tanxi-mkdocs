# 山前純三十六公行狀
```
题：[18世/贤151]族孫昌言謹述
峕：[11修]嘉靖甲子秋八月望日
初始点校：[20250512]民国庚辰本[3/33]P338
修订参考：[]
```

府君諱璹，字文誠，顯十一公幼子也。聰明特達，穎悟夙成，不求仕進，惟樂邱園。因祖居偶遭回祿，卜居吉地曰“白巖山前”者，兩水流合，四山環拱，如天區地軸，風氣攸藏，因以朋溪自號，奠厥居焉。

正建廳堂門院，前後五重，計一十七楹；東西樓廡各二重，計三十一楹。他如明堂道路、內外界限俱甃築祥彩，井井有條，可以觀經緯之略矣。廣拓腴疇，貽厥孫謀者，無不備矣。且好棋畫琴書，與文人哲士往來賡唱，以樂昇平。嗚呼！眞聖世隱君子之府君。

娶安人徐氏，又娶周氏，皆有令德，善相府君起家廣業。府君生男三人：宗彬、宗麟、宗煥；女二，長適姚，次適虞。孫男十人，曾孫男三十餘人，恪守禮法，動循規矩，皆有俊偉特達之才，超出尋常之表。孰非府君積德之所致乎？

余忝譜任值，元孫嘉言備述府君行狀，囑余以記之。余不敢辭，遂書以誌不朽云。

嘉靖甲子秋八月望日
族孫昌言謹述
