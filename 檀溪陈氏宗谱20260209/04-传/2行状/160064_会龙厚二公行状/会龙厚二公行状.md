# 會龍厚二公行狀
```
题：[21世/恩54]第六世孫邑增廣生克敏謹識
峕：[14修]天啓七年嵗次丁卯孟冬月
初始点校：[20250512]民国庚辰本[3/33]P339
修订参考：[]
```

府君諱勇，字宗良，純四公長子，三節氏之冢孫也。年十六而父喪，遺弟四人、妹三人，乃泣而告母曰：「吾家三世守節，今吾父生我兄弟五人，家之幾不絕者如線。父今又棄我而歸，天之所以厄吾家者，何其至也！」遂立志爲人，篤孝寡母，慈撫四弟，擇嫁三妹。壯年家頗豐裕，爲四弟婚配，同爨而居。年五十三，將己置田土五股均分，無私積焉。

府君生我伯父四人，拓基建業，聿新華宇。當糧長一十八年，始得休息。厥後善良合天，名著鄉邑，是皆善體祖父之志，世守三節之所畱也。況自絕（純）四公傳今，子孫百有餘人，女字名門，又非世節累仁之所致乎？

嗚呼！三節之苦，得府君而始慰；天之所以厄吾家者，府君爲得亨矣。設或三傳之時而不生府君以繼之，府君經（繼）之而不體祖父志、友羣弟焉，則後之子孫又不知其何如也。但三節之傳世登紀錄而顯揚之子孫有無難，必府君之屬望於後人者，又不知何如其至也。言生也晚，惟述聞伯父之言而序之。
