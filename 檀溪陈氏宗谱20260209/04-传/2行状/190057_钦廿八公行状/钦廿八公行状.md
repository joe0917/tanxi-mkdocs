# 欽廿八公行狀
```
题：[20世/承55]祈山姪庠生光虞拜撰
峕：[13修]萬曆三十一年癸卯春月
初始点校：[20240412]民国庚辰本[3/33]P348
修订参考：[20260715]加公元年份
```

府君諱九經、字子誠、號一齋，邑庠增廣生，賢十八公次子也。生嘉靖二年癸未五月十四日，治詩經，以儒士應癸卯（1543）科試，入郡泮。甲辰（1544）歲考文宗，以府君為入（八）邑首薦，時府學無廩缺，遂改補邑庠廩員。
娶深溪王氏，係朋十九公之女，安人善體夫志，孝奉翁姑，可謂賢內助矣。
府君聯赴嘉靖丙午（1546）、己酉（1549）、壬子（1552）鄉試，以數奇不第。時適遘改科之變，政內鄉歲加浮米七百餘石。府君毅然陳愬憲司，反被連刑繫獄，累及身家。癸丑（1553）五月初五日，械遞法司，事勢窮蹙，潛脫械解，奔告水程，赴闕上疏。命下在甲寅（1554）冬至日也，恩頒司府悉除加糧苛政，救民樂業。府君始得脫罪安歸，伶仃殊甚。
至庚申（1560）生子，命名一龍。府君以繼述有賴將為，杜門謝事，笑傲煙霞。
詎意萬曆丙戌（1586），復罹照畞加糧，府君抗愬，定為十六則，鄉民始得安堵。
重興惠雲寺，請僧葛真滿住持互相，捐贖寺田，鐫碑畈僧，祝延聖壽。
辛巳（1582）造報功祠，另置祭誌惠民碑錄，永奉府邑恩主。
萬曆癸未年（1584），起大宗祠，重造始祖碩公墳塋，編宗約家規。敦睦九族，仗義疏財。婚配弟九春、姪天龍天眷、及義嗣大賓等。念祖三代早亡，世節寡孤，一系垂繁，力舉捐修祖居家寢。縣誌表楊尊崇報本。助修邑東古塔，重建寺前水月禪亭，另置香田一十三秤，永司香燭之供。
辛卯年（1591），會眾將後山朽木易價二十五兩，糾工樂助，鼎新楊樹角祖業廳堂，義諧後堦沿九族同居。
癸巳年（1593），以身歸隱惠雲禪寺，靜攝談經，清修自在，樂享天年。
以萬曆丁酉（1597）年五月初十日棄世，時年七十有五。
嗟乎，以府君宏藻之文，何難玉堂金馬；以府君經濟之才，亦堪烏臺青鎖。而僅僅以青衿終，何天之儉以報府君哉。蓋天欲。以府君一人，為政內一鄉甦民困，而陳氏祖宗之靈欲，以府君一人，為陳氏一姓萃宗盟，故厄其遇、老其才，而表表輝映於斯世者，有如此耳，附葬祖塋之側，俾後人知始祖即知府君報本之功為不可湮沒也。
小姪才慚襪線[^1]，無以贊揚府君之萬一，而姑略序其大概云。

萬曆三十一年癸卯春月
祈山姪庠生光虞拜撰

[^1]: 才慚襪線：像袜子上的线一样很短的才器。比喻才能小。多为自谦语。也作“袜线之才”、“袜线短才”。
