# 會龍魁九公府君行狀
```
题：[]賜進士第文林郎知直隷常州府武進縣事通家侍教生黃承纘拜撰
峕：[13修]
初始点校：[20250512]民国庚辰本[3/33]P341
修订参考：[]
```

府君諱瀛，字廷廣，厚二公冢子也。昆季四人，公以長而總理家務，不求仕進，力課農桑。不數年，增米數十石，接賢士，待賓朋，門無虛日，而名譽之隆，統遠近如一也。

以先舊第居楊樹角之上，基址頗窄，乃與三弟廷淮公拓展布政公未闢之基，鼎建前廳，極其華麗，匾其堂曰「德星堂」，以光先業。一凡所費之資、心力之勞，大抵公任其半，而檀溪門第家聲，得府君而丕振矣。

娶安人毛氏，賢而內助，贊成家業。生育三子：長曰泰，入邑庠生，次恭，幼敬。俱善士也。二女皆適名門。今其蘭孫秩秩，咸英俊瑰偉，表異於常。裔孫有諱[[陈一龙|一龍]]者，會修家譜，乞狀於余，以誌不朽。

予聞喟然曰：「宗祖有德而勿知者，是不仁也；知而不傳，是不孝也。一龍子知及於此，其亦孝子順孫之所嘉尚也。」是爲狀。
