# 會龍純四府君行狀
```
题：[18世/賢151]裔孫昌言謹述
峕：[11修]嘉靖甲子
初始点校：[20250512]民国庚辰本[3/33]P338
修订参考：[]
```

公諱瑩，字季芳，先名遺腹，生永樂丁亥十一月十九日，事節母董氏極其孝敬，且長文翰練達世故，嘗割股療親，令名廣播，邑侯屢旌賞之，縣尉朱公贈娶黃氏，名清一生，永樂丁亥四月十一日，乃同庚之配，孝奉節姑，勤勞內助，生子厚二、厚五、厚十二、厚十八，女三，俱適名門，又娶石氏，一子厚四。

府君卒景泰甲戌十一月初二日，享年四十八歲。黄氏卒成化甲子十一月二十日，諸子哀泣卜葬，感天神指引黄毛庄長蛇趕蛤形，且曰，此地若葬，後必福壽，並臻言訖，風化不見，今乃果如其言。孝節感天如此，其曠世之奇報也。謹誌以垂不朽云。

寶慶府教授石埠宗孫純仁謹誌

嘉靖甲子，裔孫昌言謹述。
