# 祈山欽三百五十一府君行狀[[陈师贤]]
```
题：[]眷侍教生樓如曾頓首拜撰
峕：[14修]天啟七年丁卯孟秋月
初始点校：[20250514]民国庚辰本[3/33]P352
修订参考：[]
```

丁卯嵗，浦北陳謀修譜牒。余深仰陳爲望族，與余樓爲世姻，高人逸士，未易株舉。乃適有以陳完初之尊翁仰巖公來謁者，其言曰：

"完初尊翁諱師賢，號仰巖，行欽三百五十一，府君浦邑隱君子也。秉性慈祥，制行純篤，諾重千金，取嚴一介。
素心質貌，晚季中之古人；
問月吟風，塵世外之閒叟。
賓之耆席，縣帙三旌不起，何高蹈也；
僉之公正，稽派縣額一清，何忠勤也；
充之富戸，輸邊累年不辭，何慷慨也。
至若督理畚插，千倉萬箱，而又恬退自守，抑何富而好禮也！

享年六十有九，生三子：長曰尚恭，次曰尚美即完初也，幼曰尚敦，咸是克家之允。一女適席場橋虞諱文佐，號兆莘者，係邑庠授例太學生。且遞而孫而曾孫，繩繩繼美，謂非積厚流光之明驗歟？先生將不吝珠玉，以生我府君之色也。"

余曰："嘻！有是哉！嘖嘖膾炙於人口，復何容贅乎？請即以斯語勒之梓氏，以爲仰巖公之實錄。"

天啟七年丁卯孟秋月

眷侍教生樓如曾頓首拜撰
