# 山干賢百五十二公行狀[[陈仕熛]]
```
题：[]盤溪孫壻周振發薰沐頓首拜撰
峕：[14修]崇禎元年戊辰中秋月
初始点校：[20250513]民国庚辰本[3/33]P346
修订参考：[]
```

公諱仕熛，韜光不仕，蓋古之篤行君子，非流俗中人也。立身修潔，秉性溫雅，事親以孝，接族以和，課子以義方，而服衆以公忠。嚴君魁八十六公疾遘甚慘，水火不濟者旬餘，雖盧扁莫效。公晝夜承侍，寢食俱廢，潸然涕泣曰：「烏有人子坐視其親之斃！」乃吮之出其溺，導之而疏其閼，自是沉疴立起，享年耄耋。此精誠之所以格天，與古有代身嘗糞之仁孝，而茲實其媲美已。

更具練達之才，邑尊文侯者廉明特著，博採輿論，舉公都長，復僉公正監丈田畞。窮陬僻奧，足迹無不到之鄉，任勞任費，毫不狥私。浮糧盡豁，宿蠹悉清，是大有造於邦家也。雖邑侯以冕紳榮之，退然不自以爲功。夫何回祿作祟，室爐罹災，衆多訟及胎禍者，公惟委之天數而已，怡然不與之較焉，其汪度越人如此，且也刑于有道。

淑人王氏貞順是敦，繼娶鄭氏，女紅益勵。而伯允嶽、仲允岐，循謹騰茂，孝友蜚聲，固伯仲之克閑父訓。總之公之身教豫也，其孫謀之貽，方雲礽而未艾。天之報施令德，豈不亦彌久而彌昌耶？

迄於今公沒三紀[^1]餘矣，凡鄉之耆舊、黨之俊耄，無問識面與否，靡不口碑之不替。名節之赫於勢位也，若是夫今其建祠宗長[[陈九经|一齋公]]子[[陈一龙|一龍]]，剛方士也。宗有惡者，雖榮必擯；宗有善者，雖晦必揚。甚景仰公懿行，緣黃譜牒，乃悉其生平梗概以語余。余小子雖渺陋，忝公震君之半子也，恆以不𫉬親炙是憾。聞之不勝感激咨異，因嘆其才其度，人莫能企焉。惟吮溺導閼一事，誠閱古今之賢哲所未經見者，意者泣歷號天之懇忱，所以留其脈與？故忻然紀其略，以醒後之爲人子者。

崇禎元年戊辰中秋月

盤溪孫壻周振發薰沐頓首拜撰

[^1]: 「三紀」指三十六年
