# 祈山魁百廿二公行狀
```
题：[18世/贤151]增廣生姪昌言謹撰
峕：[11修]嘉靖四十三年甲子秋月
初始点校：[20250512]民国庚辰本[3/33]P343
修订参考：[]
```

府君諱廷銓，將仕郎[[陈叔起|常三公]]之元孫、宗信公之幼子也。府君篤性良善，沉靜自守，務勤儉以操家，重公課以輸國，待鄉族以仁讓，課後嗣以義方。內君毛氏，貞淑性成，內助有方，家益充裕。子曰逑、曰進，咸克肖特達。何天不祐善，而安人早逝。嘉靖壬戌十二月初十日辰時，卜穸於大徐塘上荷花形，而安厝之。

越二年甲子秋，會余修譜，泣告予曰：「吾父一世爲善，名播近遠，而譜如未載，實人子之責也。惟兄爲述誌之。」余聞爲善者必慶其後，修德者必契於天。府君初年財產不及於諸兄，而今反過之，此皆以義安命之騐，而亦爲善之應也。是爲狀。

嘉靖四十三年甲子秋月
增廣生姪昌言謹撰
