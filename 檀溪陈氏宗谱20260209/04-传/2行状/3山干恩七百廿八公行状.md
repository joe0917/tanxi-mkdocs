# 山干恩七百廿八公行狀
```
题：[]壻男邑庠生黃紹統拜撰
峕：[17修]康熙四十年辛巳孟夏月上浣
初始点校：[20250730]民国庚辰本[3/33]P354
修订参考：[]
```

君諱克淸，字思纓，承五百六十四公之次子也。君少有揮霍之才，具先幾之哲，於古今卷集不甚究心，多所交遊。欵送迎候，略不見有倦色。兼之天性孝友，事二人色養無違，彌深愛日之誠；與昆季處，友愛之念老而彌篤，雖析居常如合爨，怡怡之氣甚足動人。

嵗丙戌，旱魃[^1]爲虐，山寇猖獗，官兵四剿，士卒雲集，連年不平。君隨父外避，寄身戚屬，定省奉養之禮，視平居無異。乃昊天不惠，於奔突竄伏之際，方賦黃鳥，忽咏蓼莪。越數載而奉柩歸葬，其攀號拜引，婉如初喪，見者泣數行下。厥後安居未幾，而骨肉之變又起，旣揮淚而慟失吹塤，復頓足以悲丧吹篪。

晚年甲寅之亂，闔室又盡屬灰燼。計共一生，蓋歡愉之日少而愁思之日多也，未免有情，何能堪此？屬卒坦懷消受，搆造重新，僅免露處，未及落成，不疾而奄逝矣。嗚呼悲哉！

安人王氏，內則風嫻，生四子，其二早殤。君存者一名元樞，一名元格，皆具不凡器字。庚辰冬，元樞子董輯家乘，痛君之行弗傳，且謂非予莫狀也。賁然來告，予揮毫立狀其概，鐫諸譜牒，以遺後人之觀感焉。是爲狀。

康熙四十年辛巳孟夏月上浣

壻男邑庠生黃紹統拜撰

[^1]: 魃：ba2古代传说中造成旱灾的鬼。
