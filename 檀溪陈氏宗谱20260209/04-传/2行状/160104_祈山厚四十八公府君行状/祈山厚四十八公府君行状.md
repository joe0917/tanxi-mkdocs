# 祈山厚四十八公府君行狀[[陈宗元]]
```
题：[21世/恩54]第六世孫邑增廣生克敏謹識
峕：[14修]天啓七年嵗次丁卯孟冬月
初始点校：[]民国庚辰本[3/33]P339
修订参考：[]
```

斌三公創居祈山，收浦邑以北之勝，然天作始荒，未遑光大也。嗣後常三公宦遊於廣，顯二公孤孑於庭，純廿六公雖增置世業，而遭時不偶，未克盡展其所欲爲。自創居以來，屈指計之凡四世矣。地脈有靈，豪傑自宜挺生，於是府君誕生於景泰丙子，諱生，字宗元，號祈山樵隱，純廿六公之長子，月山毛氏安人所出也。

相傳府君生於外祖月山之環翠樓。生時有鶴橫空而鳴，其樓遂爲祝融收去。噫！此孰非瑋琦之徵，而世世子孫所藉以爲燕翼之兆與？

及長，事親孝，撫異厚（母）弟厚六七公極其友愛。外而師傅，內而家室，皆府君爲之營辦。兄弟和翕，家益饒裕，與弟厚六七公擴新輪奐，廳堂門廡，規模爽朗，氣概軒昂。即古人所稱「堪容駟馬」，何多讓焉？

府君又自造凝雲樓於廳堂之後，共計九楹，高出層霄，廣容千人。入其門者，步步陞高，階級森然，深邃層密，據地之秀，搆宅之雄，未有若府君者也。至今六世幾二百年，仰視榱桷[^1]，則府君之手澤如新。

府君素性禮賢下士，善於詩賦，惜所遺無全藁。丁卯搜集遺文，僅得《閒居十律》，語語温潤，字字清新，眞足駕中晚而上擬盛唐。然染指一臠而未飫珍奇，僅窺一班而未覩全豹，好古之士所深用把腕者也。

良田廣廈𨷺分各房者雖多不可考，惟遺有賢產若干，侵漁乾没之外，存畱尙有五石餘，子孫之事舉子業者，猶得沾餘惠而供祇筆也。然則府君之芳名，固與養賢之世業共垂不朽矣。

正德丙子，督修家譜，其承前啟後爲何如也？享年六旬有七，十壽藏於前方山麓，結屋一區爲守墓之計，置田數十畞備享餕之用。登其穴，兩水環帶於前，千山拱嶂於旁，宜其子若孫世世簪纓勿替。若府君者，生居祈山之勝，爲一鄉之豪傑；沒擅前方之秀，貽萬代之景福。舊譜怪無片言誌府君之狀，想爲遺失，或祖龍得之。夫府君而無狀也者，將誰爲可狀乎哉？

敏生也晚，聞見寡陋，無以畢宣府君之碩德，僅拾其並邱山同日月者，授之於梓，以與後之賢子孫共追思之勿諼。

天啓七年嵗次丁卯孟冬月

第六世孫邑增廣生克敏謹識

[^1]: 榱桷：榱同椽，椽方曰桷。
