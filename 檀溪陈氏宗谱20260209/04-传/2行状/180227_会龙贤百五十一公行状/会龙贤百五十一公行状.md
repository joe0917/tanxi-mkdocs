# 會龍賢百五十一公行狀[[陈昌言]]
```
题：[21世/恩54]增廣生姪孫克敏謹誌
峕：[14修]天啟七年丁卯冬月
初始点校：[20240414]民国庚辰本[3/33]P346
修订参考：[20250513]
```

府君諱昌言，字希禹，號龍橋，邑庠增廣生也。胸𫎓（貯）珠璣，筆驅風雨，頃刻成文，追倚馬之高才；須臾詩就，躡七步之後塵[^1]。奈罹改科之害，遂阻上進之心。恬澹寡約，安貧樂道，著《貧愚集》以自娛。乃以女聘釋親兄縲絏[^2]之累，而手足之義敦矣；奉岳父盡膳養葬祭之禮，而夫婦之倫篤矣。名高望重，車馬敦迎，如市良有以也。

享年五十有九，曷勝孔明五丈原之悲。淑配毛氏，靜德幽閒，享壽八十五歲。其殆不足於府君者，取償於安人也乎？生二子：九街、九衡。長字子正，博學善文，工於楷書，中棄書業而歸事雙親，開義塾以訓弟姪，例授本邑社學生，奉養寡母，友愛昆弟，纂修家乘而光先德；次字子平，亦善詩文，雅有父風。兄弟隆孝養而敦友于[^3]，通族之所景仰也。以次子一信字德重繼兄爲後，亦長厚能文，割股療伯，可謂一門孝友，翰墨餘香，引之弗替者矣。

後學敏因狀龍橋府君而波及之，然三世隱德，固非拙筆所能繪也。

天啟七年丁卯冬月
增廣生姪孫克敏謹誌

[^1]:「倚馬」用袁宏典，「七步」用曹植典
[^2]: 縲絏：亦作缧绁，音léixiè。捆绑犯人的绳索。引申为牢狱。
[^3]:「友于」用《尚書》典，指兄弟友愛
