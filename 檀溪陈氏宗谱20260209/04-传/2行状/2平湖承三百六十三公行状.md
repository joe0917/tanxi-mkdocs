# 平湖承三百六十三公行狀
```
题：[]眷小姪郡歲貢虞良璵頓首拜撰
峕：[16修]康熙廿三年甲子仲冬吉旦
初始点校：[20250730]民国庚辰本[3/33]P354
修订参考：[]
```

公諱一周，字汝和，係欽二百廿六公之長子也。秉心醇良，制行忠厚。爲子孝，爲兄友，爲父慈，殫力倫常之中，克全彝懿之好。素懷畜馬，常乘駜[^1]牡以前驅；情嗜隱淪，偶挾釣竿而自適。與時偕隱，處世和平，合族咸有湻龎樸茂之慕。

娶安人張氏，出自名門，婦儀逈異於恒流，每以助夫常子爲事。生四子：長克懋，除學舉業中廢，書貿易成家；次克思，惟務農業；三克念，木植經營；幼克慰，耑治一經，博通六藝。弱冠時，翁有恙，割股療翁，不事表揚。至國初戌子年，改名鼎新，備員弟子，樹幟詞林。伊子元兆，幼年入泮，克紹箕裘。

公之桂子蘭孫，家業豐裕，書香不絕，誠公忠厚課子之報也。公享年五十有六，安人享壽八十有四，合葬本邑東門外"出水荷花"形，乾山巽向，誠秀穴也。

噫！予與公幼子爲忘年交，義不容辭，敢述其狀於譜云。

康熙廿三年甲子仲冬吉旦

眷小姪郡歲貢虞良璵頓首拜撰

[^1]: 駜：bi4马肥壮貌。
