# 祈山勝峯魁五十八公行狀[[陈时和]]
```
题：[]賜進士第兵科車駕司主事眷晚生張應槐頓首拜撰
峕：[13修]萬歷三十一年癸卯季秋之吉
初始点校：[20250512]民国庚辰本[3/33]P342
修订参考：[]
```

語云：「褚小者不可以懷大，綆短者不可以汲深。」[^1]世之凉德者欲其貽慶後人也難矣。余與檀溪陳奕世姻戚也，內有碩德隱逸高士，諱廷陽，行魁五十八公，號勝峯，係予叔元中岳父也，享壽六十有八。癸卯（13修）纂修家乘，表揚勝峯公之陰德，係余叔事，而余叔先捐賓客[^2]逝矣，予敢代爲之說。

曰：公賦性寬洪，存心平易，與物無忤，居無戚容，有大人度，不較於瑣屑。公家事甚饒，尤好施與。人有借貸，不責其必償；里中有窘急者，不時賑濟。嘉靖丙子歲，大饑，流離相望，公出粟賑給，公輸於官，以佐國家之本急。縣奉恩例給冠帶以優禮待焉。雖公之盛德不以升斗自多，然非耆碩高賢，朝廷胡以寵賚若此哉？

公五子、女二，孫十六，曾孫、元孫以百數，多俊髦。長女適義門鄭諱廷述，邑庠生；次適在城張諱元中，中嘉靖丙子浙江鄉試舉人，卽予叔也，授河南尉氏縣知縣。三甥：長諱應麟，授廣東雷州府推官；次甥應豺，授南直粟陽縣二尹，轉陞湖廣黃陂縣二尹；幼甥應騶，授陜西布政司經歷。亦公之餘庇也。

《易》曰：「厚德載物。」公德厚矣，子孫繁盛，固天報也，焉可湮沒而不稱乎？余誼係至戚，深愧謭材，而稍爲揄揚其一二云。

萬歷三十一年癸卯季秋之吉

賜進士第兵科車駕司主事眷晚生張應槐頓首拜撰

[^1]: 「褚小」「綆短」用《莊子》典，喻德福相配
[^2]: 「捐賓客」指去世
