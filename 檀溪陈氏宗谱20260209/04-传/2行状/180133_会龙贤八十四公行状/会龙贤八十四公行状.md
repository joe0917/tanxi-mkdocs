# 會龍賢八十四公行狀
```
题：[21世/恩54]邑庠増廣生姪孫克敏敬誌
峕：[14修]天啟七年丁卯
初始点校：[20250513]民国庚辰本[3/33]P346
修订参考：[]
```

府君諱敏，字仕敬，號東源，忠厚持身，義方課子。家不富甚，好爲施與。萬歷癸未，有烏傷駱家義女被掠，賣與佃人陳義一爲婦。越年，駱主緝𫉬（獲），禁錮囹圄，幾乎殞命。府君聞之，慨然助聘解釋得全夫婦之命。至後無告，以子鬻聘，爲之撫長遺還，毫不受其原聘。

及姪一齋公首建宗祠，樂助白金十兩、魁木一百，以成厥美。至今人稱「八四公」者，無不稱羨。公之長子欽六十八公，諱九陵者，謙沖謹厚，持己以平，循良愷悌，與物無競，有東源公之鳳毛，可謂箕裘善述，有光先德者矣。因并及之。

天啟七年丁卯

邑庠増廣生姪孫克敏敬誌
