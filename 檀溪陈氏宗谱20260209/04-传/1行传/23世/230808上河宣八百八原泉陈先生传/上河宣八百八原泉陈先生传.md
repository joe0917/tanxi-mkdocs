# 上河宣八百八原泉陳先生傳
```
题：[]年家眷姪孫笠山張希大
峕：[20修]歲在柔兆攝提格（丙寅）旦月之望
初始点校：[20260804]民国庚辰本[3/33]P311
修订参考：[]
```
[[檀溪陈氏23世（宣）#^230808]]

（未核对原文） 

原泉先生者，篤學力行君子也。諱之倍，字渭符，性取介，不隨流俗，然立身能舉其大，以之磊落有奇節。事其父病彌留，忘身以救之，人弗知也。後母傷其足，幽憂者半載，侍左右，刻不忍離。三年之中，疏食淡如，獨有不擇然者。自此寸心傷感，長為望雲嗟樹之人。其先大父遭中路之阻，先生念之，卜於舍之旁，新其堂宇而祀焉。又於先祖歲時祭享，著為成規，傳之可久，則使其族之人咸知所自出也。  

處昆季，憂樂未始不相同。兄周文時在睦之建邑，訟不得息，往訴焉，不數言而其紛立解。兄之得以成業於姚村者，今可十餘年矣。然不以為功，酬以田，誼不終受云。先生美髭髯，器宇軒昂，邑侯黃公，江右名進士也，一見而偉之，雅慕其才，遂作布衣交，往還累月。後歸去，先生持數十金贈之，毫無德色。侯亦謀於先生之所以顯其親者，乃署「太邱雅望」四字為之匾於堂，誌留別也。夫慷慨而重然諾，先生之式服於名流類如此。  

晚年尤耽邱壑之趣，别墅小流塢數椽，買田十畝，一童奚使治之，時而習靜焉，足以知其老而志在矣。昔先生之在子小結廬也，先君子與執經者有年，其後好益密，予因述之，不辭載筆以從事。至於詞章之學，表而傳之，多先生之嗣人在，則不之詳焉。

歲在柔兆攝提格[^1]旦月之望，年家眷姪孫笠山張希大謹為傳。

[^1]: “岁在柔兆摄提格”是一种源自古代的太岁纪年法，它本质上是干支纪年法的一种古老而雅致的别称。简单来说，“柔兆”对应天干的“丙”，“摄提格”对应地支的“寅”，合起来就是“丙寅”年。
