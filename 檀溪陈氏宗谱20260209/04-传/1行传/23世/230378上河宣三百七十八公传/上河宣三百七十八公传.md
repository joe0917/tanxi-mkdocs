# 上河宣三百七十八公傳（賢祭田移載行傳）
```
题：[]年家眷弟壬午科舉人任富陽學訓導黃元弼拜撰
峕：[]乾隆四十一年歲次丙申春月
初始点校：[20260803]民国庚辰本[3/33]P306
修订参考：[]
```
（未核对原文） 

公諱之正，字永祥，惠二百六十七汝應公之冢子也。居家孝友，處世謙冲，其質樸醇良，端莊厚重，人近之如飲醇醪而挹春風，無有厭其意者。邑侯聞其風範，舉登賓席焉。祖居廿六都上河庄，齒繁多，所居僅二十餘楹。見十七都雙溪之濱，名大地者，四山環翠，溪流如帶，平遠高朗，可容千人，遂卜居其上。搆廳堂門院，東西兩廡五十餘楹，且廣置田疇，建立賢產，其貽厥孫謀者，規模宏遠矣。公誠雙溪始遷之祖也。

又大嶺頭往來之人，肩摩踵接，實為通衢，而山高路峻，十餘里無息之所，行者苦之。公出己資百餘兩，造凉亭一座，砌路百丈餘，且為築地開田，付於住持之方某，令其奉茶湯，具烟火，供給往來困乏者。至今行人謳思之。蓋其所計者遠，而所行者實。大略如斯，他若造橋施履，救急濟貧，不盡一一為公數也。

元配黃氏，善事舅姑，克嫻婦道，生以璋、以琯，俱廉介自守，扦葬上河後山坪。繼娶周氏，勤儉持家，御下以寬，生以瑚，習舉子業，英達有文名。孫男七，曾孫、元孫四五。而公髯鬚皓首，濟濟繞膝，非厚德之所致與？享壽八十有四，安人七十有五，合葬徐裹塢前山麓，面北坐南之地。登其穴，秀水環抱，奇峯拱峙，宜其世世子孫福祿綿衍也。爰書其犖大者，以垂後人云。

乾隆四十一年歲次丙申春月
年家眷弟壬午科舉人任富陽學訓導黃元弼拜撰
