# 祈山欽五百十一松岑公行傳
```
题：[]外孫虞啓明頓首拜撰
峕：[16修]大清康熙嵗次甲子仲冬吉旦
初始点校：[20250429]民国庚辰本[3/33]P283
修订参考：[]
```

公諱大量，字伯洪，號松岑，乃明之外祖父也。貌雖蒼古，心實仁慈；行必端方，言必忠信。惟孝友傳家，謙和處世。娶外祖母在城張氏，賢淑軼羣，躬嫻四德。庄明母與舅父四：孟曰尚皐，仲曰尚萃，季曰尚準，善繼善述，克勤克儉。舅母俱諧伉儷，咸出望族。

明生未滿一週，適母襁負歸甯。祖母張氏愛明過甚，即畱撫養，至髫年方歸。叨公之德實深，知公之行亦備。蝸角蠅頭，公無着念；官糧農事，公勿營心，蓋賴有諸舅父代勞。公自能樂其眞趣，宅後有一山，離家一里許，周環皆空，圓肖如龜，乃我公怡情自在之所。或因平坦而開鋤，或就高下以磡疉，或種菊栽茶，或植瓜樹果。想幼年擕杖追隨之景，宛然在目。臨溪山脊開一巖阿，排石列坐，靣祈山之聳翠，檀水之流清，即名其洞曰「觀瀾洞」，豈非取其晝夜不舍、有本如是之謂歟？除山水外，別無他事。性酷好棋，一與人對局，以至忘食忘憂，不知老之將至。

歲在戊子，邑侯韓公慕其高風，推舉鄉飲，因遭白寇蜂起，舉家逃竄，遂爾中止。後妖氛掃蕩，正樂昇平，奈昊天不吊，棄厥典型，未聽鹿鳴之歌，遂阻嘉賓之願。然恩雖未沾夫黌序，而德已甚著於鄉邦。迄今口碑傳頌，不啻旌匾流徽。故人或有抱歉於斯者，而我公之曠懷，諒必怡然於九京也。况今蘭孫滿砌，書香有托，而囊篋豐腴，方興未艾，豈非我公仁慈忠信、孝友謙和之果報乎？

明身多病，叨沐恩深，涓埃未報。今値陳氏修輯家乘，諸舅父咸已仙遊，未獲闡揚。幸明稔知巔末，不揣固陋，聊以傳其萬一云爾。

大清康熙嵗次甲子仲冬吉旦

外孫虞啓明頓首拜撰
