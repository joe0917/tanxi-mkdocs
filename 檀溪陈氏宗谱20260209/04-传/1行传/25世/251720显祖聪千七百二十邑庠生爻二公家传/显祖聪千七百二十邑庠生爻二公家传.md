# 顯祖聰千七百二十邑庠生爻二公家傳[[陈祖现]]
```
题：[27世/延1172]家孫貢生仲鴻敬述百拜
峕：[31修]光緒六年嵗次庚辰小陽之月上浣
初始点校：[20250728]民国庚辰本[3/33]P323
修订参考：[]
```

祖父諱現，字文田，號鑑湖，爻二其晚號也，邑庠生，昆季四行居次。曾祖漁隱公以伯祖繼曾伯祖後，本房遂以次作長。

祖生而敏達，讀書“出於心之所好，精思卓識，自幼卽迥不猶人，長習舉子業，文義斐然，鄉前輩周盤洲先生，深契之仲生也，晚十三齡，而祖遽棄養不獲長，承祖訓詳悉生平之懿行淑德，哀痛何極，顧自初識之無，食同席、寢同榻，諄諄不倦之教，有耿耿於心，未嘗或忘者。”追憶之，猶若依依於面命耳提親侍左右時也。

曾記祖父命仲曰：讀書要幼少識秤無肉賣，不受苦中苦難爲人上人，一日之計在於寅，淸晨傾受清氣，足長人智，慮消人昏濁。汝其敬遵之。

又曰：學貴務心得𣶬（涵）養爲先，不可妄思，僥倖成名，尤不可恃才傲物。背“滿招損謙受益”之垂誡，吾幼就傅兩載，讀四子書畢業，往廿七都外家拜新正，外祖卽勗我從師擇善之道，囑受業於盤洲師，師以吾齒穉漫應之時，館中諸同人皆採究經義，習文章詩賦，而予以總角厕其間美甚，因以讀經解經請師，欣然色喜，告外祖曰，此子可造才也。遂畱共肄業。

嗣自侍函丈者有年，所授經解註疏詩，古文詞法律音韻皆有得於心，惜遊庠後，析炊㕓家政，師亦赴海鹽儒學任不果，從間有課藝，唯與祈山雨田先生互質證，屢試卒不售，故終老一襟，然所得力於師承者，每風雨雞嗚，輒手一編不輟以中，心所好在是也。汝其敬識之，佩諸終身，毋負我老人教訓爲，此皆吾祖本身教爲言敎，曩昔所數聞者，故仲在孩提時卽促之早起，稍延督責不少恕，燈下猶以畫所讀，逐字令解晰，又將古樂府漢唐等詩相訓示，務熟習後已在爾日甚苦，祖之酷勞我，豈知正祖之酷愛我乎。而今悔悟無及矣。

祖父孝謹正直，人所信服，曾督建遠祖墓碑，復因嘉慶九年九月朔，祖先堂多被回祿村長以瀛公等力邀之任綜理司，出入不辭，辛瘁以底於成，今“長發堂”雖被匪焚於光緒元年，仲復集合門抖資鼎承祖業董理重建，其欽百四公之寢堂，具在吾祖筆蹟多有存者，每一展觀彌不勝手澤之思悽悵久之焉。

暮年於住宅旁闢西園、搆書室，爲課孫所築，圍墻二畞餘田於其前，種塒蔬果花本，藉娛晚景，嘗戚戚於吾父單傳功名不得志，癖嗜飲，傲岸不諧於俗，念小子不可無成，就日坐室中以誨仲爲事。著有《鑑湖遺稿》《爻二氏草》，常手披口唫，無間寒暑，書法學小歐極精勁存。有諸子鈔本猶寶藏之。蓋所見聞於吾祖者僅此。

嗚呼，仲不克仰承先志，博顯揚光宗緒，不肖奚如，而又遭家不造刼運。重經自咸豐丁巳七月旣望之夜，水災大祲，將祖遺西園，及吾父續置“半規草堂”、“夢花廬”，并自昆季所造著書别墅，房舍凡四十餘楹，盡付洪流。又值辛酉髮匪擾踞，烽烟蹂躪，散離逃亡，至身外別無長物，不得不爲經營生理計，乃頻年以來所謀不遂，欲圖恢復舊業，而卒不可得，甚辜負吾祖一腔厚望苦衷，今忽忽年六十有二矣，屈指吾祖之殁已五十載，而回憶當年訓容宛然，訓誨儼然，亦安禁淚之潸潸然下耶。

兹當家乘重修，敬敢據實敘之，傳後之子孫得悉梗概，永奉爲家法，聊以盡小子之責也。夫履歷巳詳，行傳故不贅。
