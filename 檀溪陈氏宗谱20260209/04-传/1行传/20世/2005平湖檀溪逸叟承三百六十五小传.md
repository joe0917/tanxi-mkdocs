# 檀溪逸叟承三百六十五小傳
```
题：[]外孫府庠生葉茂林頓首拜撰
峕：[16修]康熙嵗次甲子仲冬吉旦
初始点校：[]民国庚辰本卷[3/33]P286
修订参考：[]
```

檀溪逸叟陳公，諱一鸞，字汝佐，號瑞廷。爲林外大父也。秉性英敏，氣宇恢宏，幼爲舉子業，後棄去，磊落湖山，閒好馳馬，尤精於象戲，一切勢利不入其心胸，言論慷慨正直，絕不隨人可否，人有執爭者，得公一言輒各輸服，見豪强者不少降志，至困弱者必多方濟之，盍大都類古任俠者流，至今鄉里中推賢豪者必稱焉。此林彷佛外大父之大略也。

康熙癸卯夏，竟以壽終，享年八十有三，娶外祖母戴氏，生女二人，長卽林母氏，次適張。生舅氏四人，長克經、次克釋、三克綬、四克繼。娶葉氏生舅氏克儀。五舅氏咸俊傑競爽，而三舅與四舅其胸懷舉動，皆儼然外大父。四舅父娶舅母葉氏，生表弟如章、如孟，皆未及冠，而舅氏早世，今二表弟之成立皆舅母力也。三舅父尤卓犖不羣，而外孫中特鍾愛林，林嘗念舅父之音容，不可復見，今表弟如柏，其性情胸次又儼然三舅父，則林見表弟猶之見三舅父與外大父也。三舅父娶舅母虞氏，生偉明，繼娶徐氏，生表弟如柏、如臺、如鏡、如御，今如柏善事，其母與兄且教弟如御負笈從師，冀有成立，此尤可以慰吾舅與外大父之心於無窮也。是爲傳。

康熙嵗次甲子仲冬吉旦

外孫府庠生葉茂林頓首拜撰
