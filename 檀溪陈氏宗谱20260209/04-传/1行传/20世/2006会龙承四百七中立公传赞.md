# 會龍承四百七中立公傳贊
```
题：[]眷侍教生府庠生黄鳳翼頓首拜撰
峕：[15修]順治戊戌年仲秋之吉
初始点校：[20250511]民国庚辰本[3/33]P287
修订参考：[]
```

公諱一信，字德重，號中立。性至孝友，自幼出繼伯父，其爲人後無異其爲親後也。及伯父有疾，多方求醫不效，遂割股療之，此其孝行最表表者。

處昆季敬而有禮，待諸子嚴而有方。於服用飲食，悉尚以儉，嘗曰：「禍起於侈，慾生於逸。」時以爲格言。至居宗族戚里間，無餙（飾）情，無飾貌，辭氣藹如也，人無不稱其長厚者。

公每慮族之繁也，久而路人視之，慨然有考亭、眉山之志[^1]。故其於家乘，兩董其事，丁酉之輯，公復倡率焉。未及襄事而卒，年七旬有二。學問該博，文章雅贍，所著有詩歌行世，雖學士詞宗有所不逮云。

贊曰：道腴風古，樸貌文心。閑閑十畞，終其身。嗚呼！無懷氏[^2]之民。

順治戊戌年仲秋之吉
眷侍教生府庠生黄鳳翼頓首拜撰

[^1]: 「考亭、眉山之志」指朱熹（考亭）、蘇洵（眉山）的修譜志向
[^2]: 「無懷氏」用《莊子》上古淳樸之民典
