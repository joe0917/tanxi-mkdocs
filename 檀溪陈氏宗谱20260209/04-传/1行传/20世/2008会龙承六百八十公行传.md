# 會龍承六百八十公行傳
```
题：[]麟溪眷晚生鄭應第頓首拜譔（撰）
峕：[16修]康熙嵗次甲子仲秋榖旦
初始点校：[20250511]民国庚辰本[3/33]P288
修订参考：[]
```

公諱可佐，字德輔。生長名族而勤樹蓄，潛隱林泉而善居室。樂觀時變，人棄我取，人散我聚，以此居積致富。鄕鄰有求濟者，虛來實往，兼之出入公平，雖甚强梗，卒無負者。

至其聘師訓子，好禮賢士，有雅尚詩書之志；鼎新峻宇，肯構肯堂，有高大門閭之風。

抑且慷慨仗義：有族姪克繼，幼失怙恃，抱歸撫養，迨成人，捐資聘娶，生六子咸長大，仍令歸宗，宗族義之。

洵哉！居樂土，鍾桑麻，殷阜繩武於陶朱[^1]，已沐堯天之雨露；
惜乎！廣心田，培蘭桂，有志不逮於燕山[^2]，未沾舜日之恩光。

安人徐氏，內助稱賢，善中饋，精女紅，克相夫子成家，至老不衰。今其麟趾[^3]森森，咸克勤務本，課農桑而攻詩書，將有後裔發祥，以見天心食報不爽。

甲子之秋，適修家乘，次子思瑜甫偕孫汝振氏，以乃翁隱德未彰，囑余作傳。因採其族之輿評，傳公之懿行，以表其永言孝思之意云。

康熙嵗次甲子仲秋榖旦

麟溪眷晚生鄭應第頓首拜譔（撰）

[^1]: 「繩武於陶朱」指繼承范蠡經商之道
[^2]: 「燕山」用竇燕山教子典，喻教育理想
[^3]: 「麟趾」用《詩經》典，喻子孫賢能
