# 祈山欽四百九十二公傳
```
题：[]眷侍敎生傅應洙撰
峕：[]
初始点校：[20250511]民国庚辰本[3/33]-p283
修订参考：[]
```

公諱大順，字伯高，别字懷宇，仕德公冢嗣也。厥性肫篤，厥志澹斂，迹邱園，不求聞達，棲靜養閒，與物無競，視世人之務華者迥異。惟是孝友勤儉，有長者風；於先君產業，多光大之；又好施捨，周人之急，解人之紛，慷慨多大節，不爲利疚，不爲勢回，卽一時期許，終身堅若金石。

邑令譚公心知其賢，延以鄉飲賓。浦陽冠裳駢集，固多廟廊柱石，然炳炳烺烺，老成敦樸如陳君者，詎可一二數耶？或者奕葉之後，因斯言想見其人，死且不朽。如曰「人以言重」，則余之負罪滋多矣。

眷侍敎生傅應洙撰
