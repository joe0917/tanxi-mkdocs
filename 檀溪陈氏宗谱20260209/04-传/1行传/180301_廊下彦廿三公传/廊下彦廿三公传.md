# 廊下彥廿三公傳[[陈尧智]]
```
题：[20世/承83]姪孫邑庠生尚睿謹識
峕：[14修]天啓丁卯年孟秋月
初始点校：[20250511]民国庚辰本[3/33]P282
修订参考：[]
```

仙華之北，祈山之南，耆英南塘公之居在焉。公諱堯智，字良眞，號南塘。厚重端莊，內外徯志，遐邇遜心。

萬歷三十八年（1610），家廟聿新，人心鼓舞，而祠長尚未有屬。衆論紛然，予即以公應之。衆人無不交口曰唯唯。予復曰：「未可驟也。非合族之老幼敦請則不尊，非奉府道之詳允施行則不信。」衆人又無不交口曰唯唯。遂集合族，具呈請於邑侯吳。邑侯許可，申明府主楊、道尊蕭，亦許可。蕭道批云：「維風易俗，孝友為政。惟祠約可以善俗。今據陳氏呈申，尤在家長躬督嚴行，以為族範。由此踵行，比屋皆成可風之俗云。」

由是，合族之人奉道、府、縣帙，俱齋沐詣公居敦請。公至祠，大小尊卑數千人，以次序進拜。公儼然以國法行於家廟，而宗族又儼然奉祠長為良牧也。設立公座，僉舉房長。族之有不肖壤（壞）家教者、忿爭頑梗者，咸聽命於公，而無不輸服焉。

嗚呼！若公者，年高望重，公忠耆彥，下以豁羣情之鬱塞，上以補有司之未逮，屢膺耆席，頤高享壽，豈非逸士之高標乎？妄以數言誌之永久。

天啓丁卯年孟秋月
姪孫邑庠生尚睿謹識
