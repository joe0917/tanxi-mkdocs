# 廉千三百八十[[陈恒署|亞咸]]公傳
```
题：[]嵗貢生候選儒學訓導樸里姻弟鹿坪朱宴康人氏頓首拜撰
峕：[]大清咸豐七年歲次丁邑孟春之月中浣
初始点校：[20260730]民国庚辰本[3/33]P325
修订参考：[]
```

在昔道光丁酉（1837）嘉平之月，歲既單矣。余方蹙蹙靡聘以，竊愁萬斛，思傾家釀以敵之。忽有高軒過我，入門下馬，吐酒氣如長虹者，亞咸陳公也。公諱恆署，世居浦北平湖村。父文田[[陈祖现]]，先公以邑文學負盛名，娶盤溪周氏，生公。

公自幼嗜酒，不悅學。父母計以酒勸學，使公必從學得酒，遂酒與學俱進。稍壯，從其家[[陈宗泰|平階先生]]遊。講堂前有小池，畜赤鯉數尾，公竊取下酒。先生怒曰：「鯉也死，必以文哭。」公援筆立就。又帖顛字為題，公用殷盤之「顛木」、周爻之「顛頤」。先生莞爾而笑曰：「古有張顛、米顛、周顛，並陸放翁之海棠顛，今復有恆署顛耶？」由是世皆呼為顛公，亦故作顛狀以玩世。然而把杯則猖狂，放盃即沉靜。為酒聖，不為錢虜，看破一片銀世界。平生樂善好施，所作利人事不少矣。

如吾浦向無考棚，公既慨然捐白金二百餘兩以襄事，又自構“半規草堂”為家塾，其勸學有如此者。
平湖前臨大溪，水漲時令人有望洋之嘆。公別開一徑於住村上首長舉塢口，獨架石橋以通大道；又於下首城頭地方，捐造“鎮湖橋”及各處橋梁，費皆不資，其宏濟有如此者。
素善漁，裸身翻入數仞之淵，取魚以出若寄。余嘗見其家積網如山，忽有悟於蓮池放生之說，一炬空之，火光明達旦，其解脫有如此者。
歲祲，竭其粟而貸之。家人曰止，公獨登樓鍵戶，投粟檻外，呼貧兒各以其器自下承之，傾其囷，至無隔宿之糧矣。乃徐出金，從富家貸粟數十石以自給，又半為擔夫肩去，公亦置不問，其豁達有如此者。

顛乎？不顛乎？無乃以不顛為顛，猶狂國之狂，其不狂者乎？

甲午、乙未之間，山中又大饑，公又出粟以貸，自春徂夏不濟，乃告糴以設平糶局，費金四百餘。邑侯黃崑崙山先生詳府太尊潘光藻編修，即贈以「仁渥榆社」額，並上其事。當道奉覃恩，授按察使司檢校。為善最樂，不虛矣。然公自以束髮受書，至如此種種，曾不得一厠名黌序。胸中抑塞磊落，無聊不平之氣，無所可吐，畢寄之於酒。故或握拳拍几，或泥首沾衣，或吐隸人強之飲，遇顯者踵門，偏不以屑意。或肩輿掛一瓢，徜徉山水終日；或散髮箕踞，醉臥墟墓間，非家人覓之，即竟夕不返。如是者有年。

年五十有八，竟病酒以卒。未卒之前一月，忽卻酒，屏一切藥物不御，獨日取清水飲之，曰：「吾欲此中空空洞洞，不畱一物，以還吾無物之天也。」然則公固不物於物，豈物於杯中之物哉？

伊子[[陈仲鸿|仲鴻]]，以余知公最悉，囑為公傳。

嗚呼！余不足以知公，又烏足以傳公？公時靜時躁，時黠時癡，時莊時諧，時人時鬼，如蜥蜴一日十二變。其體雖公亦不自知，人何足以知之？又何從而傳之？茲姑就余所知，為傳一篇，以質世之知公、傳公者。
