# 平湖恩五百六十二鉉玉公傳[[陈鼎新]]
```
题：[]眷小弟府庠生虞書頓首拜撰
峕：[16修]康熙歲次甲子仲冬吉旦
初始点校：[20260802]民国庚辰本[3/33]P296
修订参考：[20260921]
```

士之處世，有孝悌自盡者，有友誼克敦者，有睦宗族而持危濟變者，吾於檀溪陳公諱鼎新字思易號鉉玉者見之矣。蓋跡其行誼，溫清無懈，定省罔間。幼遭父疾，藥餌難愈，割股以療親。斯時雖未表揚，迄今猶皆傳頌，以為無忝所生。不料雲暗椿庭，而萱花獨茂。其母悲泣之餘，惟以教子誦讀為念，於是請師延友，酷望為士林中人。公矢志芸牕，風雨不輟，遂列名黌序，豈非寓孝親於慰親中乎？

且廼兄有三，愛公實甚，固皆體母以玉成之，而公之視兄如父，言必聆，行必遵，以致常棣興歌，而為一家之政。此其孝悌自盡者一也。

凡與友處，本坦白之懷，為結納之雅，猜嫌不作，歷久彌敬。炊金饌玉，款接愈殷，雖瓶罄而不吝。古道照人，殆其謂歟？此其友誼克敦者一也。

至枌榆內，不貧貧人，不賤賤人，視彼富貴，澹如也。閒有鄉鄰爭競，無不勸釋；同室致鬭，力為解救。至今春風和雨，拂拂於閭閻間，非公惠乎？此其敦睦里黨者一也。

他如戊子年（顺治，1648），白寇[^1]蜂起，勢焰猖狂，人皆束手無術。幸邑侯韓公聞公之德，慕公之才，遴為鄉正。設法守禦，招安投誠，歸順者俱俾星散；附居編入保甲。以致孤黨烏合之人，轉為稱干比戈之士，撲滅萑苻，咸公之德。

至庚辰年（年份疑为庚寅，1651），歲遇凶荒，奉憲委帖，沿村勸賑，即將本村富室所捐之資，給於本村匱乏者，而一都之饑荒受濟，皆公之惠。此其持危濟變者一也。

公娶安人周氏，內儀淑慎，生一子諱元兆，字𨳩生。溫文儒雅，穎悟不凡。初就試，連獲遊庠，公不既幸書香之有繼乎？而未已也。開生負笈余館，曁二載，窮其志，如登百尺樓頭，俯視一切；閱其文，如挹三春新柳，奕奕動人。余不禁忻然喜曰：「子豈池中物耶？行將登壇以光日月，破浪以遡天風，直指顧間耳。」況蘭枝吐秀，品格超群，異日必為大成器，豈非公之積善所致而能若是歟？雖然，公踰耆年而猶進德不已，不已其德者必永其壽。《詩》曰：「樂只君子，遐不黃耇。」徵公其誰與歸？是為傳。

康熙歲次甲子仲冬吉旦
眷小弟府庠生虞書頓首拜撰

[^1]: 白寇：指清初白头军起义。详见[[奕世修谱#順治戊子，白寇之乱（1648）]]
