# 平湖恩四百七十八慶庵公傳[[陈克有]]
```
题：[]海鹽徐鑑拜撰
峕：[17修]康熙歲次辛巳春王正月望後十日
初始点校：[20260802]民国庚辰本[3/33]P294
修订参考：[20260921]
```

余樣不趨時，動輒倣古處，但以孤陋寡聞，每思老成，自俾稔聞浦邑月泉，乃晦菴[^1]講道處，必私淑有人，遂博訪在念。己巳（1689）秋，取道富川，抵浦陽，衣冠循古，禮樂雍熙，小鄒魯之傳，良不誣耳。與月泉諸君子盤桓旬日許，及品論高士，則羣推慶庵。於是越仙華北道，見懸崖牽薜荔，倚磴映絲蘿者，湖嶺也；奇石為屏嶂，清流抱曲灣者，汪潭也。少焉殘照沉波，流霞散樹，俯仰間鶴髮童顏，素巾野服，若地行仙者，揖余住趾而敬陳焉。余亦請其族望，系出太邱；詢其家風，高傳徐孺。諱克有，字思餘，號慶庵也。

余驚喜交集，謂天假以緣，得披雲之覩，慰饑渴之懷。果容貌端莊，言詞慷慨，誠雄豪絕俗之資，高深羽流之傑，殆傳之非謬也。即止余宿，余亦如命。連袂行半里許，黃花三徑，明月一池，稚子候門，僮僕歡迎，如登龍門之陂，恍入芝蘭之室。令子循序而相敘，曾元以次而接見。炊金饌玉，琬液瓊蘇，所道嘉言懿行，厚語德音，不覺星橫斗柄，月在海棠，則余酩酊而就寢矣。

次日，因余是他鄉之客，非入幕之賓，復邀客數輩會予，其文章議論，博古多聞，咸與慶庵組織仁義，琢磨道德之素交者也。予備述慶菴（庵）高誼，客曰：「慶庵之概，子知之否乎？」予曰：「未知所以至也，恐傳之非其真耶？今所見過所聞耶？」客曰：「子之聞所聞而來者，今果盡見所見乎？慶庵耶？親敬友肅，然為政於家，安老懷幼，即已教成於國。憐孤恤寡，心存羊舌之仁；濟難扶危，事合麥舟之義。攜杖閱耕，得淵明歸來之句；延師課讀，羨教子一經之傳。元配盤洲周氏，婦儀貞靜；女適同山邊氏，質成詠絮。長君諱作梅，德量温菾，書窮二酉，已遂芹香；仲君作舟，氣概磊磊，學富五車，未沾泮水。則元配夢遶吹臼，詞著碎琴，因家政紛紜，童僕無倚，繼配本邑傅氏，神清散朗，有林下高風，幽閒玉映，為閨中雅秀。得推慶庵於月旦鄉評，能成仲君於青襟座右。再添幼君諱作霖，頭角崢嶸，才思捷敏，河東美名，他年有待；慈明香譽，指日堪誇。」

客言甫畢，予喟然曰：「仰止長者之高風，足當古今之則傚；領略仁人之懿德，堪為持己之楷模。則晦庵之流風私淑者，慶庵也；而余之做法古處者，舍慶庵其誰也？」余後每因煙水棲遲，雲山躑跼（躅），時登庾亮之樓，久虛陳蕃之榻。

於今辛巳，復造請謁，叩其幼君，知長仲二君已先慶庵而修文天上，不作賦人間。慶庵亦以戊寅而乘洞庭之黃鶴，跨函谷之青牛。噫！高霞孤映，明月獨舉，青松落庭，白雲誰侶乎？然幼君學已升堂，名登天府，諸孫曾元輩文章造就，終成大器。慶庵生當世而有聞，沒後世而有傳，余無足悼矣。厝於郎家畈，余往拜謁，山峩峰疊，水遶沙明，仍享烟嵐雲渚之趣，霽月光風之味，誠福人福地也。但青簡尚新，宿草將烈，懸劍空隴，引恨紼緣，慳能已於悲乎？

康熙歲次辛巳春王正月望後十日，是傳。
海鹽徐鑑拜撰

[^1]: 晦菴，指朱熹。

# 平湖恩四百七十八慶庵翁傳  

今夫枝繁者本大，流長者源深，後昌者德厚，理勢然也。世之人不務積德，非崇刻薄，則尚虛華，父子兄弟以是為傳家懿範，是猶拔本而欲其枝之繁，塞源而欲其流之長也，豈不惑哉？若慶庵陳翁，所稱蓄德長者也。翁生而岐嶷，長而克家，天性謹厚純樸，痛絕奢靡。儉以教家，而家日隆；和以處眾，而眾自服。嘗曰：「人之行事，常常靠實近理，自常衾影不愧。」讀書知大義，以雅慕林泉，不求聞達。既而曰：「勤儉者，治家之本；詩書者，禮義之府也。人不知學，則禮樂不與，禮樂不興，家胡可久？家胡可大？」乃專心教子，延請名師，束脯之厚，敬禮之誠，始終如一。以故長君作梅、次君作舟，俱弱冠蜚聲庠序，為名諸生；幼君係籍京璧，才氣超逸，名譽著縉紳先生間。諸孫頭角崢嶸，皆麟趾之選也。  

翁以蒼顏白髮，當慶祝時，賓盈階，觴稱繞膝，人望之如喬松仙鶴，無不嘆羨。翁諱克有，字思餘，慶庵其號也。府尹李公以齒德俱尊，授冠帶旌異之。享年八十有四，其生卒具載譜牒，子不贅云。  

贊曰：萬石君以醇厚勤謹起家，身都壽考，子孫貴顯，為世罕覯。翁豈聞風而興者與？名簡滿膝，目覩五代，何其盛也！《易》曰：「積善之家，必有餘慶。」翁之命名以是，若翁者，豈不實副其名哉？  

康熙四十年春王正月  
眷小姪龍溪張德允拜撰
