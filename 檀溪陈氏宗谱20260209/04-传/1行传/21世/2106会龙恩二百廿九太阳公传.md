# 會龍恩二百廿九太陽公傳
```
题：[]麟溪眷晚生鄭應第頓首拜撰
峕：[16修]康熙歲次甲子仲秋穀旦  
初始点校：[20260801]民国庚辰本[3/33]P291
修订参考：[]
```

公諱惟城，字思宗，號太陽，仰山公之幼子，邑庠生也。稟性醕厚，雅尚詩書，而行敦古處。席祖父豐亨之餘，雖富甲一鄉，驕奢不事，惟以齊家訓子為業。次子汝芳氏，早遊泮水，克承乃志。時以海氛未靖，縣主命公往甬江督造戰艦，功成而歸，范公旌獎，給匾以勞之，有曰「嘉勞艦績」，其功已著於為國。又念宗祠頹壞，捐資修輯，渙然聿新，宗族義之，配享不祧，功更表於為家。  

爰是郡邑嘉公行誼，兩請介賓，毛公錫之匾曰「儒林雅望」，合邑榮焉。長子汝用氏，幼子汝能氏，咸麟趾振振，英邁卓越。雲礽代起，孫永旭氏，今又青年入泮，三世遊庠，亦閭里所罕覯者。人僉曰：「檀水之地靈人傑，夫孰非公之積厚而流者耶？」  

余竊遐慕焉，而未獲親其令範。今幸而與其賢允交遊，雖公之嘉言善行，有非余所能備悉而誌載者也，聊約略其素履，以髣髴（彷彿）公之萬一云。  

康熙歲次甲子仲秋穀旦  
麟溪眷晚生鄭應第頓首拜撰
