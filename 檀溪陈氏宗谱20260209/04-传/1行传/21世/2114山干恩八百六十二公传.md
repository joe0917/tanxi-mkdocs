# 山干恩八百六十二公傳
```
题：[]麟溪外甥庠生鄭守鈿頓首拜撰
峕：[16修]康熙歲次辛巳孟夏月望後一日  
初始点校：[20260803]民国庚辰本[3/33]P298
修订参考：[]
```
（未核对原文）

公諱克渭，字思望，號恆心。天性孝友，為人易直。年未及冠，輒失所怙，每以不獲奉養為憾。母病，供甘旨，侍湯藥，始終未嘗有懈怠，一鄉士民咸稱之。兄弟三人：孟曰克清，體度沖和，有長者風；仲曰克濂，有學行，習舉子業，嘗試不售；而公其幼也，聿敦弟道，凡家庭事務，必稟命兄長。至父遺財產，一錢寸帛，莫敢私己。而孟兄克清嘗樂貿易，家業幾罄，公毅然告兄曰：「貧富皆由天定，欲圖微利，反致虧資，何如專守農業之為愈乎？」兄悟而止。厥後家道昌熾，較倍於前，則公之力也。《詩》云：「式相好矣，無相尤矣。」公其有焉。  

歲甲寅，寇亂，居室被回祿。踰年，邀同尊長，重葺堂構，以復宗祖舊制。乃公忘私，幾經費力，則又其繼述之善。先君遺業，亦漸恢廓，豐腴課子詩書，冀有成立。以年臻衰晚，未如所願。接親友宗黨，藹乎其有儀也。公可謂賢子孫矣。  

余向仰植溪陳姓，為吾浦望族，其間英賢世出，孝友傳聞者，代不乏人。若公者，非其接踵者耶？娶在城趙氏，溫柔爾雅，能敬事夫姑，以諧閨闈，相夫成家，婦道無愧。二子元榜、元相，昆弟友于，事親克供子職。至榜以割股療父，孝心彌篤，有乃父遺風，斯亦德流光之一徵與！爰是載諸譜牒，以為世世子孫勸勉云。  

康熙歲次辛巳孟夏月望後一日  
麟溪外甥庠生鄭守細頓首拜撰
