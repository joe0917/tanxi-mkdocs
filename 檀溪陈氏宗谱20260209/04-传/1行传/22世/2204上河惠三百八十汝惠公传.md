# 上河惠三百八十汝惠公傳
```
题：[]邑庠生族甥張啓鰲頓首拜撰
峕：[19修]雍正七年桂月之
初始点校：[20260803]民国庚辰本[3/33]P303
修订参考：[]
```
（未核对原文）

翁諱元吉，字汝惠，鰲外祖君立公之同族弟也。與外祖幼同筆硯，奮志功名。翁緣數奇不遇，兼之兄弟分爨，遂棄儒業而操家政。外祖嘗曰：「斯人也，隱而賢者也，吾未之逮也。小子識之。」弟之為人也，其容退然如不勝衣，其言呐然如不出諸其口也。樸貌古心，然諾未嘗之或爽也。弗行所悔，弗安所殆，與人無忤，與世無求，雖權貴弗附也。以斯知翁誠隱而賢者也，其生平可誌也。雖然，未足概翁，請核其行事：孝于親，友於弟，恭於兄，宗族稱其敬，朋友仰其信，兒童僕婢誦其慈。使得時而駕，上佐昇平，下奠百姓，將綽有餘裕。彼趨功名而祿與庸人等者，豈可同年而並語哉？

翁之為人，鰲總角時聞於外祖者詳矣。今陳氏家乘重修，鰲相與勸力，敢聽其湮沒而勿傳也耶？至於翁子蜚聲庠序，翁孫待詔金門，曾孫鵲起玉立，此翁積善餘慶所致，不必多贅。是為傳。

雍正七年桂月之吉
邑庠生族甥張啓鰲頓首拜撰
