# 祈山惠二百八十三旭山公傳（另列贊）
```
题：[]眷侍教生歲貢樓澐頓首拜撰
峕：[17修]康熙辛巳暮春上浣之吉 
初始点校：[20260803]民国庚辰本[3/33]P301
修订参考：[]
```
（未核对原文）

今世之所重者，非端方誠直之品乎哉？然求之於古，庶幾遇之；求之於今，百不得一焉。余是以心儀其人，所至輒為訪問。辛丑歲，余館縉紳潘會成先生家，嘗與先生言：「此都之山，磊落而秀拔；其水，清澈而深長。當必鍾靈出俗之士，足模楷乎鄉邑者。」先生曰：「洵有之。自盤溪溯流而上，有檀溪陳翁，諱元素，字光行者，制行端方，立心誠直，真覺古道照人，非復晚近所能仿佛者。」余曰：「其詳何如？」先生曰：「其事親也，色養無懈；其待昆季也，友愛性成；其處鄉里也，遇豪強而不屈，遇鰥寡而必矜。至於族黨有事，人所累日而不能剔白者，翁每以一二語解其紛賾。且其生平取與，皆準乎義，非其義也，雖有道施捨祈禱之說，介然不為所惑。至於義之所在，凡有功於族，有濟於人者，慷慨捐資，初無吝色。前甲寅，邑遭兵燹，宅有祠堂，悉已傾圮，翁出其橐囊，助以沃產，興二三同志修葺，煥然一新。又每建造輿梁，不惜數百之貲，眾人往來，利涉咸嘖嘖稱道勿衰。他如濟急扶危，完人夫婦，活人孤幼者，蓋指不勝屈焉。至今屆耄耋，年彌高而德彌邵，志益壯而神不衰。課耕課讀之暇，日攜杖於祈山之麓，翔步於檀溪之濱，徜徉自得，如地上行仙。斯非所謂出俗之士，足模楷乎鄉邑者耶？」

予聞而慕之，嘗以不見其人為憾。甲午春，翁率其次孫女睿訪余於盤溪館內，命就學焉。余見其精神矍鑠，風岸高騫，冠履舉止，誠非時下所有。潘先生所稱於此，已見其梗概矣。而詳問植溪居人，其所稱述與向之所聞，片言不爽，乃益歎翁之立身行己，自有法度。繼子象賢，宜其諸孫率教，俱能以禮法自律。長孫以智，光明俊偉，無齷齪之氣；幼曰以聪，資秉穎，方業儒之始，而頭角已嶄然可見矣；次孫以慧，力學勵行，志無少衰，其文與品，又將甲於鄉邦。夫以翁立品之高，制行之純，終當得有力之人操椽筆以表揚其盛德，以風勵夫當世。而予亦不辭謭陋，述所聞見，特為之蒿矢云爾。

康熙辛巳暮春上浣之吉  
眷侍教生歲貢樓澐頓首拜撰
