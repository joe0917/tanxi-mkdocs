# 大畈惠千二百十二公孝行傳
```
题：[]小姪之芳拜撰
峕：[19修]雍正歲次己酉季春望後
初始点校：[20260803]民国庚辰本[3/33]P305
修订参考：[]
```
（未核对原文）

嘗聞立行多端，莫大於孝；人生至痛，莫切於死。乃有以死成孝，而其孝卒不彰者，最可嘆息矣。余族叔諱元情，字汝篤，係恩千五十四公之幼子也。其孝誠有異於尋常者。平日問視定省，竭力以事親者，不可勝舉。適當其母患病，醫無效，病日篤，舉家束手無策，親鄰嘆為數盡莫救。乃至性感激，聞惟割股可愈，乃遂告天，割股以啖母，母復得安康如故，至今尚未艾焉。豈非孝行格天，有以致之哉？  

惜母雖保，而身已亡。當其時，恐家人知其事，聞於母，病反不痊，於是取水洗血，冒風遂至殞生。其身雖亡，其行不益足表歟？今適修譜牒，其兄元惇每念幼弟，不禁涕泣傷心，常囑於余，欲誌其行。余亦謂孝若斯人者，安可使之冺沒而不彰耶？故敢妄措數辭，以示不朽云。  

雍正歲次己酉季春望後  
小姪之芳拜撰
