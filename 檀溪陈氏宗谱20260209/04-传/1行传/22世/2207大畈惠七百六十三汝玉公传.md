# 大畈惠七百六十三汝玉公傳
```
题：[]鄉貢進士眷小姪毛可珪頓首拜撰
峕：[19修]雍正七年歲次己酉季春望後
初始点校：[20260803]民国庚辰本[3/33]P305
修订参考：[]
```
（未核对原文）

吾浦之北有陳公，諱元珠，字汝玉者，系出名門，世傳忠厚。考其生平，慎交遊，重然諾，不苟同乎流俗。迹其家聲，課耕讀，新棟宇，大克昌乎前猷。乃世多曰公本分，嗚呼！本分可易言哉？夫不矜才，不使智，無以耀庸流之耳目，故公之不足以炫一時之口碑也。詎知立大本，安素位，有以體聖賢之庸行者，實深足以培奕葉之福基也。  

公幼失怙，與兄元琳自襁褓以迄成立，克供子職，奉母以節壽終。元配黃氏，舉案齊眉，生子四：之益、之芳、之華、之萼，皆箕裘克紹，孫子振振。其次子之芳，字徽仲，敦敏夙成，克勤舉業，將來附鳳攀龍，今已采芹折藻，積厚流光。豈非公之無虧乎本分，而有以獲無窮之報哉？  

余愧不才，誼屬姻戚，得與徽仲兄遊。凡遇公，即以勤讀是訓，其誥誡諄諄，期望殷切，冀余與其子以共底於成立者，殆不啻父師。故不辭謭陋，聊紀其實行，以垂不朽云。  

雍正七年歲次己酉季春望後
鄉貢進士眷小姪毛可珪頓首拜撰
