# 祈山惠五百廿六金谷公傳[[陈元炳]]
```
题：[]浣溪府庠增廣生員通家眷侍教生蔣祚增敬撰
峕：[16修]大清康熙歲次甲子孟冬月之吉
初始点校：[20260803]民国庚辰本[3/33]P303
修订参考：[20260922]
```

余向偕二三同志，把臂舒懷，凡巖壑佳勝，輒為登陟焉。蓋欲歷覽名山大川，博觀風土人物，誠以山川峙流逈異，其間必產豪邁不羣之士，固其常也。

今甲子春，予過浦陽之墟，見夫巍然聳秀者，祈山也；悠然不息者，檀水也。且路寢奕奕，孔碩孔曼，其煙光相錯，廬旅而處者，陳氏之家廟與居宅也。夫陳為邑著姓，其英賢之挺生，代不乏人。有諱元炳字君文者，偶與語，卓犖不凡，殆所稱賢豪問者耶？  

公幼失怙，克自樹立，秉性孝友，制行剛方。義所當為，必奮勇為之。少攻舉子業，以事繁不果就，日課農桑，謀生殖，又謹少慎微，無不周悉夷考，其地屢為綠林所侵。一摧殘於順治戊子[^1]仲春，而公乃祖所建創之華厦，輪奐於前者，至是而灰燼矣；一破毀於康熙甲寅[^2]季冬，而公先人所經營之祖廟，巍峩於昔者，至是而傾頹矣。斯時也，父兄宗族莫不深離黍之悲，而有似續之志。僉曰：「是舉也，非正直無私之人，曷克勝其任？」於是咸舉公董治宗廟宫室之事。廢者興之，玘（圮）者葺之，而棟宇峻起，以成大雅之觀焉。  

然使家聿新者，固所以妥先靈；而使家乘秩然者，尤所以垂後裔。又敦睦九族，取譜牒而纂輯之，俾親疏長幼之等，支分派合之源，無不犁然而畢舉。至於會眾重興本境胡公聖廟，大其規模，亦敬以事神之道，又安可湮沒而不傳？由是而觀，纘緒繼述之事無不至，尋祖敬宗之舉無不周，愈以知公之挺生於其間，誠由岳瀆之降靈與山川之鍾毓，而後豪邁不羣若是耳。  

余於是不辭固陋，因忻然敘其生平，而樂為之表揚云爾。  

大清康熙歲次甲子孟冬月之吉
浣溪府庠增廣生員通家眷侍教生蔣祚增敬撰

[^1]: 1648年“白寇之乱”。
[^2]: 1674年“三藩之乱”。
