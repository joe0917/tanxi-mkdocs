# 會龍惠二百八十六鈍庵先生傳
```
题：[]蘭江後學庚午科舉人諸葛琪頓首拜撰
峕：[17修]康熙歲次辛巳季秋之吉
初始点校：[20260803]民国庚辰本[3/33]P302
修订参考：[]
```
（未核对原文）

先生諱元彥，字汝聖，恩百五十四公之長子也。性嗜學，工詩文，採芹最早。然讀書不事剽竊，制行務合中庸，蓋三代以上誠確君子也。每疾世人以巧詐相尚，因自矢其意曰「鈍」，遂表為號。

後甲寅冬，賊寇猖獗，鄉曲多無寧日。先生以為士君子一失身賊人之手，忠孝二字不可言矣。遂率妻子，負其二母邊與蔣以逃，始於暨，終於杭。越明年始歸，而家計已盡付之灰燼矣。先生初不惜之，略結草堂數間以課其子，繼及其孫。

而長子炳文氏補餼，次子之烓、幼子之焜勤儉持家。孫以俊、以仕俱已弱冠，相繼遊庠；以侯、以傳甫五六歲，已善讀書，聰明過人，將來定作國家偉器。嗚呼！非先生貽謀之善，烏能若是之昌且熾乎？矧將來者之駸駸未有極也。

時修家乘，囑余作傳。余欣然操管曰：「余知何傳？惟傳先生之所不能盡傳者而已矣。」

康熙歲次辛巳季秋之吉
蘭江後學庚午科舉人諸葛琪頓首拜撰
