# 平湖蘆洲公行述[[陈仲鸿]]
```
题：[]舉人姻再姪虞廷頓首拜撰
峕：[33修]光緒紀元廿九年，嵗次癸卯，立秋後一日
初始点校：[20250728]民国庚辰本[3/33]P375
修订参考：[]
```

翁諱仲鴻，字志飛，廬洲其號也。世居政內鄉之平湖，自其祖邑庠公[[陈祖现|現]]、父議敍公[[陈恒署|亞咸]]，以詩書世其家，爲鄉里所推重。

翁幼時承世業爲文章，雍容渾穆，巳非時輩所企及。年未冠，邑庠公辭世。議敍公閑淡不事，翁以家督任家政。有弟三人，咸服翁教，門庭以內肅如也。

翁性孝友，爲祖父母營度葬地必謹，因是曉靑烏術。議敘公沒後，兄弟析爨，某田某宅與某某，一惟翁命。翁與堂兄弟偶因細故，致䦧[^1]於牆，然或有外侮，禦之必力。

翁祖遺“西園”、“半規草堂”、“夢花廬”，咸豐丁巳沒於洪水，翁締造“自怡軒”、“醉月園”兩所，皆規模宏厰，倘所謂“繩其祖武”者非耶？

陳氏固巨族，祭祀田畞記載淆亂，非所以垂燕翼也。翁淸釐挨次，著錄於譜，其爲後嗣弭患於未形者至矣。粵逆之變，宗祠燬焉，翁與同族英樣、榮炳等創議重建，至今廟宇常新，蒸嘗時舉，不至興黍離麥秀之悲者，皆翁與同事諸君力也。

嘗應童子試不售，援例貢入成均。翁由是遂棄八股，乃肆志於古文詩歌。浦陽鄉先生著作流傳如崑山片玉，人知珍重，率以無力付梓多湮沒而不傳。翁所手錄如朱氏《鶴皐》、《周易闡義》、王氏《味經文集》、朱氏《康人詩集》皆是，此外尚不下数十種。鄉先生有知，宜何如呵護也！

匪平以後，世事滄桑有可爲浩歡者。吾浦藏書家或不能守其業，翁則購藏而掇拾之，視守錢虜多藏厚亡，其賢不肖相去遠矣。

浦陽邑志歲久失修，御史張公少蘿首創重修之議，翁聞欣喜過望，謂："自乾隆以來百數十年缺而不舉，此大憾事。今得身與其役，掇百年之事實，成一邑之典故，敢不力乎？"以積勞故，病劇而亡，時光緒甲午四月廿八日也，距生於嘉慶己卯六月日，享壽七十有六嵗。

翁沒逾年，張公又謝世。浦人與修志事者或侵漁公欸，或記載不實，囂然相爭，事以中梗。翁在地下，宜何如飲憾也！翁晚年尤工書法，求書者繹絡不絕，翁皆應之不辭。著有《亦可居詩文集》若干卷。

娶周氏，幼嫻內則，嬪於名門，稱佳耦焉。生克家子三：長曰時遇，庠生；次曰時逢，皆先翁卒；幼曰時遌。孫男五：曰橊、梅、枝、相、樞；曾孫二：曰柏林、杏春，生時翁或親見或不親見，今皆嶄然見頭角矣。翁子若孫以庚子年土月葬翁於王司坑之原，卽翁生時所自營兆也，青烏家稱福地焉。後嗣之昌，又可量耶。

翁長孫橊，廷姊丈也。廷每至翁家，翁爲廷稱引古昔，指示書法至剴切。維時廷年尚幼，不能盡記憶也，然至今猶可想見翁之爲人。略敘顚末，以俟後之修志者採擇焉。

光緒紀元廿九年，嵗次癸卯，立秋後一日。
舉人姻再姪虞廷頓首拜撰。
