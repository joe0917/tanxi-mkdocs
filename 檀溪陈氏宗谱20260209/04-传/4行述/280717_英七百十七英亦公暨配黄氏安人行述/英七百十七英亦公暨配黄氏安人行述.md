# 英七百十七英亦公暨配黃氏安人行述
```
题：[]族孫崑山琳謹識
峕：[]光緒二十九年端陽後一日
初始点校：[20250804]民国庚辰本[3/33]P376
修订参考：[]
```

補拙者莫如勤，養廉者莫如儉。勤也儉也，大言之爲治平之要道，小言之爲修齊之本務，無貴無賤，同爲寶訓。此克儉克勤，所由載諸《大禹謨》也。雖然，勤儉二字談何容易！儉而不勤其失也吝，勤而不儉其失也奢。使奢且吝，人將鄙夷之不暇，而何暇稱道弗衰哉？

鄉飲賓英亦公者，行英七百十七，湖山派延七百五十七之次子也。自幼至老，且勤且儉。舉凡男錢女帛，及一切家務，悉以一己總其成。至如鄰里往來，友朋贈答，或豐或菲，各適其宜，不失吝亦不失奢，其諸異乎勤而不儉、儉而不勤者歟？

元配黃氏，長公二歲，四德三從，素嫻姆訓躬。爲炊手，爲紡織，斯何如其勤也；荊爲釵，布爲裙，斯何如其儉也。內助之賢如此，則公之刑于可知矣。

舉丈夫子二：長曰毓深，服田力穡，乃亦有秋；次曰毓江，榜名麟祥，藝嫻韜略，縣試冠軍，曰破天荒，嘖嘖人口。而二子俱勤儉持家，有乃父風，洵不愧爲肖子歟！抑亦恃有義方之訓也。

孫男六人：頴棹、頴樹、頴椆，能負薪矣；頴悟、頴鑑、頴亮，年尚幼穉，然俱頭角崢嶸，加人一等。豈是惟勤儉可風，繩其祖武云爾哉？曾孫二：豐植、豐梅，試聽啼聲，共推英物。爾熾爾昌，正未有艾。

夫勤儉如公，近今有幾？而年幾八旬，猶復矍鑠。《書》所謂「身其康强，子孫其逢吉」者非歟？今修家乘，琳忝與事，固不自揣固陋，姑述公之梗概云爾。若夫煌煌鉅篇，傳誌不朽，請俟後之能文者。

光緒二十九年端陽後一日

族孫崑山琳謹識
