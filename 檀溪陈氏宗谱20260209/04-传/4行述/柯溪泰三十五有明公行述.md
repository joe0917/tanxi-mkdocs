# 柯溪泰三十五有明公行述（祭田移載行傳）
```
题：[]泉溪廪膳生員周重賢拜撰
峕：[]
初始点校：[20250803]民国庚辰本[3/33]P373
修订参考：[]
```

翁諱有明，字汝𤤁，與予居隔三十餘里。其孫以琜嘗就學於予，因知翁生平大概，誠高坑間之隱君子也。

幼習舉業，長於文詞。旣而聖賢垂教，以修身行善爲先，弄筆墨其聲華耳，以是不應者援祥於視履。躬耕爲先，養親惟崇實黜是務。
居鄉周貧乏，和宗族，里閭爭仰之。
居家篤友誼，盡慈愛，子弟胥率之。
其殆匹夫而化鄉人，父兄而垂法則者歟？

邑侯邢公聞其賢，旌其行實，以爲民望。而翁益懋厥修，年高而德邵。以故天故長亨，諸福駢臻。生三子：長之玉，次之添，幼之初，恂恂有厥考風。嗣孫十餘人，耕者樂業，讀者英異，類皆頭角嶄然，奕世濟美。一家之貽慶，何窮乎？

棄世時，壽已七十有九矣，而舉案齊眉白髮偕老，非修德之徵而能無傷參差歟？今卽名不列宮墻，爵不登仕宦，而仁讓家風，薰德善良者猶彰彰耳目，誠巖居野處之君子哉！

予高其德行，聊綴數語，并附祭產於篇末，以誌不朽云。

泉溪廪膳生員周重賢拜撰
