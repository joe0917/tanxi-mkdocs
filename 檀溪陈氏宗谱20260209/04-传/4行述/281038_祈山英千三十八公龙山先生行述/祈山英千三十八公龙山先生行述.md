# 祈山英千三十八公龍山先生行述[[陈拱辰]]
```
题：[]蘭谿蔣六山拜撰
峕：[]民國五年之秋前二日
初始点校：[20250804]民国庚辰本[3/33]P377
修订参考：[]
```


浦陽山水奇險峭拔，其最著名者仙華山，屹立空際如筆一枝，高插天半。而仙華山後湖溪出其間，曲折環繞，層嵐疊嶂，左瀠右洑，以直趨富陽江。產其間者，往徃多高士畸人，隱德君子閉戶潛修，老死而名不傳者，何可勝道。如吾龍山先庄者，亦其一也。

先生姓陳氏，諱拱宸，字龍山，邑北鄉廿六都之寺前人。少入邑庠，補增廣生，隱居不仕，澹泊自守，以道德淑其鄉。後生小子每從之游，薰其德而善良者，不知凡幾。先生守老氏“誡知白守黑”，不爲天下先，淡于榮利，沈靜寡言笑，執贄門卜者，如坐春風中，不言自化，故成就者頗多。晚年課田園娛老自樂。

配虞氏，得內助力，閨門肅睦，無間言。子一，頴喜，畢業中學堂，明敏好學；女二，長適虞宅虞柳堤公子廷。公晚年以壻奔走國事，不遑家居，爲經紀其家，治田力穡，鄉人咸尊敬之。

公生於道光辛丑年十一月初四日，薨於民國五年三月廿六日未時，無疾而逝，享年七十有六歲。嗟乎！如公者，不謂非一鄉之善士也已。今年秋，其族中修譜牒告成，特爲表而出之，以俟後之知先生者。

蔣子曰：世界交通日趨文明，習俗嬗遞，新機代出，可謂極一時之盛矣。所缺者，道德耳。先生抱德煬和，隱居自樂，保存一鄉之醇樸，維畱萬世之綱常。古之所謂"鄉先生沒而祭于社"者，微先生其誰與歸？安得如先生者數十人，爲吾婺維持社會，式靡振浮。惜乎其又弱一个也。先生有知，當不斥予言爲謬妄乎？

民國五年之秋前二日

蘭谿蔣六山[^1]拜撰

[^1]: 蒋六山（1848年—1925年），名倬章，号鹿珊，浙江兰溪柏社乡水阁村人。清末民初实业家、教育家，曾任金华丽正书院主持人，参与襄办中国公学与《经世报》。早年创办梅溪试馆、兰溪缪源煤矿公司及金华北林牧公司。
