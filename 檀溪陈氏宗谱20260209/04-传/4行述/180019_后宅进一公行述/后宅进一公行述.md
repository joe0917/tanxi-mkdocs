# 後宅進一公行述
```
题：[23世/宣640]祈山派邑庠生孫啓經拜撰
峕：[18修]康熙五十四年乙未春月
初始点校：[20250803]民国庚辰本[3/33]P373
修订参考：[]
```
[[檀溪陈氏18世（賢貞彥英明進）#^180019]]

吾族居檀石派者，惟公之後爲最盛，而合族祭田亦惟公爲最多。

甲午春，重修宗譜，裔孫之文、之欽囑余傳公之行以誌譜牒。余生也晚，不獲見德徽於當日，又未嘗得諸父老之傳聞，小子何敢妄贅？自春至冬，屢以爲言，余終以自相矛盾爲嫌。

乙未春，譜師印刷文集，偶見節婦傳中「全四公安人王氏」卽公母也，敘公行事甚詳。適二兄時末迫余，因仍其舊傳，獨述而表之。

接舊行傳載公諱白，而《節婦傳》又云公名廷白，或者諱白而字廷白也。舊傳云：公生八月，慈父見背，母深溪王氏立志撫孤，家苦酷貧，惟廷紡績以供衣食。則公幼時伶仃孤苦，概可知矣。從來節婦難爲，節婦之子更難。

舊傳云：公方弱冠，初通文墨，或有勸公謀舉子業者，公辭曰：「吾無老母，無以至今日；老母無吾，無以卒餘年。母子二以，形影相弔，總顯親揚名，何忍遠離膝下也？」公之克全孝道，又可知矣。

男女之情，兩不相侔。舊傳云：公之安人周氏，姑病歲餘，衣不解帶；及臨喪時，哭泣哀慟，死而復甦者數次。豈安人之天性然耶？抑公之孝行有以感發而致耶？

《易》曰：「積善之家，必有餘慶。」全四公之不絕者如線，而舊傳云：公方中年，爲曾祖父立祭田甚豐，是公始於貧而終於富矣。

公生宏治庚戌九月初八日，卒嘉靖辛酉三月十四日，享壽八十有二。安人生宏治壬子十一月十一日，卒萬歷戊子二月初一日，享壽九十有七。生五子，女二，孫十餘人。豈節婦之後，必報之富壽多男如是耶？抑公之夫婦應合富壽多男如是耶？迄今相傳不過五世，而子孫何啻數十家，莫謂冥冥之天報施或爽也。

凡此皆考之舊傳中約略可信者，今特纂述其舊而已，小子何敢妄贅？

康熙五十四年乙未春月
祈山派邑庠生孫啓經拜撰
