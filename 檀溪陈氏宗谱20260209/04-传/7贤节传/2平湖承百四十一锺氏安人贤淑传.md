# 平湖承百四十一鍾氏安人賢淑傳
```
题：[]浦汭愚表弟陳大悅謹誌
峕：[]大淸順治六年己丑冬月
初始点校：[20250808]民国庚辰本[3/33]P397
修订参考：[]
```

淑人閨諱□□，乃余母舅祿七公之女。余童子時，嘗同吾母在外祖母家，淑人時年八歲，繡織松竹梅於肚褡內，舅姆與余縛之，其枝之茂，葉之蓁，儼如土壤之栽培者。吾父訥齋翁見茲繡本而嘆曰：「非凡針繡所爲，若仙姬之織於布帛者耳。」

及長而于歸吾族平湖陳一鰲公，孝養翁姑，教順夫子，嘖嘖人口，賢哉茲淑人也歟！當年三十餘而夫君被洪水溺殞，喪祭之禮，靡不自盡。淑人攸生六子，長諱克紋，次克紳、克紈、克績、克守、克勤，咸英敏特達。淑人振設家規，罔敢踰越，乃搆造華居一座，計二十餘間，另扦居住，姑媳之和，諸子孫之康樂，人皆曰：「淑人真女中男子也。」

居孀四十餘年，明崇禎年間，邑侯蘇公諱闌翰贈匾曰「秋霜勁節」，洵不誣也。余讀孔子有言：「歲寒然後知松柏」。後彫若然，淑人預鳴也歟？追憶幼年淑人之織松竹之堅，寒梅之潔，追今耄年之操節，其亦幼年之蓄志適相契云。

姑在陳門爲節婦，在父族爲貞女，誌之以垂不朽可耳。賢節著夫族內，父族不錄。

大淸順治六年己丑冬月

浦汭愚表弟陳大悅謹誌
