# 茅坪明故欽百四十九凌氏安人寡母傳
```
题：[26世/廉258]祈山派裔孫耀偀謹撰
峕：[23修]大清嘉慶三年戊午十月
初始点校：[20250807]民国庚辰本[3/33]P395
修订参考：[]
```

譜之例，凡婦人勵志守節，至老無玷者，節力不足以上聞，亦必立傳譜前，彰其貞德。其或孝養舅姑，敬夫敎子，可爲閨閫模範者，亦必特爲表出，以訓後人。是有其一者，且不可以弗傳，而況兼有其二者乎？

邵子之言曰：「死天下事易，成天下事難。」昔呂九儀爲讐家擠水死，其婦痛欲自經，卒用姑之命，修業而息之，撫子抱孫，以天年終。方子大其從命有後，爲述數百言，流連反覆，惟恐弗詳。嗚呼！使其聞我母之行，抑又何如也？

母凌氏，茅坪派欽百四十九公室也。公諱大潘，行事不少槪見，要亦勤儉樸實者流歟。生二子曰尚遜、尙敏，公斃於虎，時皆幼，母遂矢不二之志，紡績畜之，俾至成立。又日積其所餘，娶媳名門，生孫曰克金，爲祖母。

夫呂節婦者，家有業之可修，子有姑之可托，一瞑不視，未必無生。非如母之足，或一搖志，或一懈惰，不惟藐諸孤不幸而無成，而欽百四十九公之血脈，固已随踵而斬矣。

嗟夫！富貴不能淫，貧賤不能移，大丈夫之所爲也。母固弱女子，乃獨以改節爲恥，盡瘁爲期，挫折生死於困苦中，而不敢以不可知者委之。

天使爲臣者能是道以事君，則不失爲忠矣；爲子者能是道以事親，則不失爲孝矣；爲弟與友者皆能是道以事與施，則亦不失爲悌與信矣。廣母之行，宏母之教，志士仁人胥無愧焉，又豈特貞德之宜彰，閫範之足式巳哉？

昔泰陛公嘗深見及此也，故特書其略以列於節傳之編，辭簡義長，其於母之所以可傳，無弗賅矣。顧發微闈幽，長言則彌彰，永言則益著，此有志於世道人心者，所以每千百言而不自
知其辭之費也。是傳之作，夫豈云然？

大清嘉慶三年戊午十月

祈山派裔孫耀偀謹撰
