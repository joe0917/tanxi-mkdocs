# 車方明湻三十七黃氏安人節母傳
```
题：[26世/廉258]祈山派裔孫耀偀謹撰
峕：[23修]大淸嘉慶三年戌午十月
初始点校：[20250807]民国庚辰本[3/33]P392
修订参考：[]
```

母以節名，非母之幸也。然世之賢父兄，日督責其子弟，使遜志時敏學工文辭，弋科第以大其門。卽不然而農恆爲農，工恆爲工，商恆爲商，亦莫不習勞苦，忍凍餒，篤燕翼課，俾待時以褒大於世世。賢子孫不欲没没終者，又莫不勵志砥行，爭自樹立，以爲光裕前後之計。名之於人，回大矣哉。

吾族自碩公於茲，瓜瓞日藩，以丁計者不下數千，以戶計者不下數百，以里計者不下數十。稟山川清淑之氣，被朝廷敎化之美，母儀閫範接踵其間。而德之可以輝彤管，操之可以咏者，益不勝數。然類皆大厦之覆，賴一木之支，否極而泰來，其名之遠也固宜。

節母不然，母適公，生一子曰宗興，興生三子，長曰魁又百三十八，次曰魁百四十四，幼曰魁百四十五。[[陈廷直|友梅公]]書於傳云：「兄弟三人至永康小橋頭，攺名爲榮一、榮二、榮三。」自是而後，無復聞焉，抑亦凌夷衰微矣。且昌言公之歌曰：「壯歲夫亡家又貧。」[^1]是其日用之需，飲食之給，皆紡積之爲，非能如巴蜀之淸，擅數世之利，用財自衛，抗萬乘而名顯也。况矢不二之志，旁欲起而奪之，遂至呼天號泣，對死悲生，苦可知矣。

嗟乎！影弔寒燈，生飫孤孀之苦；骸委荒野，死無坏土之安。不幸如母，更何可言？然而按譜牒所載，或不詳以行傳之次第求之，母與三十七公，蓋正統人也。溯而上之，則知爲布政公之孫，顯六其所出，顯十其所繼；推而下之，則知爲厚六十九之父，永康小橋頭之祖。

夫世固有廣田園，搆宅第，粟紅貫朽，奴隷鄉鄰，不轉瞬莫識而莫識爲誰。抑或挾其所得，曳裾侯門，貤宗蔭子，焜耀當時。不數十年，而其門有莠者。節母之生久矣，而祖之閥閾以傳，公之行諱以傳，若父若孫，亦無弗傳。母雖不幸乎，其爲族之幸何如也？

譜舊無傳，惟昌言公嘗卽其所聞於友梅、思本二公者，作爲長歌以紀其事，列於節傳之編。偀以爲節母之行，賴昌言公之詩傳之也，然以此當之，則不合於譜例矣。因不揣僣妄，掇其略而補之。傳固欲使後之人有以知：不朽者名，立德爲上；忠孝節義之名，必無有幸而能成，成而不幸者。

大淸嘉慶三年戌午十月
祈山派裔孫耀偀謹撰

[^1]: “壯歲夫亡家又貧，獨勵冰霜守清節。”[[贫愚集#明故湻三十七黄氏安人苦節歌]]
