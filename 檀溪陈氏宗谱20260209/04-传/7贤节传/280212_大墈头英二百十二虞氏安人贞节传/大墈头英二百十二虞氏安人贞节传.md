# 大墈頭英二百十二虞氏安人貞節傳
```
题：[]郡庠生佐唐拜撰
峕：[32修]光緒十八年仲冬上浣之吉
初始点校：[20260824]民国庚辰本[3/33]P416
修订参考：[]
```

曠觀古今來，淑媛貞婦較忠臣孝子尤難。其志堅，其節勁，其操心也危，其慮患也深，貧賤不移，富貴不淫，威武不屈，誠巾幗中偉丈夫也。士君子尚論及此，每樂得而表揚之。

安人虞氏，席揚橋志井公之淑女，大墈頭時達公之元配也。自笄于歸，克嫻婦儀，厥修壼範，方期永諧琴瑟，不幸驟斷鸞弦。公年廿三，天奪其終。斯時安人年僅二十有五，遺孤襁褓，甫及三齡，呱呱而泣。教養以成，慈兼嚴父；恩同義母，愛則兼勞。於是理家務，操井臼，伴媳紡績，課子桑麻。不數年而家業盈豐，子孫昌熾，享遐齡以謝世者，使非秉性貞烈，何能致天心之默佑乎？

今當家乘重修，其子中行為母誌其懿德，請序於余，遂出旌帖以覽。旨准其節孝建坊入祠表揚。余因之而感曰：聖天子崇獎節孝，許有司不時上聞，建坊表揚，乃盛典也。余鄙陋不辭，聊陳數語而錄其苦節，以為後世之觀型也夫。

光緒十八年仲冬上浣之吉
郡庠生佐唐拜撰
