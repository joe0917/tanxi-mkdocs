# 平湖承三百廿五安人毛氏節婦傳
```
题：[]眷晚生樓啟經頓首拜撰
峕：[]
初始点校：[20250808]民国庚辰本[3/33]P399
```

安人同里月山毛氏女也，年十六歸陳公一榮，勤執女工，恪守婦道，事公姑至孝。生一女一男，而一榮公患癘[^1]，安人求醫調治，百方不効，輒虔禱鬼神，願以身代。未幾，公卒，哀毀躬立，極其迫切。

時安人年甫二十七，子克仕在襁褓，自矢靡他，撫孤守節，行勵乎貞，言不踰閾。子稍長，教以明習經史，卓行成人。有孫一、曾孫二，行年七十有六，壽方未艾，而清潔冰雪，論則定矣。合傳之誌不朽。

眷晚生樓啟經頓首拜撰

[^1]: 癘：同“癩”lai4，麻风病。
