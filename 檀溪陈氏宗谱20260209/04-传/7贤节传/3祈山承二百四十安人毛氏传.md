# 祈山承二百四十安人毛氏傳
```
题：[]烏傷眷侍教生陶錦頓首拜撰
峕：[14修]天啓七年丁卯孟冬月
初始点校：[20250808]民国庚辰本[3/33]P398
修订参考：[]
```

浦邑陳承二百四十安人毛氏，係毛料院洪公之後裔，毛立四十二公之次女也。安人德容工言，奪月山之秀；端莊貞靜，飲洑水之淸。於歸陳門，卓稱賢助，事姑嫜以孝，待勝媵以恩，正擬琴瑟之諧和。

豈期藁砧之疾生，安人躬親湯藥，坐卧攜扶者三年。萬歷辛亥，良人長逝，安人悲慟號絕復甦。嗟乎！此時安人方青年，卽立志撫孤，柏舟自矢言不出閫，足不踰戶。

有丈夫子二：長曰明藩，娶烏傷王氏，卽余表兄復如女也；次曰明勲，亦己納釆虞女。聘娶二媳，皆係安人自為營辦。延師教子，追截髮之高踪；寒燈課讀，擬熊丸之芳躅。

先儒以浦邑分野正屬婺女之慶，故其地多產賢節女人。若安人者，真可嫓美三節，上應列星者乎？次君以髫年蟄聲藝林，而不永其年，天之所以報安人者，豈可問哉？然長君渾厚練達，舞彩階庭，而孫枝榮秀，將來正未可量，固知安人之迓福無涯也。

余因表兄與安人長君有葭莩之戚，敢忘其陋而敘之於前，倘侯高明贊揚之，以俟聖天子之寵命。

天啓七年丁卯孟冬月

烏傷眷侍教生陶錦頓首拜撰
