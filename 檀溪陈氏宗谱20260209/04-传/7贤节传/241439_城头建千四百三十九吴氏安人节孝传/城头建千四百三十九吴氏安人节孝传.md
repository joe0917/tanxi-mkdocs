# 城頭建千四百三十九吳氏安人節孝傳
```
题：[]祈山派姪孫邑庠生宗麟頓首拜撰
峕：[25修]嘉慶廿三年戊寅仲春上浣之吉
初始点校：[260824]民国庚辰本[3/33]P406
修订参考：[]
```

大凡立行，莫大於孝；守身，莫難於節。而婦人秉性柔弱，其處之也為尤難。乃不因艱苦動其心，不為存亡改其志，凜然能謹守撫孤以報地下，非達天理、明大義者，其孰能之？安人吳氏，建千四百三十九公淑配也。自笄于歸，克盡婦道，相助夫子，方期偕老百年。不幸公年未逾三十，天奪其終。斯時安人年僅二十有七，遺孤在襁褓，教育以期成立。事舅姑致敬盡禮，處妯娌長幼之間無不周浹。嘗自慮堂上雙親，暮年風燭；孤子僅數週，不啻水上浮漚。安人上順下慈，代夫行之，人無間然。嗚呼！遭家不造，自非操冰霜、盟金石，能保其不渝乎？於是蓬垢忍耐，奉耆耄老翁，晨昏定省；撫齠齡孤子，煢立艱危。勤理家計，督子力田，伴媳紡績。居常訓誡，惟儉與勤。值有無之際，隨事區處，淺深合宜，無異泳游之詩。歷數十年之辛苦，志尚松筠，自勵壽登七十有五，孀居四十八年。其間風晨月夕，凄楚伶仃，人所最難堪者，處之泰然，終身如出一律，誠不可以泯沒也。嘉慶二年，邑侯王公諱廷桂給匾嘉獎，彰安人之心志，旌安人之行跡，所謂「坤厚載物，德合無疆」，其信然歟！安人能以婦道了平生之願，而於節以見其孝，正以孝而全其節者之難也。今當家乘修葺，伊子祖佳屬余為母誌其懿德，據實行告。余因思節孝若安人者，真可作閨範，勵末俗，昭淑順不忒者也。余非能傳安人者，義不容辭，不揣固陋而為傳云。

嘉慶廿三年戊寅仲春上浣之吉
祈山派姪孫邑庠生宗麟頓首拜撰
