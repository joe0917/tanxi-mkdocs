# 平湖惠六百廿二公毛氏安人貞節傳
```
题：[]祈山派邑庠生姪啓經拜撰
峕：[19修]雍正七年己酉仲春上浣之吉
初始点校：[20250809]民国庚辰本[3/33]P403
修订参考：[]
```

歲甲午重修宗譜，予以誌書所載三節傳備列譜前，示獎誇微意。族叔[[陈元霖|君起]]見而嘆曰："三節其誠難矣，然而今日巾幗中亦有可媲美三節者。"予怪問為誰，叔曰："即吾大功兄諱元遇之嫂毛氏是也。"

蓋嫂于歸時年方十八，舉止端莊，言詞不苟，事上待下，綽有大家閨範。生一子甫三歲，一女僅得兩月。兄入山採樵，為虎所噬，幸五兄元思偕往，挺身相鬬虎，拖尾而逝，乃與同樵者負尸以歸，置於家側。嫂聞慟戚若狂，匍匐而視，呼天搶地，僵死復蘇。跪於尸前，刷淤濣血，以衣包裹，若病故人形。是夜積薪引光，悲號達旦；次早殯殮，俱親自點檢；扶柩祭葬而歸，勺水不入口者數日。飲泣吞聲，恨不能赴虎以俱死。及環顧夫子若女，不忍以一死棄諸孤也。

厥後鄉里中有慕其賢而來聘者，始拒以婉詞，繼悚以危言，隱欲效曹氏之屠靣以自免焉。且其家素食貧，伯叔七人，長蚤分居，其餘共爨，有終身不娶者，有娶而幼稚者。嫂則總理中饋，以身先之；奉姑嫜以甘旨，待妯娌以和柔。及姑卒時，治喪之事，達禮而哀，諸兄弗若焉。兼之男婚女嫁，能以母道了平生之願；及各立門戶，朝督子以力田，夜伴媳而紡績。居常訓誡，惟儉與勤。夫人生行誼，雖曰蓋棺始定，今寡居三十餘年，而其子又生孫，決不以末路而改節可知矣。若此者，豈不可以步三節之後塵乎？

予聞其言，半信半疑，意叔未免以嫂故多溢詞耳。越數載，偶散步平湖，綠陰深處，主伯亞旅羣聚而憩息。中有未經會面者，詢之，即安人之子之富也。予見其人，貌則樸如，言則訥如，晉接則藹如，殆非深漸夫閨誨者不能也。因想族叔前言，披草而坐，細述相質，咸首肯曰："其信然耶？其言之非謬耶？"夫而後知所譽之無過情，而安人之行之實也。

去歲會譜，平湖少長咸集。安人之從姪震先曰："吾姑之履歷，賢弟素聞矣。奈我等才力拙弱，可能申明有司，奏聞朝廷，旌表建坊以彰苦節？近蒙邑侯給匾嘉獎，其始終行述，冀代為一傳，昭茲來許，何如？"少長譁然曰："此而不為之傳，及誰為可傳者？"予應之曰："唯唯。是安必他有所傳哉？即以向之所聞者，握管託之，而安人之行，已可與三節並垂於不朽云。"

贊曰：

夫子云：孝哉閔子騫，人不間於其父母昆弟之言。
吾於安人之行亦云：疾風勤草，晚節松筠。筆之則簡編生色，其此之謂與？
但以襪線庸才，揄揚美德，臨楮殊多自慚耳。

雍正七年己酉仲春上浣之吉

祈山派邑庠生姪啓經拜撰
