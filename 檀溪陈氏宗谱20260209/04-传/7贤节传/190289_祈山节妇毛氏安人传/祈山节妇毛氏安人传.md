# 祈山節婦毛氏安人傳
```
题：[]暨陽眷生甲子應順天鄉試舉人邊維寧拜撰
峕：[]天啓七年丁卯冬月之吉
初始点校：[20250807]民国庚辰本[3/33]-p395
修订参考：[]
```

安人毛氏，欽百九十六公正室也。余諭知其詳，聊卽其懿德而述之。  

安人生於嘉靖甲辰，芳年二十有二，公以疾捐世矣。生一子承百十八，撫孤成家，名節自勵，孰謂非難？安人以窈窕精神，修身愼德，外言不入於壺，內言不出於戸，閨門甚爲雍肅。蓋丹心則靑年鐵石，而素操則白髪冰霜。由是遐邇感慕，邑侯給匾恩表，不亦光祠室、耀門楣乎？  

更遵節儉敦樸，素爲娣姒效；調慶有方，資產益饒。一子丕承基業，不隕家聲。孫男九，次曰克偉，邑庠生，名籍當時；孫女三，曾孫男六，繩振之美，皆安人積慶所致。一門之盛，尤安人節孝所難也。  

後有登江南第一峯，遠對靑草，不恍覩在日芳躅，宜青史之停不朽云。

天啓七年丁卯冬月之吉

暨陽眷生甲子應順天鄉試舉人邊維寧拜撰
