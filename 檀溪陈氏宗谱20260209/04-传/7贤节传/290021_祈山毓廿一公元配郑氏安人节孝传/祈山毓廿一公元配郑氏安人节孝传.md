# 祈山毓廿一公元配鄭氏安人節孝傳
```
题：[]從叔廩膳生其善拜撰
峕：[31修]光緒庚辰孟夏之月
初始点校：[20260824]民国庚辰本[3/33]P414
修订参考：[]
```

遇之至苦者節也，事之至難者孝也，而以節成孝，以孝全節者，其志有人不得而撓，亦天不得而屈者矣。吾家鄭氏安人，行毓廿一識兄之妻，善之從嫂也。兄幼失怙恃，惟賴伯父母撫養成人，家甚寒微。安人來歸，孝義之門，素嫻四德，識三從，長兄二歲。兄年二十五，為肩挑赴試，行裝道遠，任重傷力，成疾。安人晝夜奉侍湯藥無效，焚香祝天，願以身代。奈何兄命已終，溘然而逝，僅生一子頴祥，甫三月。安人大慟，哭震天，哀毀骨立，死而復甦者數次。鄉鄰咸勸以伯父母在堂，賴汝侍奉；孤兒賴汝撫育，汝從夫亡，則夫家其無望矣。再三勸慰，安人始漸收厥淚。後稱未亡人，婦兼子職，母盡父道。晝則力作田園，夜則篝燈紡織，刻苦持家，上以供二老，下以撫孤兒。且撫養桐江潘氏女為子婦，全婚配以延夫脈。茹苦含辛，端莊純一，內外無間言，是亦可謂以節成孝，以孝全節者。此其志，夫豈人所得而撓，天所得而屈者哉？

噫！世之始諧琴瑟，夫目一瞑，遂棄翁姑，捐兒女，不數月而往適他門者，固不足道；即有終不再醮，或因家屬素封，深閨靜閫，初無艱難辛苦之嘗，猶為易易。若安人者，外習農桑，內供俯仰，而其堅貞嚴毅之氣，且格於神明，不與古之義士忠臣並爭光於日月哉？安人全苦節者三十餘年，享壽六十有四。縱無責報於彼蒼，吾意天必為之眷顧也。今頴祥生子壽祺，年方弱冠，而克儉克勤，成立有基，或者天將有以昌大其門閭與？善誼屬從嫂，有美必彰，善之責也。茲當家乘秉筆，遂為之傳，以待後之闡揚者。

光緒庚辰孟夏之月  
從叔廩膳生其善拜撰
