# 祈山建九百十一潘氏安人節傳
```
题：[]歲貢士任海鹽縣儒學盤洲周璠謹題
峕：[23修]嘉慶三年戊午三月上巳
初始点校：[20260824]民国庚辰本[3/33]P406
修订参考：[]
```

浦北山之北，檀溪陳氏最為著姓，其族重節孝。嘉慶戊午輯譜之役，公舉極貧者孝子一、節婦一，懸額大宗祠，以持風化。余不述孝子，其節婦則吾比鄰潘氏公良之姊，承宣之外祖母也，耳熟得詳，謹盥手而書其太略，後之人得以考焉。

承宣為余言：宣不幸生七歲而失恃，往來外祖家。外祖母嚴氣正性，撫養教誨，不以禽犢愛宣，蓋敬謹遵守以至於成人。承宣曰：外祖母年十三歸於陳，年十七而姑亡，年十九生承宣母，二十四生外舅季山，至二十有六而外祖謝世矣。牽率弱女孤甥，閉門稱未亡人，儲桁懸罄，都無足恃。鄰里親戚稍有為之謀者，外祖母益堅，茹荼淡蘗，甘之無怨色。篝燈紡績，每徹午夜，夙興碾磑，拮据以營生，未嘗干人一粟。承宣蓋得之於所聞者半，得之於所見者猶半也。

公良曰：吾姊夫名以義，其卒也貧幾無以殮，余為治喪事，且營葬地。姊曰：「蒿里一歸，後且千年，豈僅不食土，遂可以棲冥魄哉？」以不愜置之。蓋行潔而志高如此。每歲時迎歸，兄嫂弟妹各面見問無恙，外未嘗假一顰笑。鄰里以酒食相邀，謝不往；鰲燈市劇，不一窺也。居數日辭去，未嘗久滯留。其嚴毅耿介又如此。生於雍正戊申，孀於乾隆壬申，卒於嘉慶丙辰，蓋持苦節者四十有五年云。

說者曰：乾坤有正氣，麗乎人身，則為孝為節。其或不聞於有司，不膺朝典，則是氣磅礴往來，靈怪變動，難方物，誠之不可揜也。題牓高懸，發揚於上，為昭明，入廟肅然，咸知悚惕，俾兩間之正氣收攝乎人心，而人心亦正。陳氏族人其有見也夫。

嘉慶三年戊午三月上巳
歲貢士任海鹽縣儒學盤洲周璠謹題
