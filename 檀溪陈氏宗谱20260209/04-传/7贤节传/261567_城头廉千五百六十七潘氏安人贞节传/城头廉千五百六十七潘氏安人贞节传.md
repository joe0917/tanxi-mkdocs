# 城頭廉千五百六十七潘氏安人貞節傳
```
题：[]邑庠生龍溪雲軒潘士林頓首拜撰
峕：[31修]光緒六年歲次庚辰菊月
初始点校：[20260824]民国庚辰本[3/33]P409
修订参考：[]
```
天地正氣，鍾毓於人，在國為忠臣，在家為孝子，而為貞節者其事較難。如陳母潘孺人者，士之從堂姪女也。少失恃，賴祖母方氏撫育訓迪。年二十一，適陳君諱榮長，字春林。事舅姑極敬，處妯娌惟和，琴瑟和諧。越四載，生子星聚，未及週而夫病故。孺人年甫二十有六。噫！斯時也，嘉耦方新，遽喪夫君；傷破鏡之難圓，僅存孤子。煢煢孑立，形影相弔。論家計，產不滿半頃，僅得一株。撫存哀泣，衣食艱難。姑舅憐其境，聽伊自便。而孺人悵然泣謝曰：「夫亡子幼，吾一失足，血食斬矣。」於是矢志毅然，以丈夫之任為己任。夜織曉舂，一切家務，以一身勞苦自任。而命子讀書，教以義方；娶媳傳宗，閑以閨訓。厥後子能成立，孫亦迥殊。至五十七歲，一夢黃粱，孀居三十一年。嗟夫！松柏不歷夫風霜，不足以表其高節；金石不經夫磨礪，不足以發其幽光。想孺人守志之初，空幃寂寞，月冷風酸，以視夫履豐席厚者，其為飲冰茹蘗，何如耶？迄今子若孫，綿綿延延，何莫非孺人數十載苦節之報乎？咸豐辛酉，邑侯許公題額曰「冰霜自矢」，此正所謂沐霜勵節而自矢靡他者矣。士也鄙俚無文，不能闡揚幽德以樹風聲，然事關風化，誠不可以默默無所表揚也。故不嫌謭陋，略傳其實云。

光緒六年歲次庚辰菊月
邑庠生龍溪雲軒潘士林頓首拜撰
