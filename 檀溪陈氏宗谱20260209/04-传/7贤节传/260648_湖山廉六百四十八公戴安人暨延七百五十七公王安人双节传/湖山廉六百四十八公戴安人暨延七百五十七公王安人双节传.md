# 湖山廉六百四十八公戴安人曁延七百五十七公王安人雙節傳
```
题：[]姻姪邑廩生虞善揚頓首拜撰
峕：[]光緒七年嵗次辛巳冬月上浣之吉
初始点校：[20260724]民国庚辰本[3/33]P410
修订参考：[]
```

辛巳歲，余舘湖山之昌後堂。英永翁之孫穎栗，與英亦翁之孫穎焯，皆從余讀。余見二翁之為人，居家勤儉，處己端方，力田外世事不知，祗以教子訓孫為務，心竊敬者久之，尚未知戴、王二安人之節也。及冬，余自金郡歸舘，英亦翁始以其祖妣戴、生母王之節為余告，囑予作傳。余聞而歎之曰：「翁家子孫之昌也，其肇於二安人之節乎！予雖不文，其又奚辭？」

謹按戴安人，乃同邑戴氏女，年十三歸陳公榮璠。榮璠家貧，四壁以外無長物，天寒猶衣敝，負薪困苦艱難，幾幾不能自活。安人處之怡如也，惟勸夫安分守己，不妄為非義事，此其性情之純正為何如哉！及嘉慶戊寅，安人年三十五，榮璠病危甚，安人躬親湯藥，籲天請代，卒不遂志，而榮璠亡。當是時，榮璠遺一子宗起，甫三歲，煢煢孑立，形影相弔，又家無斗粟之儲。人有為安人危，勸之再醮者，而安人則曰：「未亡人在，則陳氏有後，可卜其昌；未亡人去，則陳氏自茲絕矣。茹苦含辛，在所甘也。」勸之者遂不敢復言。

後子宗起稍長，遂命之勤耕苦種，以為衣食謀。養媳王氏，但教之紡績而已。王氏事姑孝，惟姑命是從，雖姑或有時督責太嚴，亦受之無怨色，并勸夫力田以養姑，以故戴安人晚年得稍稍安泰焉。道光癸巳，戴安人病卒，殯殮盡禮。越四十日，而宗起因哀毀過甚，又病不治。王氏一慟而絕，絕而復蘇者再，水漿不入口者累日，祗願從姑與夫於地下也。繼又念夫遺二子尚幼，長英永甫六歲，次英亦僅三歲，氏若不存，則二子終當為餓殍填溝壑，不惟無以慰夫心，且無以承吾姑撫養之苦矣。於是强進湯粥，誓以守節撫孤為志。雖然未可知也，陳家素貧，居破屋中，風雨時侵，寒無以為衣，饑無以為食，寂寞蕭條，兒啼婦哭，真有一刻難安者矣。而王氏年僅三十有六，謀奪其志者，或甘言以誘之，或危言以激之，氏惟慟哭以謝之焉已耳。

故當永與亦方幼時，親井臼，躬灌溉，日復一日，不知其勞。時訓二子曰：「爾輩須當勤以持家，儉以守己，以無忘爾祖母與母之苦志焉可也。」卒於同治丙寅，享年六十有九。今英永有一子毓求，孫三：長穎栗業儒，次三尚幼。英亦生子二：長毓深，幼毓汪，邑庠生，孫四：長頴焯幼讀，次三四俱在襁褓。家業日隆熾昌盛，苦節而終以甘，不得之於身者，必得於其子孫，固天道也。後之人其亦有鑒於斯也夫！
