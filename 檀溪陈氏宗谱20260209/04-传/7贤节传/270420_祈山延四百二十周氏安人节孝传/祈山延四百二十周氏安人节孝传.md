# 祈山延四百二十周氏安人節孝傳
```
题：[]邑廩生從堂姪英稅頓首拜謹識
峕：[28修]道光廿八年戊申端陽後三日
初始点校：[20260824]民国庚辰本[3/33]P415
修订参考：[]
```

安人周氏，獅溪邑庠生占山公次女，立模公胞妹，吾服叔薦于公淑配也。系出名門，夙嫻閨訓。未歸于公，以力學神疲，下堂傷足，延醫無效，心抑鬱，病日以沉。時公已失怙，母夫人計無復之，因念時俗有因病革而迎新婦謂之冲喜者，是或所憂之一道也，遂涓吉而為之娶。比婦車至門，公病力不能支，舉婚禮，家人扶翼而出，勉强而行。一時觀者咸失色，驚其不久於人世，而竊為安人終身憂也。禮畢，安人拜姑堂上，退即卸粧而侍於公側，親奉湯藥，無間晨昏，其服事周詳，蓋老婦無以過之。自是病彌留，焚香祝天，願折己壽算以延公命。奈天不祚公，未匝月而公竟逝矣。安人椎胸慟哭，將以死殉。其姑慰之以命，遂收淚坐定，起而亦有以慰姑者。既而曰：「婦不敢死，以姑存也。但恐婦之不能兼盡子職，有以獲罪於姑與亡夫於地下耳。」其姑未達其言，憂其難寡居也。後與其父母以語試之，安人乃從容誓以夫死無再適之義。其姑始信其心之素定，而幸家之有賢婦也。

伯氏宗芹憐其志，而欲為之後，以次子英珍繼之。安人仰事俯育，有丈夫氣，苦節中舉止安閑，不見有矜持之色流露於眉睫間。其姑見之心安之，而若無所用其憂者。噫！巾幗中不少賢節，有因孤兒在抱，相與茹荼啖蘗，冀其有成也；有因遺子於腹，所望不失而心以安也；亦有煢煢孑立，明知曙後星孤，回憶數年情好之深，終不忍决然舍去也。是誠難矣哉！乃安人與公，以病中成婚，有同室之親而無同夢之樂，尤為夫婦中不幸之甚者也，而其節為更難矣。

安人生於乾隆丙午，孀於嘉慶戊辰，卒於道光癸巳，蓋守節者二十六年。繼子珍方欲上達天聽，冀輝彤管，惜有志未逮，中道而殂。珍子毓釵年尚幼，然已勝衣就傅矣。天或者欲昌大其門閭，故晦其節使之久而後彰乎？是未可知。茲值修譜，不揣謭陋，錄其實以俟後有力者。
