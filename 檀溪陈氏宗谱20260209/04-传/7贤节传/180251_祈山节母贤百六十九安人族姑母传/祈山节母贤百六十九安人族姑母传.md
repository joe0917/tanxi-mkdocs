# 祈山節母賢百六十九安人族姑母傳
```
题：[]萬歷己酉科浙江試舉人內姪孫張應鑑拜撰
峕：[]天啓六年丁卯冬月
初始点校：[20250807]民国庚辰本[3/33]-p394
修订参考：[]
```

安人，陳公諱遷字仕善號西源淑配。余族祖吏目東由公之女也。

生於閥閱，夙叨姆訓，自于歸於陳，克盡婦道，相助夫子，恩隆好合，滿斯偕老百年。不幸西源府君天奪其年，斯時安八年僅二十有二，遺孤應奎、應龍俱在襁褓。慈愛教育，以致成立，事奉舅姑，克盡孝敬，處妯娌以和，御婢僕以恩。享高壽八十有八，孀居六十六年，內外無間言。

二子俱爲擇配，一女適善溪何，男婚女嫁，安人自爲處辦，各得其宜。

遐升後，與西源公合葬樓家樣，真所謂貞心不攺，與良人相逢地下，纖毫無愧者。以是焉可無一言以識之。

天啓六年丁卯冬月

萬歷己酉科浙江試舉人內姪孫張應鑑拜撰
