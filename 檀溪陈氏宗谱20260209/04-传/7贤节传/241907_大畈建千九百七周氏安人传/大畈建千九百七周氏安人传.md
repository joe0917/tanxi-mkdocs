# 大畈建千九百七周氏安人傳
```
题：[]祈山派姪邑庠生祖諤拜撰
峕：[25修]嘉慶廿三年戊寅仲冬月下浣之吉  
初始点校：[20260824]民国庚辰本[3/33]P407
修订参考：[]
```

傳者，傳也，傳其事以垂訓後人也。唯人無可傳之事，則莫為之傳耳。頴川都建千九百周氏，盤洲邑庠生周鶴書之姊，諱以侯之德配也。系出名門，素嫻禮教，敬夫教子，和親睦鄰，洵足嘉矣。然尤有可傳者：乾隆癸巳春，厥姑潘氏一朝染病，日漸沉疴，求藥罔效，舉家驚惶無措。氏乃焚香禱天，割股以療之，姑病如失，復康健五年。姑乃默念其孝，請於翁曰：「願給微產，以表婦心。」乃翁欣然，拔土名後楊畈田八秤以授氏，氏辭焉。翁止之曰：「聊以見吾心耳。」後翁壽八十有九，鄰里聚處，言及事奉，嘗為稱道。族人固多有知之者，然無一言以識之，世遠年湮，幾何不沒而不彰耶？今春修譜，玉等請傳於余，以垂示無窮。余不揣孤陋，因筆其共知者以傳之。氏生四子：長祖玉，出繼；次祖寶；三祖珠；幼祖現。均有子二三，其奕葉之蕃衍昌盛，誠有未可量者，謂非天之陰祐孝思也哉！詩曰：「孝思不匱，永錫爾類。」其在斯乎？其在斯乎？

嘉慶廿三年戊寅仲冬月下浣之吉  
祈山派姪邑庠生祖諤拜撰
