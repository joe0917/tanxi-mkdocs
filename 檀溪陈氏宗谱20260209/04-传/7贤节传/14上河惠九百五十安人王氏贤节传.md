# 上河惠九百五十安人王氏賢節傳
```
题：[23世/宣568]從堂姪府庠歲貢生之環謹識
峕：[20修]乾隆十一年丙寅冬月
初始点校：[20250809]民国庚辰本[3/33]P404
修订参考：[]
```

大凡人生世上，順而處常、素位而行者多；逆而處變、由困而亨者少；至貧而守節、撫孤成家者更少。

予從堂叔父元寵兄弟六人，叔居其四，各自爲家。祖業微薄，嬸母王氏自幼未字，父母遭變，又無叔伯，終鮮兄弟。來歸吾叔，親操井臼，拮据勤勞，視諸妯娌獨能突出。叔爲妻族凋零，祖墳被佔，挺身告理，義俠駱名。無奈家業未成，中年仙逝。

嬸乃安貧苦守，撫子成人，娶媳生孫，嫁女生甥，收養在家。代夫而盡父道，侍奉老姑，孝養獨至，喪葬盡禮，代夫而盡子道。次伯元純幼祖克任乏嗣無靠，供奉過老。伯叔諸姪哀憐孤苦，猶子比兒。幸而一生康健，勞碌奔波，至老無倦，真女中丈夫。其子之賢，敢作敢爲，成家立業，自始有少有漸將富有飽食燰衣。非母氏賢能教訓，焉得有子克自樹立若是哉？

一日，予嘗獨立廳上，嬸之長孫以足從予姪正漼在予家讀書。嬸懷抱幼孫以鎮，手牽次孫以萬，來呼長孫就食。余笑而言曰："年近古稀，何自勞苦如是？"乃笑而答曰："子婦之債未足，而債尾又接續而來，非好勞也，無如何耳。"余乃喜而慰之曰："先貧後富，始勞終逸，老而享福，自此而耄耋期頭，正未有艾也。"

談答之間，伊甥承榮又來催去就養。而是日譜師適至余家，因不辭鄙陋，略措數詞以付之，託載譜中，爲嬸氏慶。

乾隆十一年丙寅冬月

從堂姪府庠歲貢生之環謹識
