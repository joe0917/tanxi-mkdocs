# 後宅廉六百四十七周氏孺人節孝傳
```
题：[]族姪增廣生滙川頓首拜撰
峕：[30修]大清同治九年歲次庚午季冬之吉
初始点校：[20260824]民国庚辰本[3/33]P412
修订参考：[]
```

古未有含辛茹苦、惕厲憂勤之嫠婦，而不發潛德之幽光於身後者。然使斯世無蓄道德、能文章之學士，雖有卓絕之節操而不能傳；即或間有著作者矣，而其後嗣不知激發其仁孝之心，向學者以求傳誌，則猶湮沒而不能傳。偉哉周伯母！至今逝世已三十餘年，而其孫乃於重造大宗祠之日，不惜捐錢文，立享勝以為節孝祠福嘗之計。吾以是知伯母之節行，實足以感發其苗裔，而使吾大書特書，牽連以書不能自已者也。

孺人周伯母，吾族下宅派榮惠公之妻。當伯父惠與諸兄弟同居，勵志詩書，伯母恪遵婦道，以事舅姑，人皆悅服其孝行，而以為閨門中之絕無僅有者。既而伯父惠疾病，親奉湯藥，月餘不解衣帶。又嘗焚香默祝，願以身代。夫死而疾終不可瘳。是時伯母年三十歲，長子宗亨甫離襁褓，次子宗享尚在孩提。伯母慟哭悲哀，幾至毀滅。一時伯叔母之勸慰者，以為汝若志在同穴，則二子失所倚恃，不若強勉育子之猶有可望也。周伯母於是拭淚向妯娌而言曰：「吾非不知從夫而死，則孤哀子更屬可憐，而舅姑於遲暮之年，在高堂又重貽之以憂患也。然竊自恨我生不辰，夫君仙逝，不應如是之早耳。」

居十餘年，族伯叔父等因父母相繼即世，而食指眾多，遂議分爨。叔母蹙額而言曰：「伯叔父此舉，自為計則可矣，獨不為未亡人二少子計乎？」時叔父宿惻然為之動容，又與之同居三載。及亨等能發憤持家，伯母次第婚娶，又撫其孫。乃與子婦言曰：「吾雖出入顧復汝二子，而農桑為衣食之本，不可不胼手胝足以勤勞稼穡；且女紅在紡織，慎毋悠忽以蕩廢恆產也。吾以一婦人勞心家務，食以時，用以禮，而家業又能稍增者，以夙興夜寐之所思，乃在勤儉耳。」

周伯母為人端莊嚴重，舉動必以禮法，一顰一笑不肯假人。時有妄人以勢凌之者，伯母厲聲叱之曰：「我家向待汝以禮，而汝乃敢橫逆若此，豈以老寡婦為可欺也耶？汝必欲為此事，吾將見里中長老與論曲直。」其人乃慚而自退。亨等敬事伯母四十有六年。其後伯母兒孫繞膝，四代同堂，人皆藉藉稱道，以為節孝所致。伯母曰：「舅姑之晨昏定省，吾亦賴有伯叔母耳，豈敢自矜而滿志？獨念平生苦節自貞，並不使兒孫輩於日用倫常之間為非禮事，此乃所以慰舅姑，以慰伯叔父者也。即吾一旦瞑目，亦有以對吾夫於地下矣。」

伯母以乾隆丙戌七月十一日生，道光庚子五月十五日卒，享壽七十有五歲，與伯父惠合葬發壠坑。今歲在庚午，我陳姓既重建宗祠及續修家乘，伯母孫時成、時寵、魁等，不忍節行之磨滅，乃為立享牌於節孝祠，而丐余言以作傳。余慨慕久之，遂秉筆而書曰：嗚呼！吾族三節婦之流輩，其之死靡他之志，發於至誠，可貫金石，可泣鬼神。以汝祖母之刻苦砥行，而頡頏其間，夫何不可以類之也者？且先君子誨我以古文，而我不為祖母顯其奇節，將於何者而揚厲也耶？然吾嘗聞祖妣善行無窮，彼蒼報施亦無窮。以汝祖母之享福壽，而子若孫螽斯蕃衍，且又履厚庸豐，安知不更有文學士篤生於其後也耶？時成等尚其勉子孫以讀書，是又吾引領以屬望也夫。
