# 平湖恩一百三十節婦方氏安人傳
```
题：[]外甥張以讓敬撰
峕：[16修]康熙廿三年甲子孟秋月
初始点校：[20250808]民国庚辰本[3/33]P400
修订参考：[]
```

余舅母方氏安人者，秉性幽貞，持躬淑慎。於歸舅父克紹公，舉案齊眉，克勤克儉，自始有少有而至富有，罔有矜色。方期偕老以光大門閭，不意得一表弟陳元嵩甫七十日，而舅父先逝。斯時卽矢志自誓曰：「夫亡子幼，皆未亡人任也。」於是蓬垢忍耐，直至古稀之餘，教養無倦，俾七十日之孤兒，竟能成家立業。宗族鄉黨，咸不推敬。

舍弟張右麒，筮仕寧海廣文，乃余姊石門甥壻也，聞其名，嘉其事，贈其匾曰「孟母齊芳」。予愧不敏，不克闡揚盛美，縷縷細陳第，據實而錄其苦節，以俟異日之旌表爾。

康熙廿三年甲子孟秋月

外甥張以讓敬撰
