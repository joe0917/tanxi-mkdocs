# 上河惠三百八十呂氏安人傳（贊另列）
```
题：[]邑庠貢生虞邦暹拜撰
峕：[18修]康熙五十四年乙未月春
初始点校：[20250809]民国庚辰本[3/33]P402
修订参考：[]
```

親母呂氏，陳諱元吉字汝惠親翁之元配也。秉性慈祥，宅心醇厚，有巾幗丈夫概。生二女一男，操持勤儉，克創宏圖，內助之賢，於今罕覯。奈昊天不弔，親母年甫四十，而親翁已捐館矣。婚嫁雖畢，愈加勤儉，家業擴充，益增大焉。

其事舅姑也孝，其教子孫也嚴，井井有條，初終罔懈，而人無間言，是真能代夫以爲父爲子而無愧矣。廼子字殷重，胸藏氣宇，迥不猶人，早歲遊庠，士林所仰；又孝於母，凡母所欲爲者，靡不曲體而善全焉。計閭里之遭祝融者，乃發餘倉粟以賑之，覩黨族之窮無告者，乃出棺槨以濟之；以至骨肉親友之間，又能盤桓懇到而無厭心。種種善事，難以枚舉。此雖其子所爲，亦孰非慈祥醇厚之母德以致此哉？

歷年六十有四，由古稀而屆期頤，未有艾也。子已生孫，名文光，少年英偉，善讀書，行將綿瓜瓞而振家聲，實嘉賴之。

今陳氏重修家乘，而殷重請言於予，以誌母之懿行於譜牒。予以亡姪廩膳梅卿岳母，向悉其素履，即以向之所悉者，應廼予之請，而爲之述其槪。遂口占數言以贊之曰：

贊曰：
母德醇良，俾壽爾臧。
勤儉宜家，詩咏倉箱。
教子成立，名重宮牆。
子又生孫，淑範貽芳。
是誠壺內完人，宜應福履與檀水而流長

康熙五十四年乙未月春

邑庠貢生虞邦暹拜撰
