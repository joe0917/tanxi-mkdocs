# 祈山聰三十八樓氏安人節孝傳
```
题：[]桐江邑庠生潘朝璇頓首拜撰
峕：[21修]乾隆二十九年歲次甲申清和月
初始点校：[20260824]民国庚辰本[3/33]P408
修订参考：[]
```

安人，陳君聰二十八府君之配，子友靈運，諱榮椿，繼母也。姓樓氏，出自名門。年二十餘而字，未四五年而陳君卒，遺一女。翁姑以其無子，欲聽其自便，安人不可，乃效故梁高行、楚貞姬之所為，卒撫其孤女以長成家，而以靈運為繼體承祧之子。年六十，內外無間言。邑侯王公旌其操，額曰「節比松筠」，行且欲上聞云。

方府君之甫卒也，安人哭之哀，且曰：「吾既未有男，而吾夫遽死，別無所冀，不如與之同穴。」乃引刀欲自裁，賴以救免。當是時，安人慷慨激昂，無所顧慮，豈知有今日乎？由是每過歲時伏臘及府君生卒之期，雖有僕隸侍從，不相假借，必親拜於府君之墓，仰天悲號，不自勝，久而常然。然其立志之堅，操行之潔，雖金石無以過也。且戒遊冶，絕宴安，稱未亡人。凡一切麻枲絲繭之事，必躬；酒漿籩豆菹醢之屬，必親。事公姑以孝，處妯娌以和，撫諸幼以慈。謹起居，寡言笑，日以勤勞貞靜自勉。所謂「以歇之家而主猶織」者，是耶非耶？嗚呼！是豈得之師傅保姆之教、詩書圖史之成耶？抑所謂天賦者誠厚，而率於性者自真也。

然吾嘗慨夫風俗失，人心壞，人倫中求其始終不失者，蓋亦寡矣，而况其在婦人女子乎？不幸而有分鏡之悲，其始也寸板方隔，寸心尚存，非不指天誓日，之死靡他。然不過一時氣激之隆，迫於死生之際而為是激切之形耳，乃運之久而變矣。即不然，或慕夫剛烈之為，貞節之名，勉强支持，不至中道而易轍，然悼嘆嗟怨悔恨之情，未免形於語言動靜顏色之間，甚或有幃薄不修，不可詳言者矣。即不然，抑或夫亡子幼，未能成立，而徘徊以俟諸後，則尚有冀也。而安人當府君棄世時，靈運固未生也，承祧未可知，無所冀，一搖足則府君之嗣絕矣。夫而乃堅持雅操，皭然不滓，今老矣，雖語及府君，未嘗不泣下沾襟也。而子孫蕃衍宏多，世世為承家冢子，鄉黨稱之，朝廷旌之，芳聲美譽垂諸無窮。回憶守節自誓時，豈意其至是耶？其亦可以愧夫世之為不嫁者矣。

今年春，靈運以祠中輯修宗譜，不可無以誌之，語其事於余。余不敢以不文辭，為述其梗概，以俟諸有道德而能文章者之張大之也云爾。

贊曰：  
惟松有心，惟竹有筠。  
憐其操，翼其仁。  
明景內映，朗節外新。  
芳徽夙邁，淑慎其身。  
嗚呼！誰與有似安人？

乾隆二十九年歲次甲申清和月
桐江邑庠生潘朝璇頓首拜撰
