# 山前恩廿九毛氏孺人節孝傳
```
题：[]眷弟歲進士樓澐頓首拜撰
峕：[19修]雍正七年己酉冬月吉旦
初始点校：[20250809]民国庚辰本[3/33]P402
修订参考：[]
```

孺人毛氏，應華公之女也。幼而聰敏，長嫻女訓，其於四德，蓋無歉也。年及笄，適白巖陳克允。傳曰：「希允居長，有弟三人，凡一舉一動，諸弟惟克允是視。而克允亦以父死母寡，家務任重，一切家中艱鉅事，獨爲負荷，而其身竟以心勞力竭，獲病而逝。時孺人年僅二十二歲，遺一男一女，女方髫齡，男尚在抱。永訣之夕，承夫付託，孺人即憑牀立誓，必無背負，而其夫竟已瞑目矣。」

於是，孺人竭力奉姑，凡衣食供奉，以及定省温凊，俱能先意承志，而姑乃得以壽終。其女其子，提攜保抱，養育成人。女則律以閫範，無違《內則》諸訓；子則教以義方，不蹈誕妄諸行。故其女適庠生毛可璠，宜室宜家，賢聲藉甚；而其子元變，亦以孝悌循謹，見稱鄉評。此何莫非孺人朝夕薰陶之所致耶？

夫孺人以藐然女子身，凡其夫之子職未竟者，而克修婦道以代之；其夫之父道未盡者，而克殫母道以終之。舉向之立誓夫前者，一無少歉，是真可謂死者復生，存者不愧也。因爲傳其行實，而贊之曰：

贊曰：
古人重盟（誓），山海不可移。
忠臣不背負，貞婦亦無欺。
婦道代子職，慈母兼父師。
心肝冰雪冷，志操松筠資。
聖朝重節義，坊表良在茲。

雍正七年己酉冬月吉旦

眷弟歲進士樓澐頓首拜撰
