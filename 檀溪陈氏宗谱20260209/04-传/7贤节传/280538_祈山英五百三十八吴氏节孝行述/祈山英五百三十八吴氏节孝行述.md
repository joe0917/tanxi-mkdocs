# 祈山英五百三十八吳氏節孝行述
```
题：[]從堂叔父增廣生滙川撰
峕：[31修]同治十年歲次辛未孟春月上浣
初始点校：[20260824]民国庚辰本[3/33]P413
修订参考：[]
```

自古茹苦含辛之嫠婦，莫不以專靜純一之心，成其不朽之名節。雖涉險阻艱難境遇，一一備嘗，毫無怨悔。此前史所載，能令讀者肅然起敬，潸焉出涕，恨其人不獲再見，以為古今人不相及。而不謂於吾村吳氏立節，竟目睹其為人，而為之流連感嘆也。

吳氏者，大墈頭自行公之女，從堂姪英五百三十八童梯山之妻也。梯山嗜讀詩書，專心致志，欲博一衿以慰親心，而屢蒙備取，終焉不售，鬱抑不得志，遂嘔血以亡。其舅姑憐其年輕無子，且家業寒微，聽其自便。一時求配偶者不一姓，吳氏皆力拒之，甚至厲聲以罵，事乃得已。於是因無可立足，遂依母家兄弟以居，紡織縫紉，自食其力。每當清明、冬至二節，挈酒食以上夫墓，哭聲震天，哀音動人。而逆其耳以勸者，謂以汝之德容，自有佳偶，汝既家貧，又無子息，何乃終身自苦若是？吳氏指其心以誓曰：「吾夫刻苦以求功名，吾所親見。吾乘其死以圖他適，來何面目以見吾夫於地下？且吾亦知暮年絕無所恃，顧吾尚有二伯父，猶可求育其子，以續吾夫之後，使吾夫不餒耳。願姑姊輩慎無再出此言也。」

其後往來吳、陳二家者二十有餘年，親送舅姑與父母之喪，哭泣盡哀，至於骨立，見者為之惻然。吾村當咸豐壬戌之秋，西匪入，屋舍皆焚，吳氏母家亦被鄰舍火災，遂成焦土。氏益發憤以謀口食，慷慨激烈而言曰：「吾夫家既不幸如是，吾母家又不幸如是，是皆天之所以厄我，我又何敢少休？以報二伯父及兄弟平昔拮据之勞，始終一節，是吾所立之志也。」蓋其自矢者有如此。

余於咸豐乙卯失王氏偶，厥後二子被擄，又娶羅氏，乃從姪婦所舊相識者。嘗至余家坐談家境心事，余見其顏色憔悴，兩鬢蒼然，而問其年，起而對曰：「姪婦五十餘歲矣。」問其子繼否，曰：「吾賴堂伯叔父之力，祧繼二伯父之子，而今而後吾願已畢，願天早賜我以同穴，毋以壽卑我也。」余聞其言而悲之，因歷舉節孝祠之孤苦而享期頤者以勸。

嗚呼！世人皆咎造物不仁，謂以吳氏之行誼，而多方以困厄之者，若不遺餘力焉。豈知困吳氏之境日益險，顯吳氏之節日益奇；顯吳氏之節日益奇，揚其夫之名日益新。雖使起梯山於九原而問之，平生所願榮不過博一衿，無足輕重，孰如其妻貞苦之節，使千百世而後不可湮沒之為愈者？然則梯山雖憾生前不能成名，必將幸死後其妻之能勵節也。彼蒼天，報施異路，誰謂造物待吳氏之夫，而使苦心孤詣之士，寂寂無聞也哉？余故表而出之，使後之有權力者得上書請旌表焉。
