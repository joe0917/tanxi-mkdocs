# 山干欽四百二十八公張氏安人節婦傳
```
题：[]孫邑庠增廣生 克謹識
峕：[]天啓七年丁卯冬月
初始点校：[20250808]民国庚辰本[3/33]-p397
修订参考：[]
```
安人，浦邑在城名家女，本族庠生曁百八十一公甥女也。幼嫻四德，長諳三從。

萬歷乙酉歲，于歸陳門欽四百二十八公諱文昌，字子懋。甫彌月而夫鹽商在杭，去久不歸。翁賢百七十公、姑黃氏倉卒問（間）兩人病作，安人仰天默禱，願以身代，割股和湯藥以奉。蓋不但展一已孝思，而且兼以報夫主之罔極者也。

萬歷乙未，生子起贊；戊戌年，子甫四嵗，而子懋公變易家產，援例授北京萬全左衛鎭撫，兼屯田軍務。勞於玉（王）事，遑恤其家？安人以青年撫孤，砥立於狂瀾洶湧之中。子幼稚，家事無人掌理，猶望其夫之宦回也。

萬歷庚子，文昌公卒於任所。安人不勝悲慟，愈勵初心，命僕三龍直至任處，載回夫柩，以受家庭祭奠，安葬於社塢口祖墳之左。豈僅尋嘗（常）婦姒之流哉？

豪右以安人夫故子幼，不無貪噬之念。而安人理家勤儉，饒有餘資，恢復冷水坵等處田產，撫子長成，娶媳張氏。正宜遐享天福，而萬歷丁未亦爾物故。何天之報施節孝若此也？

然勁節芳名尚在人間，子克成家，孫枝榮秀，此足以報安人矣。丁卯檢譜事，表表如安人者，烏容冺滅？敬書之，以為閨閫勸。

孫邑庠增廣生 克謹識

天啓七年丁卯冬月
