# 溪下明七安人朱氏節婦傳
```
题：[]眷侍教生邑庠廪生王天俸謹撰
峕：[]天啟二年壬戌冬月
初始点校：[20250807]民国庚辰本[3/33]-p394
修订参考：[]
```

安人朱氏，係明七公淑配也。慎修節孝，格遵婦道。明七公棄世之日，安人芳年止二十有二，遺子諱世旭，僅一週。上有老親，下有弱子，安人奉侍撫育，曲盡其道。豈期世旭年三十有五亦逝，遺孫景濂。以祖母而撫孫，復能創置世業。

夫世之夫死矢志不嫁者夥矣，就有能仗節撫孤，且老景攜孫，二代懸系，非安人不幾湮滅不傳哉？陳氏世稱三節，若安人誠可尾其後躅矣。享壽七十有二，節孝天植，經緯性成，女中丈夫也。恨不能垂之青史，姑以列之家乘。

余耳聞目覩，知之世真，僣敘數言，以俟大方之正董。

天啟二年壬戌冬月

眷侍教生邑庠廪生王天俸謹撰
