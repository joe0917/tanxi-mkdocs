# 獨石宣五十吳氏安人賢節傳
```
题：[]桐江眷弟庠生張廷諫拜撰
峕：[18修]康熙五十三年甲午重陽之吉
初始点校：[20260824]民国庚辰本[3/33]P405
修订参考：[]
```

安人吳氏，宣五十公之元配也。產自名門，長歸望族，嫻習婦道，宜室宜家，其淑德可知也。育二子，長以耀，次以錦。錦在懷抱，安人年二十有九。淑人運蹇，夫君倐遭瘋疾，煢煢孑立，兼無隔宿之儲。安人奉事藁砧，衣不解帶，勞瘁不辭。奈康星數奇，竟而登仙。安人年方三十有五，乃兄欲奪其志，矢志堅貞，泣天曰：「婦人從一而終，此分內事也。寧為陳氏之饑莩，斷不譜他室之瑟琴，以遺吾夫抱恨於九泉也。」遂親操井臼，總理家務，躬勤紡績，課子農桑，有陶孟之遺風焉。迄今家業豐饒，年近古稀，享遐齡之福，豈非立志矢節，何致彼蒼篤祐乎？余產桐江陋隅，別業其家，鄉鄰長幼嘖嘖稱道安人之懿行如此，屬子為文以誌之。余愧謭陋，聊陳其槪，以附諸君子之後云。

康熙五十三年甲午重陽之吉
桐江眷弟庠生張廷諫拜撰
