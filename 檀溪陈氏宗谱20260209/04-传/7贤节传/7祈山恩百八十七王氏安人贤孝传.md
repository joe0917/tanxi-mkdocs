# 祈山恩百八十七王氏安人賢孝傳
```
题：[]眷侍教生邑庠董明易頓首拜撰
峕：[15修]順治十四年丁酉冬月
初始点校：[20250808]民国庚辰本[3/33]P400
修订参考：[]
```

覽歷代淑媛，有美行彰聞，巳經表異，傳諸不朽者數人，然亦不可易得也。

余適肄業惠雲，聞祈山下陳恩百八十七院君者，乃當時之閫秀，奕世之闌婨，深宜尊尚者也。細詢其生平：外不必受乎傅訓，而訓規自若；內不必奉乎姆儀，而儀禮宛然。此係義烏表戚王泰寰之珍愛也，出自龍岡勳臣之甲族，向檀溪閥閱名門之子。于歸時經一紀，宜其家室，化洽四鄰。

見姑年高，朝則承歡，夕則問寢；見夫疾病，焚香拜告，愿身代患。若此者，誠與唐夫人並孝，孟德耀齊賢者也。𬢶（謚）之曰：「賢者淑慎，豈浪言文布也哉？」是爲傳。

順治十四年丁酉冬月

眷侍教生邑庠董明易頓首拜撰
