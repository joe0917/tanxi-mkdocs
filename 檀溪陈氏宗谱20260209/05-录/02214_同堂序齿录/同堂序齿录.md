# 同堂序齒錄
```
题：[20世/承83]第二十世祈山派承八十三邑庠生尙睿謹撰	
峕：[13修]萬厯嵗次庚戌春月
初始点校：[]光绪甲辰A本[1/22]P087
修订参考：[]民国庚辰本[2/33]P214
```

自鼻祖以來迄於今，計其世凡二十有三，子孫蕃衍，族屬渙散。

萬厯癸未，一齊公始建家廟，備立祭儀，合散萃渙之義，其庶幾矣。然歷今又二十餘年，則在廟之神主不無參越者，尊卑失序，長幼失倫，蓋祖宗在天之靈勿安也。生者其忍坐視乎？[[陈仕冲|仕冲]]、[[陈一龙|一龍]]創爲整飭序次之儀，合族習事者咸集商確。

祠之中寢，始祖碩公此百世不遷者也，若唐公、頊公各派繼世之祖，亦廟食無窮者也。至於歷代忠臣孝子、功德宏茂可爲子孫模範者，序於中寢之左，配享不遷焉。厯代閨闈節烈賢孝著聞堪爲內屬取法者，序於中寢之右，享祀不替焉。其餘世遠者，五世一斬，限於勢也；在廟者，九族同堂，遵古制也。其位則以等輩分昭穆、敘伯仲。雖列有字母異同，而位次初無優劣；雖生平有貴賤賢愚，而名分亳無假借。若然則疎者庶聯屬而親矣，如一脈之融貫；暌者庻膠漆而合矣，眞一氣之流通。命之曰：同堂敘齒。并續其錄，垂以不朽，故序之以見當事者之苦心，其功不可泯滅焉。

爾時協力者，大铭、大立、應詔、尙懋、尙福、尙美、維垣也。輯錄者，大錄也，并序。

萬厯嵗次庚戌春月

第二十世祈山派承八十三邑庠生尙睿謹撰
