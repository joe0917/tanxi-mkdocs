# 清釐大宗祠各項田產錄

## 清釐大宗祠各項田產錄序

```
峕：[31修]光緒七年歲次辛巳冬月

```

編輯不綜核互參，則散帙難稽；修注須縷分條貫，斯簡明易覽。吾於宗祠譜牒所載公產名目紛繁，欲為釐而整之，有志未逮，不勝耿耿焉。

攷自正己公彚輯譜圖、一齊公創建祠宇以還，未有公田。厥後修葺均需捐助，或銀或產，繼起從公，不一其舉。主持者節省勤勞，將各輸銀產經營生息，歷相授受，以底於成。復有山前德言公創捐養賢田，以為與祭紳衿給胙之資；祈山上街路永輝公義捐培學田，以為應試生童赴院之費。而譜牒纂修，尚籍工銀婦穀。

至乾隆戊申，上河之葉公、平湖以川公、向總理祈山井柳居祖淐公等，憫念科抖維艱，因與合族首議捐修譜田，湖山增入大宗祠合祭田。上河以佩公捐助守祠香田。同治間，余與同人設立祠燕田，捐資歷歷，置產紛紛，照依年分陸續登載。但所置助之田，或輯譜首，或注本人傳內，或祗注收租賬簿，殊難驟者。

茲當値事纂修，持為清釐分晰，按諸譜牒，核之租簿，互相較對，挨列坐落某都某保某畈某源，析其名目，繕敘坵片，揆其畞分，俾以一目了然，不致有星花數漫之虞。會計下間有不能符合處，殆由傳管多番，年代久遠，未免差池。仍遵前譜載存，不敢妄為刪置：一則勿負先人舊德流傳，一則俟諸後起清查追復云。鑒者原之。

## 科举停摆以后

吾族自科舉停罷以後，合族議將祠內文公紳胙之田并祠燕、蔚起二田，盡撥爲興學之資。祭費胙肉亦歸壺校理值，民（國）十八年改爲縣立，所有田產爲縣有，以致祭胙懸如。乃向縣再三力爭，教委會堅持不允。

幸王縣長之廉明，謂：“陳氏之祖若宗，助產爲獘（獎）勵後學之苦心，至今胙祭無着，殊缺獎勵助學之規勸”。於是特拔胙祭田十二處，共計一百九十八秤，有另立文蔚、燕戶，摺推舉管理四人，四年一更。理值春秋祭胙，并始祖碩公、唐公、頊公清明墓祭，八月初一日永輝公特祭，公之派下二人，祠總一人。茲將田畞開載于後，是爲引。
