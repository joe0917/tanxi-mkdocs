# 大宗祠管帳規條
```
题：[]
峕：[]光緒三十二年歲次丙午六月
初始点校：[20250416]民国庚辰本[2/33]P171
修订参考：[]
```

宗旨：以“協力同心，共襄公舉，務使各除私意，同敦族誼”爲極則。

法律：規條議定後，務須若實照行，如違議妄爲公衆議罰。

一、管帳員俱由族中公舉，以平日為人公正信實爲合格，被舉者不得諉，未舉者不得爭。

二、管賬員一經賬後，務當推誠，希公集思廣益，以期上無負乎祖宗、下可對乎宗族爲極歸。

三、管帳員以四年爲期，如果勝任應由公議接充，否則照規别舉。

四、一祈山派總理祠賬，近年登記槪不詳細，每爲各派藉同，故於祈山派外，又舉六派六人，添設賬簿，合同六本，以備各派對核稽查。俾得盡知出入，其任事諸人，務須詳細監祭（察），不得徇情。

五、一切銀錢出入，除逐年費用外，尚有餘錢，或放息，或受產，須會七派公議定奪，如祠中有大舉動經費或缺，亦會七派公議籌措，均不得由管賬員私行僭擅。再一，祠中所餘錢款，管脹人雖有契據，亦不得借。

六、欵項雖極瑣屑，務須逐一詳細記明，以備公衆稽查，不得僅以“雜項”兩字了之，庶足杜蒙混之獘，除登簿外，另行鈔謄榜示祠壁，以供大衆考察。

七、每年租穀，濕租若干，燥租若千，秋收畢後，照依租簿詳細開明，榜示祠璧，以供大衆考察。

八、一切祠中器皿，除祠用外，應藏祠中，管賬員不得攜家私用。

九、兌穀時所出穀票，每票須用票根，以存証據，所用圖章，各派帮理幹事人各帶一印到祠，或用二三印，或用某某印，皆由臨時酌議，庶免冒充之弊，其合同賬，亦各帶到祠中，以備登記。

十、一切賬目，如有浮報浮記，一經大衆察出，卽鳴族公議重罰外，不得再操管理之權。

十一、每年兌穀，無論穀價低昂，公議定於四月二十日爲期，不得任意先後，至管賬人等卽有出入瓜葛，概備現洋出穀，免致混端。

十二、每年糶穀時，須會七派舊理新理，及事外公正若干人，將一年費用進出，逐一詳細會稽，着事外公正人，將合同上總結登記，不得自行糊塗妄結。

十三、祈山派總理祠賬，每年收租時，逐日一人登祠，其六派六人，三人一班，五日一更，到祠帮理，照顧收晒，其將近了場齊集到祠，結算封倉，如不到祠，族中另銓。

光緒三十二年歲次丙午六月合祠立，合同賬薄柒本，柒派各管各執壹本。

祈山派、登二公派、平湖派、廊下派、駙馬派、會龍派、顯九公派。
