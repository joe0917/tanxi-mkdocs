# 誦三節詩
```
题：[]賜進士第前嘉靖乙卯解元慈水鄭卿拜撰
峕：[]
初始点校：[]民国庚辰本[4/33]p460
修订参考：[]
```

賜進士第前嘉靖乙卯解元，慈水鄭卿（鄉）拜撰

大節原爲世所稀，歷觀三節事尤奇；

一門正氣貞元會，萬古貞心天地知。

風拂荒臺知勁草，蘭生幽壑長新枝；

遺編不盡思前泪，誰獻當時勒鼎彝[^1]。

[^1]: 鼎彝（鼎彜）dǐngyí：古代祭器，上面多刻着表彰有功人物的文字。宋代刘克庄《凯歌十首呈贾枢使》“自古勋名勒鼎彝，老于文学即今谁。”

## 誦三節-用鄭解元韻

四明毛順之

婦全節守古來稀，三世流芳更所奇；

混沌卽今惟一見，旌書莫及有誰知。

萬載貞心天地老，滿門正氣柏松枝；

遺編閱罷潸潸淚，埋沒英名惜鼎彝。
