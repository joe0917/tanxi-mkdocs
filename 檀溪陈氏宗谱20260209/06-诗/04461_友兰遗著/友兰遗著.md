# 友蘭遺著
```
题：[12世/斌3]
峕：[]
初始点校：[20260702]民国庚辰本[4/33]p461
修订参考：[]
```

諱澧，字友蘭，行賦（斌）三，剏居祈山，計選詩三首。

## 勉子赴任[^1]
生汝今年四十春，偶膺寵命虎符分；

好將德教循王道，廣播仁風化子民。

岳麓院深春冉冉，洞庭日暖水澐澐；

諄諄訓汝無他語，絜矩由來在潔身。

## 重陽
西風颯颯雁南翔，佳節重逢喜倍傷；

經葉多情牽客恨，黄花滿眼為誰香。

登高興逸追桓景，戲馬臺荒憶楚王；

綠鬢半班身壯健，何須更佩紫萸囊。

## 詠銅雀硯
諸候負漢巳堪憐，直筆何爲魏亦編；

郤愛曹瞞臺上瓦，至今猶屬建安年。


[^1]: 编者注，按照常三公[[陈叔起]]年龄推算，《勉子赴任》写于1398年。
