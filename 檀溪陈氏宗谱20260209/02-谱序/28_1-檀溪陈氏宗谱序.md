# 檀溪陳氏宗譜序
```
题：[]欽命都察院江南道察院監察御史，朱能作，頓首拜撰
峕：[28修]大清道光廿七年丁未，清和月上浣。
初始点校：[20250218]民国庚辰本[1/33]p038
修订参考：[]
```
檀溪陳氏宗譜序[^1]

蓋自《禮經》垂帝繫之文，《史記》列世家之傳。
分甲乙丙丁之姓，帶礪[^2]同盟；
遡封胡羯末[^3]之稱，簪纓望族。
譜系所載冊府胥登，惟族屬非董狐[^4]之任，而宗譜豈檮杌[^5]之書。
溢美固非，索瘢[^6]亦謬。
司馬紀家人之事無待譏評，
左氏敘門内之行奚誇艷麗。

葛藟根庇須知鼻祖有人，
藕節絲連應識耳孫似我。
千尋建木探本良難，
九曲黃河窮源匪易。
有如檀溪陳氏之譜，不愧繼志述事之詳矣。

陳氏世傳舜裔，族著頴川，
有媯之後，古制云遥；
太邱以來，舊章已渺。
祖追派始，系衍本支。
溯鳥程之舊族，憫鳳卜於新田；
想罨畫之苕溪，六朝風韵；
訪湖山於浦汭，兩姓姻緣。
諧秦晉於車方，託絲羅於嫘祖。
遂乃醴出有源，燈然無盡。

赴上京而作使，偉哉方伯勳名；[[陈叔善]]
擢提舉以宣猷，藉甚淮南治績。\ref{陈一遇}

門題駙馬金枝玉葉之榮，
橋號會龍甘雨和風之所。

幸縉紳之雀起，
欣簪黻[^7]之蟬聯。

告身有自肯認畫像於梁公，\Ref{狄青}
受姓何來駭聽彈文於滿奮。\ref{满奋}

據情入奏，復姓歸陳。

伯益後以趙易赢，\ref{伯益}
文正公舍朱祧范。\ref{范仲淹}

此天經地義之有常，
亦孝子慈孫之佳見者耳。

仰前哲之流芳，
嗣後賢而奮起。

騷人墨客名噪詞壇，
志士義夫誼聯宗社。

當其衅起攤征，訟興均畞，奸胥虎視，豪右鴟張，
加餘糧者千五百石，
隷爰書者九十六人，
以致社長衿耆盡入羅鉗吉網，事經百折，案歷八年，欲雪奇冤，誰籌秘略？

一齋公剖心犯諫，白簡飛霜；
昌言公啮指陳書，黄堂誓日。

詔行許可，獄始平反，
力可回天，歡能動地，
貪狼遠竄，害馬永除。

書生胆固想見勁節英風，
君子營堅賴有筆鋒文陣。

仁者有勇，見義必爲，
洵足垂光於廟碣，
何慙（惭）配享於祖庭哉。

是蓋神明相餉，文獻有徵，
奕奕才名，輝輝德曜。

讀孔璋[^9]之檄，名世文章；
卧元龍之樓[^10]，待時經濟。

宰天下亦如此，藹聞主社之風；
大丈夫安事斯，雅負人倫之望。[^11] [^12] [^13]

今陳氏篤念宗盟，導揚先美。

撫杯棬之手澤，
思簡笏之心傳。

聿追芬響，以表門閭。

鄕曰至德，里曰如曾。

載式清徽，允繼家風。

元方將車，季方執杖[^14]。

是雖人傑，亦由地靈。

仰蔭慈雲，旂（祈）山簇簇；
俯承德澤，檀水溶溶。

宜其燕翼貽謀，鴻猷永裕。
已兹以歲屆丁年，譜宜庚續。

集雲礽於奕禩[^15]，
會星聚於宗祊。

對越堂中，序昭序穆；
萃渙庭畔，辨貴辨賢。

芸生形，瓜瓞之綿；
似續合，桑梓之敬。

一門著姓，百代留歌。

索我讕言，例存譜序。
但學慚測蠡，技愧雕蟲。

排俚語之蝗吟，
附羣賢之貂尾。

此日誦芬述舊，足表祖功宗德之深；
他年旌節褒忠，堪備國故朝章之採。

是爲序。

大清道光廿七年丁未，清和月上浣。

欽命都察院江南道察院監察御史，朱能作，頓首拜撰

[^1]: 本文是一篇对仗工整的骈文，引经据典，阅读较为晦涩。
[^2]: 带砺：出自西汉·司马迁《史记·高祖功臣侯者年表》：“封爵之誓曰：‘使河如带，泰山若厉，国以永宁，爰及苗裔。’”，成语“带河厉山”比喻比喻国基久远，国祚长久。文中“带砺同盟”指长久联盟。
[^3]: 封胡羯末：均为兄弟的小名，“封”指谢韶，“胡”指谢朗，“羯”指谢玄，“末”指谢川。后用以称美兄弟子侄之辞。
[^4]: 董狐：春秋晋国太史，亦称史狐。董狐为史官，不畏强权，坚持原则。后人用“董狐直笔”指敢于秉笔直书，尊重史实，不阿权贵的正直史家。
[^5]: 梼杌(táowù)：出自《孟子·离娄下》：“晋之乘，楚之梼杌，鲁之春秋，一也”。赵岐《孟子章句》注云：“梼杌者，嚣凶之类，兴于记恶之戒，因以为名”。文中指记录像梼杌那样的“嚣凶之类”，并以之为戒。
[^6]: 瘢：音bān，瑕疵
[^7]: 黻（fú）：指古代礼服上黑与青相间的花纹。簪绂：冠簪和缨带，古代官员服饰，喻显贵，仕宦。
[^9]: 孔璋：中国东汉末年文学家陈琳（？-217年），字孔璋，广陵射阳（今属江苏）人。陈琳擅长撰写章表书檄，风格比较雄放，文气贯注，笔力强劲，代表作有《为袁绍檄豫州文》
[^10]: 卧元龙之楼：出自《三国志》卷七〈魏书·吕布传·陈登〉，“欲卧百尺楼上，卧君于地，何但上下床之间邪？”。后用“元龙百尺楼”借指抒发壮怀的登临处。
[^11]: 出自《钦定四库全书·集部·橘山四六（宋李廷忠撰、明孫雲翼注）·卷二·回黄州知府》“宰天下亦如此肉矣，藹聞主社之風；大丈夫安事一室乎，雅有清時之畧。”。分别引用了《陈平传》和《陈蕃传》两个典故。
[^12]: 李廷忠（1154～1218），字居厚，号橘山，于潜人。宋孝宗淳熙八年进士。官于潜教授。著有《橘山四六集》二十卷。（注：“四六”是骈文的别称）
[^13]: 孙云翼：明文学家。字禹见，一作禹俭，号鹏举，丹阳人。万历十九年(1591)举人。历任广东龙川知县、彝州知州，陵州知州。撰述甚丰，文工齐梁体。著述主要有《广福山志》、《哑绍编》、《清畅斋骈语》、《鳌阳漫稿》、《桔山四六笺注》
[^14]: 出自《世说新语校笺·德行第一》陈太丘诣荀朗陵，贫俭无仆役，乃使元方将车，季方持杖后从，长文尚小，载著车中。
[^15]: 奕禩：亦作奕祀，世代，代代。
