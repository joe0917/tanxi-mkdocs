# 丁未重修宗譜序
```
题：[25世/聰554]編次裔孫，松齡，謹撰
峕：[22修]乾隆丁未冬月之吉。
初始点校：[20250220]乾隆丁未本[1/1]p134
修订参考：[]民国庚辰本[1/33]p031
```

尊祖、敬宗、收族，一以貫之，事極平常。然非如古之孝子仁人用心真摯，不能推其本源之所結聚與血脉之所流通，以警發愚頑無識者，俾得還天地心，遠禽獸行也。故夫宗譜之設，以聯宗也，以明倫也。而善善惡惡，不稍假借，則又未嘗不奉行國法，以維風厲俗爲兢兢。如之，何其可以鹵莽厥事哉。

吾族自宋居浦時，猶未盛已。而登三\ref{陈应纪}、俊五\ref{陈珪}、[[陈惟能|常十一]]諸公，相繼而起。存仁孝之思，推一本之念，各有論述，以著宗法，譜始萌芽，然其語已剴切[^1]詳盡，可爲子孫世守。

自是厥後，雖屢有修輯，不過備書婚娶、卒葬、祀産、祭品而已，無所發明。甚至科斂丁錢毫無部署，一任譜師開局刷印，不肖者私行囑託，希載佳語以欺後人。或隱理根據，以爲異日訟本。其他魯魚亥豕，沿訛襲謬，不一而足。弊乃不可勝言矣。

乾隆丁未，董理宗祠光大\ref{陈光大}等，慨然曰：“吾家宗譜自乾隆癸未（21修），迄今二十餘年不修，失今不舉，漸且遺脫，無從稽考，爰請族長會集諸紳士，商酌妥議，務期核實訂正，以成善本”。

因搜得前明萬歷四十一年[^2]譜一冊，雖多殘缺，間有完備可讀者，存其信，闕其疑，猶見先人慎重此事不爲荀作之意。

按冩本，內有云“與諸暨白門會譜至第十三世而止”，乃正統元年[^3]（7修）常十一公遺下親筆老譜。

又前此冩本，止有系圖。至[[陈宗元|宗元公]]，始定鴈行世傳。嘉靖四十三年，昌言公\ref{陈昌言}復加篆輯，各有小引。今譜皆削不載，實可駭歎。

冩本或因年遠不可考，生卒從畧，以示慎也。今譜多確鑿注明，反詳於寫本，以至核對年號，種種紕繆，其爲妄意増添，顕然明白。

故自萬歷以前一從冩本校定，萬歷以後但逐字細核，要於近理。不爲穿鑿附會，以滋荒誕。

此一役也，族中諸紳士，各司其職，罔不精心鈎討，協力研求，以歸允當，其於“尊祖、敬宗、收族”之義，庶有合焉。

嗟乎，任事者心，治心者學，不學則心懵，心懵則事乖。通吾心於祖宗血脉之處，因卽還吾學於族黨本源之地。

昔劉知幾\ref{刘知几}作《劉氏譜》，援據明確，學者服其該雅，尙不免爲流俗所譏。則信乎“仁人孝子之用心”為最難也。後之覧者倘執是譜以求之，或病其學之未精，固疑不免，至於推尋反覆，不遺餘力，此心發幸無罪也已。

峕：乾隆丁未冬月之吉。

編次裔孫，松齡，謹撰。

[^1]: 剀（kǎi）切：切实，跟事理完全相合。
[^2]: 萬歷四十一年：1613年，癸丑年。按照“修谱名衔”各修年份，最接近的为第13修，为万历癸卯年。其后为14修天启丁卯。
[^3]: 正統元年：1436年，第7修正统丙辰
