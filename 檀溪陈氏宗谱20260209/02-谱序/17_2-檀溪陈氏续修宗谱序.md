# 檀溪陳氏續修宗譜序
```
题：[]義門麟川釣叟鄉貢進士鄭尚王頓首撰
峕：[17修]康熈辛巳仲春之吉
初始点校：[20250224]乾隆丁未本[1/1]P126
修订参考：[]民国庚辰本[1/33]P025
```
（乾隆丁未本，本谱序放在19修谱序后）

浦陽邇來聚族之繁推陳氏，陳氏之宗惟在浦之廿六都檀溪者爲尤盛。

盖檀溪之陳，自宋天聖間有碩公者，自湖州烏程來贅浦之方氏，遂家焉，子孫遂從其姓。

六世[[陈珝|珝公]]，爲宋督府都事，始奏復姓，因爲“車方陳氏”。第今陳氏之在廿六都者，散居分處，各自爲派。其始遷者爲湖田，其後或爲寺前、爲前後宅、爲會龍橋、爲平湖、爲上河、爲大畈、爲廊下、爲內外柯坑，其他不能悉数。然其派雖分，而譜則合。

余嘗觀檀溪陳氏之譜，見夫族属繁衍，宋明之世名賢蔚起，傳今二十五世，其載列派處者幾遍北鄉，誠盛矣哉。

及讀譜中家先伯父憲副[[郑崇岳|霽華公]]之序，益信今日陳氏後人之盛，爲有自來也。

乃今辛巳孟春，陳氏之居檀溪前後宅者，有良星（良信？）、良源\ref{陈良源}輩，復持是譜來麟溪之上，請於余，曰：

“余家修譜，昔明天啓之歲，嘗䝉霽華先生賜之序矣，今者復修，欲得先生一言，以續霽華先生之後，可乎？

盖余五世祖汝功公\ref{陈汝功}，爲駙馬。
六世祖一遇公\ref{陈一遇}，仕宋爲淮南提舉，建前後二宅，助田百畆入惠雲寺。
八世祖公舉公\ref{陈公举}，爲宋浙江儒學副提舉。
九世祖應清\ref{陈应清}公，爲宋校勘。崇三公諱夢魁，中至元鄉試舉人，弟崇六公諱文昌亦中鄕試舉人。
十一世祖榮三公諱天祐\ref{陈天祐}，洪武間隨征寜國爲知府。
十二世祖[[陈彦道|彦道公]]，仕明爲寧國知府。
皆檀石前後宅之派也。

意欲先生假以一言，俾我後人知，昔日之在前後宅固有如斯之盛者也，庻使有所觀感而興起乎。”

余乃爲之喟然，曰：
“國之興廢，家之盛衰，固不可常也。苐今之居前後宅者，皆車方碩公之後也。夫爲人後而不能彰先世之美者，非仁人孝子之心也，善乎？

余伯父之言曰：‘陳氏子孫誠卽是譜，而思夫支分派别之原出自一人，則相愛相敬亦止以鬯我一氣’，則余今日之所以塞陳氏後人之請者，亦仍無以易乎是言也，雖然要不可不自勉也，自勉者何亦惟務相親睦，以益敦愛敬之風，則他日之爲名賢、爲仕宦，悉無以踰乎此矣。

康熈辛巳仲春之吉。

義門麟川釣叟，鄉貢進士，鄭尚王，頓首撰。

[因前譜宦蹟，未及開載明白，今良信，國賢，國亨字良源，國亭，元傑，儒憲、之文、之孟、之欽、以孝八人（8人待考），特索序文，載諸譜首，以爲世世相傳之意，此記]

八世祖公舉為宋浙江儒學副提舉；九世祖應清公，為宋校勘；崇三公諱夢魁，中至元鄉試舉人，弟崇六公諱文昌，亦中同科舉人；十一世祖榮三公諱天祐，洪武間隨征寧國，為知府；十二世祖彥道公，仕明為寧國知府。皆檀石前後宅之派也。

意欲先生假以一言，俾我後人知昔日之在前後宅，固有如斯之盛者也，庶使有所觀感而興起者乎？

余乃為之喟然曰：國之興廢，家之盛衰，固不可常也。第今之居前後宅者，皆車方碩公之後也。夫為人後而不能彰先世之美者，非仁人孝子之心也。善乎余伯父之言曰：「陳氏子孫，誠即是譜而思夫支分派別之原，出自一人，則相愛相敬，亦止以鬯我一氣。」則予今日之所以塞陳氏後人之請者，亦仍無以易乎是言也。雖然，要不可不自勉也。自勉者何？亦惟務相親睦，以益敦愛敬之風，則他日之為名賢、為仕宦，悉無以踰乎此矣。

今良信、國賢、國亨（字良源）、國亭、元傑、儒憲、之支、之孟、之欽、以孝八人，因前譜宦蹟未及開載明白，特索序文載於譜首，以爲世世相傳之意，此亦不忘祖宗之孝思也。因援筆而為之序。

峕康熙四十年辛巳仲春
