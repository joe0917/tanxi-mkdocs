# 陳氏重修宗譜序
```
题：[]金華府浦江縣儒學教諭，葉廷璧，頓首拜撰
峕：[20修]乾隆歳次丁卯季春月
初始点校：[20250221]乾隆丁未本[1/1]p130
修订参考：[]民国庚辰本[1/33]p029
```
檀溪陳氏，世系淵源，年代乆（久）遠。自宋天聖間，由烏程遷徙。諱碩公始，歴今二十七世，族繁氏衍，不可殫紀。其家宗譜，燦如行次倫序、歷朝宦蹟咸在，不失前人纂輯之功，可謂巨矣。

余司浦陽鐸接[^1]，其裔孫學宿，名望聲噪膠、庠名登仕版者多人。余歲時相見，殷勤請教，耿耿于衷。

一日，以重修家譜爲事，譜凡十九修，自雍正已酉（19修），距今一十九載，生齒日殷，恐散軼無統紀，鳩族重増各分董其事，用以承先世之緒，聨子姓之繁，不廢前人纂輯之功，可謂篤厚於親矣。

譜成，請序於余。

余因念《禮記·大傳》有曰：“綴姓故合族，合族故尊祖，尊祖故敬宗”[^2]。夫以祖宗爲念，自以族姓爲心。族姓散軼則祖宗之派衍漸卽遺忘，其不等視爲路人也者。

幾希昔歐陽永叔\ref{欧阳修}作譜牒，用史氏年表法，以人係世，以世紀人，上下其聨属，俾在服宗親，揭譜易識間疎遠者，亦得追水源木本之義，而歸於一。

茲譜之修，雖凡例不必盡同，其於“綴姓、合族、尊祖、敬宗”之義，一而已矣。且其譜攷系自近，紀事以實，不攀援、不遺逸，炳炳鱗鱗，以次相求，則億年子孫永綿續於無疆矣。

余因陳氏之請不辭，謭陋而爲之序，又續之以歌。歌曰：

	瓜瓞綿綿，以引以延，
	
	祚啓卜鳳，派别龍纒。
	
	芳流浦汭，皇繼檀川，
	
	以裕於後，以光於前。
	
	宗功祖德，子邁孫賢，
	
	爾昌爾熾，貽翼貽燕。
		
	渙以廟萃，族以譜聨，
	
	本支百世，於萬斯年。

旹：乾隆歳次丁卯季春月

金華府浦江縣儒學教諭，葉廷璧，頓首拜撰。


[^1]: 鐸接：意思不明，待考。
[^2]: 全句为：“亲亲故尊祖，尊祖故敬宗，敬宗故收族，收族故宗庙严，宗庙严故重社稷，重社稷故爱百姓，爱百姓故刑罚中，刑罚中故庶民安，庶民安故财用足，财用足故百志成，百志成故礼俗刑，礼俗刑然后乐。”
