# 同治庚午重修宗譜序
```
题：[]辛酉壬戌舉人揀選知縣，眷姪樓簡拜撰
峕：[30修]同治庚午冬月穀旦。
初始点校：[20250217]民国庚辰本[1/33]p040
修订参考：[]
```
	
天下者，一鄉之積也。譜也者，史之細也。是故史有世家、有世表，皆於譜爲近。然譜之言普，譜之言屬，修譜之舉必愼且勤。勤則不漏，慎則不濫。普其所普，屬其所屬，皆曉然於愛親。敬長、敦本、睦族之道焉。

檀溪陳氏，北鄉望族也。自碩公遷浦以來，傳三十餘世，歷八百餘年，譜凡二十九修矣。向來修無定期，乾隆丁未[^1]始，議十年一舉，逢丁開局，後因費用不支，復議十年小修二十年大修，不疎不數，固爲勤且愼已，而族中猶虞其或漏與濫

於道光丁亥[^2]，係小修之年，均以大修爲是。公議嗣後槪行統修小修之舉，遂於是乎，變咸豐丁巳[^3]大修。

後至辛酉（1861年）九月，粵匪[^4]擾浦，宗祠遂被燬。是以丁卯（1867年）屆期，未克舉行，然其愛敬之心、教睦之誼，蓋未能一日忘也。

今年春，族長祖第\ref{陈祖第}與族屬，會商建復祠宇，并議修譜。奈兵燹後，譜田餘資不敷大修經費。不得已今次從“建”字以下仍將小修，暫行一舉，“建”字以上載舊牒而無漏濫者，俟後大脩（修）再行印輯。

爲此經理捐輸，付諸剞劂[^5]，凡“建”字以下，生某年，卒某日，名某，號某，嫁於某，娶於某，遷徙於某，悉詳之。

始事於本嵗冬，初告竣於來年春季。是役也，董事者皆竭心盡力，克愼克勤。

帙成，董理英樣\ref{陈英样}等，囑簡敘，簡固不文，但不獲辭。

展而讀之，見其宗約之詳，家規之肅，
勸者勸，戒者戒，昭然法守也，
筆則筆，削則削，凜然大義也。
而且，
紀官閥爲耀祖也，
誌文學爲華國也，
傳德行，表節烈，爲足爲子孫法也，
上治、下治、旁治，綱舉而目張，
大宗、小宗、無宗，有條而不紊。
由是，
昭穆以分，支派以别，長幼以序。

不禁掩卷留連，深嘆[[陈九经|一齋公]]之作於前者，法良意美，而孝子慈孫之矢勤矢愼、修舉無廢者，愛敬敦睦之情，不更有加無已耶。

夫源遠者流長、根深者葉茂。讀斯譜而知陳氏之瓜衍椒蕃、寢昌寢熾者，其來有自也。至於得姓受氏，與歷世之嘉言懿行，諸名公暨鄉先生序之詳矣，固無庸贅。

同治庚午冬月穀旦。

辛酉壬戌舉人揀選知縣，眷姪樓簡拜撰。

[^2]: 道光丁亥：1827年第23修
[^3]: 咸豐丁巳：1857年第29修
[^4]: 粵匪：指太平天国起义。[[奕世修谱# 太平天国运动（辛酉髮匪/粵匪，1861）]]
[^5]: 剞劂，音JīJué，刻镂的刀具
