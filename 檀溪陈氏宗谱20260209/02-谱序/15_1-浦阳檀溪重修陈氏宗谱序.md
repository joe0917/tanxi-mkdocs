# 浦陽檀溪重修陳氏宗譜序
```
题：[]前進士授丹徒令，眷社弟，錢塘關鍵，頓首拜撰
峕：[15修]順治戊戌春三月中浣吉日
初始点校：[20250225]乾隆丁未本[1/1]P112
修订参考：[]民国庚辰本[1/33]p022
```

粤以甲申（1644）之變，中原瓦解，余遂解組歸田，澄坐湖墅，日與造化者逰，凡文墨之事一皆謝𨚫（却）。

余友陳君諱[[陈泰陛|泰陛]]者，昔遊學文林，與余爲忘年交。間以數載兵燹乆（久）阻班荆。丁酉（1657）夏，偕族長[[陈德卿|德卿]]來謁，且言鼎革之際，我浙東義士拒守江岸歳餘，两軍互相焚掠無虛時，故婺浦被兵特甚。崇甍，巨室化爲灰燼，家牒先型盡属祖龍一炬矣。士民懲其害，多竄身巖谷間。

於玆十載，稍獲平定。念譜圖𠷔（喪）亡，恐後世無所考究。謀爲修輯之舉，請序於余。

余思氏族之學，昔人所甚重，盖以辨親疎、明異同也。

向聞車方陳氏自碩公，逮今二十三世，族屬之衆將数千人。有造之者見其棟宇鱗次，衣冠濟如孝悌雍穆、淳龎樸茂之風，素著望族。一旦狼狽流離，星散野處，曩時之盛，凌替什九，將無親者疎之、同者異之歟。

雖然祖功宗德貽謀深遠，孝子慈孫永思不忘。陳氏之能亢宗，以食前人之報者，固未有艾也。而德𪤼（鄉）尤其樂善好義、敦宗睦族者，雖踈遠宗黨，勿忍見其乖離。彛（彝）性使然，非逢屯離[^1]之所能移也。

所以當譜廢之餘，惓惓切念輯祠，聘師考訂先世遺蹟。蒐采[^2]丁卯（14修，1627）以後文學、行諠、忠孝、節烈可據者續編之，以補其闕。仍倣先哲體裁，序述、遺文、行傳、世系爲四類。至若始祖斷自碩公，勿援引無據，以惑後世。

譜成，什襲珍藏之，俾後之披覧者，灼知前人之源遠流長皆由於立德，族衆之支分派别皆本於一氣。必能敬其所尊，愛其所親。紹述箕裘累葉，而勿替耳[^3]。

是集也，豈僅聚渙合散，辯親疏、明異同哉？其於崇孝廣敬之道，亦大有裨矣。余故不辭而爲之序。

旹：順治戊戌春三月中浣吉日。

前進士授丹徒令，眷社弟，錢塘關鍵，頓首拜撰。

[^1]: 屯（zhūn）和離分别为两个卦象。
[^2]: 蒐采，亦作“搜采”，指广泛搜集、采集。
[^3]: Desspseek解释：出自《尚书·大禹谟》，原文为“紹述先志，箕裘累葉”。这句话的意思是继承先人的志向和事业，像箕裘（古代的一种服饰）一样代代相传，不断积累和发展。
