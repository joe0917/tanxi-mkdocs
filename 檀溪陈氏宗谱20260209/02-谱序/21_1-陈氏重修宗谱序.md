# 陳氏重修宗譜序
```
题：[]乾隆癸酉浙江鄉試舉人年家眷姪張邦彦薰沐拜撰
峕：[21修]大清乾隆歲次甲申初夏月
初始点校：[20250220]乾隆丁未本[1/1]P132
修订参考：[]民国庚辰本[1/33]p030
```
陳氏於吾浦最爲巨族，而其在廿六都者，尤甲於北鄉。族大村繁，不能悉数。而總其號曰“檀溪”。其為人，類皆敦詩書、重氣誼，衣冠文物郁郁彬彬。有學有行之士，聲噪黌序、名登仕版者接踵而起。嗚呼，何其盛也。

予嘗至其地，但見秀峯叠叠，峙其前後，清泚滔滔，環其左右。奥如復曠，如每到一處，輒爲流連不忍去。

夫泗水東山，實産賢哲。陳氏之寢昌寢熾意者，惟地靈故人傑乃爾。

乃今展其譜首，讀其歴代裔孫序文，始知其所以盛者，淵源固有自也。

吾於學諭登三公\ref{陈应纪}《節要》一書，而見祖功宗德之遠焉。於文學[[陈克敏|思斌公]]《地里》一辨，而見溯流窮源之確焉。於俊五公\ref{陈珪}《姓氏異同》，而見其非種之必鋤。於俊四公\ref{陈玛}《原譜程式》，而見其本支之甚重也。他如《大宗小宗定說》（6修[[大小宗定说]]）《重修宗譜提綱》（8修[[重修家谱提纲]]）篇，一以敦宗睦族、激濁揚清為兢兢。

嗚呼，前人之積功累仁既如彼，而奕葉之孝子慈孫繼述又如此，宜其佑啟後人。而文章德業増輝家乘至斯也，豈盡山水之靈哉。

抑又有說，昔敬仲[^1]之初生也，有以《周易》見陳侯者，曰“自他有耀”，及其奔齊，齊侯欲卿之，則為歌“畏我友朋”[^2]之逸詩，以辭羈旅之臣，盖其慎也。然而“工正”一官已早為之兆矣。

今陳氏始祖，由烏程遷浦，已七百四十餘年，磅礴欝[^3]積，亦當“自他而有耀”，一旦“翹翹車乘，招之以弓”[^4]乎，則出其文章德業，以報國而亢宗，此其時乎。然則陳氏之昌熾，不且方興而未艾也哉。

譜凡二十修矣，今歲春，其族復開局重修，而嘱序於予。予實不文，而勉爲之者，重違□執友命也。至若其得姓受氏、遷居分泒之顚末，有前賢序在。自丙寅（20修）來所有生卒、葬娶，以及節義、孝友、仕宦、儒流，悉當遵前式續書，以成一族鴻編。則有學行兼優之執事者在，概不敢贅。

旹：大清乾隆歲次甲申初夏月。

乾隆癸酉浙江鄉試舉人，年家眷姪，張邦彦，薰沐拜撰。


[^1]: 敬仲：指《史记·田敬仲完世家》中的田完，也叫陈完，为陈国公子，逃到齐国改姓为田，后来田姓掌管齐国。详见“溯流寻源”
[^2]: 出自《左传·引逸诗》
[^3]: 欝：同“鬱”，盛，充盈。
[^4]: 同上文“畏我友朋”，均出自《左传·引逸诗》
