# 檀溪陳氏重修家乘序
```
题：[]前桐廬縣知事，山西候補知事，古鹽官，王景韶，謹撰
峕：[34修]中華民國五年六月。
初始点校：[20250215]民国庚辰本[1/33]P045
修订参考：[]
```
	
一國之中必有聖主賢臣叠興，而理一國之政，而後其國強；
一族之中必有孝子慈孫踵起，而聯一族之情，而後其族盛。

否則人以衆而易渙，地以大而多暌[^1]，如一盤散沙不能團結，甚且相嫉忌、相爭奪，尋仇啓釁[^2]，罔有已時。如此之國，雖强必弱，如此之族，雖盛必衰。
若然檀溪陳氏，誠足以風矣。

檀溪陳氏，浦陽巨族也，亦望族也，自車方發祥以來，羣聚於僊華山北者，約數氏家，儒林名宦，代有達人，懿行嘉言，更僕難數。

試以近事徵之，辛亥光復，吾浙仗義興師，攻克金陵天保城[^3]一役，戰績爛如陳氏族中與於斯役者共十數人，可不謂烈烈轟轟歟抑。

韶嘗訪舊而入檀溪，見俗美風醇，如遊唐虞三代之世，輒徘徊不能去，與其族中父老相周旋，勤勤懇懇，誠意有加，并言及讓清之季，族中各派以意見之偶岐，致釀成决裂之勢，旋卽本根是念，和好如初。

嗟乎，今日之國勢孔急矣，袁逆雖亡，而新舊之黨，南北之見，尚爭執而不休，顧瞻前途，罔知所屆，惟由陳氏一族之情事以推之一國，則恢復和平，力謀統一，當不難期之於旦暮間也。

吾友[[陈景銮|錦波]]，陳氏族中人也。嘗宰奉化、宰嘉善，韶亦嘗宰海寗、宰桐廬。錦波鳴琴而治，韶披星戴月而不治，曾對之有愧色矣。

今年春，吾浙擁護共和，宣布獨立。錦波佐今都督呂公[^4]，出守嘉禾軍書。旁午擕家乘以相隨，（韶）過而問之，具告以陳氏適重修家乘，昉於前年冬，今秋須蕆事矣，并索以序言，遂舉平時嚮慕之私，傾倒而出之，以遺陳氏族中諸父老，而不自知其不文也。

中華民國五年六月。
前桐廬縣知事，山西候補知事，古鹽官，王景韶，謹撰。	


[^1]: 暌：音kuí，隔开，分离。
[^2]: 启衅：同“挑衅”，引发嫌隙，挑起争端。
[^3]: 1911年冬，由朱瑞率领的浙军攻下南京天堡城，取得辛亥革命中光复南京的胜利。
[^4]: 吕公望（1879年2月28日—1954年7月22日），原名占鳌，字载之。浙江永康人。1913年，吕公望任嘉湖戒严司令，驻嘉兴。1914年7月任嘉湖镇守使，驻湖州。1916年5月5日，吕公望被公举为浙江督军，同时兼任省长。
