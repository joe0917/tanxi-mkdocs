# 丁巳重修宗譜序
```
题：[]同邑丁酉舉人候選知縣，芸巖王祖烒，拜撰
峕：[29修]咸豐七年歲次丁巳夷則月中浣之吉
初始点校：[20250217]民国庚辰本[1/33]P039
修订参考：[]
```

昔人有言曰，祭祀生於人心。生於人心者生於仁孝之心也。仁人孝子心惻於身之自來，而敬念其宗祖之所降臨，則有祠；因歷記其宗祖之所祠續，則有譜。此祠與譜相因，而仁人孝子之誠心，於祭祠者，所不容已於創而始，亦不容已於繼而修也。

檀溪陳氏之盛久矣，其祠創於萬歷之癸未[^1]，修於崇禎之戊辰[^2]，嗣是而修不一，修至乾隆丁未（22修），而堂寝廊宇壯麗嚴肅。敬宗合族之所，固已式廓其規模矣，而其譜之作，則愼而審，譜之修則勤而密。

蓋自碩公由烏程遷新田贅方氏，姑從其姓者，斷爲始祖，而譜系定。自[[陈珝|都事公]]復陳之本姓而譜牒明，自登三公書《節要》而譜原確[^3]，而後[[陈彦道|彥道公]]輯於洪武庚辰，而譜作焉[^4]。由是而修於[[陈惟能|惟能公]]而紀實之譜錄詳[^5]，修於[[陈昌言|昌言公]]而分類之譜文備[^6]，修於[[陈九街|九街公]]而行傳之譜序明[^7]。延及[[陈尚睿|德成公]]修之統同别異而譜法嚴[^8]，[[陈德卿|德卿公]]修之拾遺補闕而譜例新[^9]，[[陈元和|子貞公]]修之訂訛刋謬而譜考精[10]。

至於族益繁、議益增，議於逢丁輯譜，而修譜之期益近，迄於今子若孫登其祠、展其譜，于八百餘年中，生卒婚葬晰然而不淆；三十餘世中，里居族聚秩然而不紊。且經二十餘次之修，其仕宦 、功績、文學、孝義、貞烈之輝乎家乘者，粲然而不泯此。觀陳氏之祠譜，而知其先人之德澤遠，其後人之賢嗣多，要皆其仁孝之心所綿亘也。將廣大其祠，增廣其譜，傳之無窮也。

今陳宗衡兄來囑予序，其令祖亦曾於乾隆丁未（22修）助修祠宇者，而孫繼之助修家譜，亦可謂能繼述者矣。是爲序。

峕：咸豐七年歲次丁巳夷則月中浣之吉

同邑丁酉舉人候選知縣，芸巖王祖烒，拜撰。
