# 重修譜序
```
题：[]桐江歲貢生，何思麟，沐拜撰
峕：[18修]康熙五十三年甲午子六月朔日
初始点校：[20250221]乾隆丁未本[1/1]P122
修订参考：[]民国庚辰本[1/33]p027
```

檀溪陳氏巋然甲族也，其先世纍纍簪纓，不減江左王謝[^1]，迄今族蕃派分，而詩書禮樂之澤綿延弗替。

余館穀[^2]有年，齋居之暇，索前家乘閲之。古所謂立德、立功、立言三不朽者[^3]，陳氏祖固已兼之矣。特稽其源流之異同，傳序之參差，𭭎（欵，款）式之詳畧，句字之訛誤，私心不無涇渭，但自愧不文，何敢有雌黄也。

甲午之春，閤族議開局重修。余同年友[[陈启经|心緯]]兄，暨合弟心言\ref{陈启纶}兄、[[陈成璧|介圭]]兄，素稱博物君子，乃一一取而釐正之。

甫脫稿，取以示余，覧畢不禁爲之稱快，曰：“是誠足以壯陳氏大觀矣”。爰命齋童滿引大白，延山水之靈共訂之，以弁其首焉。夫譜例昉（仿）于遷固[^4]，備於歐蘇[^5]。

陳氏，舜裔也。先世支分派别，各居一所，相距不止千有餘里。自虞至今，相隔不止千有餘世。宗河祖海，遠不可考。

烏程陳氏，實有虞氏之嫡派，而碩公由烏程遷浦陽，則溯厥源流，其在烏程者不必遠述，例宜以碩公爲始祖，前[[陈宗贞|厚六七公]]、[[陈克敏|克敏公]]考之甚詳、辨之甚明焉。方正學有言“有而不書者忘其祖，無而書之者誣其祖”。此庻無“忘”與“誣”之咎也。

已前一齋公《平糧實蹟》，譜傳既已詳載，而昌言公一書，冩人情物理如道家常六事，卓然可傳。向譜未載，今特補入。

《三節》清操，府縣志俱採錄詳悉，而家譜中反畧，今俱遵志書詳列。

若[[陈彦道|彦道公]]等勅命，雖經灰燼，其目猶存，况[[陈尚恩|經歴公]]勅命彰彰猶存，不得不增補也。

至於陳氏分派里居，指不勝屈。其已載者，不得從畧。其未載者，尤不得不詳非所云。崑崙之出，千溪萬派，而不可竟歟。

舊譜止有族譜規例，而宗祠獨無條約，兹特遵前賢治家規矩，著爲二十四則。更撰春秋祭文數通，竝載之，以爲子孫法守。俱贍而有體。纂成，更取全部較正之，魯魚亥豕毫釐必析，不得以漫漶舛錯支吾搪塞已也。

嗚呼，今之學士大夫，囊括古今，而或不能自明其祖德，甚至視九族若秦越者不少矣。卽有譜牒，而涇渭不分、詳核不辦、褒貶不明、欵式不當，縱歲累千萬人，亦何益於宗譜有無之数。

今閲陳氏成書，信而有徵，華而不僞，一洗附會之誣，更見宏通之識，誠犂然家乘矣，不眞足以風哉。若夫檀溪族望之分，子孫昭穆之序，宗功祖德之【垂，嗣墓祭田之紀，此舊譜大凡炳若日星者也，不贅。

康熙五十三年甲午子六月朔日。

桐江歲貢生，何思麟，沐拜撰。】[^6]

[^1]: 王谢：指东晋时以“王导”和“谢安”为代表人物的两大名门望族。
[^2]: 馆谷：指作馆，教私塾或任幕宾。
[^3]: 出自《左传·襄公二十四年》：“太上有立德，其次有立功，其次有立言，虽久不废，此之谓不朽。”
[^4]: 遷固：司马迁和班固。
[^5]: 歐蘇：欧阳修和苏轼。
[^6]: 中括号中为乾隆丁未本缺页文字，采用“民国庚辰本[1/33]p028”补足。
