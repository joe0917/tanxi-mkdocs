# 檀溪丁卯續修宗譜序
```
题：[26世/廉212]第廿六世孫廉二百十二，歲貢生，祈山耀俊字升之，謹撰
峕：[24修]嘉慶十三年戊辰
初始点校：[20250219]民国庚辰本[1/33]p034
修订参考：[]
```

吾族由宋迄今，歷年七百有奇，歷世三十，修譜凡二十有三。司其事者，莫不稟凜然，懷尊祖、敬宗、收族之義。但支分派衍，族大事繁，言及此舉，往往難之。

歲丁未（22修），適逢修譜，諸賢祖父，憫科抖之艱，捐立譜田爲修輯資，誠義舉也。議以十年一修，逢“丁”開局，蓋有取於“人丁日益”之義焉。

前次丁巳（23修）閱十五月而始成，攷覈加詳，資費浩廣，然一轉瞬間，而又屆丁卯矣。嘗譜《祭義》有云：“祭不欲數，數則煩，煩則不敬；祭不欲疏，疏則怠，怠則望（忘）”。其於譜也亦然。

是歲冬之族長與諸紳士叅酌，謂：“譜之修過乎近，則數且煩，過乎遠則怠忘之患生”。

定以十年一續修，今次從“惠”字行傳始，詳其生卒、婚娶、葬所，以“惠”字而上固素定也。又十年一統修，由始及終，逐頁刋印。凡舊文之字樣訛舛，與夫墳墓、祭產之遷移增立者，可釐訂而刋載也。斟酌乎疎數之交，且無違“逢丁修輯”之議，而用亦可使舒焉。

或曰“譜者普也”。宗之大小，祖之遠近，無不遍詳也。非合全編輯之不可以言修。且前後不致成兩橛歟？

非也。先是譜田未立，或十八九年，或三十餘年，遺忘舛錯，在所不免。祖有行年三十有餘而未經入譜者，良可慨也。

然則，後閱是修者，夫亦可恍然於續修，“惠”字以下非從略也，其懼遺脫無從稽考也，不及“惠”字以上非忘遠也，蓋有待也。况由系圖按之，固一脈相傳也。安見其爲兩撅乎。尊祖、敬宗、收族之道自有合焉，而况其又積十年而統修也哉。

局之設自季春至秋杪，漸次告竣，余因諸同事之請，遂卽是以爲之序。

嘉慶十三年戊辰

第廿六世孫廉二百十二，歲貢生，祈山耀俊字升之，謹撰。
