# 續修檀溪陳氏宗譜序
```
题：[]和溪後學眷姻弟，廩膳生，戊軒石有聲，謹撰
峕：[26修]道光八年戊子六月
初始点校：[20250219]民国庚辰本[1/33]P036
修订参考：[]
```
丁亥歲，余僑居惠雲山房，謬叨檀溪陳氏講席。課讀之餘間，覽列朝世系圖、姓氏考，皆有收宗合族深意。而譜牒之設，始自有宋歐蘇諸大家。倣史之編年紀月，据經之稱字書名。採葺觀成，用垂鉅式，誠慮後人數典望祖。如遥遥華胄之謬稱閔後，而郭崇韜自謂距汾陽止四世，其見哂大方者，誠不一也。今里井間有圖重輯家譜者，當何如鄭重也耶。

吾浦檀溪陳氏，爲是邑望族，其始祖諱碩\ref{陈硕}，自烏程來遷之車方，贅方氏，遂從其姓。後六世孫[[陈珝|都事公]]諱珝者，始復爲陳，而其族遂寝熾。以視宋范文正公随姑養於朱，從朱姓，後復爲范者，更難能而可貴也。凡後，此之修是譜者，其敢不上推尊祖敬宗之意，詳爲採輯哉。

蓋陳氏之族，自宋迄今，歷世三十餘傳，歷年七百餘歲，而譜之修二十有五次。族盛則譜繁，譜繁則事雜，雖以賢子孫潛心者，核細意編摩，亦不敢云盡無錯誤焉。然不輊（輕，轻）亵前人之遺矩，不妄叅後進之新規。兢兢以率祖率親之義，昭示來玆俾合族子孫觀是譜者。庶乎不以小如大，不以疎間親，而皆有敦宗睦族之誼，悉於譜乎是賴，而余亦臨楮依依仰者久之。且以卜檀溪陳氏後，必有光大、有門閭，如鳴珂之里、列㦸之家者。

戊子之夏，適檀溪陳四諱[[陈宗思|思]]者，敬以族譜一卷見示，隨囑余序續修譜事。余與陳四係童年寅友，又與其嫡堂弟陳七諱[[陈宗植|宗植]]誼屬蝉䗡[^1]，情不獲諉，因謹續數言附諸簡末，以伸景仰之心。

其族修譜之例，自丁未（22修）後，議逢丁修輯，十年一舉。及丁卯修（24修），因費用不支，復議（二）十年一大修，十年一小修。今丁亥（26修）係小修之年，而族中多以大修爲是，茲從公議，嗣後概行統修。此係續修之例，亦序之者，之所宜特詳。至其先世來歷次第，與夫同宗之派别、支分以及生卒嫁娶、嗣體、祭葬諸體例，皆經詳前哲手筆，縷析條分，瞭如指掌，無俟余置喙云。

峕：道光八年戊子六月
和溪後學眷姻弟，廩膳生，戊軒石有聲，謹撰。

[^1]: “蝉䗡之谊”是什么关系待考。
