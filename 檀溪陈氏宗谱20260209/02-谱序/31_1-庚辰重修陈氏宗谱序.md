# 庚辰重修陳氏宗譜序
```
题：[29世/毓95]第廿九世孫，邑廩生其善，敬撰
峕：[31修]光緒七年歲次辛巳小陽春節。
初始点校：[20250217]民国庚辰本[1/33]P041
修订参考：[]
```

吾族自惟大公\ref{陈硕}中湖州鳥程來浦，流長源遠，繁衍熾昌，修輯宗譜繼起，代有其人，如登三公\ref{陈应纪}、俊五公\ref{陈珪}、常十一公\ref{陈惟能}以及彥道公\ref{陈彦道}等尚已，但族無公帑，修譜全憑科抖，厥事惟艱，且亦不能定以年例。

至乾隆丁未，之葉\ref{陈之叶}、以川\ref{陈以川}公等，創議捐田若干，其所收息積爲修譜之資，定以逢丁一修，無事科派，何善如之，故自乾隆丁未[^1]以及咸豐丁巳[^2]，率循無異。

奈於辛酉（1861年）西匪[^3]擾浦，擄掠我財賄，焚燬我房屋，虔劉[^4]我人民，傾覆我宗廟，殄滅我神主。吾鄉二十六都共興義團，抗拒賊兵，被災特甚，同里所居村落盡成焦土。

越癸亥（1863年），義勇官兵掃除賊氛，而人民寥寥田疇多屬荒蕪，卽所耕種者，租息無幾，祠中費用缺需，卽譜田之穀，幫入春秋二祭，亦無餘者。

前次同治庚午，族中公議捐抖重建祠宇，而續修宗譜，亦只於“建”字行以下，生、卒、葬、娶、行、系刷印，其於傳、贊、序、文全未之及。曾幾何時，而嵗月匆匆又十年矣，按以逢丁一修，則已過，揆之祠中生息，則又所入不敷所出，全無積儲，其何以爲修譜計哉。

去歲秋季，祠董衿耆等，公議此次之修，斷不容寬，其費項仍着照丁科抖，至於傳、序、文集，一統大修。其譜田之租息，自本年始，仍復糶錢存積，以備下次譜資，可免派抖之艱，至祠中給胙費用等項，量入為出，斷不可以譜穀充入。

庶幾，譜得永修，卽族可久聚也。夫是爲序。

旹：光緒七年歲次辛巳小陽春節。
第廿九世孫，邑廩生其善，敬撰。

[^1]: 乾隆丁未：1787年第22修
[^2]: 咸豐丁巳：1857年第29修
[^3]: 西匪：同三十修中的粤匪，指太平天国运动。
[^4]: 虔刘:指劫掠、杀戮。出自《左传·成公十三年》“芟夷我农功，虔刘我边垂。”。
