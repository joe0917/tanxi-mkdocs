# 陳氏族譜序
```
题：[]賜同進士出身，通奉大夫，山西布政司使右布政使，携李，王庭，拜撰
峕：[16修]康熈二十三年仲冬至日
初始点校：[20250225]乾隆丁未本[1/1]P114
修订参考：[]民国庚辰本[1/33]P023
```

聞之史書𦔳（助）朝廷賞罰，惟一日之是非定，則千古法戒昭焉。宗牒濬奕世淵源，知繁衍皆出一人，則萬襈親睦急焉。然則，國之史、家之譜盖相並重者乎？

陳君[[陈元和|子貞]]以醫寓禾中[^1]，與人極誠，無所粉飾。吾禾之人稱其德，謂其醫而隱之。

予既與之交游乆（久），因詢其家世焉，曰：“先生不言，予固將請之。葢前此二年會一過，其鄉族人方議修譜。今年秋告成，玆不揣，欲乞先生一言。”

因出其世系以示予，得而詳焉。

夫陳之爲氏，始於有虞，而繼興於齊，後一支居湖之罨畵溪。凡歴幾朝，至宋天聖間，有諱碩者，遷居金華浦陽之新田里，以贅於方氏，從其姓。

越六世，督府參軍[[陈珝|十四公]]，奏於朝而復爲陳，此車方陳氏所由稱矣。

及子貞之身，傳世二十五，丁滿萬，房分百餘，前後之以仕顯、以行聞及傳經隱逸之衆不可數計。浙東諸郡邑間推爲上家，乃其鄉義門之流亞也。

先是族譜，成於丁酉（15修），既而知舛悞之多，重爲攺定。

其始於碩公者，紀近不紀遠，慎也。族屬之蕃，必列其支派，悉其居址，不以遠遺，不使冐濫，慎之至也。

若夫貴者詳其爵，賢者紀其善。又加有勸焉、勉焉，其勸勉者，何也？夫使千萬子孫之衆，追本之於所始，非惟明世系而已。将以述祖德也，述之，非徒矢其頌而已。將以纉其緒也，惟有虞之大孝升聞𤔫[^2]哉，不可幾矣。

卽如車方之始，其繼别而爲宗，傳世而成祖，必有修行於身，著名於邦國者，故特崇而奉之。数十傳之中，亦必有高才、厚祿、積善、𢡟（懋）學之相承，乃得綿乆（久）而不替。使諸子孫而視斯譜也，念祖之德，而求克繼焉。

其勉而自淑者有由矣，寜不自勸也。且勸而勉者，又非徒世俗之陋知冨（富）貴而已也。有如孝弟修於家，禮讓成於俗，經學貽於世。敦華氏肅雍之化，崇石家醇謹之風，何有於金張之榮，而程卓之侈者[^3]。

予不及盡觀陳族諸君子。若子貞之德，則旣信之其家教之所凛可知矣。此乃余之所樂爲其譜言者矣。

旹：康熈二十三年仲冬至日。

賜同進士出身，通奉大夫，山西布政司使右布政使，携李[^4]，王庭，拜撰。

[^1]: 禾中：指嘉兴，又称嘉禾。
[^2]: 𤔫：音xiòng，同“敻”，远。
[^3]: Desspseek解释：推崇華胥氏（上古贤君）时代庄重和谐的教化，尊崇石碏（春秋时期卫国大夫）那样淳厚谨慎的作风，何必追求金、张两家（汉代金日磾和张安世）那样的荣华富贵。
[^4]: 携（檇）李：嘉兴古地名。濮院，古为檇李地，檇李墟。明弘治《嘉兴府志》载，“檇李城，在桐乡县濮院之西，濮院即古檇李墟也，其地有范蠡坞。”清陈曾祉《濮川旧迹》诗有序云：“吾里在春秋时檇李，吴越往来孔道，盖即战场地也。”
