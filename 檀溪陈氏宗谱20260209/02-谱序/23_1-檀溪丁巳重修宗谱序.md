# 檀溪丁巳重修宗譜序
```
题：[26世/廉258]第十六世孫，祈山派歲貢生，耀偀，謹撰
峕：[23修]嘉慶二年丁巳十二月中浣
初始点校：[20250310]民国庚辰本[1/33]P032
修订参考：[]
```
譜者屬也，屬其所屬，孝也；譜者普也，普其所普，弟也。譜之爲書孝、弟而已矣。故非仁人孝子用其心不可以言作，不以仁人孝子之用心不足以言修。

吾族之譜，作於都事[[陈珝|正己公]]之纂述。至十三世[[陈惟能|惟能公]]，稅駕湖州，筆錄其眞傳之世系以歸，而族之姓氏著。至十六世{[[陈宗元|宗元公]]}定雁行世傳，[[陈宗贞|宗貞公]]界爲譜圖，而族之服誼明。

迄於今歷年七百有奇，歷世三十，譜之修二十有二次。蓋莫不以仁人孝子之用心，尊祖、敬宗、而收族。續其事者，詳夫生卒、里居、行諱、葬娶而已，亦奚敢言修。

然而始祖冐方姓，至六世正己公而始復。

夫方姓，出自方雷氏。方雷者，西陵氏女軒轅之正妃，是爲嫘祖。或謂㒺榆[^1]之子曰雷，封於方山，後因爲氏。

而陳姓則出於虞舜，爲嬀氏，周武王封嬀滿於陳，子孫乃以國爲氏。

孔子作《春秋》，大書曰，莒人滅鄫，以其姓異也。

古有墨台氏，為墨、爲怡，怡寬負重名不能復其姓。又有牛金之子爲牢、爲尞，尞氏名點者[^2]，乃請復其姓，君子之論每不予寬而予點，在能復與不能復耳。

正己公以五世之後，復久易之姓，非始祖之厚德，則檀溪無宗支，非都事（正己公）之孝思，則烏程有餒鬼[^3]，十府君\ref{陈硕}爲不毁之祖，十四公（正己公）實不祧之宗也，又何可以忽諸。

爰稽舊牒，乃僅於本傳之內註云“始奏復陳姓”而已。自後編次行傳，則先列公派，舉凡楊樹角、寺前、墻下、湖山、檀石、溪下、靑龍頭之裔，皆各自爲第，以挨附於後。

揣其意，似於公爲特厚；揆於理，則知公有不安者。夫孝於親者，必知弟於長，祗[^4]其父者，必能恭其兄。烏有追思報本如公，而樂以疾行先長爲榮乎。夫豈特合譜之義爲不符，雁行之次爲已紊哉。

是修也，奉諸前輩，以督監其事。而偀亦得以操觚[^5]，承指給役於諸父伯叔昆季。

後於始祖傳中旣特書之于六世之首，復大書曰“始奏復陳姓十四公諱珝”，細註爲諸派之祖，著其功、仍其舊也。循序而列于十三公\ref{陈一遇}之後，變其文、繼其志也[^6]。

於年月之無考者，則以派爲後先；於生卒之可稽者，則以次爲長幼。自六世以至二十有二世，就行按第萃爲連枝，上有以脗（吻）五世之文，下有以合“宣”字之例。

監造者不狃惜於財，同事者不敢愛其力。局之設，閱十五月而始成。省是修，省讀復姓之書，孝之敎可興矣，求循序之義，弟之道亦備矣。雖不敢知曰“仁人孝子之用心”，或有類於是，而於譜之所以為書，其亦庶無戾也已。

雖然譜之修也二十二次矣，哲祖賢宗，代司其享，夫寧不之知。而因仍沿襲以至於今，科抖之艱不勝釐正之費耳。然則自兹以往，其使續修者得以力自盡，勿罹費之憂，孝弟之思，爲尤不匱矣。

英（偀）以長者之命不敢辭，爰攝其略以弁諸首，至於增之、輯之、續之、序之，其爲義亦戔戔[^7]者，固可以勿復道也。是爲序。

嘉慶二年丁巳十二月中浣。

第十六世孫，祈山派歲貢生，耀偀，謹撰。


[^1]: 㒺：同“罔”。这里应该指第8代炎帝榆罔。
[^2]: “怡寬”和“尞點”的典故暂未找到出处。
[^3]: 馁（něi）鬼：指不能享受祭祀之鬼。
[^4]: 祗：音zhī，恭敬，尊敬。
[^5]: 操觚：指写作。有成语“操觚染翰”。
[^6]: 解释了为什么在第6世行传中有两处“十四公”。
[^7]: 戔戔：音jiān，形容少，细微。
