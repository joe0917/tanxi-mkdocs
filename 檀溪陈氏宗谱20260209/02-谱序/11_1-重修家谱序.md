# 重修家譜序
```
题：[18世/贤151]邑増生孫龍橋昌言字希禹謹序
峕：[11修]嘉靖甲子秋九月朔
初始点校：[]乾隆丁未本[1/1]P106
修订参考：[]民国庚辰本[1/33]p019
```

（家谱意义）

嘗讀宋儒傳宗法之言，有曰：宗法之立朝廷大有所益，盖以國家之治本於人材之盛，而人材之出尤原於風俗之美。惟宗法一立，教化可行，忠孝可作。忠孝交作，而賢才間出，太平之風藹乎，其可興矣。謂之大有益於朝廷。不其然耶。何禮教弛而宗法亡，而後譜作焉。故譜之作，存宗法之遺意，孝子慈孫必珍重，於此以爲家政之首務。前紹祖脉於勿替，後開嗣續於無疆，下則厚風俗，上則贊國祚也。甚矣哉，譜之不可以不修也。

（家谱背景）

吾宗之先肇於周封，始祖碩公創於有宋，迄嘉靖四十三年，歴世二十有二，年六百有餘矣。子孫繩繩其麗不億，且自石阜宗兄方梧修後已歴二紀，生育之繁俱未入譜，有冠及娶而無行名者，矣失今不修，吾見族既散，而情益疎，人既衆，而各益亂矣，爲今之計，莫若禮求賢士，重復考訂，始可以挽末流之獘，而復醇古之舊也。

（写谱思路）

時有族弟曰[[陈仕聘|逑]]者，起而對曰：吾兄學成明儒，正宜修輯一家之政，以顯有用之學，不惟増光宗祖，且冇功於後世也，抑何勞於求人，而忘于自求乎？於是備查先逹始終，墳墓後裔，生年月日，再經寒暑，而其詳始備。

（修订內容与方法）

今日之修悉倣歐陽文忠公脩五代之史法，凖蘭江章文懿公之譜式。先第其卷數之目錄，次第其先後之名色。

祖宗來歴不可不知也，故詳之以地里爲卷帙之首焉。
一家之規矩不可不定也，故次之以凡例爲宗族之範焉。
先代之序文，皆心思之所存也，雖詞有工拙，不敢刪削而備載焉。
取過之字母不可以復犯也，必揭示其圖，以昭後世之遵守焉。
於是
書宦蹟誥命示寵錫之隆也，
書忠孝節義示勸懲之典也，
書隱浼儒流顯出處之義也，
遺文遺詩見祖宗之精神也，
贈遺祭文崇親友之誠愛也，
行狀傳贊明奕世之實歷也。

（结论与展望）

夫然後立譜圖以明五服之義，序世傳以隆長幼之分，其間死生墳墓婚配嫡妾支庶繼嗣之類，莫不明白登載，先后有條，如水之源、木之本，統之有宗，會之有源矣。庻幾千百年如一日，千萬人如一身矣。尚俟後之賢子孫繼脩而再圖之。

旹：嘉靖甲子秋九月朔。

邑増生，孫龍橋昌言字希禹，謹序
