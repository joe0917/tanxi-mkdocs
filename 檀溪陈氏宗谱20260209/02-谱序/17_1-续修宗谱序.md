# 續修宗譜序
```
题：[]眷晚生，黃方祤，謹誌
峕：[17修]康熈庚辰年子月既望日
初始点校：[20250224]乾隆丁未本[1/1]P118
修订参考：[]民国庚辰本[1/33]p026
```

嘗聞古來仁人孝子，勤修譜牒，考其身之所從來、祖之所從出，示不忘本也。

檀溪陳氏，始祖碩公，自宋遷居浦陽，六百有餘歳矣。因其譜牒淪失無可考究，僅知自烏程用仁公一派之流傳，至問用仁公以上所出之祖，則渺渺其無傳。

間有登三公《源流節要》一篇，但云舜之後嬀滿，封于陳，子孫以國爲氏。其由嬀滿以及于漢之太邱，由太邱以及於唐之諱融者，爲用仁公之所自出，千百年間一派牽絲之流傳，亦以荒逺難稽，闕焉弗考。

自碩公以後，天產英才，常十一公諱[[陈惟能|惟能]]者，素行孝義。永樂庚子（1420年）遷居湖山，日以考古証今爲事。目及宗譜，念及始祖之所由來。考其舊譜，徒知烏程所自出，彷彿難明。詢諸耆老，皆不及聞。因而稅駕湖州，密訪烏程同宗之所。留戀其地，晉接其人，幸留信宿交，溯水源木，本流連吟咏，告以㑹譜深心，遂筆錄其真傳之牽絲，而持其譜綸以歸。當日鳥程耆老俊彦軰餞别，慇懃徘徊道左。

考其會譜諸詩，敦睦之心如見。無何日薄西山不乘權輿。訓嘱遺裔則傚我祖，另修譜首于一派。何也？向之從事修譜者，各懷偏見，概從闕疑，致令[[陈克敏|克敏公]]有是吾作祖之辯也。

迄于今時值修譜，幸有從事者，[[陈克珪|楚璵]]、[[陈元炳|君文]]、[[陈元煜|光耀]]、[[陈元霖|君起]]諸位，頓念追遠之雅意。素知譜綸真傳久貯湖山，與家長嘀議，特修泉幣出其私藏，湖山亦欣然樂從公修，合族前譜綸體失於桐江，淂此而真傳依然其猶在。

余細觀其源流，因知周封舜之子孫胡公滿於陳。之後漢之太邱則其三十八世之孫，唐之融則爲四十世之孫，始祖碩公則爲五十三世之孫，不特此也，卽𢧐（戦）國之田單，五代之希夷，亦譜之其次第相傳，有歷歷而可悉數者矣。

由是向之，登三公\ref{陈应纪}之無足証者，於今有可証矣。克敏公之作辨者，於今竟不必辯矣。

然非常十一公之密訪，何以得此。非遺裔從事之協和，何以有此。此数君者，上有光於祖宗，下有俾於子孫，其心甚殷，其績甚鉅，皆不可以無傳。因筆之於左，以俟後之觀感者，豈曰小補之哉。

峕：康熈庚辰年子月既望日。

眷晚生，黃方祤，謹誌。


惟能公來龍坐山下首，共念畆其墳山，倂公山，日後不許背拚盗賣，如有此事，家長理論。

七保獅子形，㳟八公墳山，共壹拾伍畞。

又長蛇形，墳山一處，用全公助出。

六保羊山頭，敬十一公墳山并朝山，共陸拾畞。

又墳地家下竹園，共三畞八分。

□惟能公所遺煙火山，七保嶺裡。

一土名毛蒲壪，幷大小杉𣗳（樹）彎裡外長灣，共五十二畞

廿七都六保，盈䲧塔梘二灣迁柴地木和壪鈇湯缾䭾龍門小龍門梨頭面當壪搭生峽爲界，共六十六畞。

□惟能公所遺公田，

一土名卸堰角田，廿五秤，時景助出。

一土名畈心田，十六秤

一土名后田，四秤半

一土名山果田，六秤

一土名高畈田，八秤

一土名火補沿田，十八秤

一土各薪塢田，三十秤，用贊公助出

一土名後塢祭田口田，六秤

一土名祭田墻園裡，十秤

其公田幷祭田，昭房輪流，派下子孫不得爭輪，以爲永逺。
