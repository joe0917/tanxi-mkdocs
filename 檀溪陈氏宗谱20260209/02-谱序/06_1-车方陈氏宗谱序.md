# 車方陳氏宗譜序
```
题：[]禮部尚書，會稽友生，申屠徵，拜序。
峕：[06修]洪武庚辰歲季春之吉
初始点校：[]乾隆丁未A本[1/1]p098
修订参考：[]民国庚辰本[1/33]p017
```

古者宗法掌於春官小宗伯，所以辨親疎、别異同，睦族愛親之道，井然有條而不紊。所謂疎其所親、同其所異，無有也。去古旣遠，淳風未還，而先王之法制，僅存什一於千百，而宗法遂廢，族雖同出於一源，而視之如途人者，容或有焉。間有好古君子創爲譜牒，以統族属，以明本源，雖宗伯失官，而大宗小宗之支派脉絡猶存，且將藉有考證。此譜牒之作，有裨於世教也，豈小補哉？

浦江車方彦道陳先生，一日以所輯宗譜求予記其事。予按陳氏之先，自周武王封嬀滿於陳，子孫以國爲氏，厥後散處四方，蕃衍而不可殫。紀始由唐世季和公由長平發宗，傳及烏程凡若干世。至宋天聖初，諱碩者由烏程徙今浦江車方新田里，贅居方氏，遂定家於浦江故，今爲浦江望族。碩之子唐、唐子之（之子）頊皆從方姓。頊生五子，日祺、曰彦、曰遹，復姓陳氏，曰臧，徙居諸曁白門，從姓方氏，曰逸，徙居桐廬下石阜，亦從方姓，彼皆不入今譜，而自爲二族也。

今彦道輯成玆譜，其所以序源流之實，垂後嗣之規，而得尊尊親親之義，固可徵矣。其用心之勤，非仁孝之誠者不能也，而其繼述之善，不問可知謂非陳氏之賢允祚哉。此所以復隆古宗法之美，以厚風俗。予竊有待焉。雖然積之於前者固云厚矣，承之於後者，可不益培其根、益澄其源，而加夫積累之厚，以紹先而貽後乎？若然則陳氏之子孫，其光榮顕大豈若是而已耶。因書以爲序。

峕：洪武庚辰歲季春之吉。

禮部尚書，會稽友生，申屠徵，拜序。
