# 檀溪陳氏嗣輯宗譜序
```
题：[]忝眷月山樵，毛文佳，沐手拜撰
峕：[16修]康熈歲在乙丑春月
初始点校：[20250225]乾隆丁未本[1/1]p116
修订参考：[]民国庚辰本[1/33]p024
```

（过于晦涩，纯粹文字对联，沒有內容）

紀年定於國史，曠千秋皆傳信之期；
繼志具在家乘，歴百世悉統宗之要。

是以
帙載法傳，遠稽與近輯同心；
世隔情聨，總攝皆分編共事。

粤自重華之德慶衍於陳五世，其昌澤流；
今日閲歴前人祖述已定僕輩，奚事贅疣。

獨念夫塚墓依然，光前式後之碩公，擅一時崛起之規模；
更羡夫名義凜若，端本澄源之珝祖，障數世狂瀾於傾倒。

是則名實相須、情理昭晰者也。

繼而
命名檀溪，迄今源長派衆；
譽延梓里，僉言俗美望隆。

要知𡽪（徽）懿足傳於先，
孰若紀綱謹飾於後。

顧
累葉重熈，生齒漸蕃，非紀載難明；
長幼尊卑，歷年玆多，而倫次莫辨。

欲昭示乎來茲，
宜纂修於此際。

且陳氏門多長者，代有偉人，如思易、君祁、君韶、汝品、君文[[陈元炳]]軰，於時皇皇其志，而汲汲於事也。

敦請明敏蔣、盧二先生於塾，
重稽字母，細審行列，如商家賢聖焉於甲乙丙丁
追考世系，遡察分居，若周室藩封者之曹滕魯衛。

於以
闡揚在昔之慶源，
發撝卽今之令緒。

庶使
檀溪萬壑同歸，
子姓九世敦睦。

則
大宗小宗，聨雲漢以重輝，
左昭右穆，揭日星而並麗。

是以家之倫理嚴明，
何異國之紀事覈實。

如《經》所謂“治國在齊其家”者，非此也耶。

旹：康熈歲在乙丑春月。

忝眷月山樵，毛文佳，沐手拜撰。
