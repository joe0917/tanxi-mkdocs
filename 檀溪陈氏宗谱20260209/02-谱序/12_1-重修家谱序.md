# 重修家譜序
```
题：[19世/钦278]第十九世孫社學生九街著
峕：[12修]萬歴戊寅年春月
初始点校：[]乾隆丁未本[1/1]P108
修订参考：[]民国庚辰本[1/33]p020
```
家之有譜，猶國之有史也。家有譜，所以統宗會源，序昭穆、正人倫、垂教化者也。國有史，所以扶綱植紀，辨賢否、明進退、紀盛衰者也。故聖人立教之法，必先齊家而後治國，凡卿士大夫必珍重於此以爲家寳，是譜也，豈可爲虛設乎哉？

吾宗自碩公來遷於此，英賢繼世，宦蹟文章，載之家乘，著之史册，炳然可觀。代有哲祖文宗作之於前，吾父宏才述之於後。宗譜之作有自來矣。

今年春，宗兄[[陈大纶|大綸]]、[[陈大纲|大綱]]以爲吾家世稱巨族，皆由文獻足徵故也。若祖宗之鴻猷不錄，則將斬没而無聞矣。生齒之繁衍不叙，則將名分而益亂矣。宦跡儒流、忠孝節義、隱逸詩文、貴賤善惡當偹詳之，使後世之子孫知所敬慕而向上，有所知畏而切磋矣。玆譜之修也，其容或緩乎？於是命街修輯之，余以尚幼無知何能領此重任，况吾父之修備而且詳，惶懼不知所裁。乃謀諸兄庠生大鳯，互相正訂之。遡源流、排行傳、昭宦跡，大書其綱，細註其目焉。紀實錄、集詩文，立字母著之首簡，歴覧無遺意焉。書節孝以揚其德，列忠義以白其心，存激勵焉。著儒流以興禮教，昭隱逸以敦氣節，顯出處焉。綜理有條，燦然在目。

嗟夫，萬物本乎天人、本乎祖則。吾統其所宗、會其所源，因序諸首，以示後之能顯揚宗祖積累之厚者，當世守而勿墜，善繼述者，以齊家爲急務。此皆不肖之素望也，幸同志者其朂諸。

旹：萬歴戊寅年春月。
第十九世孫社學生九街著。
