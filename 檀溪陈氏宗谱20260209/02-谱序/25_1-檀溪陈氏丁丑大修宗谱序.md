# 檀溪陳氏丁丑大修宗譜序
```
题：[]祈山派裔孫邑庠生，然，謹撰
峕：[25修]嘉慶丁丑九月至戊寅九月
初始点校：[20250219]民国庚辰本[1/33]P035
修订参考：[]
```

譜所以一宗族詳世系、生卒、婚葬，歲積月累，有増無減。

檀溪陳氏，人繁事冗，十載一小修，二十載一大修，且爲費事况。

越其時丁丑之年，合族復舉大修。宗譜計開生者三十四人，校正者六人，總理六人，予與事焉，謂諸君白譜者，記事之史，繫年之書，宜允當也。

吾族宗譜，自明迄今，凡二十餘修。經前後讀書明理、稽考廣博之儒，凡數十手。而其間採擇之訛、考訂之異、魚亥之乖，混不堪勝指。兼之卷軸無區别、文章無體裁，令閱者開卷不見典籍之華、詞林之采。而猶享帚自珍，未免爲大雅譏也。

予欲與諸君迸力而精討之，整齊簡牘，以垂後英。

亦如曾子固[^1]之誚《齊書》，何成法[^2]之修《晉史》，豈非草茅聚族之一事乎？

諸君曰：“非也。我族人殆萬計，愚者多智者少，昧者多明者少，吾[^3]如自用而更變之、攺移之，殺青未就，百訟皆歸，而我諸人求工反拙。

况史書實錄，往古爲艱。

《史記》后稷[^4]至文王，以十五世而衍爲一千九十年，是六十始娶，八十始生子也。契[^5]至成湯四百二十年，業己十四世，是皆三十而娶，四十有奇而死也。

魏收[^6]作《魏書》，以魏無知爲七代祖，乃相去七百年，是收之祖宗，皆百餘歲方生子也。

至若班氏[^7]，以韓增[^8]之貴本於周列，杜延年[^9]之貴本於唐杜世祿，霍光[^10]之貴爲霍叔[^11]苗裔，有純襲識緯習歲者。

歐陽\ref{欧阳修}自爲族譜序世系，詢[^12]以下五世，閱三百年，琮[^13]以下僅百四十年，而業已十八世者。

蘇氏自爲族譜序世系，缺居蜀之長史，而遠追夫陸終[^14]、昆吾者。

《新唐書》之異《舊唐書》。有曰，不慈於妾戶知之者；有曰，死無他異者；有曰，萬一笑殺他人者。

往往晦澀不可解。族非其宗，系非其世。出入差誤，彼此茫然。善讀書者不勝枚舉。

然而伊古以來，相傳相衍。史書之舛誤，文士之僞飾，或數千年，或數百年，更不知得幾什伯博雅明達之流批駁解釋，而至於今日猶然，其謬者謬、僞者僞、陋者陋、晦者晦，而未有以易也。

吾之修讀，但與讀古同。未入譜者，吾當審詳而編緝之。其舊在譜者，雖謬者謬、僞者僞、陋者陋、晦者晦，而可不以易也。”

予曰：“唯唯。諸君明過於人矣。”

嘉慶丁丑九月至戊寅九月，譜工告畢，特爲辨之。其他公費則有執事者在。

祈山派裔孫邑庠生，然，謹撰。


[^1]: 曾子固：即唐宋八大家之一的曾巩(1019年9月30日－1083年4月30日)，字子固，世称南丰先生。建昌军南丰（今属江西）人。中国北宋史学家、政治家、散文家。
[^2]: 何成法：应该是指南朝宋湘东太守何法盛，著有纪传体《晋中兴书》78卷，记东晋一代事迹。被后世列为“十八家晋史”之一。在贞观年间重修晋十六国史时曾作为编撰“官修”新《晋书》的辅助参阅史料。
[^3]: 吾：“我们”的意思，区别于“予”，“我”的意思。
[^4]: 后稷：周始祖，姬姓，名弃。
[^5]: 契：商始祖，帝喾与简狄之子、帝尧异母弟 契，子姓，名契，又名卨，别称“阏伯”。
[^6]: 魏收（507年－572年）：字伯起，小名佛助，钜鹿郡下曲阳县（今河北省晋州市）人。魏收曾受命联合房延祐、辛元植、刁柔、裴昂之、高孝乾等博总斟酌，撰成《魏书》一百三十篇，书成之后，受到众人质疑，被指称为“秽史”。
[^7]: 班氏：指班彪、班固、班昭三代人共同完成的《汉书》。文中所列几处“舛误”待考。
[^8]: 韩增（－前56年）：字号不详，颍川阳翟（今河南省禹州市）人。西汉时期大臣，韩王信的玄孙、游击将军韩说之子，“麒麟阁十一功臣”之一。
[^9]: 杜延年（？—公元前52年）：字幼公，南阳郡杜衍县（今河南南阳市宛城区）人。西汉时期大臣，御史大夫杜周的儿子，“麒麟阁十一功臣”之一。
[^10]: 霍光（？－前68年4月21日）：字子孟，河东郡平阳县（今山西省临汾市）人。西汉时期权臣、政治家，大司马霍去病异母弟、汉昭帝上官皇后的外祖父。名列“麒麟阁十一功臣”首位
[^11]: 霍叔（生卒年不详）：姬姓，名处，世称霍叔处，周文王姬昌与太姒所生第八子。
[^12]: 詢：指欧阳询（557年—641年），字信本，潭州临湘县（今湖南省长沙市）人。唐朝大臣、书法家，南朝陈黄门侍郎欧阳纥之子。
[^13]: 琮：指欧阳琮，唐代湖南长沙人，欧阳通曾孙。唐天宝年间官吉州刺史，庐陵欧阳氏始祖。
[^14]: 陸終：上古时代传说中的人物，楚国先祖火神吴回之子，他有六个儿子，昆吾是长子。
