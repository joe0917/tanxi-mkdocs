# 陳氏重修家譜序
```
题：[]雍正丙午浙江鄉試舉人，年家眷弟，朱鶴鳴，頓首拜撰
峕：[19修]大清雍正歲次已酉夏，五月中浣穀日
初始点校：[20250221]乾隆丁未本[1/1]P124
修订参考：[]民国庚辰本[1/33]p028
```
余讀陳氏家譜舊序，其致詳於得姓受氏之由，以及遷居分派，何覈以精也。

夫陳爲虞裔，普天下陳姓皆然。若其自爲一宗，則當以天聖年間，始遷浦陽新田里者爲㫁。顧陳冐方姓已五世矣，至六世[[陈珝|都事公珝]]，而毅然仍復厥宗，此非卓有定識者不能當。

宋寳祐（3修）時，東陽學諭\ref{陈应纪}，卽著有《陳氏源流節要》，使九世之序瞭如指掌，至今得據此以作譜系，厥功偉哉。

至有明天啓，而裔孫文學諱[[陈克敏|克敏]]者，又復親至苕溪，尋蜀山祖里，辨金牛鄉之訛，作《地里辯》一篇以垂後。

何陳氏孝子慈孫叠出，而未有窮也？

《記》[^1]云：“作者之謂聖，述者之謂明”。

今陳氏之譜，其綱目條例旣明且備，已見於十八世孫昌言\ref{陈昌言}之叙。雖有博雅君子，弗敢復作矣。若夫生卒之期，歳無虛日，婚則宜書其氏，葬則宜詳其地。

十数年來孝友節義，以及仕宦儒流，皆當續書，以附於後。此其考覈詳明、不濫不遺，則在今之重輯是編者。

夫陳氏之殷阜甲於北鄉，其中學優行尊，負公輔之望者，指不勝屈。此誠寢昌寢熾之候也。

今之秉筆而司記載者，又皆有學有守之士，協恭和衷，以襄其事宜，其考覈詳明、不濫不遺，足以上繼《節要》《地里》諸書，而成一族之鴻編也。述者之功詎出作者下哉。

顧余有一言相質者。

陳氏之著姓夥矣，人望則推太邱[^2]，孝友則推江州[^3]，理學則稱白沙[^4]。乃陳氏之祖，皆不肯援之以爲重，以取遙遙華胄之譏，獨守其信以示於後，此其意念鴻遠。

若曰：後世自有亢吾宗者。今諸君子際昌熾之時，而汲汲以輯譜爲已任，則知尊祖矣，尊祖必敬宗，敬宗必睦族，睦族然後和氣聚而嘉詳至。

吾知必有卓然崛起、蔚爲國華以亢陳氏之宗者，將吾浦車方一族不且與太邱、江州、白沙而並著哉。

是爲叙。

旹：大清雍正歲次已酉夏，五月中浣穀日。

雍正丙午浙江鄉試舉人，年家眷弟，朱鶴鳴，頓首拜撰。


[^1]: 記：指《礼记·乐记》
[^2]: 太邱：即颍川陈氏（东汉），始祖为陈寔\ref{陈寔}。
[^3]: 江州：即江州陈氏（唐），亦称为义门陈氏、江右陈氏。始祖为陈旺，唐开元十九年（731年），建庄浔阳县蒲塘场太平乡永清村（今德安县车桥镇义门村）。
[^4]: 白沙：即白沙陈氏（明）的陈献章（1428年11月27日—1500年3月9日），字公甫，号石斋，广东广州府新会县白沙里（今广东省江门市蓬江区白沙街道）人，世称“白沙先生”。明代心学的奠基者，是宋明理学史上是一个承前启后、转变风气的关键人物。
