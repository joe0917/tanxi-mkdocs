# 重修車方陳氏宗譜序
```
题：[]蘭溪長樂葉盛書
峕：[07修]正統丁巳歳仲夏中旬
初始点校：[]乾隆丁未本[1/1]P102
修订参考：[]民国庚辰本[1/33]P018
```
車方陳隱君[[陈惟能|惟能氏]]，以其從兄[[陈叔起|叔起]]所輯宗譜，續而詳之，將欲脫藁属予序諸簡首，予惟家之有譜，所以叙天倫、繫人心、明教原、敦政本者也，而家可以無譜乎？况人之有族，自衰期至無服，世遠屬疎，會合無常，徃徃行路踟蹰，或懵然勿識，喜不慶、憂不弔，相視如途人者，政何限，而譜又可以不詳乎？

今浦江陳氏之譜，自始祖而下，凡若干世，都爲一帙，類分四卷，曰序述，曰遺文，曰世系，曰行傳，而大綱立矣。其間所載，有宗圖、諱、字焉，有行第、生、卒、嫁、娶焉，以至塟徙之地里，所遺之詩文，罔不謹書備錄，可謂詳也已矣，然所以書之詳者，豈誇多爲哉，葢將欲其子孫卽譜興思遡流知源。不以富貴而加尊，不以貧賤而加卑，族有等夷矣。

命名立字知有所避，而族無重諱矣。若夫薤露班班誦之者，知祖德之不冺，音容邈匕思之者，幸手澤之尚存。以至徵賢合姻，鄉社燕飲，見斯譜也，必能敬其所尊，愛其所親，祀彼舉近忘遠，舍新間舊者，不侔矣。邱隴蓁蕪，追養莫及，見斯譜也，必能雨露惕怵，風木興悲，視彼窀穸無存，松楸莫覩者，有間矣。

又如遷居異井，天各一方，若諸曁之白門、桐廬之下石阜，本爲同宗者，奈之何枌榆之陰不接，休戚之問不聞，見斯譜也，則宗族之情寧不藹然而生乎？又豈有喜不慶、憂不弔，視爲途人者乎？

此譜之作，其有關於世教也，豈曰小補哉？爲陳氏後者當知夫作譜之意之詳如此，而益敦夫家教，昌大其門閭，不亦美乎？於是乎序。

旹：正統丁巳歳仲夏中旬。

蘭溪長樂葉盛書。
