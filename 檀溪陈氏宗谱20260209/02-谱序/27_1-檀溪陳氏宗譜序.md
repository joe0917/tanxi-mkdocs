# 檀溪陳氏宗譜序
```
题：[]賜進士出身，誥授中憲大夫，戸部員外郎，加四級又隨帶加一級，轉陞江南道察院監察御史，雅齋朱能作，頓首拜撰
峕：[27修]道光十七年丁酉十月下浣。
初始点校：[20250218]民国庚辰本[1/33]p037
修订参考：[]
```
宗譜曷昉[^1]乎？昉於《周禮·春官》小史之“奠繫世、辨昭穆”也。故漢有《鄧氏官譜》。晉賈弼撰《姓氏簿狀》。《隨（隋）書·經籍志》有韋、傅、楊、謝諸譜。唐《藝文志》譜牒自成一類。至宋則韓氏、程氏、司馬氏、歐陽氏創爲一家。

族譜凡以“别氏族、稽閥閱[^2]、誌勲名”，由來尚已。獨是世之言譜者，援華冑、附高門，聯宗合族，焜耀一時，詎知認顏稱閔識者羞焉。

《記》曰，先祖無善而稱之，是誣之；有美而不知，不明也；知而不傳，不仁也[^3]。是賴有賢子孫繼志述事，去誣以存眞，彰美以傳後。而數典無忘、述德有自者，吾於《檀溪陳氏宗譜》見之。

歲丁酉，檀溪修譜蕆[^4]事，余以葭（遐）末竊肆，管窺其間，爲像，爲圖，爲實蹟，爲宗約編，爲碑記，爲規儀、規條，爲譜序，爲誥命，爲記，爲錄，爲議，爲約，爲案判，爲旌案據，爲外卷，爲行傳、行狀、行略、行述，爲專傳序，爲合傳序，爲賢節傳序，爲節要，爲引，爲辨，為說，爲誌，爲贊，爲銘，爲頌，爲跋，爲書後，爲壽，爲祭，爲名公贈遺集，爲先人遺詩選，為世系表。

凡例三十有九，歷年八百十五，傳世三十有一。溯一本之淵源，滙九族之統緒。儲儲然，昈昈然，詳其上治、下治、旁治，而靡遺；列其大宗、小宗、無宗，而不闕。

何仁至而義盡乎。蓋以秉筆者胥老成典型，司事者盡賢裔俊秀。故能詳記載、煥文章，無牽連、無援引、無附會而穿鑿，枝分幹合，源遠流長，所謂謹譜牒而不忘其先，孝之大者矣。

程子曰，管攝天下人心，敦宗族美風俗，須在明譜系。今陳氏譜系旣明，是卽小史之“奠擊世、辨昭穆”，以聯邦國之志也，是卽歷代史譜之“别氏族、稽閥閱、誌勲名”，以齊家治國而平天下也。

檀溪之子姓隆隆繼起，本家修以廷獻者當如何？其欽承耶。是爲序。

旹：道光十七年丁酉十月下浣。

賜進士出身，誥授中憲大夫，戸部員外郎，加四級又隨帶加一級，轉陞江南道察院監察御史，雅齋朱能作，頓首拜撰。

[^1]: 昉：起始。
[^2]: 阀阅：意思是功绩和经历；是指有功勋的世家、巨室；泛指门第、家世。
[^3]: 暂时沒找到这句话的出处。
[^4]: 蒇：音chǎn，完成，解决。
