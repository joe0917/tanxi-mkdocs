# 檀溪陳氏宗譜序
```
题：[]中憲大夫，雲南按察司副使，眷侍教生，義門鄭崇岳，頓首拜撰
峕：[14修]天啓丁卯冬月
初始点校：[20250225]乾隆丁未本[1/1]P110
修订参考：[]民国庚辰本[1/33]p021
```

陳氏爲我浦著姓聚族，而居者不一其處。考其世系，亦大抵各自爲宗，而不相謀。

𣞀（檀）溪陳氏者，世居邑之廿六都，其先有名碩者，自烏程徙居新田，爲方氏贅壻（婿）。生子唐，方無子，遂以唐嗣。唐子頊，仕宋爲宣議大夫，亦從方氏。至[[陈珝|都事公珝]]，始復姓焉。今尚稱車方陳氏，示不忘舊也。

珝之後遂大繁衍，譜系之輯代有其人，傳之既乆（久），間不無謬訛處。

其裔孫[[陈尚睿|德成]]者，深念先猷易湮，不可不力爲嗣續。爰集族之長而賢者，相與輯之。

自珝而上，止溯其因，襲之次第，餘皆不詳。珝而下，則别其支派，列其遷徙，倂記其生娶卒葬之詳。
於行諠則重孝友，
於賢淑則嘉節烈，
於豪俠則取捍護，
於建𥪡（竪）則重祠塾。
至夫叙述讚詠，出自名手者，悉捃摭不遺。書成，乃登之梨棗，以永其傳。

間走价[^1]於麟溪上，求予言弁之。

予因念譜系之修，莫盛於近世，然窺其大概以“冠盖蟬聨、族屬繁阜”相矜耀，棄祖誣宗之事亦往往有之。

今此譜之作，以辯其異，承傳分明，確有可據。其不係正派者，雖王公卿相之貴，不敢妄有所𱚔（竄）入，以統其同。則尊卑大小，條貫絲聨，若萬緒之總於一本而不亂。睦宗黨、美風俗，道無有貴於此者，雖然士君子所以通志氣於一家者，又不惟其文，惟其實今陳氏子孫

誠卽是譜而思，夫支派别合之原始自一人，卽相愛相敬亦止鬯（畅）我一氣。則尊親遞及之處，必且藹然其有恩，而秩然其有禮。將親睦之風，自一家見之，其所以嗣續先猷者寜直故，府之不墜已哉。

書之爲陳氏朂

旹：天啓丁卯冬月。

中憲大夫，雲南按察司副使，眷侍教生，義門鄭崇岳，頓首拜撰。

[^1]走价：亦作“走介”。供奔走的仆役﹑小使，派遣仆役。
