# 輯譜凡例
```
题：[23世/宣640]啓經辑
峕：[18修]康熙甲午
初始点校：[20250310]民国庚辰本[1/33]P007
修订参考：[]
```

—記曰：尊祖故敬宗，敬宗故收族，族之收也，譜斯尚焉，族而不收謂之散，收而不族謂之乱，散也亂也不如無譜。故吾族作譜之法首略紀原，以明得姓受氏之由，不敢妄引無據為路敬純衣冠譜，普非所普，屬非所屬，以诬後世。
	
—譜立系图，以明立宗傳嗣，依歐陽文忠公取法史記年表之例，以世為經，以人為緯，界為譜圖，横列五世，上系於下為元孫，下推而上為高祖，使五服燦然在目，其下五世既盡，又從五世提起，以至九世，取九族之义。
	
—譜立行傳，以字母分昭穆，以長幼定次序，通族名諱字母不一，先人遺志不敢擅改，況稱呼已定，悉難归一。自丁酉為始，通族以宣字第合而為一，凡後嗣之昌，悉照母圖定例，使無失次。
	
—傳中，照依次序編列排行，某系某派某人之子，諱某字某號某，正娶某氏或繼娶某氏，俱書生卒年月日時，合葬某道某處，生幾子，系某氏所出，幾女，適某姓，以昭姻屬。
	
—婚配正室及繼娶，雖無子皆書姓氏、生卒，側室宠媵不得與正繼并書，有子者但於其子名下書庶母某氏所出，妻有被出或再嫁者本身名下不書，有子者各於其子名下書某氏所出，蓋旧例甚嚴也，顧自癸未以後變其例，側室姓氏生率亦同正繼，被出再嫁者亦多不行删改，書法非古矣，但沿襲已久，今姑仍之舉，治絲而棼焉，固無所逃罪也。
	
—立繼之法，例有明文，夭殇未娶均所不許即應得議繼者，亦必由親及疏，於昭穆相當者立之，而親父傳下書某子諱某出繼某人為子，繼父名下書繼某人第幾子為嗣，各宜填注明白，杜其弊混，毋得妄立，不应以起争端。
	
—祖宗坟茔并所遺祀産，或有碑記墓志，俱宜將地名號畝明白注載，或年遠平踏淺露急，當擇取潔土蓋（盖）之，更立石碑，深刻名氏，勿致淹沒難考。
	
—生我者、親養我者、君成我者，師忠孝畏敬之，思不可須與離也。先師聖諱，固宜遵例謹避。而派近祖宗字諱，其子孫或有犯者亦宜即行改正，毋干忤逆之罪。
	
—婦人勵志守節，年自三十已下至六十上而無玷者，固宜遵例申達以邀“旌表”，力有不及亦必立傳譜前，彰其貞德，其或孝奉舅姑、敬夫教子，實足為閫範母儀者，更許特為表出，以訓後人。
	
—子孫有孝義實行可據者，家長當與合族申達，以冀“旌表”、“立傳”、“譜前”以啓後人。
	
—女子不書生卒，止於生父傳下書適某處某姓，以記世姻。其有孝事舅姑節行可據，夫家勿克表揚，亦特為傳、贊，列於譜前。
	
—豬狐帶令、狗尾續貂、佛助之歲，與減祖同，故本身無嗣，即或賴異姓親屬之子奉養終老，亦止許撥産其歸宗，不得編入行第，以混亂宗支
	
—子孫出繼異姓不必詳載系傳，然於其父傳下則書，某子某諱出繼於某處某姓某人諱某之後，以便查考，不致後嗣有同類合婚之罪，至若為僧人道者，亦止於生父名下注明某子某諱出家，不得編人行傳。
	
—歷世有受誥命，當尊居首卷不可類入遺文，其或登科、及第、納職、捐銜者，亦另緝仕官之錄，詳書某公中某科、援某例、授某任，某年某派某行某子前于譜前，上以誌朝廷之寵，下以為宗族之光。
	
—庠生、廩員、貢士、太學，出則有君民之責，居則為風俗之光，不等凡民庶各知自重，姑於傳系注明外，仍另輯儒學之錄，備書某派某學某行某子，某號某諱某字，習某經、游某库、於某年援例，照依序次列名以昭鄭重。
	
—宗族盛大遷徙靡常，或移住他郷，則書某派何人遷居何處，庶世遠亦可考證，不致斬其血脈，然自三世不與修輯之後，槐不準其求援求繫矣。
	
—先賢後嗣，凡有鉅勲偉績德行文學者，或作傳於譜前，或勒石於墓道，毋使泯沒不傳，以失教誨式穀之義。
	
—合族古人所撰記、序、詩文、詞賦之類，或有益於風化，或有裨於藝林，足為後人模楷者，亦須選載譜前，使為父兄者勤燕翼之胎、為弟子者長琴書之慕正不特，族有儒雅名已也。
	
—譜所以奠世系、辨昭穆、定親疎(疏)、別同異，祖宗血脈藉此錦年延久，不修則殘缺失次。一人之身為塗人，旋且以塗人為一人之身矣，不孝孰甚焉。吾族自宋至今，代有告誠以後子孫，務宜及時修輯，不得懈至二十年外。諺有云，數靣(面)成親，舊古有花樹韋家宗會法，宋謝昌國\ref{谢谔}嘗取之，以為族人，遠來當為一會，以會族，雖無事，亦當月為之。方集虛曰，月招近局，使親者毋失，其為親則非此族也，自無貂抄肉盤之誚，夫族人且以數會為貴，而况宗譜之修乎。
	
—宗譜自萬歴以前，俱屬寫本，後因子孫繁衍，不勝抄謄，丁酉修輯共印二拾二部，以天干地支編定字號，注明某派某字號，賢達之人收領，每年秋祭值祠者，預發抽查通知單，藏譜者各宜遵單持譜赴祠以備查核。不肖子孫盗賣異派，以溷(混)亂宗支，并污穢損壞者，會衆處以相當之罰金，決不寬貸，合族其共凛之。
