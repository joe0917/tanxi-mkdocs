# 宗譜凡例
```
题：[]督修之葉以川承修光義耀偀等
峕：[23修]嘉慶三年歳次戊午長至日
初始点校：[20250310]民国庚辰本[1/33]P014
修订参考：[]
```

—始祖行傳向第載其遷移葬娶不復詳所自出，雖有溯流尋源一圖登於譜首，不及細聞者仍未之曉也。水源木本，其謂之何？今特追叙五世補入傳内，庶幾識與不識，一展卷而了然耳。

—譜牒所以昭信，非所以傳疑，丁未修輯自一世至十六世，生卒葬娶悉照萬歷寫譜逐一校正，詳慎允協有足多焉，但以細字添注，或又兩存其説、易滋物議，今因覆加校訂，采其精當可信者，概以大字增入，至若音義互异、世遠無徵，則亦復從其略，此遵書自唐虞之意也
。

—傳載十四公，出繼廿三公為嗣，癸未以前譜皆如是，勝公之系現傳十一世而止，寫譜所云，因本支俱亡复轉本支其為後人之事，無疑於公傳下不宜添注，此癸未以前所以無明文也，今經刪去，并非闕疑至轉本支者，必求其人以實之，抑失之鑒矣。

—舊譜自一世至十六世，傳系互多訛異，前次輯系謹遵寫本細加校正，雖寺前、楊樹角諸派亦不敢以弗傳少存，苟簡今於行傳，照系增入庶傳系相符，免嗟殘闕。

—宗譜，系以明血脈、傳以聯同氣，吾族行母前因軍民分别、各派分立字第，至二十三世宣字始昭劃一其，前字母或同或不同，行次或序或不序，八世以後则又分立，行母類以祖宅居前、諸派列後，各行各母長幼難知矣，今則自一世至十六世，生卒年月同行者，照次序列各母者，依派挨排，自十七世至二十二世，謹按其年月先彼，鳞次叅增，年月缺畧（略）者，即粘聯附補，不特合譜之名以副抑，且序齒之誼，斯敦識者韙之。


—朝廷之治民以法，宗族之遇事以情。各執已見，無能強也。故是修於已經控訟沐。公審之案概復並存其舊，以候宮斷，賤不自專分固應爾，闔族勿以摸稜罪之。

—先人嘉言懿行可以垂訓，後裔原有行傳狀略刊列首編，但或束而不觀，亦仍美而弗彰，今既按其生平行事，惑有關於風化，或有俾於貽謀，略舉原文表其大槩(概)，載入本人傳内，又復輯孝行、節賢二錄，使讀者有所感發而興起焉，深慙(慚)負質庸愚，又以開局迫切，未獲畢登，抱歉靡既，補而全之，俟諸續輯。

—舊譜傳、略、記、贊、序、錄、碑銘等文混訂首編不特，散失難稽，抑亦查閲費力，今則分門別戶以類相從，截為四册：凡，文因事生者，曰“徵蹟”，為第一冊；事以文存者，曰“雑著”，為第二冊；世系為第三冊；行傅為第四冊。

—公奇、議約、遺囑、案判等項皆屬大有關係，向多附載文尾，或又另印孤頁，似難保其久而不失也，今故將公産號畝移入本人傳下，約嘱案判銜接成章，庶可不遠無虞矣。

—是修同事莫不小心敬慎，期於無過，但通部合計板頁不下三四千餘，或神疲筆悞(誤)，或事猝眼花，亥豕之訛正未能免，倘有賄囑舞弊等情，察出自應罪罰，非是類者，鑒原為幸矣。

嘉慶三年歳次戊午長至日

督修：之葉、以川

承修：光義、耀偀等暨同事謹具
