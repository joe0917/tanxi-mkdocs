# 上河廣安橋碑記
```
题：[]選士候選儒學教論，邑人宋寓酉巖甫撰
峕：[23修]嘉慶癸酉
初始点校：[20250416]民国庚辰本[1/33]p083
```

客歲春，余遊西江，江水暴漲，瀕江數百里橋梁傾圮，民多病涉，見而憫之。謂此邦之人，豈無一二好義出而振作之者？有之，雖不文，樂為之載筆矣。

今茲春仲，余自西江歸，而陳君祖奎之子榮裔，適以廣安礄（橋）記請。其言曰：

“裔家上河，在浦之北，前臨大溪曰壺源。源峻溜激，山潦驟至，汪洋恣肆，木杠遇之輒去。雨涘之間，行人如蟻，有窮途之哭焉。
嘉慶己卯，家君與族祖以佩等謀架石橋以通濟渡，歲歉事中沮，以佩乃去而建大姑溪口百歲橋。
道光庚寅，家君擕石工修富陽卯塔路，族伯祖啓遇諸塗，謂之曰：‘遠方修路，何如近處造橋？’家君曰：‘然。力薄奈何？兄有意，弟當倡助。’出三百金授祖啓，以佐其經營。工大而費不支，又將中止，家君遂身肩其事，復同族里諸君子遠近勸捐，凡不足者俱自輸之。共費金四千數百餘兩，而橋以成。修二十有六丈，廣一丈六尺，崇三丈二尺，闡崇二尺八寸，為墩五，萬洞四，皆以石甓，南隄數十餘丈。自經始迄落成，閱月者一十有七，計工二萬有奇。題之曰‘廣安’，言利涉大川，所安者廣也。又建大慈廟於石橋頭，為往來憩息之所，鐫樂輸姓氏碑之廟，垂永久焉。”

余曰：「善哉！義舉也，實盛事也。西江一路有好義如此者，民無病涉矣。乃翁與諸君子為此橋也，不愛財，不愛力，吾豈敢愛吾文？然余將急行，無能研都鍊京，與是橋相不朽。而廣安之功德無量無邊，不可不紀也。」遂略為序次，以墨諸石。是為記。

嘉慶癸酉，選士候選儒學教論，邑人宋寓酉巖甫撰

## 跋一

宋濂溪之記天台廣濟橋也，曰：“昔蔡襄記萬安渡石橋不過一百二十二字，又葉正則作《利涉橋記》，乃六倍之。予斟酌其繁簡而為斯記。”

蔡、葉兩記，余未之見。今考宋記，不滿四百言。此記字數稱過之，而文之足以附宋諸記而並傳，固卒無不及也。鄉先生之文，亦豈容墜哉？

東筠虞協拜讀

## 跋二

臨江太守烏傷虞午橋先生跋此記，足附宋記並傳。余閱宋記載廣濟橋，崇以尺計者二十有五，修倍之，費錢一萬緡，夫工一萬一百。茲橋高過廣濟，長五倍焉，而錢與工僅費此，勝讀宋記，稱信史矣。

昔洪紹生謀諸家人，今族祖祖奎又興祖啓，以弟兄始終其任，功足相方，而事尤相類也。附宋並傳，豈虛語哉？告厥成功，萬世永賴，敢贅數言以垂諸後云。

旹：道光十五年歲次乙未季秋月下澣

邑庠生里人陳宗拭凈如氏識
