# 上河祭惠三百八十八呂氏安人
```
题：[]浦江縣儒學署教諭事舉人沈裕，訓導陳天祐同頓首拜
峕：[19修]雍正七年歲次己酉十一月丙子朔
初始点校：[20260825]民国庚辰本[4/33]P449
修订参考：[]
```

維
雍正七年歲次己酉十一月丙子朔越四日丙戌，謹以剛鬣柔毛之奠，致祭於皇清待贈陳母呂太孺人之靈前曰：

溯水之原，太邱右族。詩禮遺風，科第繩武。子孫勤耕課讀，家號素封，人稱鸞鵠。惟太孺人，令淑天賦。紫海懷珠，藍田蘊玉。德容言工，無一不足。來相太翁，母儀整肅。琴瑟既和，鸞翼相逐。雞鳴夙興，閫內雍睦。敬奉尊長，恩周骨肉。大虔籩豆，老小沐春融。宗姻霜清，僕婢咸服。俾太翁持籌經畫，德著於鄉，禮隆邦國。云胡星限，致傷黃鵠。惟太孺人，門風如昨。灑掃中庭，潔清家塾。鄴架遺編，以教嗣續。左列紡車，右環書軸。晉接以禮，無分寒燠。凡母之德，亦罔不穀。人謂賢侶，不櫛而讀；人謂嚴父，胡不戴幗？子既遊庠，孫也允特。經明行修，才敏學殖。名列天衢，將食天祿。以光前型，以啟芳躅。篤生曾孫，渥洼汗血。閭里待駟車，崢嶸頭角。公輔之器，不日可卜。惟太孺人，備膺五福。以報太翁，九京無作。事載彤史，名記仙籙。宛然瑤池，媲美南岳。今屆小春，將歸窀穸。惟令孫賢，上答鞠育。視膳視安，遂母所欲。壽逾古稀，完真返樸。可以維風，可以訓俗。指日貤封，委蛇象服。執紼如雲，導引極福。裕等愧乏佳肴，聊供苜蓿；亦無瑤章，哀詞一軸。靈輀在堂，來歆來格。哀哉尚饗！

浦江縣儒學署教諭事舉人沈裕
訓導陳天祐同頓首拜
