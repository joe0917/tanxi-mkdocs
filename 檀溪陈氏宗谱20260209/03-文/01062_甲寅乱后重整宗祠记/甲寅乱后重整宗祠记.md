# 甲寅亂後重整宗祠記
```
题：[22世/惠155]第廿二世所山派惠百五十五，元席，薰沐盥手記
峕：[16修]康熙廿三年歲次甲子小春月望日
初始点校：[20250309]民国庚辰本[1/33]P062
修订参考：[]
```

天下事，不有作者，無以創述者之始；不有述者，亦無以成作者之終。此善始今終之人，所以相需而不可缺一也。

吾族自欽廿八公曁各派賢達，度地鳩工，捐資鼎建，創造大宗祠。一區成於萬歷癸未歲。以萃先靈之渙，以申如在之誠。此其功在合族，猷垂千譔，名播鄉邦，而膾炙於人口，不亦宜乎？

迨至崇禎戊辰（1628）年間，歲月久而梁柱傾圮，風雨飄而堦基苔蘚。過者惴惴。有崩折之慮，又賴有祠長仕沖公等，甃地中之石鋪，椽上之磚。易梁柱而廟貌如新，築照牆而前祠森肅。此其修飭之功，誠足嫓美於前賢。是以邑侯莊公有嘉獎之文，而樂助羣賢有刻石之誦。

當斯時也，上棟下宇，旣隆巍渙之觀；有寢有堂，復著深邃之式。臨其門而宫墻冠冕，入其庭而堦地平夷。美哉輪奐，左昭右穆，億萬斯年，綿綿勿替矣。

孰意甲寅之際，兵燹連年，破碎我門牆，焚燬匾額，甚至虔劉我神主，推裂我碑銘。几筵成瓦礫之場，門庭悉蕪穢之地。此始祖列宗之所爲飲恨，而仁人孝子之所以吞聲者也。

又賴有各派計費興工，照丁會斂，幾經寒暑，備歷艱辛。但丁眷雖有公派，不能充十一之費；卽捐助另有義輸，亦不敷落成之用。其中輾轉躊躇，焦勞拮据，有非筆墨所能盡述者。

而且修因果以薦先，而且演棃園以慶後。神龕奠而昭穆聿分，門廡修而內外嚴密。以至助田而充俎豆者有人，助銀而勷公費者有人。又熟非善繼善述，克念作者之不已哉？

嗚呼！創業維艱，守成不易。維我同宗，能創能述，代不乏人。用書宗牒之中，以褒孝義之舉。使後之整飭光大者，接踵而興。將祖宗在天之靈，實式臨之矣，豈曰小補之哉？

爰將効勞勸費、助田捐財諸名，詳列如左。計開督理修輯名次。

家長：諱伯義\ref{陈伯义}。

房長：德可，思章，思纓，國儒，思芳，思法，思愷，楚諭，

汝信，君祈，汝發，汝衡，完仲，君韶，汝品，汝才，君秦，

汝林，光行，汝芳，君立，君文，正芋。

共廿四人。

右各助銀三錢，生放功德節孝兩祠備祭，又桐油廿四觔（斤）

捐資名次

君餘助田三十三秤，土名祠堂下；
