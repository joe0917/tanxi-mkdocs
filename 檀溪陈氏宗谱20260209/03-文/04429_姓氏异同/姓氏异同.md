# 姓氏異同
```
题：[11世/俊5]十一世孫珪行俊五謹誌
峕：[04修]元至正丁酉正月初吉
初始点校：[]乾隆丁未本[1/1]p216
修订参考：[]民国庚辰本[4/33]p429
```

古人謂姓氏二字，何所分别？夫姓者，統其祖考所自出，百世而不變。氏者别其子孫所自分，數世而一變。

上古神聖，分姓别族，重所出也。因生賜姓，不一其人，子孫别而爲氏者，不一其類。

堯之後繼，封於唐，爲唐氏。舜之後始，封於虞，爲虞氏。此以國氏也。

傅說築於傅岩，而為傅氏。東蒙王蒙山而爲紫氏。此以地氏也。

氏以字者，曰子桑，曰子言，而龍氏、容氏則以名焉，以次者，曰孟孫、季孫，而五王續祁，左史、右史則以族以官焉。

以凶德氏者，所以著其惡而蛸也、莽也，非以凶德乎。以吉德氏者，所以彰其善而冬日也、老成也，非以吉德乎。

有以技氏者，有以事氏者，曰巫氏，曰竇氏。他如楊孫、賈孫，則有以族系氏焉。以至成公氏、成王氏，又非所謂氏以爵謚者乎。

此氏族之說不可不辯，又何以别其同反其異耶。

彼孟仲、季臧、東門、子叔，同出於魯也，而以魯爲宗。逰國封印公父伯張，同出於鄭也，而以鄭為宗。向華蕩樂鱗魚仲老，同出於宋也，而以宋爲宗。藥高崔國叔仲東郭，同出於齊也，而以齊為宗。

至若王之氏一也，吾不知出於元城之王耶，宜春之王耶，氓城之王耶。劉之氏一也，吾不知出於陶唐之劉耶，奉春之劉耶，元海之劉耶。

此氏族之同異如是，何以爲一定之規，而不相紊亂，使族有等夷哉。

不觀同人之卦，則不知族類所當先。不讀公劉之詩，則不知宗法所當立。是知，氏族不辨，宗法不立，則昭穆無由而定，尊卑無由而序，貴賤無由而分，本源無據雜亂紛更，人倫何自而明哉。

故氏族乃澄本正源之學，不容不講。宗法乃提綱挈領之目，不容不立。

隋唐以上，此意猶存。官有薄狀，以紀民之盛衰。家有譜牒，以紀族之分合。□選舉者此也，興孝第者此也。

奈何世更，五季宗法日壞，譜系漸失不傳。冐神靈於草野崛起之夫，齒中國於諸夷部落之後。

先正嘗云，雖以子長知幾二良史[^1]，猶昧姓氏之學，况其他乎。
[^1]: 源自《左傳-通志-氏族略》

嗚呼，月日星辰麗乎天，是以天為宗也。百榖草木麗乎地，是以地爲宗也。可以人而不歸其宗乎。不歸其宗，則遥匕華胄，聞者掩口。汾陽一拜，有識恥之郤梁公之誥像者，何人泣范氏之家世者，何人此氏族於人，誠不可不重也。

吾家自受姓以來，由烏程創業浦江，十有一世，族類羣分，姓氏同異，如諸暨白門、桐廬石阜，固方姓也，實陳宗之嫡裔，務欲明其源流。若小姑之里秀，義男金錢之流派也，亦附陳姓，不可使之亂宗。然則欲使氏族定而人知所本要，必自宗法始。先儒謂，宗法不明不可以復古治。

愚於此亦云，今吾所以欲使子孫知所本，而謹遵乎，宗法千載如一日可也，爲子孫者不得以吾言爲荒誕，而不之加意焉。慎之慎之。
