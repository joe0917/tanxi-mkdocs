# 功德傳芳記
```
题：[]鄉進士承德郎判直隸松江府事，通家侍敎生沿山傅巖周濟川撰
峕：[]萬歷己丑孟夏之吉
初始点校：[20250223]民国庚辰本[1/33]P070
修订参考：[]
```

一齋陳先生，諱九經，浦陽之義士也。葩經首薦，補邑庠廩員，屢試不偶。

鄉値改科加糧之害，民遭塗炭。慨然上疏奏，除鄉則浮糧千計，救民功德著於《惠民錄》。
建宗祠、督家教，光前裕後，九族莫不尊親，敦睦功德著於《宗約編》[[宗约编]]。
重興“惠雲古刹”，請葛禪師住持互相。捐資修輯鼎新，續故置產，煥然中興氣象，就建“報功祠”，另創“一齋幽署”，藏修養晦。

自著聯云：
“
避地絕塵，坐卧雲深不知處；
杜門謝事，笑設只在此山中。”
“
搜尋斷簡殘編，老當益壯；
遊玩靑山綠水，窮且益堅。”

更以“風月”二字，詠《清處隱逸》四律，嘗自吟曰：
夜然寶篆，靜鼓瑤琴；
光風霽月，我自知昔。
眼空物色，心斷塵寰；
間中風月，道氣悠然。
竹陰庭院，花夾籬笆；
吟風弄月，便是陶家。
菜根熬味，枯葉烹茶；
清風明月，佳興賖華。

正所謂“一點精靈天地老，經綸隱逸寸心工”。

青白寒星斗，安禪制毒龍；
披拂風塵外，逍遙道氣中；
精靈完太始，元妙入虛空。

興福地，祝延聖壽，每歲效上清宫故事，設春秋二𬋕，祈：
風調雨順，國泰民安，
福田日暖，善根日長，
鶯花不老，禪室雲封，
性靈神定，鶴夢俱幽。

皆先生仗義捐財、大金偉積所爲。
金爐不斷千年火，玉盞常明萬歲燈。
府縣嘉其行，學校高風，奉恩典給冠帶，以表其志。
鄉族利其利，寺僧樂其樂，合輿論塑遺像以誌其存，後之望風興起者，傳先生之功德不朽云。是爲記。

萬歷己丑孟夏之吉
鄉進士承德郎判直隸松江府事，通家侍敎生沿山傅巖周濟川撰
