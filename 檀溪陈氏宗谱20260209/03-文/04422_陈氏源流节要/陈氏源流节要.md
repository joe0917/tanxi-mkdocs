# 陳氏源流節要
```
题：[09世/登3]第九世孫，東陽學諭，應紀
峕：[03修]宋寶祐丙辰秋八月（七月八日）
初始点校：[20250510]民国庚辰本[4/33]p422
修订参考：[]乾隆丁未B本[1/6]p133
```

陳氏之先，方冊所載不一。按《左氏》，虞胡公滿者，爲周陶正，武王以元女太（大）姬配之，而封之陳，以備三恪。

又《史紀》載，虞胡公滿，帝舜之後也，周武王克商，求舜後，得媯滿，封之於陳，以奉舜祀。

《唐書》則又曰，夏禹封舜子商均於虞城，三十二世孫遏父爲周陶正，武王妻以元女太（大）姬，生滿，封之陳。

三說雖異，要之，陳固（實）舜後，以國爲氏者也。秦漢以來，子孫蔓延天下，載籍莫稽。

吾家三世始基長平山下竹田里，是其祖居，唐世諱融字季和，由長平遷居湖州烏程苕溪之上，自號霅川[^1]樵隱，生三子，曰安仁、曰用仁、曰守仁，皆不仕，有鄉行，家素富庶，千指衆，無以容，析居三族。

用仁居罨畫溪西，訛稱顯化溪陳氏。守仁居西塞山北麓，稱爲西山。

乾符丁酉[^2]（877年），安仁四世孫曰浚，子（字）伯洪，登進士第，禧宗朝累官秘書監轉湘州刺史，卒贈宣侯。

用仁五世孫曰繼先者，登中和進士，提調和州，性情清約，綜習墳典，屢進讜言，位儀曹尚書大鴻臚卿，居官內外四十餘年，年七十致仕，又起，爲國柱上卿，辭不赴召，國之大事以璽書訪之，卒諡靖侯，生一子，曰寵，仕開平庚午
[^3]（910年）
，授國子監學錄，終稽勲館駕閣文字兼良（史）館主閣學士。卒諡（丁未本无“卒諡”二字。）

宣侯生五子，曰棣、曰榆、曰槿、曰楷、曰榕。

乾化（寧）[^4]初（913年），棣爲昆明幸轉知安慶兼荊北道總管，添差隨州錄事。楷隱居不仕，撰《經世圖》十四卷，及《皇王紀錄》，《龍山詩集》，皆未脫稿（藁）而卒。榆登天復辛酉[^5]（901年）進士第，提調安豐討（转）均州，又轉爲襄陽錄事。乾化癸酉（913年），槿以明經進取爲安東通判。容（榕）敘州慶符令。

靖侯五世孫，曰經字守正，登天復（刊误，应为“天福”）丁酉[^6]（937年）進士，累官至隴西太守，以功封侯。曰綱字守常，爲建陽令，卒葬（塟）於彼，其子子仁字廷護，占業建陽。

經子（之）子松仕宋爲從駕散官，雍熙丙戌[^7]（986年），謝政歸，終於家，其子有博士者，生四子，曰（丁未本无“曰”字）許忠、許誠、許國、許明。

咸平庚午（庚子，1000年）[^8]，許忠爲廬陵令，尋隱分寧，占業於彼。許國性愛古，抵桐江，弔子陵，寄迹朱買臣祠，經（縳）廬嚴陵山厥，子曰碩，於天聖癸亥，遷婺之浦江新田里，贅（居）方應韶公女，頂方戶籍，卽從方姓，因家焉，寶（實）吾始遷之祖也。

碩生唐，唐生頊，仕宋爲宣議大夫，生五子，析居五處，琪析居苎（苧）陳溪下，彥遷居惠雲寺前，臧遷居諸暨白門，從外祖方姓，遹遷居楊樹角，逸遷居桐江下石埠（阜），亦從方姓。在家居者至六世祖曰珝，始復陳姓焉。

嗚呼，寥寥世緒，懸遠莫詳，信者傳之，疑者闕之，此其敘述源流大晷（畧），其於世次詳密備述於後。

（峕）宋寶祐丙辰秋八月（七月八日）
第九世孫，東陽學諭，應紀，謹著

[^1]: 霅：拼音zhà。霅川，即霅溪，又名霅水。在今浙江省湖州市，现在叫东苕溪。湖州市的别称为“霅”，就是因该溪而得名。又称霅上。
[^2]乾符丁酉：唐僖宗四年，公元877年。著名事件为“黄巢起义”（878年）。
[^3]: 開平庚午：开平四年，公元910年。“开平”为后梁开国帝太祖朱温第一个年号。
[^4]: 乾化：后梁末帝朱友贞复用乾化年号，于(913年二月--915年十月)使用。丁未本为乾宁（894-898），属于唐昭宗的年号。
[^5]: 天復辛酉：唐昭宗天复元年，公元901年。
[^6]: 天福丁酉：后晋高祖石敬瑭天福二年，公元937年。
[^7]: 雍熙丙戌：雍熙三年，公元986年。雍熙为宋太宗赵匡义第二个年号。
[^8]: 咸平庚午：咸平（998年—1003年）是宋真宗赵恒的年号。并无“庚午”年，疑似刊误，应为“庚子”，公元1000年。

# 《源流节要》跋

```
题：[16世/厚67]第十六世孫祐謹跋
峕：[08修]
初始点校：[]乾隆丁未A本[1/1]p222
修订参考：[]民国庚辰本[4/33]p447
```
先人遺墨難爲刪削，然於大叚頗有不類，恐傳訛故也。考源流中所載愽士公，在先傳不及見，此則突然明載，未能必信，又不敢妄意増拓，及見江陰陳氏石刻，再四攷究，亦然，始克副其心之所安，遂編成帖，仍俟諸族有見者之校正，然後可。

第十六世孫祐[[陈宗贞]]謹跋


# 《源流节要》再跋
```
题：[21世/恩54]第二十一世孫克敏，謹再跋
峕：[14修]
初始点校：[]乾隆丁未A本[1/1]P222
修订参考：[]民国庚辰本[4/33]P447
```

前人留心於譜，雖隻字，未嘗不嚴加考究，卽源流所載博士公，必証之。江陰石刻者，何[[陈宗贞|厚六七公]]之虚心而精核也。陳氏之譜，始於[[陈珝|都事公]]之立圖，提舉公\ref{陈一遇}之輯錄，郡馬公\ref{陈雄}之篆述。所可恨者，並無遺文垂世，使後世得以仰見古人，豈回祿時盡付之煨燼，抑携往桐江時并舊稿失去耶。

敏閱譜序，若俊五公《姓氏異同》之援引博洽，寜國公《大宗小宗》之持論精確，真是騰空飛去，擲地金聲，然遡源而尋流，則賴有登三學諭公《節要》一篇，尚同日星河漢，賴以不磨。丁卯之刻，悉以是篇爲定衡，而其他作聰明無證據者不敢問也[^9]。

第二十一世孫克敏，謹再跋

[^9]: 最后四字依据乾隆丁未B本[6/6]p955补足。
