# 祈山魁百四十七公號近山說
```
题：[19世/欽279]姪孫九街謹識
峕：[]
初始点校：[20250510]民国庚辰本[4/33]P434
修订参考：[]
```

今夫山之為山也，得天地安重之氣以凝聚於天下者也。是故仰之若見其為高，而况可得而近之乎？近之若見其為難，而况可得而號之乎？

叔祖諱廷護者，其為人也雅靜厚重，得山之體。胷（胸）羅萬象，得山之用。其人如山，則其心樂在於山矣；心樂於山，則其號為「近山」亦宜。

吾見
人之仰其高者，如泰山之峻極而崔巍難企也；
人之重其義者，如崑崙之屹立而厚重不遷也；
人之慕其名者，如華嶽之廣大而寶藏難測也。是與山而相並矣，豈特近之已乎？

既與山同德，則必與山同壽。南山之祝，北海之樽，殆將為異日之獻無疑也，又奚疑此近山之哉？

姪孫九街謹識
