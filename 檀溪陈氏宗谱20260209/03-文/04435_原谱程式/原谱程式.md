# 原譜程式
```
题：[11世/俊4]第十一世孫瑪謹誌
峕：[04修]元至正丙申十月之吉
初始点校：[]乾隆丁未本[1/1]p214
修订参考：[]民国庚辰本[4/33]p435
```

周衰，聖賢不作，而五宗九两之禮廢之久矣。五宗廢，則世緒益亡，而族不聚居。九两廢，則譜系不傳，而民不知祖。故諸侯卿大夫之家，不忘其生者，賴譜書存焉耳。

李唐高祖太宗之世，驅羣雄以得天下，起圭竇者，或敞高門，奮鉗徒者，或建大斾。時君惡夫，故家之自崇，而輕吾之爵祿也。取氏族之說一槩，而非斥之當時一言，不過怒而求勝，孰知流獘陵夷，不足傳信。

至於唐衰，而譜牒棄亡盡矣。是雖矜其閥閱之高，亦不足尚。士出於千載之下，而欲本其所生，以支綴宗族，無他故也，姑自養其孝弟、雍睦、忠厚、惻怛之心而已矣。學者述譜之意，葢本於此。

若吾陳氏，本虞舜之後，今子孫不敢上同宗國之姓，故以武王所封之國爲姓，歷世旣久，隆替無常，而宗族之恩，鮮有不缺，貧冨貴賤之勢，有相軋而不相統属也。於是乎親親長
長之義，愈踈愈薄，卒然途遇，利害氣勢，莫能相及，而宗族之恩，以联至其極，不惟五服之親爲然，雖兄第之閒，不相容者多矣。

鳴呼，獨不觀禽之飛、獸之走，尚徘徊顧羣，而懼外物之害。人則靈異於物，可不知族類之爲重，而忘其所自耶？

盖嘗以吾身而視吾族，其支泒雖遠，而其初皆本於一人之身，來者惟其知此，則死喪緩急可相保，而不相棄。此聖人立爲宗法，自家至國、篤近槊遠之原也。

吾家自唐季和公，傳及於今，枝榮葉盛，興衰相忘某。竊有慮譜之遺失，每詢之遺老會之，各族凡見殘牒，採收入譜，各從本支備詳於下，使我宗人觀之，庶幾，後先相望，不致昧宗，故敢原夫程式以示後云。

峕：元至正丙申十月之吉
