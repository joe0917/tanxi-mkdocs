# 祈山承七百六十一仰岑公頌
```
题：[]甥男虞啓明百拜撰
峕：[]
初始点校：[20260825]民国庚辰本[4/33]P445
修订参考：[]
```

嗟我舅氏，尚萃其名。字乃德聚，別號仰岑。緬懷其行，月白風清。守身似玉，潔己如冰。非義勿取，有讓無爭。五倫克備，言行咸能。讒言勿宣於口，嫉妬弗起於心。鄉邦稱盛德，閭里頌徽音。壽適盈乎卦數，夢忍步乎雲程。惟期後裔子姓振振，光前裕後，桂馥蘭馨。甥舅罔極，恩深受勞。若子奚啻椿庭，一週未滿，撫至髫齡，始終如一，世所罕聞。惠深愛篤，意切情眞。飽德無瑕，雖千言而莫狀；感恩靡已，書五丙以難甯。俚言作頌，丹悃聊申。爰著芳名於譜牒，庶與天地而長春。

甥男虞啓明百拜撰
