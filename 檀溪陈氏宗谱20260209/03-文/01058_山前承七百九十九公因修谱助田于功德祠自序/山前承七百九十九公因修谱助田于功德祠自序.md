# 山前承七百九十九公因修譜助田於功德祠自序
```
题：[20世/承799]第二十世府庠生尚奏謹撰
峕：[16修]康熙乙丑春月吉旦
初始点校：[20250411]民国庚辰本[1/33]P058
修订参考：[]
```

甲子春祀，吾族復事於修輯家乘，此美舉也。前此修於丁酉，今復議修焉，時論爲迂，吾謂非迂也。蓋天道歲序，數載有變遷之異；人事更新亦然。整舊誌，煌然鉅典，有振作鼓舞之意，冀後起蔚然人文，知光宗耀祖之思。溯祖盛於始基，茂於中葉，而今且族屬繁衍，則瓜瓞綿綿，以似以續。後起者不當知所振奮乎？科名如文五公\ref{陈雄}夢魁\ref{陈梦魁}文昌\ref{陈文昌}之鄉舉，人材若[[陈叔善|叔善公]][[陈彦道|彥道公]]之里選，勳猷炳然，先哲宜效。

奏幼年失怙，誦讀功淺，幸獲靑衿，歹（反）躬慚愧。見族志上流，步先賢者，則忻然慕之哉。竊效孟子書云：「惟士無田，則亦不祭。」今助田於功德祠，以供粢盛，上薦馨香於祖考，下胙後起之英賢。勵志一族，作起後人，不能光前已矣，將此爲裕後一節。故不諱陋陋，聯以自序云。

計助田六十稱，坐落本都五保，則字一號，土名南山毛溪前橋頭。

康熙廿四年正月，德言公親筆助約一紙，交與祠長姪[[陈鼎新|鼎新]]藏。

康熙乙丑春月吉旦，第二十世府庠生 府（尚）奏謹撰。
