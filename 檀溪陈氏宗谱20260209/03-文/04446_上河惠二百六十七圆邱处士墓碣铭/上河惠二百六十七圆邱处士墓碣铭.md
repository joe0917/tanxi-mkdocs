# 上河惠二百六十七圓邱處士墓碣銘
```
题：[]浦江學訓導曾安世拜撰
峕：[]雍正二年歲次甲辰中秋後五日
初始点校：[20260825]民国庚辰本[4/33]P446
修订参考：[]
```

圓邱處士之葬也，余既題其菓矣。越六年，其子之環、之佶，手執朱拱辰所為傳，偕子師張子蘭生，復以墓銘請。憶康熙己亥冬，余之至上河也，見環昆弟四人皆美髯偉貌，進退雍容而肅然，篤睦以和，氣象形於一門焉，心竊異之。意處士在日，所以教其家，必有大過人者。既徵諸本庠諸子，而得其概。今閱傳所書，孝於親，友於弟，力田以致饒，而一錢尺布不自私。甲寅之擾，弟為賊所劫，則躬趨請贖，曾有被其德得並脫者。家居務崇節儉，至築館舍，擇師訓子弟，及救災恤佃，蠲負完聚，修橋梁道路以濟行人諸善事，則不吝。邑大夫聞而嘉之，舉飲於鄉。配亦克修內助，稱同心。而竊喜余向者懸揣之非妄也。若處士者，雖不以儒見，夫非讀書明大義者哉？乃據傳而并采世系於其家牒，而敘銘之。

處士姓陳氏，諱元靈，字汝應，晚號圓邱。其始祖碩，當宋天聖中自烏程遷浦，養於新田里之方氏子唐，蒙其姓。五世至都事珝，始復為陳。子孫繁衍，幾遍於廿六都而溢焉。有舉於鄉者曰雄，有為東陽教諭者曰應紀，皆處士之先。而明寧國知府彥道有惠政，其族之聞人也。珝傳十四世曰尚球，是為處士之祖父；曰克遷，處士之父。處士生明崇禎癸酉正月五日，卒康熙丙戌正月十五，壽七十四。配王氏，後處士十年卒，年七十七。越四年，合葬於本都之黄塘裏也。四子：之正、之環、之冕、之倍。孫八：以璋、以玿、政瑚（正出）；以先（環出）；以珙、屋出；浩、溥、濯（倍出）。曾孫際時、際康、際雍，元孫一榮。惟處士上承祖德，克修諸躬，雖隱而未耀。之環餼於府庠，與之倍俱能文，不難取科第以彰處士種德之報。孫曾繩繩，而以瑛、以先、正溥俱弱冠採芹，門閭之高可必也。夫道揚先德以垂不朽，乃人子之孝思。此即懿行無聞，猶將表之以為世勸，而况庠友之所陳，朱傳所載，不約而同，彰彰如是哉！蘭生老而好學，留意詩古文詞，乃不自任而以屬余，余固不得而辭也。

銘曰：  
鳳凰之叶陳為方，五世而復宜其昌。  
旋繁仕者遙相望，隱德未耀固爾藏。  
孝友姻睦醞吉祥，我銘千載彰厥常。

雍正二年歲次甲辰中秋後五日
浦江學訓導曾安世拜撰
