# 陳氏世居地里辩
```
题：[21世/恩054]廿一世孫邑増廣生克敏謹識
峕：[14修]峕天啓丁卯冬
初始点校：[]乾隆丁未本[1/1]P156
修订参考：[]民国庚辰本[4/33]P425
```

人禀清淑之氣，而陽舒陰惨，此因乎天者也。人具强健之質，而沃逸瘠勞，此係乎地者也。故邁種亢宗之士，注愛於天心，而尤鍾靈於地脉。

舜生於諸馮，文王生於岐周，其揆一也。然東夷之帝子，决非西方之美人郎。孔子自稱東西南北之人，而父母之邦舍魯奚適哉。審是，而大丈夫所從來可不辯與？

嫣满封於陳，子孫以陳為姓，郎以陳為居，可知也。厥後散逸，而橫秦吞噬之後，諸侯分封之處，悉剖裂而爲郡縣。自秦至漢，陳之子孫益蔓延而不可稽。

登三公《節要》云，吾家三世始基長平山下竹田里，夫有山名有里名，宜可考而知也。惜乎未書州郡，則茫匕輿地，何處容刻舟之求？予未嘗不捧卷而扼腕也。幸而又云，唐世諱融者，由長平徙居湖州苕溪之上，自號霅川樵隱，何其居苕而號霅也。葢苕霅雖有二溪之名，其實一水瀠洄而曲折者也，故其號可信也。長子安仁，世居其地；次子用仁，考之乃浦之祖，析居罨畫溪西；三子守仁，析居西塞山北麓。三子析居三處，地里瞭然指掌。登三府君於此之外並無一言他及，則爲用仁公之子孫者，宜尋盡溪而苕上與西塞不妨徐及，况苕溪之外，另有所謂蜀山頭金牛鄉耶，或曰苕溪。所該甚廣，蜀山亦苕溪中之一隅也，予應之曰，卽使蜀山在茗溪，然亦長支安仁所居之地，而與浦陽徙居之祖無涉也，况未必然也，予未束髪時，父老指示曰，吾陳從湖州蜀山金牛鄉來，心竊記之。

萬歴乙卯（1617），承先大父命，遊學吳興，不勝忻然，曰，“予先湖州人也，使得訪其故居，而勺水歸於黃河之源，拳石遡於崑崙之脉。快當何如哉”。

故肄業之外，無日不詢蜀山。忽晤一友人，陳仁吾者，相見恨晚。然叩其從來，既非樵隱之裔，而問其居鄉，又非金牛之號。余乃快匕不樂，不得不追咎於舊譜之訛矣。或曰，金牛鄉殆宋時名，國朝更之耳，然予從友人家索湖州府誌讀之，則見其記載更攺之名，古今詳盡，蜀山之鄉，名曰咸德，初非金牛也。

身歴其處，目覧其誌，卽登三公之遺筆，豈無稽之談哉？然則，彼說從何訪蜀山二字，見常十一公譜歌金牛鄉三字，則後人之以訛傳訛者矣。儻沿習而不察焉，不幾，以來歴不明之人，爲浪走他鄉之客哉。

常十一公往石阜會譜，則有方思義公盤桓留接，故譜雖失於桐江，而光景實依然其如在。

至讀烏程會譜之詩，不問遇何宗人、歴何境地、考何史牒，詩中之意不過留連繾綣之情而己，令後人何所憑而信之也。

然登三公去古未遠，其言可遵，不得舍而另摽名目也。

謹按湖州總府誌，苕溪卽在府治前一溪，豌蜒而行，凡屬湖州，俱名苕上。西塞山在烏程縣南二十五里，張志和有《漁父詞》五首，幼支守仁公之所居也。蜀山在烏程縣東七里高啓，徐賁有詩姑闕以俟高明。

罨畫溪又名西溪，在長興縣西七里，朱藤掩映，花時遊人競賞，如在畫中，可十里許，故名畫溪。唐鄭谷詩云，“顧渚山邉郡，溪將罨畫開”。劉燾有詩，“竹林深處杜鶬啼，兩岸青匕草色齊，欲識人間真罨畫，朱藤倒影入清溪”。陳襄詩云，“五雲無處間新亭，月裡乘舟夜半行，不見朱藤相掩映，鄉人遥指畫溪名”。

此碩公未遷以前所宜深究者也，碩公既遷之後，贅居湖田，其後子孫何啻千指，星列棋布各處一方，或飛棟連雲，或茅屋數椽，凡係碩公之一脉，例無不書之地里，而其中疑，似亦當辯焉。湖田祖居一撮之地，環而居之者，其名有四，苧陳溪上，則有湖田，幷斌三公析居祈山苧陳溪下，又名惠雲寺前。苧陳溪下，其居旁檀溪两水之濱；惠雲寺前，其居近祖瑩宗祠之地。两處遞有興廢。湖田則在外而臨水，祈山則在內而倚山，此時正值繁盛。所當明爲别者也。乃若江陰縣既不辯其析居之人，而會稽羅山亦不知其創業之由，可深爲嘆息者也。而好事者曉匕曰，畨禺有常三公之遺裔，富陽有陳氏之分枝，則非不肖所能蠡測也。

是為辨。

峕：天啓丁卯冬。

廿一世孫邑増廣生，克敏，謹識。
