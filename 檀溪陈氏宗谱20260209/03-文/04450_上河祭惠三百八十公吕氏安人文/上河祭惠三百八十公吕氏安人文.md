# 上河祭惠三百八十公呂氏安人文
```
题：[]眷姻姪潘調燮率男起兆
峕：[19修]雍正七年歲次己酉丙子月朔
初始点校：[20260825]民国庚辰本[4/33]P450
修订参考：[]
```

維
雍正七年歲次己酉丙子月朔越七日丁丑，眷姻姪潘調燮率男起兆，謹以剛鬣柔毛、清酌庶羞之奠，致祭於皇清待贈孺人陳母呂太君之靈曰：

嗚呼！天姥峯傾，夫人城圮。蓮凋華井而馳弔，夷娥竹裊湘江而牖悲嬃姊。唯我太君，淑慎儀貞，令儀令德，蘭馥蘭馨。遡厥華裔，和鸞鳴題鳳之宅；來嬪望族，瑞靄聚德耀之庭。若夫平章閫內，佐理中庭，理讌會則賓筵眾核，襄祀事則湘釜繁頻。富而能勤，綿自溫而常卻；惠而好施，冬無寒而不春。

方其太封翁之仙逝也，賦既傷於我特；繼而太親家之捐世也，愁倍切於喪明。爾乃望夫石者，心匪石而可轉；慈母機寒，練在機而更瑩。剉薦則陶家令母，已箸乎奕世；畫荻則歐氏賢慈，更授經於孫曾。肆我親翁，英才卓犖，譽列成均，經明太學。賓山之桂樹，長有連枝；謝室之蘭莖，秀成雙萼。

爕自慚葑菲，得附絲蘿。方其廣蔭乎柔蔓，竊喜托植於中阿。何期變起太清，驟駕還乎月姊；乘蚪入植，遽旆返乎星娥。嗚呼！石母風寒，趙兒霜白。金坑光掩，白嚴稿色。安仁之誄德煌煌，宋玉之大招些些。莫傾松柏之堅貞，誰寫冰玉之皎潔？聊執椒醑以徬徨，庶傍靈旆而彷彿。尚饗！
