# 提舉公贊（集文選書）
```
题：[[26世/廉258]]祈山派孫耀偀謹題
峕：[]
初始点校：[20260916]民国庚辰本[1/33]P124
修订参考：[20260916]乾隆丁未B本[6/6]P3833
```

往哲是與，魯之璵璠。
道風秀世，豈不信然。
澘精墳籍，書記翩翩。
長才廣度，所懷萬端。
懷文抱質，恭儉下人。
羣英翹首，郅惲投竿。
一行作吏，心不耐煩。
飛翼天衢，便欲引還。
廣開土宇，吾將老焉。
高論堯舜之道，慷慨重阜之巔。
末覩厥誰與為歡，把玩無厭，藏之名山。

祈山派孫耀偀謹題
