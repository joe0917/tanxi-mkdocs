# 茅山建五百五十八邑庠生諱以純公墓誌銘
```
题：[]孫太學生諱時悟字魯軒謹誌
峕：[31修]光緒六年歲次庚辰
初始点校：[20260721]民国庚辰本[4/33]447
修订参考：[]
```

誌者何為？葬也。筭者何以誌？為葬之地所在也。故量地之大小，以定穴之多寡，勿令前閉而後塞，左夾而右攻。則藏身之所，沒者妥而生者亦安矣。

念我高祖邑庠生以純公，暨高祖母張氏安人，厝葬於茅山住家之東南土名周村，眠牛形，乙山辛向，逆水來朝。伯曾祖際靉（霼）公與伯曾祖母王氏、虞氏，葬於高祖之左；而吾曾祖際靉公同曾祖母潘氏，葬於高祖母之右；吾祖與祖母另穴合葬於右傍之右；而吾父葬於曾祖母之右傍，羅城之內。高曾祖父妣姑婆媳，共作一家，生無異室，死則同穴，殆其然輿（歟）！

雖然，吾觀其地褊小，穴己（已）繁多，欲止將來未成規範，故特刊譜以誌之，嗣後不得再侵行犯云爾。

光緒六年歲次庚辰
孫太學生諱時悟字魯軒謹誌
