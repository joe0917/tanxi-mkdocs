# 祈山惠百十二公祀田記
```
题：[]暨邑外孫王以勤盥手拜撰
峕：[18修]康熙五十四年歲次乙未上浣之吉
初始点校：[20250416]民国庚辰本[1/33]p079
修订参考：[]
```

聖經云：「孝子純孫，善繼人之志，善述人之事者也。」惜我外祖後嗣無繼，不能有孝子純孫，即無繼志述事之人，蒸嘗何享？俎豆何供？幸繼堂姪母舅用興者，承立宗祧，使吾外祖稍可含笑於九京（泉）矣。

所遺產業不甚殷厚，止遺田十六秤，坐落本都十保，履字四百六十三號，田一畞三分七釐，土名屋後，以爲生卒之需。三房立議，輪流收租供祭，毋得私自侵蝕，永遠爲記。載之譜牒，以垂不朽。

康熙五十四年歲次乙未上浣之吉

暨邑外孫王以勤盥手拜撰
