# 平湖承百四十一公又號承六三公祭田記
```
题：[25世/聰1494]裔孫 祖蛟誌
峕：[26修]道光八年戊子二月日
初始点校：[20250416]民国庚辰本[1/33]p078
修订参考：[]
```

承百四十一公向鮮產業貽畱，惟有山場二處：一落圭坑口山頭，一落長舉塢磨石灣。因乾隆二十五年廳堂回祿以後，祭祀之期，神主設立無所。

迨乾隆三十八年，議將山頭松柴一處拚折錢七兩正，以爲豎造堂樓之費，餘皆派下裔孫捐湊，多寡不等。而泥水一作，以川獨任焉。嗣後並將磨石灣禁樣出拚得錢若千。以川、際山、榮華、榮虎、祖傳等勤謹生放，次苐受田䜿（豎）碑，坵片稱數開載於後。

竊思子孫不肖，惟知肥己爲懷，祖產雖多，日形其不足；子孫誠賢，專以秉公爲念，祖產雖少，自覺其有餘。後之子孫若能繼以川等之志，將見產日益多，不獨無負於先祖，亦且光於數人，正今日之所深望也。勉之勉之！

道光八年戊子二月日
裔孫 祖蛟誌

七保新塘嶺一坵廿秤，八保王石灘一坵廿秤，
王司坑橫路頭頂十一秤又八秤，王司坑前山灣口三坵三十六秤，
大洑堰頭小溪灘二坵三十秤，九保太祖殿沿一坵廿秤，
又後溪地十稱，長車塢西山脚四坵五十秤，
共計田一百九十六秤。

公理收息生放。
