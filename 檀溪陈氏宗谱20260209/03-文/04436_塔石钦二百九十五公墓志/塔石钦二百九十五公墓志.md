# 塔石欽二百九十五公墓誌
```
题：[]眷侍教生丙寅貢生鄭尚憲謹撰
峕：[14修]天啓七年丁卯冬月
初始点校：[20260824]民国庚辰本[4/33]P436
修订参考：[]
```
公諱大積，字伯餘，賢三十五公之幼子也。娶蔣氏，生三子：尚壽、尚北，俱能勤儉成家，克肖子也；幼尚南，繼兄百五十五公為嗣，足徵友于之愛。年六十有四，乃始捐賓，而安厝於廿八都三保九十三號，土名上山頭，癸山丁向之地。佳城天設，山環水抱，奇峯拱秀，誠福地也。子孫繁盛，不卜可知矣。余與公仲子有一脈之親，以墓誌屬余，愧不文，無以記公之盛德，略序數言，以垂不朽云。

天啓七年丁卯冬月
眷侍教生丙寅貢生鄭尚憲謹撰
