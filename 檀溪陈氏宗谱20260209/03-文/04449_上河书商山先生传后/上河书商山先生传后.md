# 上河書商山先生傳後
```
题：[]門人姪邑增廣生光琳頓首百拜謹撰
峕：[21修]乾隆廿九年歲次甲申桐月
初始点校：[20260825]民国庚辰本[4/33]P449
修订参考：[]
```

家端賢兄所爲商山先生傳詳矣，琳何敢贅？然琳與先生居最近，受先生恩最深，又安能以無言？先生與先大人同庚，少相善，而季叔竹齋公則兄事之，其文行略相等。惟先生遊庠最早，補廩餼則先竹齋公一年。各受徒時，相過從，季冬散館，朝夕聚處，劇談至夜分。琳時年少，聽先生言，灑洋洋猶河漢之弗竭也。又內外完好，色夷氣清，可畏而親。越數年，先叔早世，琳家貧廢學，先生收而教之，且丐以所需為遊揚焉，故得以蒙館餬其口。

嗚呼！先生秉鐸惠雲山房，學者歲五六十人，靡弗因材善造之，而尤加意於孤貧。如族子邵音者，年少能文，其病時，日往反數四，力為調治，勿知疲，及卒，有喪子之痛。而琳則頑駑鈍弱，弗堪教也，以先生故，亦得列名庠序，為多士後，其受恩為何如耶？猶憶琳受業時，太翁篤老加病，先生躬進湯藥，旬日間鬚髮盡白，諸弟子爽然以駭，而先生弗知也。後太翁以天年終，先生獨事太夫人，承意承志，雖老弗衰。又篤愛其弟藍玉如少時然。迴憶先生與先叔劇談，其丰容色澤，已不可復識矣。

夫以先生揭德振華，於古有光，宜掇魏科，列尊位，而乃終於鄉薦。太夫人沒後四五年，在丁丑三月十一日，先生卒，以貢士服。嗚呼！於今又七八年矣。世無老師宿儒，坐擁皋比，冀為後生小子鑿混沌，然如先生之取精用宏，迎刃而解者誰乎？則先生之楷模士類，因能篤實，又曷可再得？且先生嘗以顯微闡幽為己任，謂琳先大人律身不苟，有長者風，既成季弟之名，又黽勉令琳就舉業，而溘焉以逝，欲為作傳未果而沒。嗚呼已矣！先生有孫曰紹祖，少從予學句讀，後先生授以經義詩古文辭，靡不工，將大其家聲，先生為有後云。

乾隆廿九年歲次甲申桐月
門人姪邑增廣生光琳頓首百拜謹撰
