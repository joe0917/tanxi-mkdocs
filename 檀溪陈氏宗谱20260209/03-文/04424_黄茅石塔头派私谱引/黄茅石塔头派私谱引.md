# 黄茅石塔頭派私譜引
```
题：[24世/廉1409]裔孫榮臺謹誌
峕：[25修]嘉慶二十三年歲次戌寅仲春之月
初始点校：[20250510]民国庚辰本[4/33]p424
修订参考：[]
```
余派自承四百三十三公諱可學、承七百十三公諱可嘉，由會龍析居，迄今延行已八世矣。析居既久，生齒漸繁，奈生娶卒葬難於考徵，無如何耳。

顧余會龍派向有公譜係人居繁盛，藏譜每無定所，既不便於考核，且所居與會龍又隔數里之遙，徃（往）返為尤不便。是公譜雖存，而於余派終無濟也。

今丁丑宗譜重修，派下議刊私譜，而公中無餘資。賴祖追、文埜等不辭其勞，隨科抖若干，并各家樂輸若干，而猶不滿於數，因更出己資以襄此舉。雖所輸之輕重不一，而所以贊成其事則一也。是舉也，在各家既不吝於財，而首事者為尤不吝於財，不洵足多歟？

嗣是而公譜之藏固所大共，私譜之作便於考徵，誠美舉也。茲係房祖以威命臺等曰：「是不可無一言以誌之也。」臺因承長者之命，而為引。

嘉慶二十三年歲次戌寅仲春之月

裔孫 榮臺謹誌
