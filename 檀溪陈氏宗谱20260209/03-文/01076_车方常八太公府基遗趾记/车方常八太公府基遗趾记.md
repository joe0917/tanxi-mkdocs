# 車方常八太公府基遺趾記
```
题：[24世/建673]第十二世孫以先謹誌
峕：[21修]乾隆廿九年甲申季春之望
初始点校：[20250307]民国庚辰本[1/33]P076
修订参考：[]
```

太公諱正性，字叔善，行常八。前明洪武間，欽賜河南大方伯，時居車方後宅，成[^1]因風水不佳，命長子顯五公遷居平湖，三子顯九公遷居山干。晚年又率幼子顯十一公遷居前陳，惟次子顯六公仍居舊宅。傳三世，魁四十八公亦遷棲雲洞口。其安土重遷者，日漸衰微。

入國朝，康熙十三年（1674），寇發[^2]，廳堂房屋被毁殆盡，遺下三正基地及前後天井餘基，四派公管。山干所居最近，自始遷後，每年正月十六日迎燈往叅，至今無間。其餘村庄二十餘處，則以遠地爲疎，數或五三年，或十餘年一往，參差不等。此因始受封爵，祖居遺趾，不忘本初之意。

至乾隆廿六年（1761），迎燈到基，不期而會者適多。見公基蠶食不整，因新舊桑木絆碍龍燈，砍倒數根，以致涉訟。

蒙縣主何公兩番勘審，以向外右邊前靣丈還承仁一分七釐，令本派出銀三兩帮貼築牆，定界永杜訟根。又斷左邊後靣照依舊墻，聽之永管業，其餘悉歸四派公管。

但公基荒蕪不毛，止爲年節參燈之地。又前缺西南，後缺東北，而四靣俱屬外派種作園場。恐日後年遠世隔，不知始末，復起爭端。兹因修譜之便，略叙判案，載在譜前，庶幾本派內外兩各遵守，永全族誼。是爲記。

乾隆廿九年甲申季春之望

第十二世孫以先謹誌

[^1]: 依据乾隆丁未本为“或”。
[^2]: 指三藩之乱中的南王靖南王耿精忠起兵反清，分三路出兵，其中中路攻浙江金华、衢州。

## 简体标点
太公讳正性，字叔善，行常八，前明洪武间钦赐河南大方伯，时居车方后宅，成因风水不佳，命长子显五公迁居平湖，三子显九公迁居山干。晚年又率幼子显十一公迁居前陈，惟次子显六公仍居旧宅。传三世，魁四十八公亦迁栖云洞口，其安土重迁者日渐衰微。

入国朝康熙十三年（1674），寇发，厅堂房屋被毁殆尽，遗下三正基地及前后天井余基，四派公管。山干所居最近，自始迁后，每年正月十六日迎灯往参，至今无间。其余村庄二十余处，则以远地为疏数，或五三年，或十余年一往，参差不等。此因始受封爵祖居遗趾，不忘本初之意。

至乾隆廿六年（1761），迎灯到基，不期而会者适多。见公基蚕食不整，因新旧桑木绊碍龙灯，砍倒数根，以致涉讼。

蒙县主何公两番勘审，以向外右边前面丈还承仁一分七厘，令本派出银三两帮贴筑墙定界，永杜讼根。又断左边后面照依旧墙听之永管业，其余悉归四派公管。

但公基荒芜不毛，止为年节参灯之地。又前缺西南，后缺东北，而四面俱属外派种作园场，恐日后年远世隔，不知始末，复起争端。兹因修谱之便，略叙判案载在谱前，庶几本派内外两各遵守，永全族谊。是为记。
