# 陳氏源流辨
```
题：[21世/恩054]第廿一世孫祈山恩五十四邑増廣生克敏謹撰
峕：[14修]天啓七年夏月
初始点校：[]民国庚辰本[4/33]P427
修订参考：[20260618]乾隆丁未B本[6/6]p3955
```

粵自天開地闢，而人生焉，故天地者，人之祖，又以一人爲千萬人之祖，渾沌以前，書契未興，莫可窮詰矣。

羲農以降，黄帝有熊氏，文明稍啟，考之史冊。堯，爲黃帝五世孫；舜，其八世孫；禹，雖姒氏，亦黃帝之孫；帝嚳，次妃簡狄生，契而爲商之祖，元妃姜嫄生，棄而爲周之祖，帝嚳者黃帝之元孫也。然則，唐虞三代以至今日，執非黃帝一人爲之祖哉。

余家陳氏，爲舜後子孫，以國爲姓，其中鴻名偉迹，煥史冊而炳日星者，屈指未易數，寧特漢桓靈時，太邱公一人哉。須無見稱於至聖，陳平出奇於漢室，前五代覇先之應運，其功業何隆也，後五代希夷之淸夢，其意趣何高也。以黄帝一人觀之，則凡若此輩，非我嫡派之祖，亦我旁枝之宗，縱自我作祖，不必强附梁公，而遞傳至我亦何能托生空桑哉。但不欲竊其影響，若梁（黎）邱之鬼昧，其本來似蕉葉之鹿耳。

丁卯嵗（1627），不肖敏適遭題石之厄，因取舊譜而讀之，心竊惋惜焉。舊譜系圖，悉以太邱公爲祖，夫德星會聚，二難毓秀，豈非後學楷模，而一傳之後，輒附以融，夫融唐人也，遡唐而五代，遡五代而漢，相去懸絕，而竟以融爲實（寔）之孫，其來脈何不清也，且武帝覇先，前五季人也，陳隋之後，方及於唐，而舊本系圖，反次覇先於唐世融公之後，何可令博（愽）洽君子見之哉。故寕爲傳信毋爲傳疑，悉取而釐正之。

總以應紀公之《源流節要》爲主，遵是者取之，反是者去之。太邱以前，世遠年湮，不敢妄立己見，故闕以待識者之訂正，而以融公之實歷可據者爲始。

融字季和，自號霅川樵隱，由長平居湖州。融次子用仁徙居罨畫溪西，用仁生以德。以德生敏，字明程，有德行孚於鄉邑。敏生濂，字伯正，仕唐爲節度使。濂生繼先，登唐僖宗中和進士，仕爲上柱國，封靖侯。繼光生寵，字德明，授梁開平庚午國子監學錄，終稽勲舘駕閣文字兼學士。寵生盛。盛生詵。詵次子經，字守常。經生松，仕宋爲從駕散官。松生陵，仕宋爲博士。陵生四子，次（三）許國。許國生碩，是為浦陽檀溪第一世之祖也。

天啓七年（丁卯）夏月

第廿一世孫祈山恩五十四，邑増廣生，克敏，謹撰

（第廿一世孫邑増廣生克敏謹辨）
