# 廊下建百九十一公墓誌
```
题：[]元孫宗察謹誌
峕：[]道光廿七年丁未十一月
初始点校：[20260824]民国庚辰本[4/33]P436
修订参考：[]
```

建百九十一，諱以宦，字思濟，宣八十四公之子也。兄弟五人，公居幼。公父素高尚，家政一歸於冢子。分居時，公年方幼學，後克自成立。娶安人張氏，生一子諱際輝。公繼娶安人某氏，烏漿山朝位公之女，國勤公之兄弟也，生一子諱際忠。公一女，適場橋虞光吳公。

公生於雍正戊申十一月初五日戌時，卒於乾隆辛亥五月二十日酉時，享壽六十三歲。末年家業滋盛，二子四孫，皆一時表見。葬於本都二保，土名舊住墳頭山田內，乾山巽向。蓋達二府君之始居也，故以舊住名。築土為墳，崇高七尺。親友觀者咸曰：「脫龍就局，藏風納氣，稱為佳穴」云。

合葬：安人元配於左，繼娶於右。後之附葬者，繩繩相繼：際輝公暨戴氏安人附於左之左，際忠公暨張氏安人附於右之右，榮珍公附於右，宗突之安人方氏附於左。蓋以祖孫父子，生也為親屬，歿也葬以類從，有以見昭穆之序焉。孝敬以存，人心以萃，周禮墓大夫之職，令民族葬，由是道也。

道光廿七年丁未十一月
元孫宗察謹誌
