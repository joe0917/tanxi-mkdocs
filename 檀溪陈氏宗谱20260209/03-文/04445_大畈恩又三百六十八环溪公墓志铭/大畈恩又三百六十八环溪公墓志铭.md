# 大畈恩又三百六十八環溪公墓誌銘
```
题：[]孫壻張一位薰沐敬撰
峕：[16修]康熙歲次甲子仲冬月 
初始点校：[20260825]民国庚辰本[4/33]P445
修订参考：[]
```

陳公環溪者，諱克富，字思美。秉性公直，凡遇雀角之爭，輒行勸解。平居存心尚義，見富厚無歆求之心，遇困乏有周急之意。雖生平之美不克枚舉，約略數端，大都如此。余屬葭莩，偶睹公之墓道，因撮數語為之銘曰：

山聳而秀，水繞而清。有此靈區，豪傑自應挺生。憶公直道維世，排難解紛；臨財仗義，忘情富貧。才能堪禦侮，獎匾著芳名。門庭遇外變，雖至仇必勇往，而曲直聿伸；或逢內難，惟據理而涇渭立分。塋光皎潔，心胸坦誠。鐵中錚錚，性體堅凝。律身敬恪，治家嚴明。內助有淑媛，繼述有賢孫。義惟親君子，情不厭友朋。乃如之人兮，嶽鍾奇英。天祐厚德兮，桂馥蘭馨。家業昌盛兮，久大維新。敘茲數事，約略所云。

康熙歲次甲子仲冬月  
孫壻張一位薰沐敬撰
