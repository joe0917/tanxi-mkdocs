# 常八公贊（集韋陶詩）
```
题：[26世/廉258]祈山派孫耀偀謹題
峕：[]
初始点校：[20260916]民国庚辰本[1/33]P126
修订参考：[20260916]光绪甲辰B本[1/3]p0034
修订参考：[20260916]乾隆丁未B本[6/6]P3835
```

赫矣我祖，實宗之光。
旣令厥德，映懷圭璋。
天子我監，車服有常。
賜命建伯，瞻仰靡荒。
八政始食，誰將遐征。
我嘉我慶，作使上京。
王事靡寕，四牡翔翔。
和風清穆，揮兹一觴。
旣耉致位，允搆斯堂。
慶流于裔，厥族以昌。

祈山派孫耀偀謹題
