# 祈山裏房祭典記
```
题：[22世/恩991]祀孫元炳謹書
峕：[16修]康熙廿四年乙丑仲春吉旦
初始点校：[20250416]民国庚辰本[1/33]P077
修订参考：[]
```

從來有廟必有祭，然欲祭垂不朽，必須建祭產以爲久遠之計。故譜中載有祀產、祭田與倡始繼述之中，非具文也。

本房昔年原將圭坑盤山嶺下俊五公所置以祀文五公之田，祖爲備祭之需，與會龍派各拍一半。我祈山上下臺門又各一半，分定春秋二祭。

至洪武丙戌（无此年号，疑为顺治丙戌1646），下臺門裏外二房又各一半，分定各祭一年。本房祭凈餘租，積累生放，置買前方田四十四秤，庶幾粢盛潔而犧牲備。孰意合門公訟，此項祭田己費。

至順治己丑（1649），圭坑之田又遭洪水，二處咸歸鳥有。同事者各賠己資，勉强擔塞而已。

丙申年（1656），祭期在邇，費用無着。我先考澹如府君會同各房兄弟叔姪德龍、思緯、思愼、完仲等三十七人，欣然捐資，共成會典。除供祭祀外，一應餘銀、租穀、田契、會簿俱交思愼收藏生放，受買廿六都六保吳由成田六十秤，土名落潭頭；又受廿七都六保田廿四和，土名塔塘。會典旣成，庶幾備物備儀，享神惠於不替焉。

詎期康熙甲寅之歲（1674），山賊竊發，焚掠地方，會簿契券俱付丙丁。

至乙卯季（1675）春，又輪値祭，共會者束手無措。於是老成家長咸舉克遇、克鑑、元蘓、元鵬、元炳、元煜六人共司其事，清查舊帳，整飭經理。

至康熙庚申年（1680），受買廿七都六保土名於大塢田五十稱；甲子年，又受本都十保土名深塘下田十，且備置五事以供俎豆之需，另做戸口以圖悠遠之慮。

茲因輯修家乘，炳承同事六人囑余撰記，以垂不朽，以示後人云。

旹：康熙廿四年乙丑仲春吉旦

祀孫 元炳謹書
