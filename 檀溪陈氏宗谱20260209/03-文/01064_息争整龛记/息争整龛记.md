# 息爭整龕記
```
题：[21世/建601]第二十四世祈山派建六百一鄉進士光顓謹誌。
峕：[21修]乾隆二十九年歲次甲申正月穀日。
初始点校：[20250307]民国庚辰本[1/33]-p064
修订参考：[]
```

余謁家廟，每見先世神位，左昭右穆，秩然有序；考妣相依，儼然如生。雖未敢曰能格先神，竊不勝其謹敬而如在也。

顧雍正乙卯，猝聞考妣神龕有析分左右之舉，頓覺令人駭然驚而惶然懼也。乃旣而省之，徐而覈之，彼亦挨次序列，無他咎耳。而族衆則以非出先祖之遺訓，羣焉不遵所分矣。數旬之內，宗廟之中，諠譁不寧，爭端雜出。氣性柔弱者，則欲抱主回家，而使考妣同居；氣性剛勁者，則欲帶械入祠，而以猛施爭鬭。

嗚呼！此誠不察尊祖敬宗、敦宗睦族之道也。

抑思先祖之創譜也，非所以萃渙散、立宗法而敦萬代之誼乎？其建祠也，非所以安先靈、序昭穆而定尊卑之分乎？然則與族人質事，豈可如此其躁妄也耶？顓生也晚，急望前輩之賢能入祠而救止矣。

乃昔者溯流尋源，則有先祖學諭公之節要，不許亂宗；及有先祖俊五公之嚴論，而大宗小宗之法、世居地里之名；更有彦道公之定說、克敏公之詳辨也。今也乖宗法、忤昭穆，誰爲發一言、費一詞，而不袖手旁觀者乎？

吁！祠內如此，宗人渙散，先靈不安，豈不釀成大患，且貽笑江州與白沙也哉？

於是顓懷恐懼，想祖宗作譜之心，思祖宗建祠之意，而目擊夫乖宗忤族之狀，輒欲痛發慟哭之聲，而姑强陳和悅之語。偕族內叔姪兄弟等入廟，便便竭力勸和，不分左右，定議修飭神主。而族之長幼尊卑，無不欣然樂循。自是爭端始息，存沒安康，庶不負祖德宗功也矣。

明年乾隆丙辰，整修神主。顓也適遭丁母之憂，不能效力公堂，而諸兄弟從事者，巳別誌之，茲不復贅。

今者纂輯家乘，余同校閱。因念事闕尊祖敬宗、敦宗睦族，不可不記。若謁廟感格而善爲繼述，更有望於後之賢子孫也。是爲照情實序。

## 简体标点

余谒家庙，每见先世神位，左昭右穆，秩然有序，考妣相依，俨然如生。虽未敢曰能格先神，窃不胜其谨敬而如在也。

顾雍正乙卯（1735），猝闻考妣神龛有析分左右之举，顿觉令人骇然惊，而惶然惧也。乃既而省之，徐而核之，彼亦挨次序列，无他咎耳。而族众则以非出先祖之遗训，群焉不遵所分矣。数旬之内，宗庙之中，喧哗不宁，争端杂出。气性柔弱者则欲抱主回家，而使考妣同居；气性刚劲者则欲带械入祠，而以猛施争斗。

呜呼！此诚不察尊祖敬宗、敦宗睦族之道也。

抑思先祖
之创谱也，非所以萃涣散、立宗法而敦万代之谊乎？
其建祠也，非所以安先灵、序昭穆而定尊卑之分乎？
然则与族人质事，岂可如此其躁妄也耶？颛生也晚，急望前辈之贤能入祠而救止矣。

乃昔者溯流寻源，则有先祖学谕公之《节要》，不许乱宗；及有先祖俊五公\ref{陈珪}之严论，而大宗小宗之法、世居地里之名，更有彦道公之定说、[[陈克敏|克敏公]]之详辨也。今也乖宗法、忤昭穆，谁为发一言、费一词而不袖手旁观者乎？

吁！祠内如此，宗人涣散，先灵不安，岂不酿成大患，且贻笑江州与白沙也哉？

于是颛怀恐惧，想祖宗作谱之心，思祖宗建祠之意，而目击夫乖宗忤族之状，辄欲痛发恸哭之声，而姑强陈和悦之语，偕族內叔侄兄弟等入庙，便便竭力劝和，不分左右，定议修饬神主。而族之长幼尊卑，无不欣然乐循。自是争端始息，存没安康，庶不负祖德宗功也矣。

明年乾隆丙辰（1736），整修神主，颛也适遭丁母之忧，不能效力公堂，而诸兄弟从事者已别志之，兹不复赘。

今者纂辑家乘，余同校阅，因念事关尊祖敬宗、敦宗睦族，不可不记。若谒庙感格而善为继述，更有望于后之贤子孙也。是为照情实序。
