# 家乘異議
```
题：[12世/]第十二世孫山西按察司僉事石阜潼謹誌
峕：[04修]洪武庚辰冬十一月中浣之吉
初始点校：[]乾隆丁未本[1/1]p210
修订参考：[]民国庚辰本[4/33]p432
```

禮無古今之異，而俗有古今之别者，何也？

後之人不知古有家有國者，毎匕與古人宗法相反，遂至百宗，蕩析而莫之尋究源委，間有妄委其姓而冐人戸貫，或妄以戸貫而亂其宗族，何止於託漢壻而冐姓劉，狄種朱邾而附李膺籍也。至於無嗣絕續，而欲立繼者，又不本聖人同宗爲後之正典，乃字育螟蛉耶，非族類，或取妻之黨，或取女之出，或以他族苗裔，或以他姓奼孕，爲已所出。

葢鄫人立莒、郭氏立柴、賈氏立韓、李氏傳王、秦政本不韋、宋蒼梧木李道兒之類，又有若漢鬼之歆祀、司馬之牛眷，意其得於荒茫，遺棄而陰爲曖昧者也。

凡若此者，非惟閭閻[^1]編伍為，然在縉紳宦族之間，盖總匕如也，此無他，非有高見卓識乃自立斬絶之道，以混僞之所爲也。

又有以弟爲子，以子爲孫，位姪於叔之上，班叔於姪之下，不復省名分，不復顧服制，往匕降爲氓隸、爲戎閫，而不知愧赧，甚至父母見存、兄第尚總角，且出入同堂，而互相殘賊、婚娶，不相助患難，不相恤，或競利而懷詆毀，或好勝而務爭鬬。

若此者，遜順之風何在焉？禮讓之習何在焉？於是遞相倣效，雖族黨皆然，皓首諸父而見憎於少年之子弟，華鬘庶姪恥屈節於妙齡之叔父，家匕自為俗，人匕自爲法，雖聖人與居不能化而入也，等而上之異於此者。

若張公藝九世同居，相與忍為雍睦。江州陳氏七百口，廣席長幼以次坐共食。樊重三世共財，子孫朝夕禮敬，常若公家。楊播緦服百口同爨，昆季相視如父子。劉君良屢世同居，共庖兄弟至四從皆如同氣。李昉子孫数世至二百餘口，猶同居其炊，田園俸祿皆聚一庫，計口日給。蔡郭泰兄葵軓，公祿賞賜皆入兄庫，如有所資皆請於兄，不敢專行。

凡此數者，是皆天理良心之所固有，所以知重其本而恪，遵乎宗法者也。夫如是又何古人之不及哉。

吾家宗譜，高祖作之，曾祖纘之，雖不能如古人之盡美盡善，然尊祖之意，豈外是耶。所以述兹異議於篇次云。

洪武庚辰冬十一月中浣之吉

第十二世孫，山西按察司僉事，石阜潼，謹誌。

[^1]: 闾阎，音lǘyán，意思是原指古代里巷内外的门，后泛指平民老百姓。出自《史记·列传·李斯列传》“李斯以闾阎历诸侯，入事秦。”
