# 平湖承百四十一稱承六三公祭田簿注辨

```
题：[25世/聰1720]第六世孫現謹誌
峕：[]旹嘉慶十六年夏五月朔日
初始点校：[20250510]民国庚辰本[4/33]p428

```

高高祖承百四十一公舊有祭田八斗，在墳前溪北寺嶺背上者，是既爲祭田，又作案山，適墓而望，血食即在眼前，天然湊合，可謂二幷。好事者往徃（往）述青囊家以盤龍呼穴，以關揚刀名其田。云是田也，不知當日公之所自爲歟？抑高曾之繼志歟？顧年遠不可考。

嘗憶少時與清明祭，六七世之子孫不下四五十家，而奉祀而飲福不數人耳。曷有爲分，曷爲無分？其故何歟？

席長告余曰：「此剝果蒙泉也，汝其聽之。自雍正時，以造公廳乏資，衆議是田押元孫某，而孫利租息，數贖固拒，公轉爲私，多歷年所，廢祀之痛其何能已？因質於庭，斷贖完祭，惟汝祖首任其事。今之有分者，以公無餘資，前後兩次取由若曹之先人出己橐以相助也。是以值祭者於秋取其租，取租者來春備其祭，與祭者頒胙獎其功。奈田不易名而實如會然。余聞之始恠（怪），而其議之未恕，何不捐忿以鳩族乎？夫以雲仍甚衆而掃墓者寥寥，先靈有知，不其愴然？《禮》曰：『綴之以食而弗殊，一臠之細，不念舊可也。』」

既而思之，又曰：「惟士無田，則亦不祭。曩者咸吝其資，不推私以贖公，則嘆鬼之餒者，幾與若敖[^1]等，而何有於胙？故無分者無分，惟有分者爲有分，夫亦可以深長思矣。」

今年春，有以乾隆十八年祭議一紙示余者，然後知席長所告不誣也。

嗚呼！考之譜牒，自公之卒於今幾二百年矣，而是田之動搖而復固者，非徒舊德之永，亦賴乎當事者之力持其正也。凡而後裔終當效之，爰以弁譜簿。
