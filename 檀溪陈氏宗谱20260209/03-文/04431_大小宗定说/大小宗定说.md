# 大宗小宗定說
```
题：[12世/忠2]第十二世孫彥道謹誌
峕：[06修]洪武己卯春三月中
初始点校：[]乾隆丁未本[1/1]p220
修订参考：[]民国庚辰本[4/33]p431
```

立宗之法莫盛於三代，尤莫備於三代，故諸侯卿大夫，生有宗死有廟，皆得以識其先而不絕。不幸罹於秦火，不見於前經，而幸出於漢儒雜記之書。學者藉此而得以考識其遺意，其綱領大畧見大傳小記，其變禮條目見曽子問答，其他見曲禮內則喪服傳文王世子王制等諸篇。但其文有殘缺、事有變更，可不講訂以明之乎。

按禮經，謂别子為始祖大宗子是也，是以繼別爲大宗，匕其爲始祖，後者爲不遷之祖也，謂禰爲小宗子，是以繼禰爲小宗，匕其為高祖，之後謂禰者五世則遷之宗也。

諸侯嫡子嫡孫常繼世爲君，自第二而下，諸子不得禰先君，而别立正嫡，皆稱别子。其後
子孫爲卿大夫，不敢祖諸侯，必立此别子爲始祖，而别子之世嫡，則常繼此别子之正統，以立始祖之祭，與族人爲宗，爲其所尊宗，故謂大宗子。

雖五世之外，與之絕服者，亦皆爲服，齊衰三月，其妻亦同，雖婦人不敢降此之謂，百世不遷之宗，其别子之庶子，又不得禰别/子，而自使其世嫡子後以主世子之分，與兄弟爲宗，謂之小宗子。

旁例而降，其第一世繼禰，第二世繼祖，第三世繼曾祖，第四世繼高祖，皆謂相繼之小宗。繼禰小宗爲親兄弟所宗，爲服期年。繼祖小宗而同堂兄弟所宗，爲服大功九月。繼曾祖小宗為再從兄弟所宗，爲服小功五月。繼高祖小宗爲三從兄弟所宗，為服緦麻三月。

自高祖五世之外，則無服。祖遷於下而宗易於上，是為五世，則遷之。宗雖别子兄弟五人，其爲宗法皆然，更百世未嘗絕，何以見之，雖貧賤富貴不等，必不以同姓之知識者，互通婚姻。

此大小宗法之意之畧。如此其在宗婦族婦亦然。吁，舉天下無二理，通天下無二法。奈之何，俗有美惡，世有盛衰，不能與古禮合轍同途。為是故耳。

今吾家世系流傳，雖不敢效古先聖王，而其立宗傳嗣之法，正吾子孫事耳，何慕效爲哉。因書以俟後之賢子孫，繼承勿替。

洪武己卯春三月中。

第十二世孫，彥道，謹誌。
