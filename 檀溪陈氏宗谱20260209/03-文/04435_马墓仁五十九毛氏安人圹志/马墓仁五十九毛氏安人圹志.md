# 馬墓仁五十九毛氏安人壙誌
```
题：[]太平府府通判外弟趙儒臣謹撰
峕：[]
初始点校：[20260824]民国庚辰本[4/33]P435
修订参考：[]
```


安人自出名門，適歸巨族。其在室也，蘭資蕙質。年十八，配吾妻兄諱世觀，字守光，行仁五十九府君。躬勤組紃，無忝中饋。時嘉靖戊子，鄉遇平米之變，岳父子美公赴驅奔馳，安人竭力奉事，繼姑定省甘旨，內言不聞。越數年，翁夫相繼而亡。丁亥居值回祿，次年戊子孀姑辭世。雖屢歷多艱，而衣衾棺槨之類，盡禮罔缺。安人衣惟稿素，饘止薤鹽。子二人：長震亨，次臨亨。安人享壽八十而終。辛酉之冬，安葬於廿八都土名後陽，扦作酉山卯向。適余解冠之暇，一表姪乞予誌銘。予在明館時常聞其椒德，義不敢辭，為之銘曰：

安人之德兮，洑水所鍾；  
安人之行兮，植溪所宗。  
享壽耄耋兮，其生也隆；  
厝斯靈地兮，其死也榮。  
作此以後昆兮，萬世無窮；  
羨此以興美族兮，比屋可封。

太平府府通判外弟趙儒臣謹撰
