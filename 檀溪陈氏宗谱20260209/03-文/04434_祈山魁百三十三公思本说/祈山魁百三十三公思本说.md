# 祈山魁百三十三公思本說[[陈廷谱]]
```
题：[18世/賢151]姪昌言識
```

嘗謂本之為用大矣：有身之本，有家之本，有國與天下之本。析而言之，雖各有自；約而言之，同本於身。故孟子以守身為所守之本，以事親為所事之本。

愧自世道壞而風氣日偷，教本之思不復見（於）天下也久矣。吾族諱廷譜者，篤實人也，而其號曰「思本」。家世良善，兄弟友愛，和氣萃於一堂，令聞著於鄉邑。其心以為：
物本於天，則敬天以守一身之正，于是慎之以言，敏之以行，而順時以求衣食者，因地之利而無貪得之心也；
人本乎祖，則敬祖以考生本之源，於是謹治家法，珍重遺文，而隨塚立碑以垂不朽者，祭祀以時而存孝思之念也。

噫！公之以「思本」為號，其於重本之說，固名稱其實而無愧者矣。是爲說。

姪昌言識
