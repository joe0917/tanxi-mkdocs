# 宗兄陳士策先生六旬壽序
```
题：[]單級教教授畢業生宗弟錦堂拜撰
峕：[]民國十五年歲次丙寅仲春月
初始点校：[20260825]民国庚辰本[4/33]P444
修订参考：[]
```

蓋聞厚德克載厥福，至行必獲大年。勞於始者逸於終，寒於前者享於後。此揚厲之行，克勉於己，然後福壽之報，錫之自天。如我宗兄士策先生者，姓陳氏，字國楨，天資英敏，定卜蜚聲上達。惜乎洪楊亂後，家境中落，先生遂棄士力農。於耕耘之暇，參究醫卜星相等書，確有心得。言醫，盡明虛實寒熱，補瀉溫涼得法；言地理，深究山川美惡，進退取吉避凶；言命理，細研旺相休咎，五行生尅，與人各異，新法無殊時室明燈。其彰彰在人耳目間者，非一日矣。

淑配傅孺人，嫻姻儀而勤紡織，有從有德，事舅姑，訓子女，鄉咸稱其賢。子三人：長長庄，次乾生，幼金生，各勤各職，皆奉先生義方之訓者也。余假館於此已五次矣，課讀之暇，日與先生談論，知之稔矣。今適值六旬攬揆之辰，敢不揣謭陋，謹為壽言。先生其將對孝谿綾筆諸勝，撚鬚浮一大白而許之也否？是為序。

民國十五年歲次丙寅仲春月  
單級教教授畢業生宗弟錦堂拜撰
