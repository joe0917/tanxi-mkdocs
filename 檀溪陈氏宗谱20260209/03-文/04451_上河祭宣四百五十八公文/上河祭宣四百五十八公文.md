# 上河祭宣四百五十八公文
```
题：[]年家眷弟趙嵩等
峕：[]康熙六十一年孟冬月望
初始点校：[20260825]民国庚辰本[4/33]P451
修订参考：[]
```

康熙六十一年孟冬月望越五日，年家眷弟趙嵩、黃德銈、趙崇惠、於一求、張範、趙必仕、鍾守坦、季朝元等，謹以牲酌庶羞、冥資束帛之儀，致祭於皇清待贈文學殷翁陳先生之靈曰：

惟公之生，太邱之裔。天姿英敏，勤學篤志。澤被鄉邦，持躬以禮。年幼失怙，家業倍蓰。長遊庠序，遵訓守己。孝事萱堂，亙古無比。宜其令嗣英奇，早策名於天府；鳳誥龍章，拭目待之。無何昊天不弔，遽奪天年。論公之年，未登上壽；而公之行，必裕後昆。覩孫子之聰俊，知後先之輝映。公在九泉，亦復何恨？

予等親炙有年，登公之堂，想公之素，接公之容，令人悵怏而不能已矣。嗚呼！傷哲人之遽逝，淚淋浪兮莫禁。生芻一束兮聊表微情，惟靈有知兮庶其鑑臨。哀哉尚饗！
