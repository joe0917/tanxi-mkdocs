# 山干宣千百六十八公捐田立牌位記
```
题：[27世/延130]祈山派姪孫邑庠生 思謹誌
峕：[24修]嘉慶十三年歲次戊辰孟冬之吉
初始点校：[20250415]民国庚辰本[1/33]p069
修订参考：[]
```

我族之制，重功德，崇節孝，特立牌位，春秋享祭，給胙，禮有嘉隆。凡賢子孫之樂尊崇其祖父，其或捐錢，或助田，以爲尙齒養賢資，使其先人得與饗乎春秋時祭，其用意爲尤厚。

顧捐例之設，舊有成規。錢以三十兩爲至輕，田以三十秤爲極少。縱極貧之家，有志樂輸，不得破格狥情，所以隆祀典、遵舊制也。

今丁卯修輯譜牒，間有喜捐樂助者，例不得輸田立牌。有山干派名以樑者，年六十四嵗，决意助田入祠，爲乃父宣千百六十八公諱之桁立牌位一座，向理祠人請焉。

謂自少孤苦，年八歲而父殁，十一歲而母氏又謝世，窮而無告，何苦如之。少長能自食其力，勤儉自持，漸次積累。數十年閒（間），僅得數十金，而年已五十六矣，（）不得娶。乃受田二十秤，身已老病，親鄰無依。卽有斯田，吾父其能血食乎？此所以於助田立牌位爲斤斤也。

是舉也，其志則甚可嘉，其心則深可憫，而其事則更有難處者。田二十秤，於例不符。一允斯誼，不幾褻祀典而違舊制乎？其何以免合族之議，而禁後人之不接踵也？然余謂必執一見，亦甚不情。今世俗所稱孝子者，不過服勞奉養而已，安有若斯之自幼至老，艱苦備嘗，稍稍積累而不忘先人之血食者乎？

於是嘉其志，憫其心，以共成此舉。凡族之樂尊其祖父者，卽貧而有志，其貧諒不若斯之甚，其志諒不若斯之專，又何得視此爲例也？同事者遂乃釋然於心，爲之破格。卽所助田入養賢條，另洋錢五元爲置牌及收冊費，并交董事人手。余甚幸斯舉之得以有成也，爰據其實而爲之記。

峕：嘉慶十三年歲次戊辰孟冬之吉

祈山派姪孫邑庠生 思謹誌
