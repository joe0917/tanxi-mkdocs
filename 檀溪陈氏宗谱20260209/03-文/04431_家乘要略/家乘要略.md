# 家乘要畧
```
题：[13世/常11]第十三世孫，文，謹誌
峕：[07修]正統丁巳仲夏吉旦
初始点校：[]乾隆丁未本[1/1]p100
修订参考：[]民国庚辰本[4/33]p431
```
吾氏之先肇自周封舜後胡公滿於陳，子孫以國為氏，歷世不易者也，備見《源流節要》。

此而重輯是譜，不敢再述，姑以始遷今居之祖諱碩者，由烏程來，實天聖攺元初也，其地曰車方，其鄉曰政內，其里曰新田。有車方氏人，皆以車方氏稱之。

於是時，碩贅方家，生子唐，唐生頊，皆從方姓。

頊生五子。曰祺，曰彦，曰遹，追宗陳姓，子孫不下百餘指衆，因稱爲車方陳氏。

曰臧，徙居諸暨白門方，從方姓，稱爲白門方氏。

曰逸，徙居桐廬下石阜，亦從方姓，相為下石阜方氏。

嗚呼，彼二族者，入彼版圖，自不能歸宗復姓，非吾故外之者，識者韙之，而又鄙之。韙之者褒其族盛也，鄙之者貶其昧宗也。至若随時隱顯、與世推移，不特前時烏程然也，以今吾族之譜，亦無忝於先世簪纓族也。

吾嘗念之桐廬、諸暨二族，倘能復姓有日，故以譜書携往質之，使之錄為副本，以偹考訂。不意彼遭延燎所，及併失吾譜，是以不能不痛恨也。

文思近年以來，日就衰朽，深懼愈久而愈失傳。謀諸族衆，遂因舊式，重新如舊，是輯是續，俾子孫寶藏於家。庶幾不忘先德也，用是錄諸。

峕：正統丁巳仲夏吉旦。

第十三世孫，文，謹誌。
