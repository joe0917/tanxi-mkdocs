# 重整神座位次建上祖碑亭墳靣祭臺記
```
题：[23世/宣58]廿三世上河派宣五十八歲貢生之環謹誌
峕：[20修]乾隆丙寅冬月吉旦
初始点校：[20250414]民国庚辰本[1/33]P063
修订参考：[]
```

嘗聞太上立德，其次立功，其次立言。環蓋自慚無用，不能有一，惟於祖先宗族諸凡重大之事，每爲留心一二。此亦吾徒分內切己之事也。

是以生平以來，嘗從諸君子後。

自康熙辛巳、甲午，至雍正己酉，重修宗譜，一再至三；又嘗會集合族賢能元敏、啓緒、啓承、之松等，於乾隆丙辰、丁巳，議搆祠中神座，重整位次：左昭右穆，自上而下，分世代，定尊卑，續送神主入祠，排列次第，字異行同，合而爲一；查年月，序長幼，創立遠代墓祭，補竪未有石碑；又於乙丑重建始祖墓坊，再造二世墳面等事。

乃通族照丁均抖，或動支祠內公資。環與諸君子等，未嘗多費己資，不過跋涉奔走，竭力贊成而已，豈敢自鳴得意哉？上承祖志，下啓後昆，亦稍慰萬一云爾。

當時創首傳柬會衆立議，環與之芳同心協力，搆造油漆。備料督工，以智一人始終勤勞；合行查齒，以純一身獨任其事。洗查神主，排整前後，有行無主，總開牌位；之儒、以驕、以珙、光繁諸人之力居多。創立墓祭，補豎石碑，修砌祭臺，收租値祭，之芳一己之事；重建墓坊，再造墳面，掌理祠賬，成璧、啓岱、光灝等六人之功。至建議主持，竭力盡心，環不敢他諉矣。

事開繼述，諸賢任事之功不可冺没。以是爲記。

乾隆丙寅冬月吉旦 

廿三世上河派宣五十八歲貢生之環謹誌
