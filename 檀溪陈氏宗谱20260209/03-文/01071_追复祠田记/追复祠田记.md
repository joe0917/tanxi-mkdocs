# 追復祠田記
```
题：[26世/廉258]祈山派雨田氏耀偀謹撰
峕：[24修]嘉慶十三年歲次戊辰長至月
初始点校：[20250227]民国庚辰本[1/33]P071
修订参考：[]
```

吾族宗祠之有田，自德大、國興、光行、君餘諸公樂輸始。而矢志廉介，節省勤勞，以式廓丕基者，則又賴於族祖汝吉、裕後二人。因年老不耐煩。劇鳴族繕單，議人值理。至於今，闔族乃稱道弗衰。

厥後風化日隆，仁人孝子接踵而迭出，莫不爭助資產以敦孝友。多者嘗至數十畞，少者亦不下十畞數。或恤老，或優賢，或以供粢盛，輯廊宇秩然，藹然之思浸淫成俗矣。然而肥磽遠邇，勢不得不惟券爲憑，轉移接受者又不獲習焉。而後代夫是以拾遺於其間，遂久假而惡知非有也。

惟族弟榮彥不忍以宗族之事度外置之，乃嘗按諸譜牒，履其畞坵，知某者爲某之所置，某者爲某之所捐，與同志以文、以言、以科、祖愇、祖性、祖琢、祖諤等，家諭（喻）而戶曉之。昧其由來者皆幡然悔悟，署券輸租，祠益豐盈之慶，而人無詛呪之言。諸君子之以善服人，又可知矣。

且夫“人惟患其弗誠，誠則無弗動；事惟患其弗公，公則無弗悅”。彼擅吾祠之產以爲己業有年所矣，今以數人之力成反璧之功，而得以明目張膽，毅然弗懼者，豈非恃無他腸也哉？

嗚呼！苟終身以之，則詩人所云“孝思不匱，永錫爾類”，其在《易》曰：“直方大，不習无不利”。吾將爲諸君子誦之。

今以修輯將竣，値理光芹、紹孝、宗惠等囑英曰：“追田之功勿可没焉，必識於譜以垂後”。斯言誠是也。

夫靡不有初，鮮克有終，古聖危之。吾族之不惜饒腴，慨焉樂助，正欲其相傳於勿替。而不有諸君子者克繼夫始作之心，又何勿名存而實亡？則諸君子之爲與德大、汝吉諸公爭烈矣。

是爲記。

峕：嘉慶十三年歲次戊辰長至月

祈山派雨田氏耀偀謹撰
