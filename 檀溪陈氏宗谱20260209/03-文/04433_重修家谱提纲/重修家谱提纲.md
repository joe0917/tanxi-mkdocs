# 重修家譜提綱
```
题：[16世/厚67]第十六世孫祐謹誌
峕：[08修]正德乙亥孟冬之吉
初始点校：[20250310]乾隆丁未本[1/1]p104
修订参考：[]民国庚辰本[4/33]p433
```

今之家譜，卽古大宗小宗之法，所以叙天倫、繫人心、别親疎、序昭穆、敦禮教者也。

君子無志於古，則己苟有志於古，不於此而用心，惡乎，用心耶。

凡人於饑渴，皆思乎飲食；於居處，皆思乎廬室；於服御，皆思乎裘葛、車馬。至於家，猶不思夫譜牒乎。

嗚呼，吾深有慮焉，恒切切以立家廟，修家譜爲中心妄想。

嘗捧先人所遺舊譜觀之，殊覺與古人立法之意頗相背戾，乃取正學方先生[^1]《宗儀》讀之，恍然有契於心。故以譜書持徃諸曁豐江，以質於東明周立夫氏。

東明迎而喜曰：志惡在？

吾應之曰：欲訂輯是譜也。

東明曰：輯譜焉用質。

吾曰：欲倣豫章黃文節公，七世以上不知者不書之例，斷自陳碩公，可據之祖爲始，以上無知者不錄，所錄有知行第而不知諱字者，則缺以傳疑，不知可乎否？欲倣歐陽文忠公，取法史氏年表，以世爲經，以人爲緯，界爲五世，譜圖上系於下為元孫，下推以上為高祖，使五服宗親舉目可識，又不知可乎否？又以宋太史作譜之法，其諱大書，而行字細書於下，而生卒、葬娶、遺文，亦類入焉，又不知可乎否？

東明曰：倣黃文節公不失於誣，倣歐陽文忠公不失於野，倣宋太史不失於畧。三法備矣，其例不同，其世次則皆可考也。

予依此，遂編成帙，然非作譜專門，未免闕畧，兹特述其世次而已，尚俟四方碩儒文以美之，俾予子孫嗣而續之。庶幾可以序天倫、繫人心、别親疎、敦禮教。所謂先王之遺意不於斯可見耶，使天下之有家者，能法古人立宗傳嗣之意，則風俗一變，而先王之世，抑豈終不可得而見乎。

某頗有志於譜，故述其言以為提綱云。

旹：正德乙亥孟冬之吉。
第十六世孫祐[[陈宗贞]]謹誌。

[^1]: 指方孝孺(1357～1402)。明初理学家。字希直，又字希古，号逊志，人称正学先生，浙江宁海人。燕王朱棣(即明成祖)兵入京师即位后，被逮下狱。因不肯为其草拟即位诏书，磔死，株连10族。他还认为，“圣功”自“小学”始，“化民”自“正家”始，并作《幼仪》20首、《宗仪》9篇，以为规范。
