# 陳氏家乘引
```
题：[]諸暨南郭居士，前刑部尚書，黃鄰，贈
峕：[06修]洪武戌寅秋八月
初始点校：[]乾隆丁未本[1/1]p208
修订参考：[]民国庚辰本[4/33]p423
```

余與浦江彥道陳先生為忘年友，予自謝政歸養息於南郭書舍而，彦道介其友楊亷夫來請予述家乘引，且彦道與予為相知最深厚者，素識其顛末奚容，寢黙於言。

按陳氏之先，始自虞胡公滿，受封於陳，子孫以國爲氏，厥後分泒四方，不勝繁夥，歴世旣久，所以埀不朽者，以其有世系爲之表證，故其所傳不絕如綫，斷自諱碩者，爲始遷浦江不祧之祖也，已上諸祖，或顯或隱，見之譜遺源流，而今譜不詳世次，謂踈遠難势使然也。然而相因之禮不得妄意刪去，又文乘中僅存者採收入譜附以遺文爲証，卽其實也。大抵今之受姓保氏，孰非黃虞以來錫土分祚哉，顧在於自立何如耳。

昔穆叔答范宣子曰：“太上立德，其次立功，其次立言”[^1]。以彦道之先世，觀之若宣侯、靖侯諸先輩，佩服仁義，動皆有則，德之立也；出爲時用，致君澤民，功之立也；發爲文草，雅有程式，言之立也。嗣是而後，若彦道者，知其先世德、功、言，皆有所則效，而表見於世用，以出守寧國，著聲朝野，是亦立德、立功、立言之可嘉羡者也。

《傳》曰：公侯之子孫，必復其始[^2]。吾於浦江車方陳彦道有證焉。

旹：洪武戌寅秋八月

諸暨南郭居士，前刑部尚書，黃鄰，贈。

[^1]: 源自《左传·襄公二十四年》
[^2]: 源自《左传.鲁闵公元年》
