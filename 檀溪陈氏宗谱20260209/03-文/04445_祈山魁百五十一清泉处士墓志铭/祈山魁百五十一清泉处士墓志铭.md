# 祈山魁百五十一清泉處士墓誌銘
```
题：[]任福建永福縣幕事愚甥潘思齊頓首拜撰
峕：[13修]萬歷甲辰季冬月
初始点校：[20260825]民国庚辰本[4/33]P445
修订参考：[]
```

公諱廷簠，字時用，號清泉。秉性淳樸，周慎處己，於伯仲多肫懇，推而族黨任恤之事，種種難以枚舉。至論其智識，則不事焯耀而自超；其資業，則不事過求而自裕。雅好詩書，不求聞達，方古潁陽之流，殆不是過。厥配合溪黃氏，靜一其性，言笑不苟，規助雞鳴，善事舅姑，益有以徵公刑于之化。邑大夫屢有鄉飲之徵，固辭勿就，成公以冠帶遺之，娶非公志也。享壽七十有七。萬歷甲辰，厥嗣仕昶奉柩葬於葛山之原，與安人黃氏同窀穸焉。

余在襁褓，就育舅氏家，而親承其花萼，耳濡目染，藹乎咸有盛德也。茲昶弟以志銘見囑，余愧謭陋，何能為文？然而其懿德之實，則不容以不揚者。乃從而銘之曰：

鴻飛遵陸，公歸不復。埋玉藏龍，葛山之麓。卜爾雲礽，桂槐芬馥。萬有千年，煇煌斯谷。

萬歷甲辰季冬月
任福建永福縣幕事愚甥潘思齊頓首拜撰
