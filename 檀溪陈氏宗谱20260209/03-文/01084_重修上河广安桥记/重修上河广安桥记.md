# 重修上河廣安橋記
```
题：[27世/延1172]平湖貢生蘆洲氏仲鴻識
峕：[31修]光緒六年庚辰之冬
初始点校：[20250416]民国庚辰本[1/33]p084
修订参考：[]
```

同治甲子，橋之東一首洞下靣被圮，本可小修完美，當以賊擾民困未蘇，因敢舉事。幸留上半洞尚可，奈因循數年，倒塌殉盡。叨胆者扶欄而跨，謹守者莫之敢步，望洋之歎，遍念舊德垂危矣。

迨光緒丁丑，祖奎公之嫡孫宗塏、祖啟公之堂孫宗生，憫先人之舊業，不可坐視傾頹，理應鼎承先澤，邀集同事中遵等，力向遙邇勸捐，鳩工鞭石，矢補天之志，成集腋之裘。費約千纏（緡），功成再造，逾年而修整如故。善哉！

今歲值修家乘，塏以前哲碑記刊譜。予撫而讀之，洵乎，前有乃祖兄弟為之倡，茲有慈弟弟兄以為之繼，庶幾鞏固遐昌，其不負吾家之難兄難弟耶？
