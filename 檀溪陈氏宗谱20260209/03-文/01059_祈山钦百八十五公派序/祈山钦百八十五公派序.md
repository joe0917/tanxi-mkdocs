# 祈山欽百八十五公派序[[陈大绅]]
```
题：[23世/宣525]祀孫啟緒謹識
峕：[19修]雍正七年，歲次己酉桂秋月
初始点校：[20250414]民国庚辰本[1/33]P059
修订参考：[]
```

歲己酉，緒倡修宗譜，合族敦請名師張氏庠生，字爾占者，予男女姻親也。

自春徂秋，業將殺青，顧謂緒曰：
「親翁家世，僕得諸父老素矣。聞高祖[[陈大绅|伯佩公]]，幼失怙恃，年未冠，嶄然崢嶸，臨事不減孟說，治生自合陶朱。迄令觀其農桑蓄牧之址，儼乎有祖宗器宇。

曾祖德施公，幼而岐嶷，長而穎悟，屢試冬烘，不求聞達。創華居以聚族，建橋梁以濟人，立廟不吝資財，訓子延請名師。逢難拯溺，遇荒賑饑，居宰慕其行，優以嘉賓；郡守聞其賢，給匾旌獎。生丈夫子三，俱弱冠採芹。

孟思誠公，遊學四方，名著江南；
仲思晉公，懷韓宏之逸才，似靈運之雅興；
季思偕公（恩242），容質修偉，博學能文，訓子義方，蘭桂盈堦。
長君遇公，雖屬早世，若其子心，廣令兄者，名重鄉邦，黌宮薦（）。溘逝之日，縉紳先生，弔軸填門，其殆不足於令伯者，取償於令兄與？
次完仲公，篤志芸窻，早入官牆，不事奢華，不趨勢利，邦之司直，至今膾炙人口。
三勝千公，博極羣書，輕世肆志；
五君泰公，舉止端方，言詞不苟，博古通今，善於文墨，與冢嗣心周相繼為鄉飲賓；
六君餘公，勇敢有為，樂善好施，壽過古稀，精神矍鑠，交遊皆賢士，親戚盡縉紳。子屬成均，孫叨黌序。
幼係太翁昭庵公，襁褓失怙恃，仲兄以成立，雅愛詩書，身立儒林，開前人之基址，拓腴田之廣茂，創祭產、葬先塋。

兼之親翁與令弟俱卓卓有譽揚。何五世以來，獨無傳贊？且殷富已久，豈無高曾所遺賢田祭產，應載入譜？」
余應之曰：「唯唯。祖父無傳贊，先人蓋有達見焉，緒何敢妄贅？若祭產賢田，徵親翁言，已脫稿久矣。」
因出稿示之，竊翁乃曰：
「即以今日之所言者，為歷世傳，且以作賢祭田引，不亦可乎？」遂執梨棗而欲梓焉。緒謹載筆而誌之，並將賢祭產列於左。

雍正七年，歲次己酉桂秋月。
祀孫啟緒謹識。
