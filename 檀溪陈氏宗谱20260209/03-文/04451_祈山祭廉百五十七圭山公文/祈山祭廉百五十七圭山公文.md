# 祈山祭廉百五十七圭山公文
```
题：[]眷姻弟周璠頓首拜撰
峕：[23修]嘉慶三年戊午孟夏月有七日
初始点校：[20260825]民国庚辰本[4/33]P451
修订参考：[]
```

夫何懷耿心之不能下兮，酒日夜其消之。惟行路之恢難兮，閨門高枕其又奚辭？升高入下之胥非吾願兮，竊悲夫前已覆而後者尤馳。孰不雞鳴而競起兮，孰認為善則孳孳？心不知翁之訓翁也，癡兮與不嘉，惟翁自細。皆曰予智，彼何人斯？羌情懷之莫達兮，明鏡忽自寫其鬚眉。急命酒以酬之兮，醪又化為糟。固方圓之難周兮，形與影豈云可持？閔迷離以寂處兮，壽算原不卜乎期頤。飄六翮乎仙矣，探洞府兮驂雲螭。挹浮邱兮拍洪厓，酒中有倦兮睡者希夷。嗟浮生之無樂兮，猶抑鬱其告誰？惟冥遊之浩蕩兮，倏山巔而水湄。陟降庭兮酒滿卮，酌言嘗兮聽我諫詞。惟我知翁兮，譜不支。爾子爾孫兮，懷而慕思。

嘉慶三年戊午孟夏月有七日
眷姻弟周璠頓首拜撰
