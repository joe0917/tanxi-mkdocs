# 第1修(1193)
```
修谱年份：宋·紹熈癸丑(1193)
主修谱人：（6世）[[陈珝]]、提举公一遇
```
修谱名衔：[[奕世修谱名衔录#1-宋紹熙癸丑一修（1193）]]

## 概述

按照“修谱名衔录”记载，“檀溪陈氏家谱”第一次撰写是在南宋绍熙癸丑（公元1133年），由第6世陈珝和陈一遇两位完成。此时距离设定的始祖硕诞辰才133年。撰写者同辈人数（记入家谱）为19人，上辈人数为15人。算是一个小范围的家谱记录，可信度较高，唯一存疑的是，当时采用“写谱”方式，流传到后来（明朝万历年间），家谱有损毁，尤其是第11世陳瑪在《原譜程式》（至正丙申，公元1356年）记载，当时曾带着家谱去桐庐和诸暨，却遭火灾损毁，“不意彼遭延燎所，及併失吾譜”。因此现在看到的“世系”“行传”，是否真实记录了“写谱”原文，有待考究。

前面“源流”中记录，始祖硕从湖州入赘到浦江方家，子孙都随方姓。而到了陈珝（此时应该还是叫方珝）这里，“由起義兵勦收賊盜，擢爲都督府叅軍都事”，家谱未记录陈珝的生卒年月，依据修撰家谱年份（1133年）来看，此时距离宋室南迁（1127年）才6年时间，经历与金国的连年战乱，到1130年金军暂停南侵，总算稍许稳定，可以偏居一隅，称之为“绍兴稳基”。

北宋末年，政治昏腐，1120年爆发“方腊起义”，方腊利用“食菜事魔”教（摩尼教，也是金庸笔下的明教，甚至与后来的明朝都有关联，后续可以专门考证）在浙江发动起义，起义覆盖到了浦江全境，虽然很快（1121年）起义就被镇压（《水浒传》中也有记载），但其影响在民间应该一直持续到后来的明朝。檀溪民间流传“方改陈”就是指方腊后代避难隐居。从时间上来推测也是有一定的可能性。

而到了1125年，金兵南下，地方更为混乱，起义军、盗贼纷起，陈（方）珝应该也是其中一路起义军，或者说甚至是方腊义军的遗留也未可知。后来南宋政局稳定下来后，陈珝归顺了朝廷，成了“都督府叅軍都事”。然后“奏復陳姓”，并修了家谱，家族名字就叫做“车方（檀溪）陈氏”。

宋朝方勺（1066-1142后）的《泊宅编》中有一段关于方腊起义的记录，其中有一句，“……而越州剡縣魔賊仇道人、台州仙居人呂師囊、方嵓山賊陳十四公等皆起兵，略溫台諸縣。”[^1-1]

编撰家谱的另一位是陈一遇。一遇公曾任“淮南提举”[^1-2]，但随着宋室南迁，淮南已经落入金人手中。而陈一遇的父亲陈汝功“初尙宋郡主，稱郡馬，後趙王登位拜封駙馬”，这里的赵王，应该指的是康王赵构，宋徽宗第九子，生于大观元年（1107年），为广平郡王（今河北邯郸），1121年封为康王，1127年靖康之耻后建立南宋，为宋高宗。再看“驸马公”陈汝功的父亲陈遹的出生年份是有记录的，为元豐戊午（公元1078年），在孙子陈一遇编家谱时为56岁。

整理来看，编撰家谱时。陈珝的继父麟38岁，而生父陈胜的父亲（也就是亲生爷爷）琪67岁。而陈一遇的爷爷56岁。此时陈珝已经经历起义军归顺，而陈一遇也已经从淮南提举回到家乡，推测年龄至少有十八九岁了，那么驸马公，也就是陈一遇的父亲至少也有三十岁上下了，而此时皇帝赵构为27岁，作为驸马爷年纪比皇帝岳父还要大，其间必有诸多故事，而那些近乎神话的传说也不在这里讹传。

总结来看，陈珝和陈一遇，作为家谱第一修的作者，未留存其生卒年月，但依据记载的几个年份及相关历史事件来推溯，其实很多记录还是有待商榷的。而在家谱初次编撰时已经有不少“派系”分支形成。各“不传”[^1-3]派系世系图及其行传不再祥列，必要时采用采用“世系分析图”[^1-4]来指示流传情况。

[^1-1]: 引自晚清葛元煦的《啸园丛书》，其中《泊宅编》为3卷本。
[^1-2]: 宋朝时“提举”为负责贸易的官员。提举本身是指管理的意思。
[^1-3]: 指没有流传至今，或者各种原因子孙没有记入这个家谱，比如迁居异地等。
[^1-4]: 世系分析图采用graphviz软件制作而成，主要用于各派系世系分析，及纠正流传刊误。需查询详细信息可查阅对应的原谱书世系图以及行传、行状等，为区分原“世系图”，改名为“世系分析图”。

### 20250429补充
在《富春上馆陈氏宗谱（民国七年）》中查到“都事公珝”的生卒年月为“宋宣和七年乙巳（1125），八月十四日申時。卒宋湻熙十四年丁未（1187），十月廿一日巳時”。同时又发现之前对第1修的撰写年份转公元时出错了，不是1133年（那是绍兴癸丑），而是1193年。但是又发现一个严重问题，就是无论是1133年还是1193年，“都事公珝”都不可能参与撰修。

另外可以不用去考证的就是方珝和方腊的关系了，因为方腊事件的时候方珝还未出生。而需要考证的是方珝行传记录“由起義兵勦收賊盜”中的“起义兵”和“贼盗”到底是指什么事件？

另外需要考证的是靖康年间浦江发生了什么？第3世陈顼（上馆谱中有诰命写的是陈顼而非方顼）是进士，又封了大夫（宣议大夫，未找到具体爵位）但是英年早逝，肯定是官宦人家，五个儿子，大儿子陈祺（琪）自然也是官身，按照上馆谱陈祺的生卒为1067-1126，卒年为靖康元年，他们兄弟五人应该都经历了方腊事件和金国入侵北宋灭亡。可能就是在这动乱时期纷纷外迁隐居。

# 第2修(1204)
```
修谱年份：宋·嘉泰甲子(1204)
主修谱人：（8世）文五公雄
```
修谱名衔：[[奕世修谱名衔录#2-宋嘉泰甲子一修（1204）]]

## 概述

陈珝的儿子陈颖，宦绩记载“由鄉貢進士元符戊寅授國子監學錄”，元符戊寅为公元1098年，这个时间与前面出入较大（过早了）。

行传中关于第8世文四公的记载出入更大，“元至正丙辰鄉試式中舉人”，并没有这个年份，元“至正”为元朝末年了，更不符合了。

陈颖的儿子陈雄，文五公，修嘉泰甲子（1204年）修的家谱，为第二修。距离他爷爷陈珝修的第一修已经有71年。

根据世系分析图的分析结果来看，后面有延续的为陈珝、陈雄的“车方祖宅”、驸马公的“檀石”和陈麒的“墙下”三派。其余没有延续至今或者散佚外地的单独列“不传派系”简要说明，不再详列世系。而续传三派在内纪二中分别列世系图，其中，“墙下”派陈珪一支传至13世，也不再详列，而陈玘一支则后来发展到“柯溪”一派，因此改为“柯溪”；“驸马汝功一派到曾孙陈根（文一公）和陈公举（文四公）分别分为“檀石前宅”和“檀石后宅”两支。因此后续陈述分为车方、柯溪、前宅、后宅4个派系。

```
修谱年份：宋·寳祐丙辰(1256)
主修谱人：（9世）登三公應紀
```
修谱名衔：[[奕世修谱名衔录#3-宋寶祐丙辰一修（1256）]]

## 概述

车方文五公陈雄有三子，都在教育系统任职，登一公陈元恺在武义县任学录[^3-1]，登二公陈元德在永康县任学正[^3-2]，登三公陈应纪在永康县任学谕[^3-3]。学正和学录类似现在学校里的教务处，而学谕则为教学的老师。

陈应纪修撰家谱为1256年，已经到了南宋末年了。距离其曾祖陈珝初次编撰（1133年）已经有过了123年了。陈应纪写了《源流节要》，考证了从唐陈融到始祖陈硕这段源流，但考证出自哪里未做记录。作为“学谕”的他相较前面两次撰修，应该更为严谨了，因此后续修谱均以这个“源流”作为肇始的说法。

[^3-1]: 学录：“太学录”省称，与太学正同掌学规，纠不遵学规的学生，并掌供给等事，正九品官。《中国历代职官别名大辞典》
[^3-2]: 学正：“太学正”省称。与太学录同掌学规、纠不如法者，为正九品官。《中国历代职官别名大辞典》
[^3-3]: 学谕：“宗学谕”略称，宗学训谕之官。也称“宗谕”或者“谕”《中国历代职官别名大辞典》

# 第4修(1356)
```
修谱年份：元·至正丙申(1356)
主修谱人：（11世）俊四公玛、俊五公珪
```
修谱名衔：[[奕世修谱名衔录#4-元元貞丙申一修（1356）]]

## 概述

乾隆丁未本中“修谱名衔录”中记载为“元貞丙申”，实际按撰文推断应为“至正丙申”，后面进行世系讲述时也做了相关推断。

前面几世人物均缺生卒年月，到了陈珪有了详细记录，生于元延祐丙辰（1316年），卒於武洪甲子（1384年）。问题又来了，第四次修撰的日期为元贞丙申（1296年），修撰时主修人还未出生。而《原譜程式》的作成年份为至正丙申（1356年），作者为陈玛，写成时弟弟陈珪为40岁。这两个日期较为符合。可以推断“修谱名衔录”中的修谱日期（年号）记载错误了，正确的应该是与《原譜程式》一样，同为至正丙申。

俊四陈玛写了《原譜程式》，仍居车方。

俊五陈珪写了《姓氏异同说》，后来迁居到了会龙，为会龙派始祖。

陈沣的哥哥，斌一公陈沄，生卒年不详。其一家相当凄惨。家谱引用了（哪一修引用待考）县志记载，并说明连省志都记载了（事載府縣并省誌）。具体参见“人物简传”。大致内容是：

陈沄在洪武年间，去南京科考的时候死了，儿子陈厚还在襁褓中，妻子毛氏也才19岁，独自将儿子抚养长大。陈厚娶了张氏，生了个儿子陈现。结果洪武丁卯（1387年，洪武20年），陈现刚满月，陈厚也死了。此时张氏才17岁，这样婆婆媳妇两个女人带着陈现生活。同样的命运发生两次，尤其是对于毛氏其痛苦可想而知。

所幸，陈现平安无事长大成人，娶了个老婆姓董。不料命运真是会开玩笑。永乐癸未（1403年），董氏怀孕五个月，陈现又死了。祖孙三代人都英年早逝，无法看着孩子长大。董氏生下一个儿子，取名陈莹，小名直接叫“遗腹”了。靠着给人“纺织”艰难度日，宗族乡邻看她家可怜，想尽量接济她，都被她婉拒谢绝了。三代女强人啊。（毛氏享寿61，张氏享寿68，董氏享寿71）

前面已经“三重打击”了，还没完。

遗腹陈莹10岁时，得了小儿麻痹无法走路，在床上躺了五年。母亲董氏看着儿子病情无法好转，崩溃到了极点。焚香祷告，愿一命换一命，拿自己的命换儿子的命！原文祷告词是这样的：“陳氏三世寡守以存祀，僅畱此一點血，倘天譴夙愆，願降罰吾身以贖此”。

这时，不得不相信天命了，或者说神灵了。如果是前面的三次打击是天意弄人，那后面再来一次可能天神都要看不下去了。

于是上天终于回心转意，给了董氏一个奇迹。等董氏祷告完，陈莹突然有如神助自己站了起来，能正常行走了。

董氏原本就是出身书香门第，于是教育儿子陈莹长大成才。

陈莹不负母亲厚望，长大后虽没有说飞黄腾达，但是至少改善了家庭困难，还当了粮长（不是官，帮助政府收粮的负责人）。娶了两房老婆，生了6个儿子，3个女儿。

陈沄这一支后来发展起来就是现在会龙桥的陈氏。

而陈沣迁居到了祈山上台门，也就是现在寺前上台门。

修谱名衔：[[奕世修谱名衔录#11-明嘉靖甲子一修（1564）]]

## 概述
这是平粮后的第一次修谱，由平粮的核心人物陈昌言主持，也写了序。

陈昌言的序堪称谱序的范文。如果语文课本有“谱序”这个类别，那这篇肯定可以编入教材。内容包括家谱编修的意义、本家家谱背景、写谱的思路、修订內容与方法、结论与展望几个方面，结构明晰，文句工整。

而这一修另一项文学成就就是“檀溪八景诗”，由[[张元中]]写序，[[张元谕]]写诗，诗是写给檀溪渔隐[[陈仕行]]的。陈仕行与陈昌言同辈份，但是比他大了19岁，他们一同参与了平粮，可能一起跪过衙门一起蹲过大狱，一起经历过劫难。一个是耗尽了大半生的家财富贵，一个是葬送了后半生的仕途前程。修谱时陈仕行已过世，陈昌言邀请“大家”写诗文以纪念这位“难友”的高光时刻。

而张元谕虽为嘉靖二十六年丁未科进士，但仕途并非一帆风顺，而更羡慕“隐君子”，专心创作诗词歌赋，研究哲理人性，后来他创作的《詹詹集》和《篷底浮谈》主要就是关于这些方面。

这一修有一个疑点，就是为什么“大名鼎鼎”的平粮一号人物陈九经没有参与修谱？他在哪里？他在干什么？

## 概述
这是明朝灭亡前的最后一次修谱，修谱完成时，明朝进入最后一个皇帝年号崇祯元年。陈克敏接过父亲陈尚睿的接力棒，开始主修家谱。另一个原因也是陈克敏在“举业”遭受了挫折，“丁卯嵗，不肖敏適遭題石之厄”，“後學敏因狀龍橋府君而波及之”，因此潜心研究家谱（那个年代除了科举其他可拿得出手研究的可能也只有家谱了）。对檀溪陈氏的“源流”，“地里”进行深入考察，加之早年（1617）刚好在谱中所说檀溪陈氏的来迁地湖州乌程（今吴兴）游学，也做了实地田野调察。因此借着修谱说明一下自己的考察结果。实际结果并没有像常十一公在地7修时那样获得了“圆满成功”，也没有与当地陈姓对接上。甚至对发源于乌程的说法产生了一些质疑。

为本修写序的是义门郑氏的郑崇岳，义门郑氏从明初洪武时期的显赫，到建文时期的郑洽达到高潮，但永乐帝的入主让其家族一下子跌下神坛，甚至为了明哲保身，直接将郑洽彻底削出族谱。而其家族更是在后来的嘉靖朝平粮事件中因飞洒而受到玷污而衰败。这一切到了[[郑宗岱]]手里总算有了改观，而到其孙子[[郑崇岳]]，更有了重振家族的气势。义门郑氏家谱现有样貌就是成型于郑崇岳时期的修订。

## 概述
这是改朝换代后的第一次修谱。距离上次修谱已过去整整三十年。
经历了十余年的战争，“家牒先型盡属祖龍一炬”，好不容易创刻的刻本型板荡然无存，只得依据印本和万历抄本重新雕刻。此时距离清朝入主中原（1644）才十余年，能够重新修谱已经相当不容易了。

但也有可能是“和平”解放了明朝中原地区。因为万历后的明朝实在太腐败了，对于这样的一个严重腐败朝廷的覆灭，百姓很坦然，甚至有些窃喜。

随着朝代变更，家族的管理团队也开始发生转变。之后祠长房长功能逐渐弱化，而逐渐出现“家长”的概念。祠长、房长是有管理实权，选的是德高望重者，有时甚至还得到县府的授权，有一定的治理裁判权限，祠长需要对家族兴盛负责。而家长仅仅是一个名誉符号，选族中辈分最高者中年龄最大者为家长。家长无任何管理职责。

# 第16修(1684)-祠堂重修
```
修谱年份：清·康熙甲子(1684)
主修谱人：（21世）[[陈鼎新]]，（22世）[[陈元和]]、
```
修谱名衔：[[奕世修谱名衔录#16-清康熙甲子一修（1684）]]

## 概述
三藩之乱后，经历了十年的修整。

这一修有两篇序。
先考证了第一篇：陈子贞请王庭写的一篇。陈元和（1630-？），号子贞，是[[陈大纲]]的曾孙，爷爷陈尚懋是[[陈大纲]]的幼子。陈元和在嘉兴檇李这个地方行医，后来就定居嘉兴。王庭（1607-1698）是檇李本地人，曾经在山西任布政使，写序时（1684）已经77岁了，应该已经退休养老了，估计是经常请陈子贞看病，然后认识了，修家谱陈子贞就请老先生写了这篇序。
看来还是渔隐公家族。

再看第二篇序。是月山（今石姆岭下）毛文佳写的一篇骈文。内容纯粹是一篇赞颂美文。

时间进入清朝的“康乾盛世”。这修家谱的规模也是空前的，总计印了22部[^16-1]，后续的版本基本以这修为蓝本。写了很多人物传记，有族内人写的，也有很多外族亲人所写。

该修的“祠长”是[[陈鼎新]]。因抗击“白寇”有功[^16-2]，而被任命为乡正。
此时族内势力由明朝中期嘉靖年间的“会龙派”陈九经家族到中后期“祈山派”陈仕行家族，转到了“平湖派”陈鼎新家族。但不长久。

1674年，甲寅三藩之乱，祠堂又被毁于一旦。在这一修又重新修葺。

# 第28修(1847)
```
修谱年份：清·道光丁未(1847)
主修谱人：（26世）[[陈荣杖]]
```
修谱名衔：[[奕世修谱名衔录#28-淸道光廿七年丁未第二十八修（1847）]]

## 概述
待
公众号“朱能作 | 一篇骈文：“元方将车，季方执杖”
引言
​
骈文，又称“四六文”，因其晦涩难懂而常遭现代文人唾弃。但骈文对仗工整，有诗歌之美。而且擅长引经据典，堪称历史文学。古人在教授文字同时又能讲授经典，从历史典故中吸取经验，在名家故事中传诵德行。

例如文中“宰天下亦如此”和“大丈夫安事斯”两个典故，一个说的是管村镇管的好，将来志在管天下，而另一个是说不愿扫屋室，却说要扫天下。以历史典故教育“做好基础”、“扫好屋室”。因此，骈文也并非一无是处，有其存在的历史价值。

《家谱》第28修中的这篇序文实际就是一篇骈文。粗读晦涩难懂，而细究则寓意匪浅。就像诗歌，如果强凑字数韵调，容易形式主义。而神来灵感与顿悟，才能成就一座兼具哲学与美学的文字宝库。

引用文中一句话，“元方將車，季方執杖”，文学数学，哲学科学，各司其职，有礼有节有内容。
