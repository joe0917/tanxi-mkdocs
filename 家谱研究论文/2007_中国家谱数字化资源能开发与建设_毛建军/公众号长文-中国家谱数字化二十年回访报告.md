# 二十年后回访：那篇论文里的家谱数据库，现在都怎么样了

**——把《中国家谱数字化资源的开发与建设》里点名的项目逐个查一遍**

2025年12月29日，上海长乐路746号，一栋青灰色小楼重新开门。八十多年前，这里是私立合众图书馆；现在，门牌上写着上海图书馆家谱馆。开馆当天，73岁的童海坤代表家族捐出《上海童家浜童氏宗谱》，他说得很实在：把谱捐给上图，以后大家在网上都能方便查到。

"在网上能查到"，这句话在2007年还需要论证。

那年1月，《档案与建设》刊登了毛建军的《中国家谱数字化资源的开发与建设》。他把当时全国家谱数字化的家底盘了一遍：谁建了什么库、收了多少条、怎么检索。收尾的判断相当克制——家谱数字化的开发和建设，"还比较滞后"。

近二十年过去，这篇稿子做两件事：把论文里点过名的项目逐个回访；再把这十年新长出来的项目列一遍。

## 一、2007年的家谱数字化版图

论文给出的坐标大致是这样：

| 项目 | 当时的规模 |
| --- | --- |
| 上海图书馆"家谱书目查询" | 书目17041条，馆藏约17000种、11万余册 |
| 国家图书馆"地方志家谱书目" | 1990年设"地方志与家谱文献中心"，当时收录3086种 |
| 台湾地区家谱联合目录 | 十余家收藏单位联合建设，始建2002年 |
| 各省级、市级馆书目库 | 山东、安徽、浙江、福建、广东、四川、无锡、金华、泉州等地各建各的 |
| 《中国谱牒库》（爱如生） | 选自先秦至民国的历代典籍1万余种、16万余卷 |

用今天的尺度衡量，这些数字并不大。上图是全球收藏中国家谱原件最多的公藏机构，那一年挂在网上的书目是一万七千条；国图的家谱书目停在几千种；福建省图书馆把90多部PDF扫描件放上网、要求读者下载Acrobat Reader阅读，已经算"服务性开发"的样板。

论文里有一句话值得记住：这些家谱库"多数缺少在线链接软件，没有人名、地名、名词数据库"，读者检索起来很困难。

## 二、回访：那些项目现在怎么样了

| 项目 | 2007年 | 现在 |
| --- | --- | --- |
| 上海图书馆家谱 | 书目17041条 | 家谱近4万种、38万余册、567个姓氏；"中国家谱知识服务平台"收录10万余种，书目数据来自全球630家收藏机构，其中7千多种可在线查阅全文；2025年12月家谱馆在长乐路746号对外开放 |
| 国家图书馆 | "地方志家谱书目"3086种 | 家谱实体藏量5741种（截至2024年12月）；2011年"中华寻根网"上线，提供500多个姓氏源流、2000多部家谱和6000种其他文献；2016年"中华古籍资源库"把家谱列为子库，2021年11月起免登录阅览 |
| 《中国谱牒库》（爱如生） | 1万余种、16万余卷 | 家谱扩至3.8万余种，连同年谱、仕谱、日谱合计约5万种；截至2025年12月，全球机构用户27家 |
| 台湾地区家谱联合目录 | 1.4万余条书目 | 汇整近3万笔；2004年取得美国犹他家谱学会授权，把近800卷缩微胶卷、约9000种家谱数字化 |
| 各省市馆书目库 | 各自为战 | 多数停更或不再维护，资源陆续并入联合目录、古籍平台 |

回访结果里最明显的是分化。上图把书目做成了数据和知识服务，国图把家谱并进了全国性的古籍平台；另一边，当年那批省市馆的自建书目库，如今还能正常打开的不多。论文作者担心的"收藏分散"，二十年里靠联合目录解掉了一半，另一半卡在数据标准上。

## 三、近十年长出来的新项目

**公藏机构的平台化。** 2016年，上海图书馆上线"中国家谱知识服务平台"，把家谱里的姓氏、人、地、时、事抽出来建成人名规范库、历史纪年表、地理名词表，用关联数据对外开放，是全国公共图书馆界第一个这类服务；到2025年，上图的开放数据里光是家谱原文就有14625种。2021年元旦，上图与市民政局合作开通"上海传承家谱家训服务平台"，从117个姓氏里筛出248条家训家规，婚姻登记现场就能查。2022年，东馆四楼的家谱馆开放。国家图书馆这边，2016年9月28日"中华古籍资源库"开通，2021年11月实现免登录阅览，总量约10万部（件），家谱是其中的子库，寻根网也已并入。

**侨务口径的寻根平台。** 泉州"南洋华裔族群寻根谒祖综合服务平台"已征集族谱1万余册，完成40万页数字化录入，正在用AI识别加速；涉侨标志性建筑的3D影像采集了12800个点位。2025年4月时，"潮汕家园"入驻海内外社团商会310家，注册用户超过8万人。2025年5月，福建推出首个基于大模型的地方文史、侨史应用平台"侨脉智联"，输入线索关键词就能完成族谱和人物关系的匹配。浙江温州瓯海区则推出"侨谱"应用，做家族谱牒的电子化服务。

**对台与两岸。** 中国闽台缘博物馆正在建设"闽台寻根溯源服务交流中心"，2025年获捐一套AKF手机族谱查询系统，收录电子族谱5万余册、300多个姓氏、44765个分支谱、500多万条记录；馆藏谱牒涉及两岸21个省市、172个姓氏、2720部10420册。近3年，台胞到馆查询族谱的需求量增长3倍。

**学术界的"数据化"。** 中国人民大学等团队建起中国族谱数据库（CGDB），流程是"版面分析—OCR识别—大模型结构化提取"。目前已收录数字化家谱86005册，覆盖8000余个宗族，全部完成后预计包含超过8000万人口信息。团队已经用这批数据画出中国过去一万年的人口寿命变迁曲线。

**商业与民间。** 族谱网这类修谱平台把录入、世系建模、智能排版、云端存储、PDF导出做成一条流水线，AI识别、疑难字库、宗法错误校验都进了工具条，批量导入、多人协作、一键出谱书都能在线完成。民间力量同步入场：宁波励双杰的思绥草堂、常州家谱馆、中国民协中华谱牒文化研究基地，以及各姓氏宗亲会自己的修谱群。

## 四、三个变化，和三个还没解决的问题

变化有三条。关键词从"书目数据"换成了"OCR""大模型""知识图谱"；形态从单馆自建换成了联合目录加开放数据，上图一个平台就连着全球630家机构；定位从研究工具扩展成了公共服务，寻根问祖、侨务工作、文旅体验、学术研究都要用。

没解决的也有三条。数据标准不统一、接口不通，联合目录能告诉你"有什么"，很多谱却"看不到全文"；一批数据库建成后长期不更新，访问入口失效；家谱里写着在世族人的信息，开放到什么尺度，至今没有一把统一的尺子。

你家那本老谱，现在是在樟脑味里躺着，还是已经被谁录进了电脑？

如果知道自家谱藏在哪儿，不妨在留言里说一句是哪个馆——也许有人正沿着同一条线，往你家祖上的方向找。
