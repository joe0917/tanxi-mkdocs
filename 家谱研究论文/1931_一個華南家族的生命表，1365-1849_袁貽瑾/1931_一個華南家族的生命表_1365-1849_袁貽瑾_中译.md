#### 引言

对欧美家族所做的谱系学研究——其中尤以卡尔·皮尔逊（K. Pearson）与 A. G. 贝尔（A. G. Bell）的工作为著——表明：此类研究能够反映出这些家族所属人群在死亡与生育方面的一般趋势。贝尔在其对海德（Hyde）家族谱系的研究中，为这一现象给出了颇具说服力的解释。他指出，海德家族第七代的子孙，其血统中只有 1/64 承自其始祖，而 63/64 则来自因婚姻而进入海德家族的新血统。因此他断定：海德家族数以千计的后裔所构成的，是全国一般人群的一个样本，而不是某个特定家族的样本——因为家族特征本应会在后者身上显现出来。

中国的谱系记录（族谱），大概是可供利用的唯一一类统计数据，足以为阐明中国民族过去的人口生命变动（vital movements）问题提供线索。中国直到 1914 年才建立出生、死亡与婚姻的现代登记制度，而且即使在各大城市，此项工作也从未令人满意地推行过。然而，遍及全国的、记录家族世系的这一古老传统，却已忠诚地沿袭了数百年之久。通常，由宗族负责对其成员进行定期登记，

> \* 本文为约翰斯·霍普金斯大学卫生与公共卫生学院生物统计系论文第 135 号。作者对洛厄尔·J. 里德（Lowell J. Reed）博士在本研究全过程中给予的指导，以及在研究方法上提出的批评与建议，深表谢意。

#### 资料来源

本研究据以立论的族谱，系北平协和医学院（Peiping Union Medical College）卫生学系（Department of Hygiene）的同事李廷安（Ting-an Li）慷慨赠与。它属于广州附近中山县的一个华南家族。其始祖于十三世纪后期自广东省北部边界一带迁来；此后，该家族便一直居住在这一地区。与中国大多数农村人口的情形相仿，这些人大概以务农为主要职业。该地区气候属亚热带性质，土地肥沃，因而生活较中国其他多数地区相对来得容易。

这份记录中最早的完整记载，记有第四代始祖生于 1365 年。自此以后，记录连续不断地记载了其后十九代人的家族簿记，直至 1914 年。

由于本研究只涉及死亡的年龄分布，故只需说明这部分数据是如何取得的便已足够。每个人的死亡年龄，是以其死亡年份与出生年份之差作为其死亡年龄。并未尝试把年龄推算到最后一个生日的精确程度。这样做看来已足够准确，因为此处所处理的全部死亡者均为二十岁及以上，且随后按其死亡年龄以五岁为一组归入各组频数。

#### 研究方法

为求得不同时期的死亡年龄分布，首先按出生年份将各人排序，然后归入 1365—1599 年、1600—1699 年两个时期，以及自 1700 至 1849 年间按半世纪划分的各时期。随后，以五岁年龄组编制各时期人口的死亡年龄频数分布。这样一来，便为 1365 至 1849 年间各个不同时期编制了若干死亡表，给出按五岁年龄间隔的死亡频数分布。因此，每张表实质上是对在某一若干年期间内出生者所作的追踪，其本质即生命表中的 d_x 栏，只不过死亡是每五年记录一次，而不是每年一次。于是可写为：

```
   生命极限
     Σ d_x = l_x
     x
```

以及

```
₅q_x = (l_x − l_{x+5}) / l_x ;
```

#### 1800—1849 年两性死亡总数的调整

由于最后一次家族人口清点是在 1914 年进行的，1800 至 1849 年间出生的男女所记录的死亡数，包含了全部在六十五岁以下死亡的人，但对活到六十五岁及以上者则必然缺少一部分。这就解释了——如表 1 与表 2 所示——为何 1800 至 1849 年期间六十五岁及以上年龄组的死亡比例，比其他任何时期都要低得多。为补足 1800—1849 年缺失的这部分死亡数，作如下假定：

```
   1800—1849 年 65 岁及以上死亡数
   ──────────────────────────────
   1800—1849 年 20—64 岁死亡数

        1750—1799 年 65 岁及以上死亡数
   =  ──────────────────────────────
        1750—1799 年 20—64 岁死亡数
```

于是，由表 1 可得，1800 至 1849 年男性六十五岁及以上的调整死亡数

```
= 316/710 × 1109 = 494
```

因此，1800 至 1849 年男性二十岁及以上的调整死亡数

```
= 1109 + 494 = 1603
```

同理，由表 2 可得，1800 至 1849 年女性二十岁及以上的调整死亡数

```
= 923 + 418/621 × 923 = 1544
```

依据这些调整后的死亡数，二十至六十四岁各年龄组的 ₅q_x 值也按性别作了相应调整。至于六十五岁及以上的各年龄组，则采用 1750 至 1799 年期间相应的 ₅q_x 值，因为前已假定两个时期中六十五岁及以上的死亡总数是按比例分布的。这些调整后的数值列于表 15。
