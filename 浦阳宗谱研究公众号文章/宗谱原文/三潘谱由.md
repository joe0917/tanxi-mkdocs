# 三潘譜由
```
题：[]裔孫通直郎昌悅書
峕：[]咸淳六年仲冬月長至日
初始点校：[20250702]《浦阳华墙潘氏宗谱》
修订参考：[]
```

吾潘氏世家滎陽，葢因王室寖弱，侯國愈強，由是散居海內。若晉之潘岳、潘京，唐之潘師正、潘孟陽，雖其所生異里，而皆榮（滎）陽氏之分派。然自吾宗評之，亦由滎陽而遷河內，後因遷爲上谷守，遂籍於斯。遷之曾孫岳爲河陽令，子孫有居河陽者。厥後裔孫才爲廣宗藩鎭，子孫大都居廣宗者尢衆。

才之後永仁爲杭州刺史，永仁之子炳，煬帝大業間監江都倉。蕭銑稱帝江陵，而炳又徙吾浙之括蒼。至周時，有諱晧者自括之婺，有兄監婺酒稅，元白公無子，見山水之秀，遂卜居焉。皓生有四子：璨、璘、玠、瓘。

以次子璘出繼與兄元白公，仕周居大名，後子孫美爲勳戚，侍駕居開封。至和國公正夫避地，仍家婺城，是爲貴潘。長子璨之後宗禮居蘭溪，其孫杲登大觀三年進士第，歴官光祿大卿，以廉介自持，不合於時，退處安静，卒貧困而死，閭里呼爲淸潘。

三子玠之後宗簡居婺城七寶寺後，其孫良貴登政和五年榜眼，剛介節操，朱子稱其出入三朝，在官不過八百六十餘日，所居僅庇風雨，郭外無尺寸之田。經界法行，獨以邱隴計輸帛數尺而已，其淸苦如此，蓋人有所不堪者，而處之超然。高宗嘗有御翰「清潘」二字賜之，今題名府左忠清坊可徵焉。以此二支皆稱淸潘。

四子瓘自婺之括之竹溪，其後宗回、宗說以文學致身，歷宦顯聞，因家饒裕，人呼富潘。此皆其土著之可考者也。他如良能秘書之判九江而跡異鄉者，俱不妄載。

夫三潘先世稱爲望族，貴者聯姻帝室，富者克紹書香，而清則又雲武繩繩，簪纓濟濟，清風亮節，聲名尤屹。三潘雖保同宗，有此三異云。

峕 咸淳六年仲冬月長至日

裔孫通直郎昌悅書
