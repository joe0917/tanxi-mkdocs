# 重修嵩山蔣氏宗譜序
```
题：[]二十二世孫大祿書于忠孝堂
峕：[]萬歷三年乙亥五月下浣之吉
初始点校：[20250823]《浦阳蒋氏宗谱》
修订参考：[]
```

蓋聞譜者，姓名之經緯，昭穆之紀綱，導一本之源流，提九族之總統，實人倫之根蒂，教化之大端也。

吾族自吾祖守善公由湖安吉來遷於浦邑之西臯，迄今二十五世。地以九遷，人以萬計，析居於浦蘭、錢塘之間，枝流蔓衍。譜牒雖存，歲會遼跶，記生之藉，挂十漏五，遂俾倫序失次，因循而未正者，百有餘年。

嘉靖辛酉，二十三世孫洽以錢塘貫領卿薦，來展列祖刺史之墓，大會宗人，遠近咸集，子姓兄弟莫辨仲偕，始傷齒序之失倫，譜牒之曠修也。當時咸以纂輯之事屬諸大祿。祿方失利而歸，銧啚再舉有志未能。

越明年丁卯，宗兄乾中自軍門歸，予始樂有所助，而權輿其事。祿總其綱，中理其目，沿襲舊文，釐正缺誤。五服之親法乎世表，生人之次類乎編年。詢故老之言以究祖宗行事之實，搜敝□之帙以萃祖宗遺翰之傳。復紀嘉言善行以寓勸懲之義，系貫本支，理通竅昧，成一家之私書，為百代之典籍。開卷指掌，真如綱之有綱而萬目井然；若絲之有緒而經徫錯綜不亂也。

然是書也，豈徒以侈族屬之繁、明故奮之風而巳哉？蓋有祖宗之重積，而後有今日之克昌。觀河洛者思禹功，享粒食者思稷德。荷祖宗之福降而弗念厥紹者，非孝孫也。是故觀內省之編，則知祖宗修己之嚴；觀為政要覽，則知祖宗惠民之厚；觀義塾義廩之制，則知祖宗利物之周。居家之理，孝友之兄弟也；配匹之良，忠臣道學之士女也。宏萬化之原以廣嗣續之基，尤積徳於冥冥之中，以為子孫承藉之地。

豊𦬊流波，瓜瓞綿引，放自宋而元而明，亢宗迭出。或以政事遺愛於郡邑，或以文學造士於成均，或以武畧除暴救民，而翊我國家之新運。以至耕者享播穫之利，讀者荷行紫之荣，詵蟄森總累及千億。祖宗德澤之所留品宏且遠矣。

故吾族子孫不患其不□，惟患其不賢。子孫苟賢，雖小而亦大；不賢，雖盛而必衰。稽上世累綬聯簪，依稀五桂，求其子孫之今存者，惟縣尉、提點二公之裔□，則絕續之機固有可淂而繹者矣。

誠能思吾祖之所以興，而拾其所以亡，因其壊而修之，如易之幹蠱；因其善而继之，如詩之繩武。□思之思之，又重思之，□索是書，羡墙祖考，則世德作求，將䆮昌而不可量。續編之筆將封塚，不勝紀矣。

凡我子孫，尚其念諸！尚其念諸！

復列八條于後以明維宗之教。

（八條略）
