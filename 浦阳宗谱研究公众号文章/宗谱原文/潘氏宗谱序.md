# 潘氏宗譜序
```
题：[]濂溪周汝嘉撰
峕：[]崇禎七年嵗在甲戌一陽之月
初始点校：[20250625]《浦阳潘氏宗谱》
修订参考：[]
```

粵稽上古，文教未興，顓蒙未啓，乃結繩以記其事。迨後文盛，國有史乘，家有譜牒。夫譜之取義何也？所以普合一族之誼，而使之昭穆序、長幼明，俾親親尊尊不致於紊而無紀。

若胡頂潘氏，乃河陽邑令岳公之後。有始祖名蕃一者，世居新昌蚊橋，累葉簪纓，繩繩不絕。及有第十世孫全二四諱明、全十七諱荒、全十五諱榮者，鍾情山水，邀遊於浦陽濂溪之源，因見山明水秀，龍虎盤旋，遂舍昌邑而遷居胡頂鄭都之地焉。

然潘氏宗譜迭次未輯，幸有殘缺尚存。族有諱良義，喟然嘆曰："吾家之譜自朱至今未經釐正，歷厯巳久，支派繁衍，昭穆難明。"乃會諸族之賢俊而商議之，拉衆捐資，以爲訂葺之舉，託余秉筆。余不克辭，乃寯其家，叅考舊譜，述其渙散，補其闕略，編成卷帙。先之以譜序，次之以凡例，繼之以系圖，終之以行傳。井井有條，秩秩不紊，長幼有序，次第攸明。披覽之間，朗如懸鏡，俾潘氏子孫永守而不墜，流芳於百世者矣。是爲敘。

峕 崇禎七年嵗在甲戌一陽之月

濂溪周汝嘉撰

第十二世孫良譽、良明重修
