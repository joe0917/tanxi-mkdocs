# 重修浦陽陳氏宗譜序
```
题：[]欽授承德郎任雲南曲靖府通判，石溪陳玉書
峕：[]萬厯二十一年孟春中浣之吉
初始点校：[20250730]《长畈官塘陈氏宗谱》
修订参考：[]
```

嘗謂水之流於地也，有溪有澗，有江有河，其流皆會之於海；木之參於天也，有葉有枝，有條有榦，其榮皆歸之於根。人之生斯世也，有祖有宗，有子有孫，其源皆聚之於譜。譜者何也？普也，普而合之爲一源者也。譜若不修，如水之無源，木之無根，人之無本矣。譜牒之修，其容忽乎？

於是有九世孫曰克元、克鎡者來謁予曰："吾族自虞帝相傳以至于胡公滿，胡公滿傳之于太邱公實，爲潁川長；太邱公傳之于陳上王，陳上王傳至于武帝霸先，霸先傳于長城公，長城公傳之于副使德潤公，德潤公傳之子昌公。公卜居爲嫌故址逼窄，乃遷之於官塘源居焉。上下相繼，其來久矣。譜之失修亦有年矣，再可久乎？"

吾應之曰："汝有志于此，亦尊祖敬宗之意也。但分壞而居，異里而處，或居嚴州，或居吾永康龍窟橋，或分之白沙，住遠人稠，恐難合一。"彼應之曰："合固易矣，但支庶繁衍，難卽就耳。不若各成一帖可也。"予曰："善。"遂命其姪曰仲、曰韶、曰鹏者，參互考訂，編成一帙，持而視予。

予觀之，昭穆分明，尊卑有序，姓字行第井然有條而不紊；先死歸葬，燦然有據而可攷。此真得乎譜之體也。卽命之曰："汝其韜之，毋怠毋忽。雖千百世之上，千百世之下，宗宗祖祖，子子孫孫，不至于爾爲爾，我爲我，相視如途人矣。"

是爲序。

旹萬厯二十一年孟春中浣之吉
