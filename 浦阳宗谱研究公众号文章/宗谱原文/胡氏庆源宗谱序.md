# 胡氏慶源宗譜序
```
题：[]賜進士出身雄州防禦推官東陽六世孫穆頓首拜撰
峕：[]熙寧二年庚戌八月十五日
初始点校：[20250627]《浦阳胡氏宗谱》
修订参考：[]
```

胡氏出於高陽，自窮蟬五世而生虞舜。堯薦之於天，授以天下；舜以天下授禹。禹乃封其子商均於虞，是爲夏賓。其後虞思以女妻夏后少康，佐以中興。及周武王克商，舉舜後得滿而封於陳，終享遐壽，故謚曰胡，子孫因以爲姓。

戰國初有胡行，爲時謀主。行六世孫建，漢渭城令，爲上官氏所陷，妻子北徙安定。建生武威太守平，平生議郎寶，寶生給事中宇，宇生冀縣令從，從生大司徒剛，剛生御史大夫肇，肇生珍，爲侍中光祿勳。珍生侍中司農卿襄。襄元孫超，超生綜。綜少孤，隨母到江東。時孫策領會稽太守，綜年始十四，與孫權讀書。策卒，權爲討虜將軍，以綜爲金胄從事。綜有遠謀，後拜偏將軍兼左執法，官至中書令監，封都卿侯，赤烏二年卒。其子冲嗣，天紀中爲中書令，後仕晉爲尙書郎、吳郡太守，卒於官。有子一人留於吳，吳之有胡氏自冲始也。

冲生鳳，爲晉太傅車騎東陽太守。鳳元孫隆，爲騎校尉。隆裔孫瑜居於江東。瑜弟玖、瑱、玘，瑜子諒、瑱子証，俱唐進士，相繼登第。証自河東從事列爲員外郎，拜兵部尚書，充嶺南節度使，贈左僕射。子孫歸京師，士大夫避亂，始還（或作遷，今改正）吳，居山谷間。雖有英才精識者，不見於世。錢氏爲國百年，取士多用蔭補，以是人不探知經術。

至吾高祖廷評，始家居婺之永康，以詩書敎子孫。曾祖郎中，始命子弟仕進。本朝端拱二年，吾祖登進士第。天聖中，以給事中入權三司使，拜工部侍郎、集賢院學士，知陳州，進刑部。知杭州，加兵部侍郎致仕，遂居於杭，而子孫又天各一方。

鳴呼！先王盛時，事事有紀律，至於族屬，則有宗子之法。使世子之弟爲别子，别子之嫡爲大宗，别子之庶子又不得禰别子，而自使其嫡子爲後，則爲小宗。五世親盡，則爲族人。凡大宗有事，則率族人以佐之。夫如是，則孝友睦婣之風，翕然可見。

自周衰，諸侯相漁獵，而民不遑寧居矣。秦廢井牧，而民始不同，休戚不通有無；漢徙豪傑實關中，民始遷播；二國分枝，而族氏籍裂，民始分南北。五季昏慝，而士大夫不知姓氏所由來者，蓋譜學亡而宗子之法廢也。古者，族人有合宗之道，婚冠吉凶必相告，朔望必相往來，歲時必相會食。迨乎五世親盡而服止，則吉不相慶，㐫不相弔，以其易宗也。今之縉紳，九族之間，親未絕，服未止，相顧如路人，冠壻輙有不相告，告而不相賙，慈順孝弟之風，委然陵夷，則可悲乎！

謹按書傳，乃推胄系之所出而爲之敘，又自高祖而降爲圖於左，庶幾廣親親之道，而存先王之法云。

旹 熙寧二年庚戌八月十五日
