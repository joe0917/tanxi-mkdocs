# 三修譜序
```
题：[]邑庠龍橋陳昌言拜書
峕：[]萬歷丁丑仲冬
初始点校：[20251025]《浦阳李氏宗谱》
修订参考：[]
```

歲在萬歷丙辰，藏修後盧書塾，與吾兄體純帷幄距十五里之遙，時相晤言，稔知李氏之受姓與夫來歷原委、德業門第。卽如宋忠定公諱綱者，忠貞超卓，才德過人，有憂國愛民、經綸天下之志，爲中興名相。嗣後簪纓不絶，代有聞人。

迨十一世元仁公，亦以詞章名世，而靜養時晦。迄五世孫仲善公、仲真公，俱以賢良徵辟，一爲縣守，一爲郡伯，絃歌保障，龍章寵錫，生色靈巖，增輝環溪，是誠繩武先志而光昭令德矣。

今歲李氏重修譜牒，囑予兄而更新之：上闡鼻祖之淵源，中究遷徙之根由，下廣錫類之永善；更新置行列、諱字，凡各十字，使李氏奕禩遵守遞傳，而億萬世不致昧祖掩宗。若夫世遠而名湮没者，從其逸；姓同派無徵者，亦統其所屬焉。他如誥勅、像贊、事實以記忠孝，宦跡、隱逸、耆碩所以備載，示不忘也。至於生卒、娶葬、詩序、遺文、記類具布，使祖德宗功、名賢碩士具在目中，而李氏譜牒足與國史同垂不朽矣。

後之觀是譜者，將油然興孝弟之心，踵先哲之躅，益思所以自立，而不忝名宗巨族之稱也耶？予爲李氏之譜告成，幸而復幸吾兄之有功於譜也。是爲序。

峕萬歷丁丑仲冬

邑庠龍橋陳昌言拜書
