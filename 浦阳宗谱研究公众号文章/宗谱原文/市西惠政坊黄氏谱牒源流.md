# 市西惠政坊黃氏譜牒源流
```
题：[]築巖子邑庠傅旭元識
峕：[]康熙二十九年歲次庚午蒲節 
初始点校：[20250818]《浦阳市西黄氏宗谱》
修订参考：[]
```

市西黃氏宗譜告成，家長世貴同姪國定等揖元而言曰：「黄氏稱江南五大族，今所輯者，惠政坊一派耳，源流未之悉也。願序其概，書之簡首，俾□覽周知，可乎？」

元曰：「黃氏遠而江夏，散而五族，其譜序系圖莫不具在焉，請按而言之：黃氏爲軒轅黃帝之後，陸終氏之裔。陸終氏，軒轅六世孫也，受封於黃。春秋時錫爵分土，而居江夏之區域。屬於齊，後被楚滅，子姓散處，遂以國爲氏，此黃氏始也。」

漢尚書令香，字文强，世居江夏，以孝子稱，而爵秩更顯。當時語曰：「天下無雙，江夏黃。」此黃氏所以稱江夏也。香公生子瓊，爲太守；曾孫琬，爲太尉。傳至苾，字惠卿，隋文帝開皇時徵兗州總管，愛民以恕，律軍以嚴，遷金陵按察軍民大都頭，贅鎭守吳英公女。英公係婺浦陽人，値大業兵亂，翁壻隱歸浦陽鎮家焉，卒葬鎮後黃家墩。此浦陽黃氏自苾祖始也。

大唐上元間，九世孫官著作郎靶（⿰革舟），偕姪皇門侍郎同平章事畦，輯其祖惠卿公遺文，重加彚釐成帙，以爲後考。此黃氏譜牒自靶公與畦公始也。

第一派十有六傳而至縈祖，字天錫，又字吉夫，德行超邁，釣隱雙溪，以壽考終，終葬黃家墩。生二子：長曰洪，洪生三子，珌、瑕、琰，幼曰浩，浩生五子，琛、玘（⿰王㔾）、璞、琬、珍，遭五季變，四散播遷：玘之子曰瞻，挾策於南唐，仕分寧縣伯；琛、珌與父就祿家焉；琬遷福建建寧之浦城；琰與璞遷廣信之弋陽；珍遷湖廣江陵之監利；瑕遷江西豐城之沉岡。此黃氏五大族也，此浦陽縈祖爲江南五大族始祖也。

開元十道圖載黃氏墓。明嘉靖間，海宼侵境，有司請城，適底墓上。萬歷辛亥，浦邑大夫拓城，而黃氏墓出焉。張氏子廣宅欲平之，裔孫黃宗盛、文奎、克昌等具情奔告府道，批存其墓，聲聞五族，咸興仁孝之心，雲集祭拜，各派各□譜牒而來也。此黃氏五大族之系圖譜牒所以俱集於浦陽也。

是歲，□水閣派良容、克昌者，環會五族；而諸暨橫山派宗長文詔、思誠，會義烏派宗達、尚奇等，各助塋資，修輯其墓，勒碑曰：「大唐江南五大族始祖黃縈釣隱君墓。」後順治癸巳，通族設祭，東市、市西、三都、十八都四處輪值。然必統會五族，方明派系。而文奎與思誠等不辭勞倦，周流各族，會其宗譜，細加考訂。此江南五族所以通譜也。

歲癸丑，文奎與其兄文正、文龍、文俊等，延思誠、堯篪與陟門蔣世恩於市西，推其所自：瞻祖生元吉，元吉生中理，官光祿卿，築櫻桃洞、芝臺兩館，來學者多以學問文章名。生五子曰茂宗、曰湻、曰湜、曰注、曰渭，皆有祿位。湻之子向、湜之子昉，兄弟復自分寧來歸浦陽。向生二子曰通、曰敎，通生三子曰偉、曰份、曰仁。偉仕承務郎，由東市遷合溪之長塘，捨二堂書院爲太極宫基，生子曰亶，字信之，生五子曰震、曰石、曰霖、曰零、曰鼎，多以進士起家。零字伯雨，贈迪功郎，生四子：長裳，字元佐，登湻祐間進士，任衢州司戶，置擬范田二百畞以濟族人，土名黃裳隴；植七里向祖墓碑。長夢弼、次夢熊，幼夢睿。伯雨公酬陳公三女俱妻之誼，陳公絕祀，以睿續陳氏嗣，更姓陳。夢睿明經登第，授廸功郎，爲馱水陳祖，見邑誌。夢弼字元寶，登進士，仕西京運幹，生五子：震龍、文龍、仲龍、雲龍、會龍。震龍行文七，號松軒，咸湻丁卯鄉進士，生二子玠、珪。珪行瑞六，號桂山，月泉山長，生三子道隆、道興、道生。道生生三子：逢吉字資善、逢原字資深、逢昌字資文。此合溪三老也，以禮齊家，以義聚族，世稱義門，與麟溪鄭氏、深溪王氏名擅浙河之東。潛溪景廉宋先生作《黃氏義門銘》，又有《三老圖贊》。道隆無子，以逢原爲子。逢原生七子，一女適鄭長史楷，而嗣宿、嗣容、嗣宙俱受學蘇伯衡太史，與方正學有合溪唱和詩。嗣宙行常八，生三子：辰六、辰七、辰八，復自長塘徙市西惠政坊居焉。

辰六公生一子祐，行義七。祐生二子曰恭、曰聰。恭行信一，生三子：長益玉，行正二四，生三子池、旭、富。其後五世孫世朋，就居莘山，世隆遷白石源口石塔塘，與信三公分爲兩大支也。聰行信三，生二子：長永正，幼正二三，出繼沈氏。永正行正一，生二子：行祥一、祥二。此兩支又分也。傳而爲裕，傳而爲禮，傳而爲禮、而爲祈為祐，其福行祿行禧行祚行，世世相傳矣。

黃文獻公潛有云：「圖譜之法，親者宜詳。」又云：「各詳其親。」此市西惠政坊譜牒之所以獨詳也。祥一公分居街西上下堂屋，祥二公得趙、沈氏兩方伯基址，創居焉。祥二公派下禮二公長子文泰，行祈二，生三子：元方、元中、元亨，遷十七都雙溪口何大園。其祐九四之幼子鳳岐，行福三十七，亦同遷焉。祈二九公次子元慰，行祐三十四，生三子：鳳虞、鳳韶、鳳庭，遷居十七都雙溪口巖頭裏。祐九四之長子鳳閣，行福八，與祐二幼子鳳誠，行福廿六，遷雙溪之樓笙。此惠政坊之分派遷居也。

康熙庚午距癸丑，巳越七十八年矣，譜牒不修，莫此爲甚，其能免夫歐陽、眉山之譏乎？族長世貴、房長國定等邀元修輯，遡其源流，序其昭穆，詳其遷居，列其人物，像贊繪焉，藝文錄焉，家範著焉。按系圖，五服九服，昭昭目前也；考行傳，三世百世，厯厯意中也。此市西之所以重修譜牒也。

昔廷堅太史謂七世祖失其譜，而各譜自廷堅太史推之，有至十二世若合符節。蓋自苾祖至惠政坊之禮字行，則爲四十世；至今祚字行，則爲四十六世矣。自縈祖計之，禮字行則爲二十五世；至今祚字行，則爲三十一世矣。然自向祖計之，禮字行則爲十有八世；至今祚字行，則爲二十四世矣。各譜有從苾祖始者，有從縈祖始者，有從向祖始者，而廷堅太史之言，蓋慎之也。此支派之世數，不可不知也。

舊譜分四卷：曰序傳，載各派譜序、傳贊也；曰賢宦，題宦名與宦蹟也，今則逸矣；曰外記，記載各派之圖系并藝文也；曰內記，記市西一派系圖、行傳也。此皆前大通譜之由，而後人不可忽者也。此惠政坊之所以并及各派而俱輯也。

嘗思宗祖一人之身，子孫千萬人之身也；子孫千萬人之身，皆祖宗一人之身也。凡同宗者自同族，凡同族者自同譜。持此譜也，不特浦陽之譜可通，五大族之譜無不可通。何也？五大族之譜序圖系具在也。此不能無望於後之孫子，而通會夫五大族，而續修黃氏宗譜，豈止爲浦江黃氏而言哉？豈止爲惠政坊黃氏而言哉？
