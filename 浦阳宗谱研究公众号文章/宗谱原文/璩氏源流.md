# 璩氏源流
```
题：[]特授文林郎山東同考試官齊東知縣浦江縣儒學訓導湖州嚴炳元撰叙
峕：[]皇清乾隆四十五年庚子春三月朔越二十有八日
初始点校：[20250901]《浦阳璩氏宗谱》
修订参考：[]
```

璩氏始祖名寧，周文王第五十五子也。武王封於蘧，賜姓蘧氏，世爲衛附庸。迨後遽侯爲衛成公所滅而國失。至衛定公時，世子首公入衛為上卿，食采黎陽，即今陕西西安府淳化縣。其孫即伯玉公。傳十四世至漢時，運一良公為西川太守，遂居西川。其子仁公、義公皆官司徒。

至唐時，有望之公歷官西臺御史，羡公歷官祭酒，歡公官侍御史，籌公官河東節度使。其子渺三爰公歷官河北轉運使兼參軍務。江西信州貴溪與閩接境，爰公領兵戍境上，保境息民，民賴以安，遂以功封西川侯，上賜佩玉出入，又名佩玉侯。子晦公、明公、昭公去草從玉，以誌厥美，改蘧為璩，而璩氏自此始矣。

傳至□時，端五□□爲徽州刺史，見休寧山水秀麗，遂卜居於龍邱。□□官尚書，□□公官承議郎，倧公官著作郎，球公官吏部尚書，珍公官兵部侍郎，玖公官刑部郎中，綬公官慶陽刺史，綿公官四川節度使，績公、縉公兄弟御史。其餘科甲相繼，不能盡載。

是時從仕在外者既多，遷居異地者不少。誠一翌公時為東京留守，遂居河南開封府中大街；誠七聳公遷居饒州餘干龍井；誠五祺公徙居杭州忠清里；誠三喆公徙居湖廣岳州西門；誠六玨公徙居建寧浦城南門。

至宋末元初時，復十四愷文公徙蘇州閶門；丙一志學公為江山縣尉，遂居三衢須江邑裏；丙七志道公爲淳安教諭，同弟丙十五志德公遷嚴郡淳安富德源；丙十志哲公遷台郡臨海大田；丙十三志賢公遷廣信貴溪江滸山；丙十九志義公遷紹興山陰灕渚；壽五銑公自江山遷龍游瀔北。

歷仁、義二世，至禮一公、禮二公遷金華蘭谿東山；顯一明卿公自灕渚遷富明坊，歷四世至澄忠公遷金華浦江城内。諸派子孫森森，人文郁郁，皆西（下闕）
璩氏創訂家乘序

家之有譜，所以序族屬、敦倫紀、垂久遠，而勸懲之意默寓其中，實一家之史也。朝廷設左右史以記言動，務在提綱挈領，使千百載下開卷了然。家乘之作，亦此物此志而已矣。

余不佞，忝膺教職。庚子春，璩生德檒、德燃持璩氏源流相示，以撰序請。吾乃今而嘆璩生之憂慮至深且遠也。夫璩氏為衛附庸，閲三十有五世聚族西川，又二十二世而遷休寧，又十三世而徙山陰灕渚，歷二世又自灕渚徙富明坊，又歷三世而澄忠公始遷浦邑。合而計之，由得姓受氏之始逮澄忠公，凡七十有五世。其間風霜兵燹，不知幾更。璩生乃旁搜遠攬而得其詳，使今日者不以譜事爲汲汲，他年支派彌分，去古彌遠，其不至於數典忘祖、貽歐陽氏受姓不知所自之誚者，幾何哉？

璩氏自澄忠公遷居此土，迄今又九世矣。公流澤悠長，累世以令聞著，孫子遊庠者相繼不絶。由是觀之，璩氏之繁昌未有艾也。德檒毅然以譜事為己任，之紹之衢，往來蘭江者累月；其從弟德燃輩又相與協力贊勷。敬宗收族之意，殆有不言而同然者歟？

余按其系圖，始祖斷自文富公，從遷浦而推所自出也；文富公而上，另為序次，探源也。噫！誦角弓之詩，傷九族之情疎；詠頍弁之什，知親親之愛篤。凡為璩氏雲礽者，披閲先人之譜，親疎上下宛如繩貫絲聯，一體相關之至情，當亦油然勃發而不可遏。余於此惓惓有厚望云。

至其賜姓之由與仕宦科名之盛，圖譜有明文矣，兹不贅。

皇清乾隆四十五年庚子春三月朔越二十有八日
