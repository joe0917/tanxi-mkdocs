# 席場橋記
```
题：[]武林博士林子燕謹記
峕：[]寶慶丁亥淸明
初始点校：[20250222]《浦陽姑山毛氏宗譜》民國辛巳重修
修订参考：[]
```

聚席埸橋者幾百家，山爲垣、溪爲𨳸也。溪沿羣山斗折蛇行，超超三百里。居民視廣狹編木以渡，激輒壞退，復作安習，苟簡久矣。

今天子践極元年，毛君日嚴捐帑廩鳩匠石，創橋於往來之津。長二十八丈，廣一丈八尺，翼以欄楣，鎭以魚虎，計工四萬有奇，越三年成工，氣勢吞壓，傑然如蛟龍臥虹沐、澹溟跨碧落也。

或見曰：“偉哉。是都邑所以迎軒，蓋遊士女也，而獨以件溪山耶”。

君笑曰：“此謂不一於汝，而二於物也。試爲子誦之。

林薄幽深，漬沙消淺，卽而境桑麻肥焉，撫而人樵牧錯焉。襏襫[^1]羅網介其上，薪鄠桔藁籍其側。狼狐猿狁出馳入息，雲霧霏靄朝幄暮幕。當是時子爲橋惜，恨其不在都邑間也。

驚濤怒漲，熊闞虎渤，觸巉巖掠斷岸。掀飛歛袵，孟賁[^2]蹙容。而童孺羸老，扶笻掉升臂梁，而浩歌臨流而思逝。談黃龕之固伏，笑激灧之險怪。當是時子爲橋喜，又幸其存溪山間也。

夫橋一之子二之子，則興感不擇地而售利。吾能推愛溪山之心而愛都邑子，復推愛都邑之心而愛溪山，則幾矣”。

余聞而高之曰：君能利人本其仁，訖事本其勇，不寶財貨本其亷，能通人情本其恕。本是四者可以觀人矣。

峕：寶慶丁亥淸明

武林博士林子燕謹記

里人石籌書

[^1]: 襏襫(bóshì):同“袯襫”，多指蓑衣。
[^2]: 孟贲:战国时的勇士。力大无穷，相传能生拔牛角。


# 席場橋記（县志版）
```
题：[]武林博士林子燕謹記
峕：[]寶慶丁亥淸明
初始点校：[20250224]《浦江縣志·藝文志》乾隆己亥
修订参考：[]
```
聚席埸橋者幾百家，山爲垣、溪爲閫也。溪沿羣山斗折蛇行，迢迢三里。居民視廣狹，編木以渡，激輒壞，退復作，安習苟𥳑久矣。

今天子踐極元年，毛君日嚴捐帑廩，鳩匠石，刱[^1]橋於往來之津。長二十八丈，廣一丈八尺，翼以欄楯[^2]，鎭以魚虎，計工四萬有奇，越三年成，氣甚吞壓，傑然如驕龍臥虹，浴滄溟跨碧落也。

或見曰：“偉哉。是郡邑所以迎軒蓋[^3]，游士女者，而獨以伴溪山耶。”

君笑曰：“此謂不一於汝，而二於物也。試爲子誦之。

林薄幽㴱[^4]，砂磧清淺，卽其境桑麻肥焉，撫而人樵牧錯焉。襏襫[^5]網𦊟[^6]疥其上，薪鄠秸藁籍其側。狼狐猿狖[^7]出馳入息，雲飛霧靄朝幄暮幕。當是時，子爲橋惜，恨其不在於都邑閒[^8]也。

驚濤怒漲，熊鬭虎哮，觸巉巖掠斷岸。佽飛[^9]歛袵，孟賁[^10]蹙盛容。而童孺羸老，扶笻掉臂，升梁而浩歌，臨流而思逝。談黃龕之迴洑，笑灩澦[^11]之險怪。當是時，子爲橋喜，又幸其在溪山閒也。

夫橋一之子二之子，則易景而興感，橋不擇地而售利。

吾能推愛溪山之心而憂郡邑，子復推愛郡邑之心而愛溪山，則幾矣。”

余聞而高之曰：“君能利人本其仁，制事本其勇，不寶財貨本其廉，能通人情本其恕。本是四者可以觀人矣。”

峕：寶慶丁亥淸明

武林博士林子燕謹記

里人石籌書

（按“橋梁卷”，席場橋係宋寶慶初年建，記中所云“今天子踐極”，正理宗寶慶元年也，舊志訛作寶隆丁亥，丁亥卽寶慶三年。今改正。）

[^1]:刱:同：“創”
[^2]:欄楯（shǔn）:“栏杆”的旧称。纵的叫栏，横的叫楯
[^3]:軒蓋: 本意为车盖，这里指带篷盖的车，意为豪车。
[^4]:㴱: 同“深”。
[^5]:襏襫（bó shì）:同“袯襫”，多指蓑衣。
[^6]:𦊟:音gǔ，同“网”。
[^7]:狖:同“鼬”
[^8]:閒:同“間”
[^9]:佽飛:即佽非。春秋楚勇士。后亦泛指勇士。
[^10]:孟賁:战国时的勇士。力大无穷，相传能生拔牛角。
[^11]:灩澦:也作“灧澦”。长江瞿塘峡口的险滩。
