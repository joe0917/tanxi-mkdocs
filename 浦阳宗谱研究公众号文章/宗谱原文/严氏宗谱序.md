# 嚴氏宗譜序
```
题：[]慈水外史嵩山周生甫謹撰
峕：[]嘉靖三十三年歲在甲寅仲秋月望後三日之吉
初始点校：[20250622]《浦阳严氏宗谱》
修订参考：[]
```

家之有譜，猶國之有史也。夫史所以明統緒、秩彛倫、定善惡、垂鍳戒，是故核之以精而弗陋，徵之以實而弗誣。陋且誣焉，則所以教天下後世者荒矣。惟家譜亦然。譜所以示本源、分統屬、敘昭穆、别尊卑，綱舉而有條，目張而不紊。陋且誣焉，則所以示宗族後世者無據焉。

吾婺州嚴氏，爲浦邑望族，世居下茅源者，子孫繁盛，乃周天旻之母族也。天旻與余有斯文雅契，一日謁余曰："吾母族兄弟輩以輯譜事，屬余願與子諧。"余愕然而良久，曰："余不佞，其譜得無陋乎？"天旻曰："嚴族迨自季瑞府君由山西徙於吳，通二府君再遷於此，凡二十餘世，昭穆有序，上下有倫，嫁娶有常，顯晦有迹，生卒有歲月，居處墳基有攸在，奚病於陋？"

余復曰："得無誣乎？"天旻曰："嚴氏由子陵先生改姓曰嚴，其宗派遂皆以嚴爲姓。及大觀末，吳地若金酋肆毒，因避亂遷婺，再徙居於此山谷者，乃通二府君也。奚病於誣？"余曰："匪陋匪誣，譜足徵也，何必改作？"天旻曰："嚴非譜之陋之誣足病也。大抵族屬踈遠，則情義罔孚；家勸弗昭，則邪偽茲甚。嚴氏之族散居如温州者，慶弔宴會，時或弗舉；貧旃患難，如秦人視越人之肥瘠，邈焉不如欣戚於其心。先人遺訓，未必克守；而華麗相高，險陂相視，而詭譎相傾。甚者好鬼信怪，而畧當務之急。是甚嚴譜之不誣，而子孫之爲甚陋也；嚴譜之不誣，而子孫之爲甚誣也。"

"誠哉！嚴霍、玉寶、統堂等，乃賢達長者，慨然有拔本清源之志，故不忍坐視誣陋之病，故屬天旻輯譜，以合情昭勸焉爾。夫合情則陋卻，昭勸則誣被。天旻學寡才謭，安能以堪卻陋破誣之任？匪先生，則昭勸合情之意勿彰，而有孤霍等之望。故樂與子共之，希君子成人之美，以全天旻之責。"

余曰："子之言嘉矣！子之言韙矣！敢靳於辭耶？"是爲序。

峕 嘉靖三十三年歲在甲寅仲秋月望後三日之吉 

慈水外史嵩山周生甫謹撰
