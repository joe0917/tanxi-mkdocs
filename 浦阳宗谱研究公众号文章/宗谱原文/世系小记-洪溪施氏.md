# 世系小記
```
题：[]野史陳雲鴻撰
峕：[]天啓元年閏二月望日
初始点校：[20250915]《浦阳洪溪施氏宗谱》
修订参考：[]
```

嘗見山之迤逶而來，千峯萬巔，総發脈於崑崙；水之湍激而下，千流萬派，悉濬源於銀河。山水且然，豈人而無本源乎？故世系之撰，所自來矣。

周有小記定世系，唐有柳沖族姓系，皆鑿鑿可據。獨廬陵歐、眉山蘓繪世系圖，皆慮服窮情盡，相視如吳越。雖“五世一提”取“君子之澤五世而斬”之義，然聯絡不絕，一氣相貫，卽傳之百世萬世，實可稽其相親也。

施氏自金邑華峯遷浦陽，其先亦剏家譜以垂雲礽。迄今聚廬托處者，若洪溪、山灣、溪口、派塘、張塢、武義、施塢、嵩山、項塢，棋置星列，經久散軼或亂或淆，相視莫識，烏覩所謂綂宗會元者哉？

九世孫廷美、廷銓等有隱心焉，而爲之詮次。一宗蘇公體式，行第統一，演繹成帙。如登崑崙之巘而疆理井井不亂也，如遡銀河之源而原委瑩瑩若燦也。俾子孫指圖而諦觀之，庶知小宗大宗、有服無服，親親之情油然興起矣，又何患吳越之相視哉？

是舉也，不惟見祖澤之不斬，實爲聖朝助化之一騐云。

峕天啓元年閏二月望日

野史陳雲鴻撰

# 流芳誌小引

余目《貞觀氏族志》、《元和姓篡》，序世系之外，例有流芳誌。凡行第名號下書爵、書事、書卒、書葬之咸備者，非綴綺以炫觀，誠欲列崇奥、示勸懲、昭追報耳。

粤稽施氏居婺之山下與東施皇安者，俱以百一府君幼子萬四四府君爲鼻祖。金華樟樹塘遷浦陽之始祖則蓮五府君、蓮七府君也。

其先字行第曰萬、千、慶、曾，異地同稱。厥后居山下者曰富、鼎、彝、鼐、鼏、仁、義、禮、智、信、儀、容、振、綱、常；析居東施皇安者曰富、鼎、厚、迪、琚、珙、瑩、琇、茂、昌、晟；居樟樹塘者曰丙、本；遷浦陽居洪溪、山灣者曰蓮、起、遠、仁、佳、傳、信、傑；居溪口、張塢、派塘者曰蓮、起、永、昱、昇、盛、富、湻。下皆曰儀、俊、任、侍、位、付、仲、倬。地遠人稠，行字不能協一。

蓮七府君大世係諱孟鎬，七世孫諱宗稀、宗祥、宗棠、宗樞等，恐愈遠而雖聯也，於萬歷十五年統宗修輯以垂後裔。歴今又數十年，勿得校讐，不惟金華祖派多有掛漏，卽浦陽一枝人紛如林，離合靡定，存亡疊現。倘或忘考，其何以存家政而免祖先之怨恫乎？

九世孫諱廷美、廷銓等，繙閱古牒，漁獵百家，稽前啓後，經幾蓂莢而成其餘傳。例多襲舊式，獨行第自傑字以下，擇字之善且類者，以二十字編成次第云：儀、俊、任、侍、位、付、仲、倬、儒、倫、侯、佐、倡、偉、俸、僖、佑、備、倧、伸，以為世遵。

卓哉此誌也！敘參差、覈異同，不混淆於魚魯。但見行第定而尊卑别，事蹟著而勸懲彰，葬卒記而追報舉。鳥有所謂少凌長、小加大、好類醜而禋祀愆期也哉？則斯舉其有關於世敎風化亦甚大矣。

余毛穎雖秃，不堪馳驟董馬，聊序其槩以志盛事云爾。

峕天啓元年孟夏月之吉

邑庠生野史陳雲鴻謹書
