# 呂氏重修家譜序
```
题：[]賜同進士出身雲南參政適齋朱方敘
峕：[]皇明嘉靖壬戌年臘月之吉
初始点校：[20250805]《吕氏宗谱》
修订参考：[]
```

家譜何爲而作也？萃聚於渙，以盡仁也。蓋天地萬物散殊，禮爲之秩之；日月星辰高遠，曆爲之秩之；蒸民氏族叢雜，譜爲之秩之。其道一也。先王作之禮禮矣，作之曆曆矣，獨於譜焉有所未遑。庸詎知夫世教攸關、人心攸係，而譜之作烏容緩哉？

且人之生本於一祖，其子若孫支分派衍，有若天地萬物之生於世，有若日月星辰之麗乎天。其造化象數之昭著，不知其幾千萬億，可謂渙而散矣。苟無道以萃而聚之，則貿貿焉莫知其所自，雖一祖之親，將漠然視之若塗之人，其何以敘昭穆之禮而盡親親之仁也耶？必有譜以聯其支派，記其行名，而統之有其宗，庶乎知其所以始，則尊禮之意生；知其所以分，則睦族之念廣。則所謂渙而散者，將必萃而聚之矣。譜其可以不講乎？

夏呂氏蓋永康望族也。予姪天秩，呂之婿也。其十四世孫呂庸、呂曉，念宗譜之廢缺，走書請予姪修譜事，來徵予序。予因歷閱圖譜而詳考之，有以知其顛末矣。

昔太公望封於呂，其得姓已肇。故其遠裔賢達，歷匕可數：其在河南洛陽，有若蒙正、居簡、公著、希哲者，仕宋人物，於斯爲盛；其在仙居白塔，由德簡之仕台州府尹，因時之亂，乃卜築台之仙居西市白塔居焉。至宋乾道中，有思安公者徙永康之仰平，爲夏呂始祖。七世禧七處士又分爲派川，若鑾之爲三府，銳之爲大尹，錄之爲三尹，及爲太學、郡縣庠生以求進取者，方興未艾，郁匕乎其文明焉。其他如巖前、亞坑及義烏公善堂等處，此皆仰平之分派也。

嗚呼！本固末茂，源濬流清，是由祖德之盛也。夫以一身流于千萬人之身，咸以是爲賴焉。然使譜法不立，則雖其世次之可知者，不數傳已莫之詳，而况望世德之傳與世澤之久乎？此諸君子之所以汲匕而不敢緩也。

故先匕後匕，上下辨焉；遠近咸陳，疏戚洽焉；男女畢錄，剛柔判焉；次別以敘，其分昭焉；薦仕必悉，其聲榮焉；配偶不遺，內外備焉；生卒必謹，始終嚴焉。庶幾後之人揭圖以知派，則宗之大小不至於溷而無別；觀傳以知齒，則族之少長不至於紊而無序。則雖祖之遷毁者，不至於樵牧弗禁，而尊祖敬宗睦族之道，胥此焉在。其紀載不巳備乎？

由是觀往迹者起廓大之心，披遺文者興悠長之念。將見昌者彌昌，盛者彌盛，而宗益振矣。然則盡仁而得萃渙之義者，謂不存於斯譜也哉？予推姪之意而爲之序。

皇明嘉靖壬戌年臘月之吉

賜同進士出身雲南參政適齋朱方敘
