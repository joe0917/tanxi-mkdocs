# 浦陽趙氏家乘序
```
题：[]前翰林學士，嘉議大夫知，制誥兼修國史兼太子贊善宋濂譔
峕：[]
初始点校：[20250705]《浦阳赵氏宗谱》
修订参考：[]
```

浦江趙友仙氏，生簪纓故家，卓然有志於儒術，念本源之悠遠，惧（懼）宗族之易踈，乃慨然曰：「凡古之受姓命氏，何莫非神明之胄？歷世滋繁，風徽寢邈，百世之後，竟懵然若無聞知。間有碩茂之士，述祖德以作歌，感衰俗而增歎，其志豈不重可傷耶？矧我苗裔蟬聯最久，載諸史牒，錄於家乘者，昔日嘗班班可考，近亦將散落而多忤矣。」

族叔祖梅石處士先生，嘗以襄陽耆舊之德，韞洛下博聞之資，久接席於縉紳，且留情於論撰。當請之以成一家言，庶幾可垂於來葉耳。處士因友仙之言，為之蒐羅采輯，閱歷三載，始克成編。燦燦乎有序而勿亂也，確確乎遐稽而無妄也，林林乎布列而成章也。

友仙讀之，喜而不寐，以未有為文以冠其端者，來謂宋濂曰：「子盍為我敘之？」嗟夫！世豈無閥閱之家哉？不營歌臺舞榭以娛樂於厥躬，則欲執籤（簽）持麓（籙）以期弘於孫子，奚知承傳之有自、敦睦之當力哉？其視友仙之為，必將面頰發赤矣。

抑聞之，歐陽氏著譜圖，人謂至為精審，今以其世數考之，多乖謬可議，故先儒深有所感。譜之不修，比之不孝；譜之不可不謹者，葢如此。友仙之汲汲於斯，其能念本源之悠遠、懼宗族之易踈者乎？是可嘉矣。予故不辭而為之序。其世次遷易之詳，見於處士之文乎，茲不著。
