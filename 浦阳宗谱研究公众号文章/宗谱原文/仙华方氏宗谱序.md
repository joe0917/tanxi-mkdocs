# 仙華方氏宗譜序
```
题：[]翰林待制蜀山柳貫道傳撰
峕：[]元至正五年乙酉冬月
初始点校：[20251013]《浦阳仙华方氏宗谱》
修订参考：[]
```

浦陽之北有山直其後，曰仙華，奇秀高聳，往往篤生異人。邑大姓方氏世居其麓。

方氏自唐處士元英曾孫景傅公由睦來遷，蓋樂其山川之靈秀也。傳四世至逢原公，中宋嘉祐八年進士，歴官至金紫光祿大夫。五世遐舉公，中宋元祐三年進士，歷官至兵部尚書。遐舉公生鑄，鑄生洙，皆有祿食於朝。餘若果、若登、若策，亦舉進士第，簪纓聯蟬不絕，乃浦陽仕族之冠也。

自遐舉公傳七世，爲予師韶卿先生。先生忠義文章，振響山川，予嘗洒掃先生之門。先生二子樗、梓與予同學，親且厚。適方氏有譜牒之修，謁序於予。予曰：「厚人倫，美風俗，使親族相維而恩義不替者，誠莫如譜牒之修」。方氏世修陰德，子孫繁昌，宗法之立蓋有取爾也。方先祖代有聞人，多以清節素風傳家，堪爲後起者師。方氏子孫其無忘先烈，顧圖譜而知所自振，則安見顯於前者不更昌於後耶？

峕元至正五年乙酉冬月

翰林待制蜀山柳貫道傳撰

# 方氏族譜序

按方姓出自方雷氏。方雷者，西陵氏女，軒轅之正妃，是爲嫘祖。或曰：「榆罔之子曰雷，封於方山，後人因以方爲氏」。未詳孰是。周宣王時方叔食邑於洛，故世望於河南。

至西漢末，王莽將纂位，司馬府長史紘官於吳中，度天下必大亂，卽避歙之東鄉，因家焉。生一子雄。雄生三子：儕、儼、儲。儕關內侯，行南部太守；儼大都督；儲字聖明，一字頤眞，太守周歆舉爲孝廉，又舉賢良方正第一，累官太常兼洛陽令，封黟縣侯。和帝時卜郊忤上意，飲鴆而卒。儲能役使鬼神，故鄉人立廟祀之，稱其爲仙翁云。

仙翁生三子：纘之、宏之、觀之（一云覿、洪、觀，蓋傳聞之異辭耳）。子孫分爲三族，其布列於諸郡者：纘之之後則嚴、衢、婺、越；宏之之後則徽、宣、池、秀、湖、常；觀之之後則莆田、九江、滁陽，至今繁盛。

纘之遠裔曰文亮，仕陳爲散騎常侍，生南昌令倫，倫生隨秘書郎祚，祚生大中大夫伸，伸生唐太子中書舍人孚，孚生右衛將軍始興。始興生二子：遵、逢。逢考功郎中、素州剌史，生皓，皓生吏部員外郎苗，苗生三子：堂、常、褚（褚宣遠將軍）。堂永陽令，生二子：達、讓。達生三子：引文、引武、引祖。引文生道屬，道屬生四子：聰、尊、甲、乙。聰生四子：令和、令興、令安、令保。令興生世雄，世雄生道明，道明生二子：赦、講。講生君讃，君讃生三子：公懇、公郁、公平。公郁生二子：整、漢（御史中丞）。生刑部尚書景漢，生四子：宗、寀、宰、宥。宰浙東觀察推官，生三子：永珍、永符、永豐。豐生十子：可榮、可昭、可浚、可瓊、可齊、可暉、可同、可度、可剛、可法。

可暉生肅，肅生元英處士千干，字雄飛，世居睦州白雲鄉，以詩名世，後隱越之鑑湖以終，生二子：翼、嚴。嚴生二子：甲、述。述生四子：景先、景珍、景珣、景傅。

景先生二子：彥超、彥安；景珍生三子：彥誠、彥瓊、彥暉，復自越還居睦；景珣生三子：彥俊、彥邦、彥威；景傅生一子彥招。

自彥招而下號爲九房，浦陽之方乃第九房。景傅始自白雲鸕鷀遷於浦陽仙華山麓而定宅焉。

彥招生文遇，文遇生光祿大夫資，資生大中大夫揚遠，其族漸大。讀書爲文辭者後先相望，如鑄、如洙皆能纘承先德，曰果、曰策者皆中進士。迄於宋季，有曰鳳字韶父，學者稱巖南先生，又曰存雅先生，乃吾師淵穎先生之師也，浦邑道學之源也。予其敢忘情乎哉？謹以是序之譜首。

旹洪武十年丁巳夏四月十五日

翰林學士兼承旨制誥贊善大夫宋濂謹序
