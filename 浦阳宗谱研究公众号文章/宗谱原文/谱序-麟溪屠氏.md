# 譜序
```
题：[]烏傷侍生劉平原謹書
峕：[]萬曆八年歲次庚辰冬月吉旦
初始点校：[20250718]《浦阳麟溪屠氏宗谱》
修订参考：[]
```

族譜之作，所以明本原、正倫理。然物爲綂也，抑亦爲踈矣。爲親分父而子，舉目可知，不必修也；爲踈分百世之遠，時異支分，恐苗裔無所據，源流無所别，皆賴此以考見而知其所出，誠不可不修也。

苟世有能脩其譜者，則又强援貴族，妄引著姓，加於其首，不思哂扵其人也。夫我屠氏之譜，始祖系出宋宗之後。三世祖瞿公，始居渤海，避亂徙居浦陽下麟溪而居。歷世旣久，生齒愈蕃，子孫繩繩相繼，綿綿不巳。宗族漸多，分門異戸，有知其親而罔知其踈，如失木本水源之義矣。宗族相視如途者，幾希矣。

切尊其譜，時宜重輯，不敢妄自加増。惟於諸文錄者，則續之而已；名次未序者，則正之而已。玆譜之作，登淺鮮哉！屠氏諸碩彦，文海、文獅輩，克承先志，遂會族衆，躳臨其門，各摭其生卒年月日時、嫁娶墳墓之詳，靡不載錄，隱顯出處行實大略，無間於親疎遠近也。譜成，展卷間，一舉目而瞭然矣。親親之義，由自而生。爲後裔者，尚當相率善繼善述，永永不墜焉。

峕萬曆八年歲次庚辰冬月吉旦

烏傷侍生劉平原謹書
