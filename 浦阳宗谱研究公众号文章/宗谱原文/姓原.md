倪氏之先，出於曹叔振鐸之後。夷父顏有功於周，其子友别封爲附庸，國於郳。至於曾孫黎來，始見於《春秋》莊公之五年。其後數從齊桓公征伐，以尊周室，受子爵，是爲小邾子。後國爲楚所滅，其故國在漢爲蕃縣，隋曰滕，今徐州滕縣是也。縣東有故倪城。

戰國時，倪良以善兵顯，與孫、吳並列。去其邑爲"兒"，後復加以"人"爲"倪"。以儒術授其子孫，預知秦嬴之暴，使後世諱爲"兒"。漢武帝時，兒寬以儒學爲御史大夫，位列三公，世居千乘，其姓復加"人"矣。

漢末有倪萌，字子明。弟爲赤眉所執，欲烹食之，萌乞以身代，賊義而兩釋之。王郎將有見宏者，與光武戰南蠻。"倪"復去"人"，又見於此。後漢有兒彥爲揚州刺史。

唐開元間，恆州倪若水以清望顯，召入爲尚書右丞，始得以詳其世次。唐末遭亂，子孫南遷。五代時有酆公者，去兒寬二十四世矣，始遷居吳興。有名盈者，復自吳興遷浦江。後晉天福間捨基建寺，今曰保安山靜慧院是也。復遷於石陵村居焉。

長子諱相，居守故宅，樸之祖也；次子宗，字仁稠，行元三，别號白碑子，遷居於通化之白巖畈，晚復遷於龍池之上金生村，後改名倪大村，今曰龍池倪氏。

## 備註

原書: [出版地不詳 : 出版者不詳], 清宣統2[1910]. 49冊 : 插圖, 世系表, 人像.

始祖(1世): (唐) 倪盈,字持之. 仕吳越為回圖令. 自吳興遷浦江之保安巖, 復遷石陵村.

始遷祖(2世): (唐宋之際) 倪宗,字仁稠,行元三,號白碑子. 自石陵遷龍池. 為盈公次子.

宗公下派祖(8世): (宋) 倪大用,字良能,行伯五(居外宅下畈) ; 倪益仲,字良計,行伯九(居中宅) ; 倪仍仲,字良思,行伯十一(居下宅) ; 倪伊仲,字良賢,行伯十二(居上宅). 皆為梓公(字大宮,行始三八)之子.

大用公下支祖(11世): (宋) 倪以諒,字允亨,行曾一(遷新塘源) ; 倪以直(失考) ; 倪以寬,字允洪,行曾又四(居外宅下畈) ; 倪以溫,字允和,行曾五(二傳後失考).

益仲公下支祖(11世): (宋) 倪以詩,字允志,行曾十(橫塘,前俞祖) ; 倪以簡,字允敬,行曾七 ; 倪以歌,字允樂,行曾廿四.

仍仲公下支祖(11世): (宋) 倪以信,字允實,行曾十五(遷居養源).

伊仲公下支祖(11世): (宋元之際) 倪以元,字允乾,行曾十九(石塘,前樓,前倪祖) ; 倪以順,字允坤,行曾五一(居倪大村) ; 倪以禮,字允庭,行慶二一(一傳後失考) ; 倪以亨,字允達,行慶四(居寺塢塘下).

以元公下分支祖(13世): (宋元之際) 倪德溫,字天厚,行瑞一(後世遷石塘源) ; 倪德良,字天性,行瑞三(後世遷上倪) ; 倪德恭,字天常,行瑞四(後世遷前樓) ; 倪德讓,字天遜,行瑞八(後世遷前倪). 皆為克寬公(字勝度,號性本,行壽四六)之子.

行派(2世起): 元祖傳繼 述始伯千萬 曾壽瑞權英 性道教興起 綱常嚴順孝 敬明聖賢良 廣運隆清(昌) 聿新先武

諱行(22世起): 仁一朝應 夢尹傅周望

字輩(11世起): 允勝天伯仕 子宗希孟仲 文心光嘉際 達元會顯揚

官名(31-38世): 允憲匡彝迪承鄒魯. 嘉慶丁丑(1817)年一族定式: 允憲安邦成如有貴.

表字(31-38世): 昭衍奎章進思修甫. 嘉慶丁丑(1817)年一族定式: 昭用全才進斯修美.
