# 浦陽青溪江氏修譜序
```
题：[]賜進士擢湖廣副使兼荆湘道，湻邑 徐應璜 頓首拜撰
峕：[]大明萬厯四十三年歲次乙卯孟冬月
初始点校：[20250717]《浦阳青溪江氏宗谱》
修订参考：[]
```

昔許由氏有言曰："有族有祖，祖者徂也。義重則尸，仁輕則祧。"蓋尊祖故敬宗，敬宗故收族。收族而神人和，幽明洽矣。不然，有人於此，以縣寓爲家，以昊（大）爲祖，以四海爲兄弟，以鳥獸爲同羣，有無不可者。不知鄉隣閉戶，室中勃溪，何有於期功強近？又何有於途之人？習矣而不察，相沿而不知其非，則後之視譜，亦猶刖者之視履耳。

今浦陽江氏，始於戰國，著於南齊，傳至宋元。自倫公遷徙之後，可以考信。作者亦惟傳信是務：非其族者，雖成不援；是其宗者，雖憊不遺。若名若字，若昭穆若婚姻，若邱墓若婦女，若爲人後，使後人班班可攷，亦皆傳信是務，蓋其愼也。

嗟嗟！鷾鴯非族也，而胥化；蜾蠕非類也，祝而肖焉。使其羣族之人，惇質行而薄紛華，務孝悌而黜忤逆。人不必仕途，要之賢良；家不必鉅富，要之力本；女不必艷美，要之亷貞。及其漸磨日久，瞿然顧化，若蓬生麻中，不扶自直矣。此其收族而尊祖敬宗、敬宗而尊尊親親之道明，此譜牒之（垂）於修也，良有以哉！吾願江之人其無忽。

峕 大明萬厯四十三年歲次乙卯孟冬月

賜進士擢湖廣副使兼荆湘道，湻邑 徐應璜 頓首拜撰


## 備註

原書: [出版地不詳 : 出版者不詳], 清光緒3[1877]. 存1冊 : 插圖, 世系表, 人像.

註 : 此譜僅存卷1-2. 缺卷3.

受姓祖 : 日旌. 伯益之後,封於江,子孫以國為姓.

遠祖 : 江乙. 安陵君拜為上卿.

始祖 : 江永嘉. 由安徽遷睦之淳安.

始遷祖(一世) : (明) 江倫,行天一. 由淳安遷於浦江,居西北截界嶺薛塢.

倫公下三子 : 江道誠,行地一 ; 江道榮,行地二 ; 江道瓊,行地三. 此譜主要為榮公派下世系資料.

榮派下房祖(5世) : 江旺,行華一 ; 江遠,行華六.

瓊派下房祖(5世) : 江如聖,行華三.

行派 : 善慶正祥瑞 得盛聖賢君 錦源林煌坦 坤鏞淵桂煥.

諱派 : 永尚啟能為 必正興家國 一元應良有 惟仁世定榮.

表派 : 汝訓之克明 以承端學本 致宜開瑞兆 厚道自垂芳.

散居地 : 浙江省浦江縣等地.

書名據書衣題編目.

Genealogy of Jiang family of Qingxi Daorong gong branch, in Pujiang xian, Zhejiang province, China to 1877.

派祖:江倫
