# 冠橋沈氏宗譜源流序
```
题：[]賜進士出身翰林學士承旨侍經筵金華蘇平仲拜撰
峕：[]洪武乙亥八月望日
初始点校：[20250914]《浦阳太平坊沈氏宗谱》
修订参考：[]
```

粵稽沈氏源流，出自周文王第十子聃季公，食釆於沈，因以爲氏。厥後奕葉雲礽，子孫蕃衍，難可備述。

至五代時，有諱約字休文者，始居吳興，仕梁。天監二年，封建昌侯。休文生旋，旋生衆，禮部尚書。衆生光，光生琳，椒戚拜司徒，封徐國公。琳生二子：長士衡，贈太保；幼士衍，右衛將軍。士衡生景福，平州刺史。景福生易簡，易簡生蒙，金吾衛大將軍。蒙生旣既濟，禮部員外郎。既濟生傳師，登進士，翰林學士、吏部侍郎。傳師生二子：長曰謳，幼曰詢，登進士，兵部尚書。謳生三子：長曰儼，次曰攸，幼曰倰。攸官常州刺史，倰生二子：長崇文，幼博文。崇文生承禮，承禮生三子：長廷蘭，大理寺丞；次廷茝；幼廷蘋，亳州推官，生望之，太常寺卿，生二子：長曰披，登進士；幼曰括，龍圖閣學士。披生逌，將作主簿。逌生煥，翰林學士。煥生三子：長曰曄，次曰晦，幼曰暄，太常博士。曄生戬，顯謨閣侍制。戬生五子：長曰瑄，官通判；次曰琮，廸功郎，監平江稅，由吳興遷居閶門；三曰瑾，登進士；四曰珂，官知州；五曰珪，江西主薄。琮生二子：長曰昌宗，幼曰昌裔。昌宗生二子：長曰鲁五，幼曰清宇，吏部侍郎，生三子：長曰本立，次曰文五，幼曰文七。本立，元處士，自姑蘇閭門遷居浦陽之冠橋，得山川之勝槩，遂家焉，因名曰冠橋沈氏云。

休文公𧺫（起）百代之人文，而爲沈氏鼻祖；本立公貽千年之世澤，而爲冠橋之始祖。吾知源遠者流長，本固者枝盛，其間賢豪相繼，忠孝挺生，昌大門閭，克振家聲，屈指待者，其可量耶？

洪武乙亥八月望日

賜進士出身翰林學士承旨侍經筵金華蘇平仲拜撰
