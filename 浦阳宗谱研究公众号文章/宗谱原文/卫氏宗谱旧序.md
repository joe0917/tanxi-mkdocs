# 衛氏宗譜舊序
```
题：[]東陽縣儒學訓導四明蔣望渠撰
峕：[]天啓四年十月中澣
初始点校：[20251031]《浦阳卫氏宗谱》
修订参考：[]
```

古所謂伯叔甥舅之邦者，以其封建之始，別乎親疎上下之分者也。而於得姓受氏之先，其辨尤嚴。所以周官明禮制而氏族不煩，經禮辨等威而冠婚益備。古聖王制作之隆，未嘗不於姓氏三致意也。

有如浦陽衛氏者，其先系出軒轅，地在河東。周文王第八子康叔受封於衛，國滅因氏焉。其後漢文帝時，中郎將綰，醇謹無他。武帝時，大將軍青，凡七擊匈奴，收河南地。晉時尚書令瓘，善草書，號一臺二妙。他如玠，則冰清玉潤，涇則試魁天下，元則領京兆尹。是皆績著公朝，名播青史者。然此或非己祖，而不得援以為引徵者也。

而浦邑之衛氏，則自懋忠公始。即浦邑衛氏之譜，亦自懋忠公始。公乃河南巨族，遥住錢江，遂為浙水名家。來兹浦汭，是先生竄身遷徙之時，正有明禮教方隆之日。公之居於金瓜樣，凡四十年於兹矣。行其野，井里桑麻，蔚然可觀也。造其廬，雞鳴犬吠，秩然可睹也。父老子弟，白叟黄童，怡然登古處而樂昇平也。猗歟盛哉！

十餘家之聚首一堂，不猶然我浦陽之世家哉？雖然，地迴矣而人未蕃，不可以言族。人蕃矣而姓未著，亦不可以言譜。求之生存卒葬之時，付之記憶傳聞之下。公不生於四十餘年之上，求遺牒於殘編。公乃遷於三百餘里之外，追祖宗之履歷。此衛氏之不可無譜也，而於是為之立其圖，而於是為之省其行，而於是為之考其舊而核其新。衆皆曰善，此浦江衛氏宗譜之始也。因爰筆而為之序。

峕天啓四年十月中澣

東陽縣儒學訓導四明蔣望渠撰
