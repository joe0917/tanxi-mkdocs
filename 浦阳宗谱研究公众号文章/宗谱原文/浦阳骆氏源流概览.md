# 浦陽駱氏源流槩覧
```
题：[]義烏楂林四十二世孫章二百八十二元旻拜撰
峕：[]康熙歲次癸卯仲春
初始点校：[20250820]《浦阳鹤溪骆氏宗谱》
修订参考：[]
```

駱本姜也，姜太公有子名駱，後子孫遂以名爲姓，郡分內黃，至漢孝順時有文盛公隨父任烏傷教授，贅縣西張氏，遂家焉，故舊譜以爲一世祖。

後祖有諱俊北，仕漢爲陳畱相，又諱統者，仕晉封新陽亭侯，至唐十四世祖臨海公者，爲侍御史，作檄討武氏以敗，隱梅林，其流裔也，後贈恩平大夫，明諡文忠公，邑世祀焉。

二十九世百三府君，自梅林遷居楂林。又三世嵩三府君，避家難□居浦之十六都吳山麓。又二世壽二府君，復遷居鶴溪之側。至賢十二，賢十三兩府君，克振家聲，恢宏基業，可謂善繼善述之人矣，賢字與楂林賢字同行，蓋自始祖至此三十七世也。

賢之後有良，良之後有佳，佳之後爲仁，仁之後爲禮，禮之後爲忠，忠之下爲和，和之下有成、信二字，未編行次，攺而與楂林泰衍二字同，衍之下爲道，爲誼，後又擬二十字，曰“漢任稠川永，唐貽桂子宏，宋季羣遷勝，枝森遡本同”，各族同字，會遇時一詢，便知昭穆倫序，實爲簡便，又見親親之意，錄之一覽。

旹 康熙歲次癸卯仲春
