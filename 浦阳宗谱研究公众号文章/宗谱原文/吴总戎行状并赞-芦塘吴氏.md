# 吳總戎行狀并贊
```
题：[]欽選文林郎知宿遷縣事，內弟鄭應兆頓首拜撰
峕：[]順治十四年歲次丁酉菊月吉旦
初始点校：[20251027]《浦阳芦塘吴氏宗谱》
修订参考：[]
```

浦陽蘆塘吳公，諱良翰，字守邦，行寧百八十九，號翠屏，别號羽侯，彥珍方伯公之從孫，乃敘州照府月池公第五子也。翁少時穎悟超羣，每懷大志。及長，訪友從師，勤敏篤實，吐詞宏麗，下筆成章。加之膂力過人，能挽強弩。明秀流氛猖獗，蹂躪州縣幾遍中原。翁嘗語予曰：「大丈夫志在澄清天下，區區青矜何足道哉！」遂廢舉業，習韜畧、奇門、六甲諸書，日以心究。

崇禎丙子，湘陰吳紫蓋老師以甲戌進士涖浦，試予儕等談及四方擾亂、盗賊竊發，文武兼才曷可少諸？予輙以翁對，慨然作書於鎭江監軍道雷公。其調有云：「汾陽一卒，李白識之獨先；武穆戾人，宗公援之獨早。儒冠可搜溺，毛錐将安用之？藥籠正宜旁收，參杰可無棄以。」雷公甚重之，薦諸安池道史公。一見異之，恨相見之晚，序千總職，命援桐城，擒獲巨寇，掃其窠穴。史公喜不自勝，自以爲得人。翁亦慷慨而前曰：「士爲知己死，雖肝膽塗地所不辭也。」

史公苦賊衆兵寡，己卯年巾題守備銜，往義、浦二縣募兵七百。義邑侯許若魯甚敬重之，謂予曰：「令親眞將才也。」彚册交史公點選，其兵果精壯絕人，名「義浦營」。史曰：「浙兵驍勇，非吳將不能領也。」

庚辰年序游擊街，改「義浦營」爲「六安營」，命守霍山縣。與賊對陣，每每以一勝百，流寇望風而靡，稱曰「吳長子」、「吳半仙」，不可犯也。

壬午年，史公督撫淮安，護漕乏人，序參將銜，命往募浙兵六百充標營，統守河口、清江浦、安東等處。翁甫離霍邑，寇忍攻陷，報其城兵無子遺。噫！吳在則霍留，吳去而亡，勢固然也。翁患瘡疾，史公親詣營，贈以藥劑，不啻情同骨肉，其見知名公如此。

壬午年，史陞南部大司馬，邀翁遠送，淚下沾襟，不忍言别，舉薦鎭守南畿兆部，具覆候缺陞補，因諭翁曰：「相見有日，耐守爲上。」

甲申春，闖賊寇入燕都，逃竄紛紛，饑餒不能渡河，翁捐俸濟之，得活數千人。時福藩船泊河北岸，驅命渡河，翁操弓挾矢，隔河免胄，正色而言曰：「古云但聞將軍令，不聞天子詔。殿下渡河，非撫鎭之令，不敢行也。」督撫路命獲駕楊州，司馬迎立南都，奏封都督僉事，掛鎭國將軍印。厥配女弟，叨封誥命夫人，飭守高陲州。

秋，大清襲破李闖，正位燕京。丁酉春，大兵直驅南渡，史閣部總四大鎮守楊州，兵圍三匝，水泄不通。翁曰：「不願與史公同生，但願與史公同死。」殺奔揚州城裏，日夜巡守十八日，援兵不至，被攻城陷。史公被馬騎所逼，援劍自刎，曰：「守土而死，禮也；死不越境，義也。」翁奮力抵敵，射傷右大指，不能提弓，左手提劍，殺死數人，頸被傷數刃，透甲寸許，猶負痛相持。下頤近喉刀傷，墮馬血流不止。

六日，浙兵有識翁面者，請痊之，翁如夢方覺，如醉方醒，不知其所以然。噫！欲死而不能死，固有數乎？

清豫藩乘勝過江，奏準明朝總鎭吳良翰照舊領營，遂勉強鎭守嘉興。翁病稍愈，設醮祭史公，哀慟不已，死而復甦，哭告靈右云：「翰不能同歸揚州，敢貪生求富貴乎？」將兵册交與姜副將，泣求歸里，時丙戌春也。

公在嘉興，黃冠野服，道號松石，與高僧隱宦扶疾以游，臘月得返故盧。好居幽谷，絕口不談世事，禮葬生母馬夫人，廬墓左，親築塋道，植松廕庇，泣曰：「爲國不能盡孝，吾罪也夫！」

厥嗣一，諱應浩，字克大，其人樸誠勤儆，翁疾篤𥸤天請以身代，割左股以療之，公病及愈。媳陶氏，義庠諱基之女，雅淑孝慈，能盡婦道。噫！國有忠臣，家有孝子，可謂兩難。以其女貞淑適趙諱貞，文辭雅秀，中己酉舉人，蓋小巖鍾祥邑侯之嫡孫也。長孫用孝，次用友，少而多慧，必能克家。

公享年四十有三，生萬厯戊申冬，卒於順治庚寅夏。夫人享年四十有二，生於萬歷壬子冬，卒於順治癸巳秋，合葬澤園封君墓左焉。

公之至戚莫如予，公之相知亦莫如予，雖細行微善不能述，而出處大節不苟，子不敢畧也。勦流賊是其勇，守揚州是其忠，棄官而歸是其義，至死不辱是其智，始終不失史公之知己，當與死難諸賢同芳青史，天之報施寧有量諸？

贊曰：

性廉而直，質温而端。
五經搜義，韜畧奧觀。
棄文習武，詩咏桓桓。
殲賊霍邑，冠聞瞻寒。
河口施惠，保障淮安。
榮封鎮國，進爵加官。
楊州死戰，几夢邯鄲。
天報忠勇，茁發孫蘭。

旹順治十四年歲次丁酉菊月吉旦

欽選文林郎知宿遷縣事，內弟鄭應兆頓首拜撰

## 又賀致仕號松石道人贊

心超萬物，屣脫一官。
鎭坐雲松之下，棲神泉石之間。
昔也斬鯨蛟而靖海字，今則調龍虎以煉丸丹。
吾親道人之凝指眞，所謂元之又元者也。

嘉興雙溪汪挺贊

## 又夫人序并贊

夫人義門鄭守祖公之女也，十五歸吳，誥贈鎭國夫人。生有淑質，端莊自持。其事舅姑也，色養備至；其佐夫於官也，忠義爲先；其廸子也嚴，其使下也惠。至於處内外婣族，一循禮節，故稱夫人之德者無閒言。

贊曰：

持端莊兮循天經，篤孝敬兮奉姑嫜。
夫爲武臣兮從征四方，斬將搴旗兮紀功太常。
鸞誥自天兮驊其寵光，夫人雖殁兮令名不忘。

峕康熙丙寅菊月

壻男趙貞百拜撰
