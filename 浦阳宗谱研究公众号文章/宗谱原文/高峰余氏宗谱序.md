# 高峯余氏宗譜序
```
题：[]裔孫伯從謹識
峕：[]大元皇慶三年歲次丙辰仲冬上浣
初始点校：[20251116]《浦阳高峰余氏宗谱》
修订参考：[]
```

余姓肇自秦由氏，其源流最爲久遠。屬族繁盛，無暇詳述舊譜所載，而知婺郡之余，蓋自饒州祥府君來為府判始也。一再傳而榮登膴仕，並掇巍科，繄我世德不冺，後嗣彌昌。歷數世而仁府君遷居烏傷，或以才名奮志靑雲，或以閥閱聯姻儀賓，一門榮盛，直與唐宋相爲終始。顯哉余氏之爲烏傷望族也！

不幸宋祚終移，裔戚窮據，此乾坤何等時耶？廉潔者恥食腥羶，高踏者甘居林壑。我祖談府君，儀戚之裔孫也，因浦陽高峯之下有廬可以蔽風雨，有田可以供饘粥，耕隱於斯，聊爲避秦之計，初不計其後之昌熾若何也。賴其嗣文顯、文繼、文昌，敬事二人，友于兄弟，卒能繼志述事，克振先猷，遂創業於兹，蓋數百年矣。

迄今子姓蕃衍，居處異地，至於途遇不相識者往往而是，其於敦倫睦族之義何居？予甚憂之，乃會諸弟姪，仍舊譜牒而續修之。敘源流，分支派，別行第，編年月，兼以詩銘傳勅畢錄無遺；墳墓壇境，圖形備考。故斯譜也，非徒竊影嚮而驚虛名也： 從源以識派，只知某爲我之祖，某爲祖之祖，本一而分殊，井然其可觀也； 分第以編名，則知昭之不混穆，少之不先長，分嚴而序定，森焉其不紊也； 有文可閱，只前人之行誼不至滅没而無傳； 有圖可稽，只遠久之墳塋不至侵欺而就圮。

祖宗者，本也，忘本者不仁； 尊卑者，分也，犯分者不悌。 文所以彰賢，見賢而不能象者，謂之不肖； 圖無以明界，界明而不能守者，謂之不孝。 然祇斯譜之成也，其可易視乎哉？凡我後昆，尙其勗之！

峕 大元皇慶三年歲次丙辰仲冬上浣

裔孫伯從謹識
