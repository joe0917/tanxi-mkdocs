# 楊氏家乘序
```
题：[]翰林學士亞中大夫知制誥兼修國史金浦宋濂謹序
峕：[]
初始点校：[20250810]《浦阳人峰杨氏宗谱》
```

三代以前，姓氏析而爲二，男子稱氏，婦人稱姓，氏所以分貴賤，姓所以別婚姻。三代之後，氏姓合而爲一，皆用之辯婚姻，而以地望明貴賤。歷世逾久，方策之所載者紛亂難明，以致受姓命氏或失其本真，至於地望之表，則尤流轉靡常，莫從辨定，而黠者唯慕其華顯為之宗。所幸纂修之家，各自爲書以志之，氏族之學因藉之而弗墜。嗜古之士，有能篤志於斯而不懈者，庸非君子之所深與乎？

烏傷楊氏，望華陰而宗囘（回）圖府君，遜孫子蟬聯以進士起家者，多至一十有八，衣冠烜赫，號爲極盛。其十五世孫芾，復從黃文獻公游，博學而𨗉於文，間嘗自謂所受之氏有二族焉，出於赤泉侯喜者，於文則從木；出於中散大夫雄者，於文則從才。蓋赤泉世居華陰，乃太尉震之八世祖；中散雖本派隅，而其先久家於成都，固若判然不相即者。震之元孫修，其言則曰修家子雲，文似未嘗不同其所自出也，此不可不致意焉。

於是研精覃思，徧（遍）覽諸書，尊其信而闕其疑，復大萃羣族之譜而整比之。、聞家有藏牒，墓有斷碣者，必親往徵驗，或移書二百里外，叩同宗之賢以質其見聞。如斯者十有餘載，始克稽其所共宗而達其所由分。經幃錯綜，畫以成圖，而疏其字配卒葬於名下。舊書官階貤典，頗乖於宋制，悉加釐正。咨採旣博，凡有繫於譜事者，亦不欲棄去，合爲一編而分爲上中下三卷。

其上卷則推原姓之異同，祖之遠近，旁支正譜，粢然畢紀；其中卷則科第及遺事遺文之屬，而碑碣婣戚識疑並隸焉；其下卷則名人之紀述與雜著祭規之當存者。若夫祭田墓林，亦附見鄉落步畮，而終之以所合齒行之序，其用意也周，其立例也嚴，其於事也辨而有據，精而弗雜，足可傳示後嗣無疑。書旣成，芾之宗兄新民甚嘉其志，乃與族父善寶謀鍥於女梓，且知濂與芾友也，求文以爲之序。

昔者歐陽文忠公采司馬遷史記年表暨鄭元詩譜，依其上下旁行作爲譜圖，非不祥且悉也。及觀公之所自序，則謂詢生通，自通三世生吉州刺史琮，能捍黃巢之亂以安州民。然詢生於唐初，巢㓂（寇）之變則在唐季，上下幾三百年，而其傳僅上於五世。又言自琮八世生安福令萬公，則萬之九葉孫是唐季至宋仁廟時，甫厯一百五十年餘，而實閱一十六代。何前之遐永而後之短促乃至此耶？夫公以閎偉雄深之學，考證經史至爲精密，而今或踳駁之如是者，蓋事情之疑似容可以理推，世系之承傳不可以知決。若其舊文之失，雖公亦莫能如之何也。鳴呼，邇者然矣，而况於受姓命氏之甚遠者乎？傳信傳疑，此不能無望於纂述之家也。

有若芾者，竭盡劬瘁以就是書，不強其所難知，而文獻森然足徵，可不謂之賢矣乎？濂竊獲而讀之，非惟謹判合明親疎，可以厚風俗而已，其有補於氏族之學，其功爲不細。所可愧者，疾病侵陵，僅存視息，而於芾之所著略無所發越，姑書其制作本旨於首簡，以告嗜古之士，相與謹其傳焉。
