# 桃溪楊氏譜序
```
题：[]太子贊善大夫大學士兼修國史潛溪宋濂撰
峕：[]洪武十三年歲次庚申仲春中浣之吉
初始点校：[20250617]《浦阳桃溪杨氏宗谱》
修订参考：[]
```

國有史，家有譜。史者載治亂、誌安危，歷朝之大帳簿也；譜者溯本原、詳支派，一族之大帳簿也。古昔盛時，氏族掌於史官，故官有譜，姓有苑，族有志。自秦火而宗法亡，越唐衰而譜牒廢。有宋歐陽文忠公修、蘇明允先生洵創造譜系以聯屬之，採本窮源，敦宗睦族之道，於斯而寄。

桃溪楊氏，姬姓也。受氏則胚胎於伯僑，星散則根柢於食我。清白傳家，羣推漢之關西夫子震；淸簡儉素，共仰唐之同平章事綰。其仕而爲公卿，隱而爲碩德，江左江右，未易屈指。婺州治中萬榮公諱倕者，綰之第十世孫也。倕生文部尙書煥，自江西卜遷浦陽之天馬山麓，正爲婺州屬邑。昌黎伯云：「中世大夫以官爲家。」其斯之謂歟？煥生昱，號伯益，仕至蘭谿敎諭。自萬榮公至伯益先生，僅三世耳，卽倦倦於世系源流，詳確備載。蓋預卜其後之必大，使子孫有所查考，非憂深而慮遠者乎？

但伯益公所畱古帙，編而爲一，距今百數十年，瓜瓞繁衍，難以合併。於是付諸鋟梓，析爲四部：稽所共宗，達所由分；纂歷代流系於正圖，鐫宋制誥命於簡端；註釋祭禮，題誌獻典，及遺文、官階、生卒、居葬之詳；訪眉山續系圖，效廬陵列行傳。其用意也周，其立例也嚴，其於事也辨而有據，精而弗雜。謂非一族之大帳簿乎？

嗟乎！莫爲之先，雖美弗著；莫爲之後，雖盛弗傳。桃溪楊氏之譜，有伯益公以開於先，有諸君子以繼於後。探本窮源，敦宗睦族之道，後先一轍，亦何愧淸白吏之子孫、文簡公之流裔也乎？是爲序。

峕 洪武十三年歲次庚申仲春中浣之吉
太子贊善大夫大學士兼修國史潛溪宋濂撰
