# 潼塘朱氏創譜序
```
题：[]五世孫諱梧行富一謹撰
峕：[]宏治九年丁巳仲春月之吉
初始点校：[20250618]《浦阳潼塘朱氏宗谱》
修订参考：[]
```

朱氏受姓，實始於邾。周封曹俠於邾，邾併於楚，子孫散落，遂以國爲姓，去「阝」爲「朱」。秦、漢、晉、唐之間，其詳不可得聞矣。

據三世祖宋吉州太守師孟公譜序稱：「世家杜陵，乃漢丞相陽鄉侯之後。」以五代天福間翰林學士公昱爲九世祖，以後周廣順中磁州判官公藎爲八世祖。其修譜則遂以學士公爲鼻祖，盖以往居河南自公始，而歷世尤有據也。今師孟公之譜已不能傳，自判官公迄於宋紹聖間左司諫公勃，相隔百有三十餘年，中間世數多不可考，似宜缺而勿敘矣。

司諫公生敦儒，字希真。宋靖康間避亂南徙杭州，由辟名官至浙東提刑。此吾朱氏南遷之始，故舊譜以爲第一世祖。希真翁生中奉大夫昉，字廷光，始占籍義烏。廷光生宗儒，字師孟，卽吉州太守翁也。師孟生通州司法叅軍璣，字仲玉，度文院判文祥。自是子姓日繁，縉紳冠帶之盛，甲於一邑，所居名邑後朱家巷焉。

文祥生智，智生禧，禧生海陽縣尹榮宗。榮宗生梓七、梓九。禧又生石首縣尹貴宗，貴宗生梓八。梓八同兄梓七、弟梓九府君，始遷居十一都餘慶塘北，是爲泮塘始遷之祖。而梓八府君又由泮塘遷浦陽二十都潼塘內而居，改行昇八。自昇八府君以迄於今，已有五世矣，冠婚之夫殆以數百計。不有譜以序之，將見生齒日繁，至有長子孫而不能以行稱者，比比而是。

於是余告諸族人，族人欣然樂從，遂叅酌譜式，彚錄成集，命剞劂創譜一帙。則今之譜朱氏也，辨其系自泮塘而之潼塘者也，故當以昇八府君爲第一世。更次第其編，細加校訂：一則列譜叙於首簡，次譜例，次字母，次詩文，次行狀，次讚傳，次譜圖，次墳圖，而以世行傳終焉。

是譜也，豈徒以記姓字云乎哉？觀於圖，則爲枝爲葉，一本而條分，井然其可覩也；觀於傳，則尊卑長幼，行别而雁序，森然其不可紊也；觀於傳狀，則行誼德業，作於前者，炳然其不冺也；觀於墳圖，則世數久近，原麓之廣狹，雖遠而勿迷也。

夫圖所以敦本也，忘本者謂之不仁；傳所以昭分也，越分者謂之不順；傳狀所以旌賢也，見賢而不能思齊者謂之不肖；墳圖所以示考也，考焉而不能守者謂之不孝。然則作譜之意深矣！凡我朱氏後昆，尙其朂之哉，尙其勖之哉。

峕 宏治九年丁巳仲春月之吉
