# 柳氏家乘敘
```
题：[]翰林學士承旨兼太子贊善大夫，門人金華宋濂撰
峕：[]洪武己未年九月五日
初始点校：[20251109]《蜀山柳氏宗谱》
修订参考：[]
```

浦江之柳氏，其先居河東解州。宋高宗時，有名鑄者，協從趙忠简公鼎扈駕南渡，以居於杭，退而不仕。尋觀山水，率其子曰瀚，自浙□浦而居蜀山之麓。瀚生森彬，森生監蘊，蘊生補之，任崇德縣主簿。補之生金，官高郵縣令，元贈泗州知州，封浦江縣男。金生四子，其次諱貫，仕爲翰林待制，以文章名天下，諡文肅公。

有子三人，皆善士，而六孫多守其學不墮。沒後三十有七年，而介孫穆書其始徙傳緒之詳，列爲譜圖，持以示濂。濂泣而嘆曰：「天道於是可徵，而文肅公有後矣。」

濂少時幸執弟子役於公門，公之爲人，其崇深宏博者，固非淺見所能窺；至其端方直易，厚重嚴慤，怒氣不形於色，惡言不出於口，不知古之賢者復何如耳。

世之妄議恆謂賢者，議論足以予奪當世，文章足以抉發至理，所爲與造物爭強者，故天道尤忌之，而多難爲其後。是殆不然。天惟有所不能也，故生聖賢出而代之：爲之政以遂天之生，爲之教以輔天之成，爲之文章言語以宣天之道，而使善者勉、惡者懼。賢者何負於天，而謂天忌之哉？其不然也明矣。

是論也，吾意爲聖賢之子孫而不能自力者，姑引天道以自恕，而非其實也。不然，自文肅公觀之，何其異於彼哉？

文肅公之傳今三世，其諸孫盛矣，固可以見天道，而未足以盡報賢之意。今其孫多有德積，久必愈昌，越十餘世將有傑然秀出者興其間，然後可見天道之全也。是譜也，君子由是觀天道焉？穆之後人，安可忽哉！

洪武己未年九月五日

翰林學士承旨兼太子贊善大夫，門人金華宋濂撰
