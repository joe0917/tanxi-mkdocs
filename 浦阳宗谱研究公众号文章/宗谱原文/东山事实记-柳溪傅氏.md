# 東山事實記
```
题：[]總理裔孫濟川謹撰
峕：[]道光癸巳冬月中浣之吉
初始点校：[20250722]《浦阳柳溪傅氏宗谱》
修订参考：[]
```

側聞嶽瀆徵鐘毓之奇，人物稟山川之秀。申甫降生，《葩經》有誌；華嵩協卜，《洛誥》綦詳。是以岡巒鑿而臂折，旺方浚而宅衰；銅山西崩，靈鍾東應。氣之所感，理或然乎？

吾族有祖遺烏頭之山、灶基之地，歷年久遠，關護陰陽。在昔乾隆，蒙勘禁於何邑候；迨至嘉慶，奉碑禁於張臬憲。庶幾驪龍穩睡，頷珠莫探者矣。

誰知道光甲申之秋，復有賈某嘯聚羣邪，鑿既類於五丁，焚更烈乎伯益。是時也，舉族方怔忪而莫措，吾儕咸踴躍以從公。竭慮殫精，恆危坐以達旦；晨霜暮雨，每安步以當車。控經上憲，不辭勞苦；理直氣壯，時歷四春而叶吉，浪靜風恬。

此固賴同人襄□之力，實荷祖先□□□靈也。茲當績修家乘，爰以□□□詳，并將兩造遵結，並爲刊梓附諸卷帙。或者信讞之昭垂，可備後人之参考歟？是爲記。

道光癸巳冬月中浣之吉

總理裔孫濟川謹撰

嵩山 哲人
