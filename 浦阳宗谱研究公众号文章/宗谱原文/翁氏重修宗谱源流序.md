# 翁氏重修宗譜源流序
```
题：[]學士六世孫梓州宗人合老謹述
峕：[]
初始点校：[20250907]《浦阳麟山翁氏宗谱》
修订参考：[]
```

謹按吾氏受姓昉於周昭王之子食采翁山，因以爲姓。迄今三十（千）餘載，布羅海內，不知其幾千萬家也。疇非昭王之子一體而分？第遷此源流莫考，恒切稽訪。忽一日檢閱學士所遺書中，僅存片幅，則曰：

「余閩莆田人。九世祖巨隅公登李唐懿宗咸通戊子進士，累官榮陽叅軍。僖宗中和三年拜左相，越三年丙午進爵海昌侯，故更鹽官郡而曰海昌，所以著巨隅公父子之緒，且以誌吾姓登庸之始。又承贊公詩云：『家世鹽官受姓翁，盛唐缙笏赫闤中。海昌受爵因分郡，閩浙須知共一宗。』

厥後襲封有承贊之子元度，授大理評事；慶之子延休，授振州司馬；休之子仲潛，仕太子正字；潛之子如椿，任建州教諭；椿之子敏政，侍御史中丞；政之子紀，乃予大父也；紀之子仲通，仕黄巖令，實予身所從出也。靖康初贈奉議太夫。

子卽不肖彦國，弱冠與吉水楊邦義俱孝友名世。先帝政和中釋褐，尋吿養親。宣和二年庚子復召見，除戸侍，擢御史中丞。靖康初遷徽猷閣學士。是年金人陷闕，二帝北遷，予亦被擊獲免。噫！痛哉！莫能言矣。止挾少子幼孜由汴歸閩，經浙嚴陵釣臺，不覺子逸思勃發。於是又適三衢，豺狼滿道，堅絶故鄉之念，更名曰韜，遂居蘆茨之源東人梓州，給廬青山之麓，庶理亂不聞，釣隱可彷佛一二云爾。後之子孫宜以子陵百世師，弗攖情出進以貽身家憂。吾尋隱之心永慰矣。」

此學士所述，確有實據。學士少子幼孜，孜生二子：長暠居睦州，次晃行福七居浦陽，詳載於後。嵩之子興祖，祖之子大行，卽子（予）父也。父祖曾高，復膺學士遺命，甘樂田園，不慕榮進，蓋有年矣。

予諱合老，尤思吾氏閩人也，而今爲人於浙，故宜以閩之祖爲浙人源流之祖，浙人之合以學士彦國為一世之始祖。子孫其知之。
