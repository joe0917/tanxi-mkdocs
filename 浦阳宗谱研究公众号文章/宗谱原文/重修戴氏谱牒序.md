# 重修戴氏譜牒序
```
题：[]仙華樵六十六翁周書聘父序
峕：[]嘉靖四十四年歲在乙丑之日
初始点校：[20250904]《浦阳市南戴氏宗谱》
修订参考：[]
```

予里戴氏有耆碩之士世臣、世湻二翁者，修輯家牒旣成，令諸子貢士輗、庠生元第持過余廬中以示，且俾釐正焉。余不能辭。

謹按，其先世家本衢之西安縣孝義井。當元大德間，有乾四二提領者因監稅浦陽，遂擇邑南隅里而居焉，是浦陽戴氏之始祖也。

傳至一十三世，歷二百二十餘年，而子孫蕃衍，遍吾邑之近郊。雖詩書簪笏勿替於昔，而其譜則自八世祖陽武教諭約齋先生於正德辛酉旣葺之後，歷六十餘載，尙未有續之者。今二翁乃能聿追先志，重爲是圖，遠紹近述而再書焉。

八世以上，其間雖有叅易變例，悉皆遵其舊，有所論而述之耳。但自八世而下，又分寧、坦二字之行：寧字則梓二府君之後，坦字則梓三府君之後。乃爲各從其親而類書爲一圖，以别二房子孫之派；共世經人緯，則因長幼之次統之爲一，以見其親親相維、相繫而無所解也。

後以先世之嘉言善行與名公之贈題，足以徵戴氏之文獻者，亦皆類收而登之於卷。故其自根而幹、自幹而根，脉絡分明如指諸掌，則其推本之心亦勤且厚矣。

雖然，觀天文者則存乎歷象，察地理者則存乎職方，闡宗法者莫辨於譜而已矣。或者言宗法而譜牒一有闕焉，□之則疏而遠逸而散、晦而離矣。是故譜牒修則宗法明，宗法明則恩義周，水木根源，孝弟之風油然而生焉。

嗚呼！約齋作之於先，二翁繼之於後，豈非君子有孝子、孝子不匱者乎？令輗輩行將獻藝大庭，顯親揚名，大亢厥宗，豈非孝子永錫爾類者乎？則戴氏方興未艾，又可知矣。是用併書以族。

峕嘉靖四十四年歲在乙丑之日

仙華樵六十六翁周書聘父序
