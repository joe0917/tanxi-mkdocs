# 洩水龍王廟記

【县志本】

環睦皆山也。其桐廬僻焉有峙於東，曰“泄水”。以水得名，豈爲山下出蒙泉之義乎？郡志雖無可考，然自上元庚辰距今凡百年矣。
【環浦皆山也。其界桐廬僻隖有山峙於東，名曰泄水山。以水爲名，豈山下出泉之義乎？羣志雖無所考，然自紹興庚申距今凡百餘年。】

崇崗峻嶺，吐霧吞雲，古木枯藤，含烟罩日。皎皎其日如麟斯煇，凛凛其風如角斯觸。半山飛瀑巽水之澤也，一江捲雪躍淵之瀾也。朝暮晦明，萬千形狀。
【崇岡峻嶺，吐露吞雲，古木蒼藤，含煙罩日。皎皎乎如鱗斯輝，凜凜乎如角斯觸。半山飛𤄗（瀑）𠸃水之澤也，一江捲雪躍淵之瀾也。朝暮晦明，萬千形狀。】

邦人異之，謂有靈物在焉。孰爲靈物？龍是也。《春秋·左氏傳》曰：“深山大澤，實生龍蛇”。《晉·趙至傳》曰：“龍嘯于野”。
【邦人異之，謂有靈物在焉。孰爲靈？龍是也。《春秋·左氏傅》曰：“㴱山大澤，實生龍蛇”。《晉·趙至傳》曰：“龍嘯大野”。】

大而深邃而有容，時飛時潛，隱顯變化，騰百川而洽萬物。謂之靈也。
【大而㴱𮟏而有容，時飛時潜，隱見變化，騰百川而洽萬物，謂之靈也。】

則宜於是，信之敬之且祀之。歲旱，有禱則有驗。初焉一邑，次焉一郡，又次則杭越衢婺，聞風而至者總總如也。
【則宜於是，信之敬之且記。歲旱，用禱則有驗。初焉一邑，次一郡，又次則杭越衢婺，聞風而至者總總也。】

戊申，旱太甚，葉林道者周覺明，悯之先里人詣山下露宿風飡瀝血忱以籲，凡七日，是夜有夢，翌早大霈，夢可誣雨不可誣。信矣，靈物之在也。
【戊子，旱太甚，華林道者周覺明，憫之先里人詣山下露宿忘飡瀝血枕石以籲，凡七日，是夜有夢，翌早雨大沛，夢可誣雨不可誣。信矣，靈物之在山也。】

自古靈巖勝境必有祀祠，此山無之。綿絶一小庵，輿缺望甚，是用辦肯心出死力。以隻影孤身募衆緣、積銖寸，累日培月，蓋砌成一大殿。紙庫庖滆亦粗備。又懼傍無棲止，孰奉香火，又曷爲𧥶（誑）者，更百計區畫，一力開創，而庵宇成。
【自古靈巖勝景必有祠。此山之緜（绵）邈，一小庵輿望缺甚是用瓣香心缺死力，以隻影募衆緣銖積寸，累日增月，砌成一大殿。紙庫庖湢亦粗僃（備）。又懼旁無棲止，孰奉香火，更百計區畫，一力開刱（創），而庵宇成。】

是役也，始於紹定三年，越明年終竣事。
【是役也，始於紹定三年（1230），越明年終竣事。】

此其志蓋欲無忝於對越，癯然一翁，心剿力憊，勿顧也，然則祠果不可少乎？
【此其志葢欲無忝於對越，癯然一僧，心殫力憊弗顧也。然則祠果不可少乎？】

昔老杜有“龍依積水”之句，楊子有“龍欲飛天”之句。
【昔老杜有“龍依積水”之詩。楊子有“龍欲飛天”之句。】

夫如是，則飛蟠上下，神仙無術，山巔水涯，時其寓耳祠之一隅，或者未稱。覺明曰：神靈固無定在宗奉，當有定所。此羹墻見堯之意也。曷其奈何弗祀。
【洵如是，則飛蟠上下，神仙無方，山巓水涯，特其寓耳祠之一隅，或者未稱。覺明曰：神明固無定在崇奉，當有定所。此羹牆見堯之意，曷其奈何弗記。】

嗟夫，覺明窶人。自其託身空門，鬻盂飯碗無恙也。其生計瀟然，非有西疇南畞，祈其雨介黍稷也。其力禱空山，非垂涎項下珠也，其寸椽片瓦，肩夯背負，非惡逸而喜勞也。斯人也，萬有苦一無覲觎，以心而求，良可嘉也。
【嗟夫，覺明窶人。自其托身空門，粥宇飯枕無恙也。其生計蕭然，非有西疇南畞，祈甘雨介黍稷也。其力禱空山，累日不息，非乘龍頷下珠也。其寸椽片瓦，肩任背負，非惡逸而喜勞也。斯人也，萬有辛苦，一無覬倖，以心而求，良可嘉也。】

隣峯崇因院主僧師昭師約具以實，且俾予以志巔求。予有幸鄉邦之若人也，其敢辭。
【隣峯崇因院主僧師昭師得具以實告，俾予以志顚末。予亦幸鄉邦之有若人也，其敢辭。】
