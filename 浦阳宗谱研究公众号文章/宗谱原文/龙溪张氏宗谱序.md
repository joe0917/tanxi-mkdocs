# 龍溪張氏宗譜序
```
题：[]翰林待制烏蜀山人柳貫道傳撰
峕：[]峕時元至正二年壬午夏
初始点校：[20250801]《龙溪张氏宗谱》
修订参考：[]
```

宗法立，則人倫厚而風俗美；宗法廢，則親族離而恩義疏。自井田封建之法變，卿大夫家無世祿之守，子孫散處，世遠益分，大宗之法不可得復立。後世士君子念水木本源，欲合親族，幸有譜牒之修爾。

余觀張氏譜，自宣王時張仲始，後肱遷姑蘇，而稷府君於齊永明中從清河至剡。乾德中，有曰源字天與者，自剡之東陽白鹿。六世孫諱貴者，生祚，為宋浙東安撫司提鎮，此吾友恕之大父也。自恕而溯之源，世雖不遠，而大宗小宗固有在矣。

提鎮公積德累仁，恩澤綿遠，他日子孫必至繁昌，不可勝計。於是乎考之，則宗法可明，人倫可厚，風俗可美，親族可以不離，而恩義可以不疏矣。茲因如心（恕）之請，敬書於此，使後張氏之子孫知如心（恕）今日作譜之意，惓惓有厚望云。

峕時元至正二年壬午夏

翰林待制烏蜀山人柳貫道傳撰

浦陽龍溪祖(1世) : (宋) 張祚,行伯十一,字叔元. 鎮守浦陽遂卜居縣東水埂巷.

祐公派下房祖(5世) : (元明之際) 張昌祖,行富一,字勝可(十甲祖) ; 張望祖,行富二,字時可(八甲祖) ; 張紹祖,行富三,字繼可(二甲祖) ; 張輝祖,行富四(五里祖) ; 張銀祖,行富六,字安可...等.

森公派下房祖(5世) : (元明之際) 張述祖,行雅一,字憲可 ; 張懷祖,行雅四,字珍可 ; 張似祖,行雅七,字學可 ; 張壽祖,行雅九,字伯初 ; 張盛祖,行雅十四,字伯謙...等.

述祖公派下支祖(9世)：(明) 張永璇,行積十四,字彥用 ; 張永環,行積十八 ; 張永富,行積二十...等.

闔族冠名字母(5世起) : 祖景仕叔永子文孟元應一德以 守邦可致時咸若世序必其榮大 能光家國.

闔族冠字字母(5世起) : 可公仲志彥思廷克伯汝尚用光 惟懷希振宗存紹崇道允宜承之 纘循先業.

散居地 : 浙江省浦江縣等地.
