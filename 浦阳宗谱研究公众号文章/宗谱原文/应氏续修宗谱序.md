# 應氏續修宗譜序
```
题：[]賜進士出身議大夫太常寺鄉奉誥進階通議大夫應存卓拜撰
峕：[]萬歴壬寅臘月吉
初始点校：[20250828]《浦阳人峰应氏宗谱》
修订参考：[]
```

應之得姓自周武王封應侯始，其遷於永康可投自太祖德鎔始。應氏之有譜也，自嘉靖間東白公璋、草亭玠倡之，竹泉栻、顧南望和之。今之重修也，則有裔孫明夫倫少陽淑徵貞卿亮廷亨通肖巖汝霖澹庵煒梧岡鳳韶、華東、昌煥邦聚椬邦本、守忠、巨川、大舟熙宇、守臣、思謨乘臯實注意云（未知人名未标点）。

昔周官比長、族師、閭胥、䣊正德行通藝刑賞，又如蒐狩、鄉飲、講訓、讀法，以至書衣冠、表宅里，凡所以敎禁章示勸迪，以納民於善紹，無所不用，然而未足也。又必使之知其世，是故有小史掌尊世系，辯昭穆。嗣後有史公拳拳於述世家，隋唐而上圖譜有局，知撰有官，四方以家狀至者，官爲考定。貞觀中又撰為氏族八數百餘姓，其指歸要使之知其世也。知其世則人各念其祖，愛其身為善者衆矣。然則譜牒之所關顧不重歟？

應氏自應侯之後，魏有璩者封開國公，食邑汝南，因以爲郡。晉時有詹者封冠陽候，徙鎮江南。余家祖之歷至李唐光啟間，德鎔、德行公實爲昆弟。德行公世居仙之夏閣，德鎔公徙居婺之可投。八世孫有少師公之忠貞受知人主，經略公之節義以身殉國，皆焜耀史册，寫奕後先，其應氏之烈烈者。餘若掇嵬科顯淸朝者更僕未易悉數，要之子姓番衍，簪纓世濟，實與余祖德行公之後實相輝映焉。

以故婺之朱門□閥不一而足，而推故家必以可投稱首，如晉言王謝，唐推顧盧然。嗚呼！斯豈偶然故哉？夫積厚者光流，根深者葉茂，世德之盛所從來久矣。然則應氏之後蓋未有艾也。

蘇子有言：觀吾之譜者，孝弟之心油然而生。吾觀應氏之譜，不令人動木本水源之思乎？今可投倫輩有繼述之志，重修宗譜，乞序於予。華東素與余善，余弟存章實與巨川遊，又嘗與余言及先君大司冠公諭以可投始祖與余祖懿親事甚悉。予亦知先君親詣可投祀始祖，敘族誼數，不憚跋践之勞。余卽謭劣不能文，敢不勉強序次，冀誦二祖之德，以光昭於弗替歟。
