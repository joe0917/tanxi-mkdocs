# 合溪魏氏宗譜序

```
峕：[]永樂甲辰年月在仲冬
初始点校：[20250901]《浦阳合溪魏氏宗谱》

```

粤稽周官之司，辨昭穆以定家邦，此譜牒所由作也。至於司馬氏作史，記其敘載傳，實欲考其詳而然也。夫國之所稽者曰史，治亂廢興存焉；家之所錄者曰譜，生卒次序記焉。然國史不纂，則暴君污吏代作；家譜不修，而孝子順孫遠矣。故家不可以無譜，恐其傳歷之久，世代之遠，承繼子孫不一，生卒無以考其實，蒸嘗無以應其時也。

我魏氏之祖諱仲仁者，係台甫公之次子也。値宋亡兵燹，羣寇剽掠，挈妻攜子，從富春分派而來浦陽靈泉嘉興合溪之界，卜地築室而居。迄今以遠，其弟五世孫文貴公追念始祖來歷之遠、創居以久，恐其失於究攷，延師同□□春查閱宗譜分派之源，錄成世系圖傳，以備叅訂於後。其木本水源之義不忘也。

然譜牒之設，誠百世子孫之所以當修也。第以年歲之遠，朝代之久，支流之分，鄉郡之異，無可考而修也，所以魏氏不能不興乎，慕羡之而然也。遡其原始，鉅鹿分派河南之族，歴世之遠由得而詳之。

自今而後，若子厥孫繩繩相繼者，能如祖公之心爲心，登是譜而不失其行傳流系之序，庻無愧矣。則魏氏之門豈不愈高而愈大乎？因書以弁其譜端，用心朂諸後人云耳。

旹永樂甲辰年月在仲冬

義烏庠生王叔豐 序
