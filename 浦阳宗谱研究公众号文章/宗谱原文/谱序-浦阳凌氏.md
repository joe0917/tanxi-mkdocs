# 譜序
```
题：[]儒學教諭、寧波府慈谿縣羅鍾謹序
峕：[]嘉靖十六年歲次丁酉
初始点校：[20251225]《浦阳凌氏宗谱》
修订参考：[]
```

先儒有曰：「民吾同胞，物吾與也。」夫民與物疎也，而有同胞與物之親，況與吾同宗者哉？人於同宗之親，往往有弗親者，勿知耳。使其知之，豈爲是哉？

譬之途人相遇，同舟以行，初相汎汎，迄聞語言，知其爲同鄉人，則懽然相就，胸臆傾倒。有勞則思均之，有疾則思救之，併力以禦之。何則？知其爲其鄉人也。使終於弗知，終於途人之相遇矣。

是故宗譜之修，所以教其子孫，使知同宗之親，豈可視若途人，而不若同舟之鄉人哉？

浦陽凌氏，其先世出自姬周封康叔之後。歷漢而唐，代有顯宦，難以枚舉。至大宋熙寧間，有諱簡者，初居全華之責溪而來，仕於浦江，爰其山水殊勝，民俗湻厚。後官至朝議郎，告歸之市，館穀三十餘日，補列新傳若干篇，加以考據。

自宋簡公第一世始，今於旻傑十八世之二十一世，編爲九卷；凡墓記、銘贊之類，編爲三卷；通爲十二卷，題爲《浦江凌氏家乘》。猶慮未精，僅可觀而可讀。讀之者，庶幾感發興起，而善端油然，將不可遏：敬吾祖、愛吾族，休戚共之；人倫明而門祚厚，子孫保之，延於無疆。不亦美哉！

峕：嘉靖十六年歲次丁酉
