# 浦陽季氏創修譜圖序
```
题：[]來遷三世孫直本邑月泉學襄述
峕：[]大德十一年丁未春二月吉
初始点校：[20250623]《浦阳季氏宗谱》
修订参考：[]
```

季氏之先，出自魯桓公第四子季友，後世子孫因以季爲氏。季友生愷，諡文子，愷生行父，諡文子；行父生宿，諡武子；宿生紇，諡悼子；紇生意如，諡平子；意如生斯，諡桓子；斯生肥，諡康子。世居魯爲相，見於魯史可考也。

至漢時，肥之裔孫有諱布者，居於楚。高祖五年拜中郎將，遷河東守，於是子孫世爲楚人。布生光，光生沖永，沖永生興祚，興祚生元。宣帝本始間除太尉。元生安世，安世生湯，湯生益德。平帝元始間授著作郎，王莽居攝元年致仕。益德生定靜。自布至定靜九世，見於東漢建武朝都尉馬武敘中郎之系，可考也。

後定靜二十四世孫，唐垂拱時有諱無者，挾才抱德，士屢薦於朝，因武后稱制不仕，與同門友鄭仁傑隱居太白山。無生德昌，德昌生永，永生可，可生廣，廣生仕信，仕信生孚，孚生艮。於中和間避黃巢之亂，由楚遷婺。艮生績，績生敦化，敦化生翊，翊生景成。祥符間累徴不起。景成生銳，銳生斐，斐生度，度生周，周生陵。宋建炎中拜中書舍人，生南壽，爲婺庠弟子。紹興中應博學宏詞科，除盱眙尉，生永嘉，遷居烏傷崇德鄉之繡湖西。永嘉生理，理生何，何生焦度，焦度生襄。大父偃於我朝至元三年由烏傷而來，遷於浦陽市西臨浦巷之北。大父偃生襄父臣，屢爲學賓。

吁！吾家受姓之端倪，傳世之次第，宗系地理分合之來歷，嫡庶嗣續引替之源流，賢哲用舍出處之行實，班班可考。而圖位次於左者如此。自吾千百世之後，子孫當世守之而不失，引長之而不替，庶可謂之賢子孫矣。

峕 大德十一年丁未春二月吉 
來遷三世孫直本邑月泉學襄述
