# 黃氏宗譜序
```
题：[]同知經筵事、九世孫溍謹序
峕：[]至正十年冬十一月甲子
初始点校：[20250616]《浦阳东溪黄氏宗谱》
修订参考：[]
```

古譜圖有局，掌於史官。迨後官亡局廢，而士大夫之家皆自爲譜言氏族者。黃氏，嬴姓陸終氏之後，相□賜姓。而其後有江夏、黃諸國，爲楚所滅，子孫之有仕楚者，有黃歇，出於金天氏者，自臺駘封汾州。而其後有沈、姒、蓐、黃諸國，爲晉所滅，子孫之仕晉者，有黃淵，皆以國爲氏。

漢尚書令香、太守瓊父子，江夏人。唐之江夏，諸暨、會稽、零陵、巴西、東郡、江陵、洛陽、晉安八郡，皆有黃氏合也，同望於江夏，何以別之？官失其守，譜學遂絕，乃欲旁引曲證而推及於千載之上，固難矣。

惟婺之黃氏，中金華而從越之剡，洪之分寕、豐城之雙井，信之弋陽、江陵之監利，爲五大族。而溍之九世祖、八世祖仍居婺之浦陽。舊譜以爲自分寕來歸，而郡誌所載黃氏先墓見開元十道圖，則浦陽之有黃氏已久，似未可以舊譜爲信，其言必有所本，無從考質也。

七世祖始遷義烏，族日蕃衍，系序之承傳，支屬之分異，斯可得而詳焉。六世祖隱居不仕，用薦者當官，未受命而歿；五世祖亦隱居弗仕。逮我高祖，乃以子孫累應贈典，其以進士登於科者，我曾祖而已。

先祖先考，在異時俱書浦官者而不及祿。溍際世時盛叨備官使□獲，難思於二代，顧以鄙劣無似，弗克負荷。駿尋暮景，一旦殞滅，以爲大恨，安可無使後人知夫源流之自，而思亢其宗乎？

昔太史公庭堅自敘本出於金華，而其始遷及於分寕，七世以上皆略弗著，蓋慎之也。應敢竊取斯志，自九世祖而下，邱隴之尚完、祭享之不廢者爲之圖若譜，歷歷可諳；疑不能明者，悉闕焉。

凡圖譜之法，親者宜詳，疏者宜略。爲子孫者，各詳其親，則其所略者自可見。今不以親疏爲間，而或有所遠者，恐諸房子孫不必人人能有其譜，而於所親者致各其詳也。來者當思補其所未備，而無厭其傷於繁哉！

峕 至正十年冬十一月甲子

中奉大夫、翰林侍講學士、知制誥、同修國史
