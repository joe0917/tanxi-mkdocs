# 東臯記

峕：[]咸湻二年首夏月
初始点校：[20250225]《浦阳姑山毛氏宗谱》民国辛巳重修[1/33]P080

石梯東行二里許，皆山也。有山巍然而高、鬱然而秀，左陵右谷、突然而深藏者，東臯山也。

環以大溪水清而猗，屏以翠巘[^1]左右是宜。美哉，山川之勝。余兄深源徃來於兹焉。寓目而盡得之，遂卜而壽隴焉。於是疏泉鑿石，去榛與蕪，搆庵於上，菴（庵）之前植佳花異卉，引流觸之水，築翫月之臺，隨地扁亭，各有佳趣。

山之巔，亭以“飛雲”名匾。水之涯，亭以“畫舫”名匾。仙種芬芳，艷葩絢彩。亭扁以仰仙想像武陵之風物也，疎影横斜，暗香浮動。亭扁以如雪髣髴孤山之標致也，玉壺呈瑞，金粟飘香。亭匾以步蟾遠挹[^2]廣寒之境界也，亭之扁不一，亭之景亦不一，幽談閒遊，不可名狀。

吾兄貪延勝景，朝而往暮而還，是去來而不憚其勞。雖旁蹊曲徑，徧蒔美草，交羅森錯，而不憚其烦。搜奇扶怪，曲盡棲亭之巧，又節以丹青塗艧[^3]而不憚其费。

一日落成，山水登臨之美，亭池花木之麗，燦然在目中矣。

客有訪余而言曰：“深源於其藏宿之地，為逰憇之所，亦吾里之所稀有者，惜其山徑崎嶇，人跡罕到，徒以借愚夫野婦之休憩，所以游士女迎軒蓋者，缺如也。不幾同夫錦衣夜行乎？”

余應之曰：“人情不同，亦各随其所，適而巳矣。喜繁鬧者，則處夫闤闠之市；樂恬靜者，則耘乎寬閑之野。二者各有適焉，不可強而同也。

余兄讀書而不切切於貴治身，而不汲汲於富進之。橋門志不願仕，其易所謂遯世者歟。厭俗態之喧譁，倦應酬之旁午。一身之外不復寸事，若將友漁樵糜鹿，其古人所謂梓人之士歟。

每兄見弟升歷華胃，必譏之曰：‘君登青雲去，我從青山歸’，怡怡自適，無一毫中熱態，宜其圃於斯亭、於斯舒笑、於斯自樂而不去，不以為憚。”

客笑而不答。

歲閏旣望，余侍兄往遊焉，盃酒淋漓，步月而歸，因以客之問予，與予之應客者告兄。兄曰：“子幾得我心之同然者。”

故執筆以攄[^4]其概。
