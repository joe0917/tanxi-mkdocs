# 家乘一覧記
```
题：[]賜進士第、御史中丞、參知政事嗣孫 京 拜手撰
峕：[]德祐元年季冬月旦
初始点校：[20250704]《浦阳董氏宗谱》
修订参考：[]
```

凡言姓氏者，皆原於《世本》《公子譜》二書。二書則本《春秋左氏傳》。《左氏傳》則因生賜姓、胙土命氏，及以字、以諡、以官、以邑五者而已。後世得姓受氏者多至三十二類，益淆雜難明，况襲氏冒姓之不一乎？無怪錄附之不足徵也。

惟余董氏，系出黃帝，著於江都，而恢於大司馬。諸先大人世代淵遠，已經更變，或宦他州，并商別郡，或贅居而遷徙，或緣事而別姓，遍布天下，厥難辨哉！遡吾本宗，因官毗陵，遂家於萬齡界。及後子孫星散各居，一分浦江，一分曁陽，一分剡邑孝嘉鄉，皆以德行文望亢宗，子孫甚眾，郡稱鼎族，係各保其一支，而統緒莫稽也。

幸書於譜者，皆吾親宗嫡派；其不載吾譜者，冒認吾族，總富而不可招。是族子孫雖貧而不可畧，玉石有別，清濁可分。京幸忝甲第，歴仕中丞，締思祖德之顯奕，名繪史册，班班可攷。特具奏章，冒犯天威，奉請御實勅書，冠譜牒之首，以傳後代。今因休致，謹修諸譜，以起將來云。

峕 德祐元年季冬月旦 
賜進士第、御史中丞、參知政事嗣孫 京 拜手撰
