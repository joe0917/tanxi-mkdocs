# 重修家譜序
```
题：[]前纂修外署史孔氏教三衢北野 伍聰（撰）
峕：[]嘉靖丙申仲秋，
初始点校：[20250709]《浦阳金氏宗谱》
修订参考：[]
```

金氏受封彭城，傳之久矣。海內蔓衍，氏族莫知幾何。浦江金氏遷自東陽白水，由宋元豐間，萬五公桓者樂通化風俗之美、土田之沃，因此卜而家焉。

萬五公生壽七，壽七生福六、福七。福七縣尹，福八點獄。傳至敬七進士，授西臺遼院判；又傳至蕪湖巡檢宗品，以陞二尹及鎭一大使。後此則咸二、咸四、滿十二、正二、正五諸翁，皆以齒德援例壽官，冠帶張大。內德則有陳氏之孀節、潘氏之賢孝，一族清絜，耕讀傳家。

自方施、上金、汪塘、櫝溪、東市、市目、湖塘、虹橋、盈塘等派，咸克振家聲。而氏族日繁，盡出孝節之裔、尙書之派、文安之族，若山若海，不亦高且深乎？夫山高勿陟，孰知其高？水深勿濬，孰知其深？扳陟仰止，疏濬沂折，在乎賢後人耳。

金氏舊乘燬於兵燹，儻存殘簡，以澄本源。世次雖赖以明，而支派混淆，名分齟齬，病由譜弗修耳。嘉靖丙申八月，裔孫廷秋暨從子姪仕陳、仕懷輩爲倡，而文盛、文容、文馭胥從而和者響應，遂延余秉筆。謹按故乘，輯舊增新，源流世系燦然詳明，名分昭穆秩乎有序，而族屬瞭然矣。

祖始於一，孫散於萬。一人者，千萬人之本，猶太極也。一元之氣，流行不息。自一人視萬人，故無遠近親疎之殺也。觀此譜，則親睦之念、孝弟之心，不油然而生乎？是以故家世族，百務可緩，於譜爲急急也！韓魏公曰：「謹家乘而不忘其先者，孝之大也。」金氏子孫引而弗替，則世相親睦，人相尊敬，保重本源，愈久而愈遠；思齊先世，愈高而愈深。尙當擬泰岱，配滄海，無窮於兩儀之閒，斯可矣。金氏朂諸！

峕 嘉靖丙申仲秋，
前纂修外署史孔氏教三衢北野 伍聰（撰）
