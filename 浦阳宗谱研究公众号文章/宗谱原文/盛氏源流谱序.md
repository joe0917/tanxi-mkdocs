# 盛氏源流譜序
```
题：[]知眞定府剌史嗣孫 宗仁撰
峕：[]大元元貞二年歲次丙申菊月
初始点校：[20250917]《浦阳盛氏宗谱》
修订参考：[]
```

粵自顓蒙既判，厥初生民之餘，君天下者分茅胙土，賜姓命氏，設史官以掌世記。緣是而後，封繁而姓氏日衆，倍蓰什百，不可殫記。天下士大夫家始各爲譜牒以統宗族，支派攸分，尊卑攸敘。慨夫家饒裕者羞其先世之寒微而遙援華胄，身顯榮者耻其祖父之卑鄙而私附哲人，良可嗤也。

吾姓本周文王以二十八子曰樊寉者，封國於盛，而以國爲氏。蔓至春秋，列國疆土星布，迨及秦政虎噬天下，國亡邦析，子孫散處四方。厥後有諱璫者，初居虞城，唐末仕錢氏爲餘杭令，家於湖州之安吉。至天成三年戊子歲，諱德恭字文正者，由錢塘官蘭谿學博，避五季之亂，攜家衆遯於婺之蘭江石塘嶺，斬茅墾土居焉。迨世寧謐，始古籍爲蘭江盛氏。

遡文正君之前，在漢有祖諱吉者，官至廷尉，視事二十年，天下稱其有恩無怨；至晉有諱彥者，事母至孝，母目失明，誠感於天而復明如故，職授中書；曰彥師者，唐武德間官至武衛總管，擊斬李密以功封葛國公；曰度者，宋眞宗朝中甲第，官至行人，奉使西域，繪西域圖以獻，官至參知政事，諡文肅。皆先宗之達者爲。

宗仁叨上世之德澤，忝任真定府刺史，致政家居，深思本源之正，遡其所自出而傍搜之，推其所可知而乏繆附之濫。家乘之祚，循蘓公世系之派於其先，效歐陽公五世一斬之制於其后，大書其名，分書其字於其下，嫁娶事跡、生卒年月、墓田行實無不備書。惜乎文正君以前譜牒散軼，如石鼓之文、山之碑，闕不可補，斷不可續者，置而勿書。自文正君以下則謹錄之，井井有條，學目可覽。

第安吉之族屬遼遠者無所攸會，今時以文正君爲第一世祖。考之文獻足徵，而圖譜世次昭然不紊。自周受姓之後，廷尉公吉、葛國公彥師、文肅公度，簪纓奕世，殊非傳濫。視彼湻安汪氏授魯族、吳寕杜氏宗漢延年者，霄壤懸絕也。

余慨世久譜牒漫而不修，則愈遠而愈失其眞矣。於是質諸耆舊，蒐羅考訂，編集成帙，用垂后裔。庶幾尊祖敬宗之心油然不冺，則吉有慶、𠒋有弔，不視親親如途人者矣。

峕大元元貞二年歲次丙申菊月
