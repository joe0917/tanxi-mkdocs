# 海塘洪氏宗譜序
```
题：[]第十一世孫澤字宗潤拜序
峕：[]景泰丙子仲冬朔後七日
初始点校：[20250908]《浦阳海塘洪氏宗谱》
修订参考：[]
```

予家譜牒奈遭元季兵火，幸於柳文肅公文集有予家譜引，及得所藏世系，始知予姓出自共工之氏。後漢有共賜生雍，雍庄劉，劉生教，教生慰，慰生友，友生普。普於漢靈帝時爲司隷校尉，因中常侍曹節、王甫矯詔誅竇陳二氏，避嫌易姓共曰洪，居燉煌。其子明，明生晉，晉遷歙之黄燉，生矩。矩子二：孝昌、孝儒。儒庄源，源子二：是、昺，是遷盱眙。昺生師敏，師敏生延壽，延壽生漢宗。宗子二：古愚、古雅。古愚居原，古雅號八巖仙翁。唐僖宗時黃巢作亂，父子卜居，卜者曰：「從南而去，遇樂則止，遇風可居。」後至樂平楓木橋，憶卜之云，遂居焉。

古雅子二：金、玉。金之子嗣遷浙江，未考其所；玉在樂平，生師暢。唐昭宗朝累官銀青光祿大夫、上柱國，贈新安郡公。子三：華、蔚、茂。華生獻邦，邦生溮、同，遷鄱陽。同生桀，傑生幹，幹生士良，士良生炳，炳生彦先。先生皓字光弼，由進士累官朝議大夫，謚忠宣，曰忠與孝，事昭史傳，不贅。子八：适、遵、邁、逖、遜、邈、遽、迅。适字景伯，遵字景嚴，邁字景盧，俱擢詞科，並登台鼎，當時稱曰三洪，事蹟亦各見史誌。逖字景遷，常州通判；遜字景和，連州僉判；邈字景宣，武德主簿；遽字景安，國子監丞；迅字景理，仕司錄。惟遵則浦陽鼻祖，而沿其裔生栻，官將仕郎。栻生備，知婺州，子三：葆、荃、茱。葆居紹興，荃居青田，茱字名纘，號衡宇，登嘉定進士，官至侍御史，寓會稽。因玩遊山水至浦江官巖山，去西北三里有地土豐而厚，卜其可以綿瓜瓞而遂堅居志焉，復名其地曰海塘。

茱子二：堯民、舜民。然於遠祖邇宗來歴之原，由漢而宗，得於文肅公之引如此。其堯民、舜民二派之嗣，而綿綿其延，詵詵其繁，大宗小宗悉載重輯之譜，又得於服叔潮陽公之功。猗歟！予姓雖曰分派有幾，遷移不一，然於黃燉於樂平於鄱陽，逸民之如孝儒、如古雅、如獻邦、如彥先，顯仕之如玉、如皓、适、遵、邁八士、如栻、如備之光前裕後，而信無忝乎共工氏矣。及吾茱公之始遷於斯而爲浦江鼻祖之後，若子若孫，仕逸固多，亦不忝於御史公矣。

抑不知予之世而子孫以仕逸相續者，或相倍蓰，或相什百，或相千萬，如先代否乎？噫！予旣以所居之處騐之，土壤不澆薄而人必無失；又以所布見嗣姓騐之，前旣孝是，後必繼焉。夫如是，則海塘洪氏之居於浦者，實（於）鄱陽、樂平、黃燉又有光矣。故又籲兄乎子仕而因繼潮陽公蹟，以序昭穆，以詔後世，烏得謂之文云？識者毋以爲僣。

旹 景泰丙子仲冬朔後七日
