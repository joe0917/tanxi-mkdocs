# 長陵祝氏宗譜源派序
```
题：[]長陵儒學齋長四世孫鳳瑾敘
峕：[]至元辛巳十八年春王正月之□
初始点校：[20251101]《长陵祝氏宗谱》
修订参考：[]
```

吾姓始自周武王封黃帝之後矦（侯）光公於祝國，後世因以為氏。氏之居太原者甚多，溯厥所自由，十一世祖方公為周上大夫，至二十三世平公為楚執圭，二十七世漢成侯永公為過江之宗，居於陵也。郡守公完為江北之宗。成侯至四十七世散騎侍郎公巡，衢之始遷祖也；成侯至六十八世承俊公，歙之始遷祖也。

厥孫象器公改名用之，登儒科為治平太學博士，與弟景先號二翁，以貲雄州郡，當時稱為祝半州，後有光焉。廷器公之子文矩，文矩公之子時高，致和間以仕寓籍處之括蒼。時高公之子物華，物華公之子伯榮公，郭吾祖也，紹興間以避地又自括而遷浦治之西三十里曰長陵居焉。而係之以陵者，以示不忘於祖居也。

二翁之子磚、□、砱、礪、磊、碏、碑、磐，磐之子堯臣仍在歙，而為歙之派也；砱之子穆字和甫，依朱文公居建，而今為三建之派也。

噫！吾氏之源流如是，吾氏之分派又如彼，又况居斯之後世纔三四。吾祖伯父俱沾一命之榮，吾伯兄與吾兄亦階仕版之登。意其永終所圖，以奠厥居，以繁後姓。無何，吾伯兄以宦成而卜居蘭之太平，吾兄以力穡而徙居蘭之厚倫，吾弟以妙齡而贅居武之方姓。自始遷斯地數人，居此纔十而有四三之播遷若是，則後之居斯土、擇里以衍吾宗之派者，又不知其幾也。使非譜以明之，焉能以昭前而信後？幾何不為塗人之相視於吾宗之派也！

故吾當斯遷之四世孫，而惟恐後嗣子姓愈遠愈繁，而愈不知祖宗之出處遷徙來歴，姑備述以為後嗣示，而并為之助云。

旹至元辛巳十八年春王正月之□
