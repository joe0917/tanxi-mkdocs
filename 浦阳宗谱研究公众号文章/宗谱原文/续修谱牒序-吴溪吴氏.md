# 續修譜牒序
```
题：[]延陵五十二世孫士諤謹敘
峕：[]洪武丁丑一陽前十日
初始点校：[20251229]《吴溪吴氏宗谱》
修订参考：[]
```

族譜之不作也久矣。予家裔出延陵，至子孫散處異方，有遷自鄱陽而蔓於睦者，又再遷浦江新田里。唐乾寧閒，三府君字國賓，遷朱村路下。嘗聞之故老言，三府君距吳季子三十六世，名諱不傳者，由譜牒之不修也。

厥後分居溪東西，而族大盛，人因稱其地曰前吳，溪曰吳溪，而橋曰吳溪橋云。然自上世以來，第行皆避八，不稱以吳。羽音屬水，八坤土相尅，八又皆不利，且以別異他族。

近曾祖堂錄府君嘗修族譜矣，謂崇族誼、睦親親，莫先於明長幼、敘倫理。於是取近支子姓，咸其一第行，會合稱呼，尊卑不紊，使不至於驕富貴而厭貧賤，誠欲敦薄俗而厚風教也。僅再傳而第行不齊者有之，又或者偏生庶出，或者婚娶卑下，或者生自他方，或者豪右欺壓，有至不敢相齒者，或甚至窮乏不肖，困苦無聊者，則又羞與之齒焉。若爾，無怪風教之日壞也。

方今世道隆平，風俗更變，而堂錄之元孫釣、銖，其子姪緯、綱等，克承家訓，欲倣先世敦俗睦親之義。以予年老，頗知前人典則，請以堂錄所修之譜訂而續之。自三府君而下，至童抱凡二十一世，其間文學政事，班班在人耳目者，皆實註之名諱之下，以彰厥後，可謂盛矣。又以本宗世次及支派之親近者，列爲圖表於祠堂之左，俾後之人旦夕瞻仰，追憶前人盛業，以自勉焉，不墜祖先詩禮之教，抑又幸也。

或曰：「昔老泉先生作《睦俗亭記》，嘗怪其激，今所書得無激乎？」蓋以勸善懲惡，聖人刪詩之義；大書特書，春秋褒貶之辭。敦薄俗、睦宗親，豈無少補哉？遂直書於譜首，使後人知所自云。

旹：洪武丁丑一陽前十日
