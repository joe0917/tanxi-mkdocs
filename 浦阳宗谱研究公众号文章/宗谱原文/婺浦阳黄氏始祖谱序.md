# 婺浦陽黃氏始祖譜序
```
题：[]官授皇門侍郎同平章事 畦 謹敘
峕：[]唐上元二年辛丑菊月吉旦
初始点校：[20250719]《浦阳黄氏宗谱》
修订参考：[]
```

古者氏族，乃史官之所記也。故周有小史，定世系，辨昭穆；有《世本》錄黃帝以來，至於春秋諸侯卿大夫名號統系。左丘明以爲：「天子建德，因生以賜姓，胙之土而命之氏；諸侯以字爲氏，以諡爲族；邑亦如之。」迨後受姓命氏，日益衆多。遭秦滅學，公卿子孫失其世系。漢興，司馬遷約《世本》修國史，因周譜以明世家，人乃知姓氏所由出終。漢世有鄧氏《官譜》、邵氏《族編》、王符《姓氏誌》。魏晉以來，有司選舉，必稽譜牒以考眞偽，故官有世胄，譜有世官。唐有《貞觀氏族志》，柳冲氏之學者自五季之後，喪亂相承，譜牒俱廢，士大夫之習其學者遂鮮矣。

嗚呼！崇德貴功，尙論氏族，此聖人所以維持天下，別婚姻，定名分，厚風俗，扶世敎，大宗小宗之法所由久存者也。

然我始祖諱苾，字惠卿者，其先本江夏人，漢尚書令、孝子香公之嫡派孫也。於隋文帝開皇時，徵爲兗州總管，治民以恕，律軍以嚴，境內頗治，政聞於朝，遷金陵按察軍民大都頭。時文帝患盜，有盜一錢者皆棄市。金陵有犯者數十人，當按軍法。惠卿嘆曰：「苟子之不欲，雖賞之不竊，曷至於是邪？」有司請施行盜事，以聞。曰：「姑緩之。吾聞殺一無辜而能定天下者，未之有也，何況數十人之命乎？」遂上書直言其非。會有劫執事以伸枉者，聞於乎朝，遂停其法。於是金陵坐盜者悉得活焉。

又嘗曰：「能穀其後，蓋先善人。漢之于公，當則也。」鎭守吳英，浦陽人，年邁無子，止生一女，以惠卿榮顯仁慈，遂以女妻之。大業間，隋唐兵亂，翁壻皆隱歸浦陽，靶偕姪畦。每慮傳敘寢遠，恐無以昭先德而迪後穎，蒐葺始祖惠卿公之遺文，重加彚次，釐之成帙，以爲後考。蓋深念夫水木本源之義，而以示夫後之子孫，俾知前人之所以顯大者，實由於世德之積，有不可誣者。其心可爲仁矣！

苟仁以立心，則雖服窮親盡，猶一世也；支分派別，猶一人也。豈可遠親疎戚，貴賤貧富，而異其情哉？繼自今，若子若孫，繩之於方來者，能以始祖之心爲心，則登是爲無愧矣。

以予嘉始祖用心之厚，遂書以弁其譜端，用以朂其後人云。

峕 唐上元二年辛丑菊月吉旦

九世孫 官授著作郎 偕姪
