# 歷代源流序
```

峕：[]乾隆廿三年歲次戊寅二月
初始点校：[20251001]《浦阳深袅何氏宗谱》
修订参考：[]
```

按何氏之得姓，蓋由周武王有天下之後，裔孫韓虔封爲韓侯。至春秋韓王安時凡十世，厥孫允公避遷穎州，視左掌有何字紋，更姓爲何。易姓始祖實自此公也。

後至嘉公，又任廬江長史，因地誌郡號曰盧江。嘉公生景，景生寵，寵公六傳至瑛。瑛公生五子：長晉、次本、三聖、四賢，皆官居上品，各遷其地；惟五子諱曰章，廟號孚惠侯。子諱宏，宇元和，號海宇者，官拜御史，因金寇攘華，護駕南渡，退而不仕，隱居古湻安之地。迄今同居之處，皆共係此公裔也。

生二子：長曰皎，遷住諸暨；幼曰皓，守舊居湻安。皓生四子：長光、次明、幼德，皆相繼而亡；惟三子達，生長子名曰和，次曰善。善生二子：長曰敬、幼曰恭。敬子永析居於義邑東江橋，恭生佳、進二公。

斯時韓王至此已數十世矣，世遠族蕃，不堪羣處，應宜擇地而遷。於是佳、進二公順湻安而下，至建邑新亭何村。此地有古遺八景，二公不愛，馴至三井。夫三井壞（壤）地狹小，不堪丕振，又遷浦江廿四都源名周塢口、中桐塢內中何。此處四山拱翠，一水繞流，二公愛而遷焉。同心協濟，怡怡濟美，不數年而家聲丕振，子盛孫蕃。

佳公遷於周塢口，進公生連，連生六子：華六、廣四、存二、存六、勝四、勝八。勝八生四子：長乾五、次乾六、三乾七、四乾十。惟次子乾六行四八者，始遷於二都壽溪源宏塢，因回祿又遷裊溪源英塢坪，乃播居而住焉。

合而觀之，何氏之先，其間名人迭出，簪纓不絕，如絲牽而珠續，瓜瓞綿綿所由來矣。何氏之後有孝子順孫，欲識其根源之始末，其閱之而可乎？

峕乾隆廿三年歲次戊寅二月
