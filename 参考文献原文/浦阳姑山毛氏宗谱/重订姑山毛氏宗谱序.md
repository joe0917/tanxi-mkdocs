# 重訂姑山毛氏宗譜序
```
题：[]邑庠增廣生車方龍橋陳昌言拜撰
峕：[]萬曆癸酉季夏吉旦
初始点校：[]《浦阳姑山毛氏宗谱》民国辛巳[1/4]P26
修订参考：[]
```
姑山毛氏，浦北世家也。盛宋時，由閩來遷，計世二十、計年六百於玆矣。其間隱德行誼，文章政事，彬彬迭出，昭炳諸史，人文之盛，無能出其右者。且祖德之源深，而孫枝之茂盛，則族屬其眾多矣。故各家其家，各弟其弟，不無倫序乖離，使無譜以誌之。

至於某祖仕於某處某也，德業宏恢某也，文章烜赫，某派親而近，某派疏而遠，一本親親之義，豈能悉數而知哉兮。

其第十七世孙，峯山子允滔、鳯軒子廷富，聘予而訂正之，余任事未幾，而月山子思仁、筆峯子臺，持其祖伯玉[^1]輯遺錄《怡叟幽君集》來示余，乃喟然歎曰：“毛氏有幸而僅存者，尚書洪公[^2]之圖譜也，毛氏幸存而未冺者，賢、哉二翁之葺錄也。”

因偕謹細之弟東楷書之，男街翻閱數過，反覆參訂。因辭以考其人，因人以考其世，因世以考其年；畧其疑，補其缺，正其訛。而宦蹟、隱德、忠孝、節義著之首簡。而所遺詩文，條其節款，別為一卷，併已隨地所作鄙句，以附其後。使知昭代，閥閱詩禮，相傳不可誣也。豈非盛哉。

毛之譜耶，雖然洩水[^3]東臯[^4]之記，冠冕佩玉之文也；場橋[^5]翠樓之頌，富貴吟濟之所也；月坡[^6]淡翁[^7]之賡，景星珠璣之落也；雲溪怡叟之錄，卞氏識荆之明也。後人收之，而後人不愛之，後人愛之，而後譜不錄之，終亦必亡而已矣。

噫，鳳軒子輩會譜明倫可焉，不可以騐廣博之仁耶，厥功之茂，後人共知之。

旹萬曆癸酉季夏吉旦
邑庠增廣生車方龍橋陳昌言拜撰

[^1]: 在陈氏家谱平糧實蹟中有记载“邑民毛伯玉，以赋役王册事，致书毛尚书。”，在毛氏家谱各次修輯序文中也多次提到伯玉，例如清嘉慶年間陳志善所撰《毛氏重修宗譜序》中寫到“……尚書公修於前，伯玉諸公修輯於後……”。但其生平事跡却无法考证。包括他的《怡叟幽君集》。
[^2]: 洪公：即姑山毛氏第七世祖南宋丞相毛洪，也是浦江历史上唯一一位丞相。
[^3]: 洩水：指毛洪在咸湻四年撰書的《洩水龍王廟記》。 
[^4]: 東臯：指南宋咸湻二年毛氏第七世祖夢弼（南宋寶祐元年進士，任貴州施秉縣知縣）所撰《東臯記》[[东皋记]]。
[^5]: 場橋：指南宋寶慶丁亥（三年）林子燕為席場橋寫的《席場橋記》。席場橋是寶慶元年由毛氏第四世祖毛日嚴捐造的。
[^6]: 月坡：指姑山毛氏第八世祖毛沔，號月坡，行“庆二十”，曾任南宋僉書海宁节度使判官。（摘自《浦陽姑山毛氏宗譜》民國辛巳本，卷1，毛氏世宦題名實蹟）。
[^7]: 淡翁：指姑山毛氏第八世祖毛清，行“慶二”，號淡翁。（摘自《浦陽姑山毛氏宗譜》民國辛巳本，卷2）。
