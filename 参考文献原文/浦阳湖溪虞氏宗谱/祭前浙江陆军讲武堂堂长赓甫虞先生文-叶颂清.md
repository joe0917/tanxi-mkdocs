# 祭前浙江陸軍講武堂堂長賡甫虞先生文（永八十一公）
```
题：[]浙江陸軍第十二旅旅長臨海葉頌清謹撰
峕：[]民國元年歲次壬子七月 日 
初始点校：[20260725]《浦阳湖溪虞氏宗谱》民国壬申本[3/11]P160
修订参考：[]

```
（未核原文）

民國壬子年六月三十夜，虞君賡甫猝遭暗殺於塗。八士震駭，同志雪涕，為鬼為蜮，不得主名。薏苡之謗未萌，鸊鵜之膏旋飲。識與不識，有餘恫焉。

夫膏以明而見煎，麝以香而致殺。生伈伈之世，而為磊磊落落之行，不苟合，不苟同，獨行其是，卒招物忌。嗟乎！虞君醉心共和，歷有年所，不流血於革命奔走之日，而流血於民國創始之時。伏波裹革，未遂初衷；來歙被戕，卒遭慘禍。君目難瞑，天道無知。嗚呼痛哉！

靈旐歸里，得正首邱。緬維典型，悲懷無極。謹以清酌庶羞之奠，鞠躬而下招曰：

濁世民棼劇紛爭些，滑梯脂韋盡冠纓些。  
維剛則折理相因些，君當橫流生不辰些。  
既媾媒孽殃厥身些，霹靂一聲神鬼驚些。  
流血五步殞俊民些，死者已矣讐何人些？  
舉世是非其孰明些？怒潮淘沙鳴不平些。  
非種必鋤生為英些，厲鬼擊賊死為靈些。  
菊黃酒綠橙其青些，潔蠲敬薦厥馨些。  
靈其有知，其來歆些，尚饗！

峕在  
民國元年歲次壬子七月 日  
浙江陸軍第十二旅旅長臨海葉頌清謹撰

附輓聯二首：  
究有何不解冤讎，咄咄怪事；  
頓失此羣英領袖，蒼蒼者天。  

但願馬革裹，豈願魚腸劃？何物么麽小醜，竟讓他一擊而逃。遺像仰巍巍，徒留將千載英名、十年偉績；  
不作裴晉公，反作武元衡。此中孽根來歷，真令我百思不得。書空常咄咄，祇諉曰人心莫測、天道難知。  

民國九年歲次庚申十月日  
不肖男兆麒敬梓
