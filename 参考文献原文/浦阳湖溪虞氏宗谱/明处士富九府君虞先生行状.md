# 明處士富九府君虞先生行狀
```
题：[]文林郎廣西平樂府修仁縣知縣眷侍敎生張孟昂頓首拜撰
峕：[]萬歷元年歲次癸酉冬之吉
初始点校：[20250825]《浦阳湖溪虞氏宗谱》民国庚申[1/1]p340
修订参考：[]
```

先生諱仕墙，字存安，世爲浦北著姓。甫周齡而父母淹沒，二長兄亦繼逝，叔氏克懋公撫以爲嗣。暨長，克懋公舉有子，先生復還所生。

後因自念少經多難，賴季父保護致有成立，益孜孜砥行，朝夕綱繆，不憚勞勩以恢宏先德。雅喜敦儒術，庄田二十五畞額，曰“養賢”，子孫一列青衿，篝燈有藉。尤重祀典，慮世遠時湮，子姓渙散不一，無以聯合之，撥某處沃田數畞，以時供粢盛，俾世世守之，毋匱乏焉。

噫！先生去今幾數十載矣，而奕世之下，至今少長起孝享之思，譽髦動衿奮之志，而親親賢賢，遞推衍於不窮。則所式穀以啓佑後人，不宏且遠哉？

余稔知先生久，且添姻戚，頃自粤致政歸，以狀請。予謝不敏，勉爲之次其行畧如此云。

峕萬歷元年歲次癸酉冬之吉
