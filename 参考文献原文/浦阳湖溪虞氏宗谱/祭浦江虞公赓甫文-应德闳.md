# 祭浦江虞公賡甫文
```
题：[]金衢嚴處同鄉會會長，江蘓省民政長，永康應德閎謹撰
峕：[]民國元年歲次壬子七月日
初始点校：[20260725]《浦阳湖溪虞氏宗谱》民国壬申本[3/11]P162
修订参考：[]
```

（未核原文）

民國壬子年，鄉弟德閎敬率金、衢、嚴、處同鄉人等，謹以清酌庶羞，致祭於賡甫虞先生之靈曰：

嗚呼！金以錯頓，玉因瑱折，物忌堅剛，人諱名哲。洸洸虞君，守正不阿。長松翳天，忽戕其柯。嗚呼痛哉！

疇昔盛年，劬心力學，屣脫詞翰，從容韜略。亡清末葉，輕武右文，君獨岸然，棄儒而軍。酒酣耳熱，狂歌斫地，壯氣激昂，裂眥攘臂。奇志大辱，痛念國仇，同志一心，惟君為尤。鼓篋告終，戎談罷講，三升論選，千夫作長。粤時四府，藍簏始開，拓荊於杭，簦笈偕來。慕君高義，相推領袖，君執其鍵，納約於牖。叱馭危阪，揚帆逆流，銳往無前，神施鬼謀。瘠牛未僨，群狼擁道，謂荇弗類，遂投荒島。

天啟中華，爰迄去秋，神獅破夢，忽炯雙眸。鄂渚風高，晴川霜肅，驚雷一震，龍蛇起陸。雲合響應，施於浙隅，君在東甌，投袂來趨。霾霧全收，湖山重秀，白虹吐氣，黃龍呼酒。連屯望澤，功高賞微，或媒其間，訛為是非。盛氣天驕，試鋒躍躍，君喻以義，歡然垂橐。始參幕議，遂任戎機，腹心干城，惟君是依。朔南暨及，靈臺偃伯，華陽歸馬，惟君是職。亦有弗順，瞋目語難，恩撫威馭，卒危而安。學子彪彪，投戈講藝，君司其成，人望所萃。期為故國，辛苦儲材，胡乃不圖，猝罹飛災？

於戲痛哉！坦地亡彭，平坡落鳳，井泉枯泣，江湖咽慟。念君坦懷，何私何仇？以君直諒，何怨何尤？何憾於君，忍此荼毒？何憾於浙，壞我梁木？天乎人乎？此理難求。非為君怨，實為浙憂。惟我四府，相依車輔，君於其間，如萼有跗。人亡國瘁，有識同哀，況接閭閈，心寧不灰？君死則死，名在惇史，頡頏陶公，為兩奇士。君死不死，功在吾浙，民國萬歲，弔君遺烈。哀哉尚饗！

峕在
民國元年歲次壬子七月日
金衢嚴處同鄉會會長，江蘓省民政長，永康應德閎謹撰

民國九年歲次庚申十月日
不肖男兆麒敬梓
