# 富九府君佚傳
```
题：[]孫邦瓊百拜書
峕：[]皇淸康熙歲次癸卯下月朔後三日
初始点校：[20250825]《浦阳湖溪虞氏宗谱》民国庚申[1/1]p340
修订参考：[]
```

富九府君，從瓊上之六世祖也。德樹於前，慶流於後，芳規懿行，昔人詳言之矣。

至幼失怙恃，叔氏克懋公撫以爲子。暨長，見家業豐裕，嗣續勿廣，府君愍焉有憂，勸叔再娶以蕃允祚。克懋公正容拒之曰：「吾先君勿壽，吾伯叔暨汝父壽俱不滿四旬。今吾行年五十有一，樂此餘生已出望外，得汝體志克家，心甚足矣，奚再娶爲？」府君知意不可挽，遂背地聘娶樓氏安人至家，請叔婚配。後生二子：一富三十一諱仕堯，一富三十六諱仕幸。

府君親愛維周，不啻同氣。分居之日，祖業對股均管，叔氏之續置新創者，盡歸之二弟，而府君不與焉。非惟不阻於言，而且無拂於色也。此中隱衷，日月並其光明，天地同其覆載。昔人知之而未及誌，瓊蓋按實追言之：一以先德，一以訓後人。

今二公之後，支分流衍，昌熾無窮，富九府君與有力也，烏可湮没不傳？是爲述。

峕皇淸康熙歲次癸卯下月朔後三日

孫邦瓊百拜書
