# 永八十一公哀啓
```
题：[]不孝男兆麒、麟、熊、騶、夔泣血稽顙
峕：[]民國元年歲次壬子孟秋月日
初始点校：[20260725]《浦阳湖溪虞氏宗谱》民国壬申本[3/11]P146
修订参考：[]
```

哀啓者，府君諱廷，字賡甫，以一介寒士，排萬難，歷千險，含憤茹痛，以壹意於鼎新民國之事業。經行其志，瀕九死而不悔。顧不死於刑獄，不死於竄徙，不死於水火，不死於槍林彈雨，徒以嫉邪守正，見忌羣小，卒遭禍於宵人鬼域之手，倉猝正命，不竟其志。哀哉痛哉！

念府君生平奔走國事，家居之日至少。不孝等又愚陋無狀，凡府君設施大略，不能推述其萬一。唯就隨侍左右，聞見所及，拉舉梗概，以就正於當代立言之君子。為是為非，為功為罪，天日在上，公論不泯，則府君雖死之日，猶生之年矣。哀哉痛哉！

吾族為南宋勛臣虞公允文之後，再四遷徙而至浦江虞宅莊。王父柳隄公，以高年邵德，有聞於鄉里。府君生而神悟，授以書，出口成誦，先王父特鍾愛之。年十八，補學官弟子，於是師友率相引重，敦囑留意舉業以圖上進。有時伏案走筆，滔滔累千言，成一藝，輒驚其長老，然非性所願，不竟習也。

歲在壬寅，清廷改以策論取士，府君勉強入場，冀得有所發舒。是年遂登浙江鄉薦。當時末俗方矜重科閥一第之榮，施及婣䣊鄰里聞報，咸動色相賀，府君顧夷然不屑也。居常獨居深念，國是如此，非置身軍界，不足以有所施設。值浙省開設武備學堂，當即報名入校。爾時以名孝廉而入軍籍，殆絕無僅有之事，聞者至於駭怪，知好百計尼之，府君卒置不顧。入堂後，見同學多一時英傑，因共討論國是大計，無不忭合，則大喜過望，益厚相結納，並為進行之計畫。蓋至是而府君平素所抱之革命宗旨，乃一躍千丈矣。

畢業後，循例派充督練公所調查員。同時金、衢、嚴、處四府士紳，創公學於省垣，延府君主其事。府君念因是可以延攬青年，聯絡鄉里，益布革命機關之導線，遂挺身任之。凡籌畫經費，整頓課程，無不悉力擔荷。校中諸學生亦親愛翕服，相處如家人子弟。暇則與之講東西歷史，述愛國豪傑之舉動，以激勵其志氣。蓋至是而革命思潮，遂流布於上游各郡，青年學子，人人有枕戈躍馬之志矣。

府君又念一旦有事，不能不從事攻守，則軍用地圖尤為切要。於是復與光復會諸同志，組織測繪專修科，實地練習，遍探大江南北之險要。校中學生皆心知其意，劬學尤甚。歷充督練公所教育科員、陸軍學堂監督、八十二標教練官，所至皆有所部勒，同志益眾。無何，而秋瑾案發，府君為奔走上下，極力營救，事迄無效，而清吏遂以此疑府君，乃調守溫州各砲臺司令官，陽畀以事，而陰示疏謫。府君到甌後，不懈初志，益悉力鼓吹，僚友部屬多被感動，咸相約以待時機之至。蓋至是而時會益迫，事機益熟，清吏之伺察益嚴，而府君十年醞釀之素志，益勃然不可復遏矣。

去歲八月，武昌首倡義舉，東南各省雲合響應，浙中豪傑遂舉旗光復。以人望所集，特推湯公壽潛為都督。露布達甌海，府君歡忭踴躍，踰於常格，即率温屬各臺同時反正。立電浙都督府，請銳師北伐，願當前敵。以臺事囑之敎習魏其倬，隻身回省，靣陳方略。湯公一見，深引重契，立授都督府軍事顧問官，參與機密。於時大難初定，各軍士或恃功驕恣，不甚受約束，各將領無如之何也。府君以為地方初定，首在恢復秩序，欲定秩序，必肅軍紀。乃以都督命，親巡視各壘，召集軍士，諭以守法紀、急國仇，激昂涕泗，感動大眾。先時府君任教練官，甚為軍士所愛敬，至是聞剴切開導，無不懾服。不一日，而各營軍士悉復其伍。湯公益重府君才，劄充第二標統帶官。府君到差後，更申明紀律，開發大義，士氣為之一振。

值東南聯師攻金陵，浙軍肉薄險地，首為衝要，而敵帥𤡑悍，相持久不下。府君念江寧為南北管轄，浙軍氣銳而力薄，萬一蹉跌，則蘇浙一隅勢成坐困，大勢且瓦解。乃亟請於浙都督，願率所部馳往助戰。都督湯公允其請，府君遂激厲軍士，倍道赴戰地。既至，見浙軍各營兵士多半夷傷缺額，勞頓殊甚，乃請於浙司令朱公，以所統第二標并合於第一標，填補足額，而自請取消第二標統帶官。旋奉朱司令委充兵站總監，府君乃悉心籌畫，釐訂章程，設立支部，以求交通接應之便利。方在部署，而南北媾和之議定，戰事將告終局，府君遂請於朱司令，取銷總監而回省新顧問之職。

於是浙都督湯公，以受南京交通部長新命，將去浙任。眾議舉蔣公尊簋繼其後。蔣公資望隆重，練達軍事，且於浙中將校皆同學舊部，情感尤洽。而一二驍悍有力者，思乘間別有擬議，出百計阻撓之。府君與蔣公無私交，徒以浙都督管轄全省，苟非其人，且誤地方大局，獨力排群喙，先後左右為蔣公道地，卒得浙議會與南京參議院之同意，而府君之深仇切怨，殆基於此矣。

浙事既定，即奉都督面諭，偕劉君崧申前赴臨淮，與朱司令會商留守事宜。事畢返命，委充都督府軍事叅議官。旋代理參議廳總參議。府君益感激知遇，規畫利病，竭誠獻替，言無不盡。今歲五月，浙軍自南京凱旋，當事者以大局已定，聚兵非計，且諸軍士久暴露，多受勞苦，宜令退伍歸鄉，俾得休息。集全軍將校於都督府會商辦法，僉以浙軍此次有汗馬功，遽置閑散，恐因誤會轉生異議，非得信望素著之人主持其事，慮無以抒下情而宣上德。因議設籌備退伍事務所於軍司令部，而公推府君為所長。府君念治安所係，責無旁貸，即詳悉討論，手定條教。所以給待之者至渥，而取締之者極嚴，並咨會團營將領，分頭曉示。諸軍士皆歡然就道，不兼旬而事畢。

既復奉都督照會，以省城將設立講武堂，俾團營將校得更番入堂肄習，以深造就，特任府君為該堂堂長。固辭不獲，則復為之詳定規章，飭治校舍，延聘職員教習，商略功課。既稍稍就緒，乃再具呈都督，力請辭職。都督固不允。府君念浙事大定，才彥雲集，若再依違其間，迹近於瞻戀權勢，且以積歲勞瘁，亦冀得閒休養，因決計襆被還鄉里。方督率家人治裝，將以七月某日戒途，不意奸人生心，前一日而禍作矣。

先是，府君在總參議任，以公事意見不合，與僚采有所齟齬，府君持之急。一時蜚語騰播，皆言其黨將致死於府君。或勸府君須慎自防衛，府君應之曰：「吾向者之爭執，為公誼也。在官言官，職守所在，不得不然。顧諸君多同學故交，私誼具在，安忍出此？」遂坦然不以為意。是日，陳統領步棠邀往聚豐園晚餐，席罷各散。府君出門登肩輿，行不數武，將出大井巷，突有匪人扳輿而立，若有所啟白。未及致詰，遽出手搶指胸，次連擊數下，槍彈洞左脇，立時殞命。輿者知有變，即釋肩尾追兇手。復出槍相擬，倉猝不得發，遂棄槍於地而逸。是為中華民國元年壬子六月三十日戌刻也。

時不孝麒在湖北陸軍中學肄業，聞耗回杭；不孝麟、騶年幼在籍，未克奔喪；惟不孝熊、夔方在杭寓，聞驚急率家人匍匐赴難。但見府君尚端坐輿中，神色不變，而血流被襟，體四肢僵冷，蓋氣絕久矣。哀哉痛哉！以為私仇耶？則府君生平坦懷磊落，與人無私爭。以為公敵耶？則府君自光復前後，力任艱鉅，無一事不可以對浙省父老兄弟。辛苦墊隘，馴至成立，而得此慘報。嗚呼！天耶？人耶？盜耶？賊耶？鬼耶？蜮耶？仰視蒼蒼，俯視茫茫，其將何從而質之耶？

當夜報由警檢各署檢騐填格後，即奉輿還寓所，如禮含殮。一面呈訴都督，請緝獲正㐫（凶），嚴究主使。雖疊奉都督命懸賞緝拏（拿），允從申理，而事隔多日，如海中沉石，杳無消息。不孝等煢煢孤寄，呼籲無門。上之既不能捐生畢志，親揕刃於仇讐之胷；下之又不能嘶聲竭力，求申理於號為人民保障之法律。有靦面目，其終將偷生視息，與仇人共戴履此天地？嗚呼！景升子豚犬，吾父其不瞑目矣。含恥忍垢，何以爲人？撫苫抱愧，何以爲子？分當刳肝瀝血，以從府君於地下，徒以大冤未報，延喘待命。恐府君之奇節苦行，一旦埋沒，終不見白於天下，則不孝等雖歷九死，終不足以蔽辜塞責。用敢泣叙厓略，仰凟（瀆）公聽。自膺大難，亡魂走魄，血淚坌湧，不能為辭。剖臆以陳，伏惟矜鑒。

峕在
民國元年歲次壬子孟秋月日
不孝男兆麒、麟、熊、夔、騶泣血稽顙

按先父於民國元年在省被刺，熊等憤憤欲死，惟以大仇未報，用敢苟且偷生。椎心泣血，無時或忘。殺父之仇，誓不戴天。幸至民國八年九月，時適値西南多事，熊亦正隨前都督呂公望從軍於粤之潮州。不意大仇盛賊，復敢潛來軍前，希圖不軌。呂督以其死有餘辜，下令槍决，彈丸二發，賊即殞命。足見天網恢恢，終難倖逃。我父在天之靈，當亦可稍伸沉冤矣。
