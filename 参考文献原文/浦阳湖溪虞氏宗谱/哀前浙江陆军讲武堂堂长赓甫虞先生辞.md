# 哀前浙江陸軍講武堂堂長賡甫虞先生辭
```
题：[]浙江公報處處長杭縣馬敘倫謹撰
峕：[]民國元年歲次壬子七月日
初始点校：[20260725]《浦阳湖溪虞氏宗谱》民国壬申本[3/11]P164
修订参考：[]
```

（未核对原文）

於乎！君生浦陽，夙產髦哲。挺若修資，貞毅之質。賢書雖薦，躬耕抱膝。已慕投筆，戎行載歷。嗟彼勝代，政寵蛟妾。玉鏡既逝，泰山為泣。君乃抗志，胡運思革。空山一廬，風雨澈。閉關昕夜，朋從翕合。

於乎！天既厭胡，其亡也忽。我浙便便，鐘鼓勿伐。乃有壬人，營兔窟。黎首悽皇，訛言讋。鴻翔九皋，馮風振翼。侏儒關引，絕臏斷肋。君憐黎首，災患反側。粤茲扞衛，惟我時責。振臂一呼，羣奸慴伏。邪謀既萌，於君致毒。君曰何懼？迎刃以腹。詎料神識，驚歌撒瑟。

於乎！招鳳集鶚，蓺蘭茁棘。浮艷湯武，隱聖盜跖。魅敵工喧，訟已反舌。飛蛩蔽空，朝陽闍匱。虎踞莊衢，皇路榛塞。覽彼行涂，奔走趾仄。孤踽正履，其何不踣？

於乎！萇弘之血，三年化碧。生寄死歸，君固無擇。魄暫依土，神耿不滅。昔从杯棬，今為往跡。君志我知，君行我述。靈車載涂，不遑攬紼。摛此哀思，慰君窀穸。

旹在
民國元年歲次壬子七月日
浙江公報處處長杭縣馬敘倫謹撰

氏國九年歲次庚申十月日
不肖男兆麒敬梓
