# 同修龍山陳氏遺序
```
题：[]車方龍橋山人陳昌言希禹書
峕：[]隆慶元年丁卯秋月
初始点校：[20260713]《浦阳龙山陈氏宗谱》民国庚午[1/8]P013
修订参考：[]
```

宗譜之作，其來尚矣。蓋自先王因生賜姓，而族類之貴賤始昭於天下。又懼其歷世既久，而莫溯其淵源之自也，是故有宗廟以合其人心，有宗法以紀其族屬。而名分於是乎定，婚姻於是乎別，教化於是乎行，風俗於此乎厚。其為世慮，至深且遠也。

迄自秦政不綱，變及宗法，族類之辨、本源之義，遂於此而大亂其真矣。故流落奔走者，則考祖之念忘；驟然富貴者，則妄冒之心生。噫！斯弊也久矣。近世作譜，皆取法於歐、蘇二氏，又或倣司馬遷、班固列傳之義，其為意非不善也。但修譜之任，同於修史之重。苟或法其文不法其意，師其式不師其全，未免掛一以漏萬，書此而失彼，何以取重於世而貴於譜之作也？

浦陽龍山陳氏，烏邑凰山之裔孫也。其族有世壠者，聘雲山張大榮氏以修輯之，其世系節目、來歷之詳，既備述於前矣。余辱雲山之請，以同是任，安可無所損益於其間耶？故曰：世宦不揭，何以昭人文之盛？隱逸不傳，何以知名節之尊？贈文不載，何以彰戚友之敬？字母不圖，何以別重犯之嫌？況有異姓過繼，年深而真偽之莫辨，此所當急書而不可緩者。余所兼數子之長，更參以章文懿公之式，不敢為世壠吝也。

雖然，莫為之前，雖美弗彰；莫為之後，雖盛弗傳。陳氏體斯意，而使世壠修焉，不惟有光於前，而且有裕於後已。豈不大有補於風化乎？故書。

旹隆慶元年丁卯秋月
車方龍橋山人陳昌言希禹書
