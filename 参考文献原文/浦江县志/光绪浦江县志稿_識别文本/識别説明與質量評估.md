# 識别説明與質量評估

## 一、底本判定

| 項目 | 情况 |
|---|---|
| `0017.pdf` | 23 頁；`pypdf` 抽取文字數 = 0 → **純掃描，無文本層** |
| `0018.pdf` | 21 頁；同上 |
| 配套帶層版 | **不存在**。已檢索整個工作區，未發現 `vol.ocr` 一類的帶文本層副本（與《光緒浦江縣志》正志的情况不同） |

因此本志稿必須**自行識别**，不能沿用正志「借用既有 OCR 文本層＋座標重建」的辦法。

## 二、版式復原結果

- 頁面橫置（約 1540×1152 pt），**一頁＝左右兩半葉**，折縫（版心）居頁寬約 46% 處。
- 閱讀順序：**右半葉自右向左 → 版心 → 左半葉自右向左**。
- 正文為**窄欄雙行小字名錄**：姓名用大字，事迹用小字；雙行兩半行**之間沒有界欄**，因此：
  - 人工目驗：須按「先讀右半行、再讀左半行」還原；
  - 機器 OCR：偵測模型會把相鄰兩半行**合併為一段**，無法分欄。
- 版心格式：`光緒浦江縣志稿／卷之上（下）／殉難錄附／葉次`，可據以逐葉定位。

## 三、識别方法與工具

1. **渲染**：`pypdfium2` 以 scale 2.0 逐頁轉 PNG（約 3080×2304 px）。
2. **版面裁切**：按頁寬比例裁出「右半葉」「左半葉」「版心」三區，供目驗。
3. **機器底稿**：安裝離線 `rapidocr-onnxruntime`（PP-OCRv3 det/rec），並將檢測解析度由預設 736 調高至 2200、關閉膨脹、降低 `unclip_ratio`，以盡量減少跨欄合併。
4. **人工校讀**：逐葉目驗「名欄帶圖」（頁面上部含全部姓名與門目標題的橫帶），取得姓名與門目；小字事迹擇錄。

**已知的工具限制**：PP-OCR 對本件的**雙行小字**仍會跨半行合併，且輸出繁簡混雜（如「時」「團」「賊」作正體，而「黃」常出「黄」），故此路徑只能作**檢索底稿**，不能作定本。

## 四、精度評估（誠實區間）

| 層級 | 可靠度 | 說明 |
|---|---|---|
| 卷次、版心、葉次、頁數 | ≈100% | 版心逐葉目驗 |
| 門目與紀年體系 | ≈95% | 目驗；個別門目小標（三德局、定陳局等）存疑 |
| 姓名（大字） | **約 90–95%** | 目驗所得；生僻字、異體字與形近字仍有誤（如「虞廷颺／虞廷棟」「黃三鍚」等已標存疑） |
| 小字事迹 | **約 50–70%** | 雙行窄欄限制，僅擇錄；機器底稿未校 |
| 民國五年識語（跋） | 約 80% | 字大行疏，但跨葉分欄，闕文較多 |

## 五、必須知道的局限

1. **本成果不是定本**。姓名與事迹均需以原件逐字回查；已用 `□`（不可辨）、`〔〕`（推補）、`……`（未錄）三種符號區分。
2. **雙行小字無法逐字還原**——這是原件版式決定的，任何 OCR 都難以解決；如需完整事迹，建議：
   - 以高分辨率原件（≥600 dpi）逐欄人工錄入；
   - 或先按雙行分欄切圖（依上下版框與欄線），再逐個半欄 OCR。
3. **未收圖版**：本志稿未見輿圖、題簽等圖版葉，封面葉（0017 第 1 頁）與第 23 頁空白襯葉未作正文處理。
4. **跨葉連欄**：名錄為連續表格，同一人可分見前後葉，故各葉姓名表在葉界處可能與實際分條略有出入。
5. **來源引用**：卷之上葉十八起見「左照浙江忠義錄」「左照新江忠義錄」字樣，說明部分條目係**據他書補錄**，非本邑采訪原冊，引用時須注意。

## 六、建議的後續處理

1. **逐葉精校**：以 600 dpi 原圖為底，按「右半行→左半行」逐欄錄入小字事迹；建議先做葉一～葉五（含序文與最早兩年殉難者）。

3. **異體字策略**：本次一律**照錄原字形**（如「黄」「幾」「㑹」等），未作正字化，以保留檢索與對校價值。
