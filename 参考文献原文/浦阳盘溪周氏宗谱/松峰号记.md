# 松峰號記（行仁三十）
```
题：[]檀溪廩膳生一齋陳九經拜撰
峕：[]萬歷乙亥冬十一月
初始点校：[20260811]《浦阳盘溪周氏宗谱》民国己丑[14/15]P082
修订参考：[]
```

天下之植皆植也，而惟植之壽者，莫如松；天下之山皆山也，而惟山之高者，莫如峯。松惟其壽也，故盤其根而堅其節，鱗其身而龍其髯，友竹梅而侶風月，結菟絲而崇茯苓。宋人稱其挺然獨秀，《記》傳稱四時而不改柯易葉者，良以是也。峯惟其高也，故崑崙衍其脈，泰岱峙其秀，翠壁嵯峩，丹梯接漢，撫景一翫，則萬里江山俱收於吾目之中矣。但在松者，不能植之於峰；在峰者，不能例之於松，故其事相須，而其勢甚落，落而難合也。

若周子諱錡，字克用，深塘公之幼嗣，柏亭先生之嫡孫也。乃祖乃考，俱享遐齡，非松之例乎？風月無邊，聲隆山岳，非峯之等乎？周子善繼先志，而撫有盈成，所友者竹梅之青翠，所持者聲價之尊嚴，其自處亦甚厚矣。故取松之壽者與峰之高者而比之，則壽者益見其為壽矣；取峰之高者與松之壽者而比之，則高者益見其為高矣。周子松峰之號，非其高壽之預兆耶？

雖然，松壽矣，不培根本，則霜雪可以凌其幹，而況得菟絲、茯苓之叢結乎？峰高矣，一卻拳石，則牧豎可以陟其巔，而況見萬里之江山乎？周子俊雅人也，尚當服膺而弗失。

萬歷乙亥冬十一月  
檀溪廩膳生一齋陳九經拜撰

又贈詩一律：  
森森培植傍崇坡，蓋倚亭亭附菟蘿。  
盤谷雲深巢海鶴，鹿門風勁聽笙歌。  
林霜秋老存孤操，山雨春深長嫩柯。  
隆棟謾誇歸月斧，且親豪客縱吟哦。
