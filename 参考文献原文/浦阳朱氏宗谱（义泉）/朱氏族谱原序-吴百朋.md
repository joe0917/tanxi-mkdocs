# 朱氏族譜原序
```
题：[]賜進士第吏部左侍郎右都察院僉都御史巡撫兩廣烏傷堯山[吳百朋]撰
峕：[]隆慶五年辛未仲秋之吉
初始点校：[20260806]《浦阳朱氏宗谱》民国辛未[1/22]P075
修订参考：[]
```

婺處兩浙上流，古稱文獻之邦，浦居其一。山川靈秀，實產英豪，由郡誌及宋先生人物考記之，德業文章，節孝政事，斌斌輩出，允矣東南人士之望也。因人傑而羨地靈，昔欲為月泉、仙華之遊而苦勿獲。辛未春，丁內艱，借閑林下，吾友張君[^1]嘗語予：「吾邑義門鄭氏，乃朱公諱佺者之所致也」[^2]。適朱氏[德章？]聘吾舊好陳子昌言[[陈昌言]]修輯伊譜，予素慕焉。批閱數過，見夫
宦蹟之列，昭恩寵也，而質公之相業極隆；
節孝之揭，重天經也，而黄母之貞烈尤顯；
隱德之書，發幽光也，而鄉賢公之清舉益高。嗣是而下，傳世二十，歷年六百，時或會享，不下數萬餘指，禮讓雍雍，和風穆穆。浦陽之靈，東南之望，大半鍾於朱氏，而亦大半洩於朱氏矣。  

方今聖天子申隆禮樂，以教化天下，其厚風俗、作人才，良法美意無不周至。而朱氏率是意而行之，以修明其譜牒，勵廉耻，敦孝弟，誠大有造也。因為說曰：家國一理也，忠孝一道也。修譜即所以尊祖，尊祖即所以敬君。是故盡孝於親，移忠於國，皆自此而推之也。凡子孫他日為臨、為質、為適之、為有聞，無第增浦邑光已哉？更鼓足以待。  

隆慶五年辛未仲秋之吉  
賜進士第吏部左侍郎右都察院僉都御史巡撫兩廣烏傷堯山[吳百朋]撰
（嘉靖26年进士）

[^1]: 疑为[[张元谕]]
[^2]: 郑氏义门始祖郑淮与其兄郑渥、郑涚曾至浦江朴树下向朱恮学习。朱恮非常喜爱郑淮，做主将自己的外甥女宣嘉许配给郑淮。宣氏为东阳家族，将在浦江麟溪上的田庄送给郑淮。郑淮自遂安迁来浦江时，二位兄长一路相送，不忍分离，遂相与迁浦，居麟溪上。（20280806陈舒平老师微信）
《晏穆沖素處士銘》鄭安仁
時同浦陽朱恮，師黄山薛公大觀。大觀善於說《春秋》，能紹述平陽孫公復遺旨，登門者千餘人，惟恮得其要領。恮既家居講授，安仁俾三子從之遊。其幼淮，穎敏絕倫，學三年，洞究經旨，恮禮寵之，以外家女宜氏為配。宜家居白麟溪上，淮贅之，因與二兄來家焉。（[[浦阳朱氏宗谱（义泉）_笔记#《晏穆沖素處士銘》鄭安仁]]）
